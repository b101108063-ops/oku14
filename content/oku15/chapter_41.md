## 1. 遠端橈骨骨折 🆕

### 1.1 手術適應症的轉變

- 最常見、最常手術的骨折之一；**盛行率上升**。
- 🆕 **新的臨床指引：>65 歲病人不一定需要手術**；傳統 X 光手術指標在 >65 歲受質疑。
- 🆕 **「關節面位移 ≥2 mm 為臨界值」（1986）至今未被臨床驗證**；已知 X 光與臨床結果不一致 → 有人質疑此標準。
- 老人：**焦點從 X 光特徵轉向功能需求**。

### 1.2 保守治療

- 位移骨折：**強烈建議嘗試復位＋暫時固定**；復位指標：radial height、radial inclination、volar tilt、關節面位移。
- 🆕 **2023 多中心 PRCT（100 人、85% 女性、1 年追蹤 93%）：石膏 4 週 vs 6 週 → PRWE 無臨床差異 → 適當復位與塑形石膏後建議 4 週**。
- 固定姿勢：
  - 一回顧支持**功能位（微伸腕）**優於傳統**屈腕＋尺偏**（three-point mold）—— 功能與 X 光較好，但資料異質。
  - 🆕 **2023 PRCT（105 人）：功能位 vs 傳統位無差異**。

### 1.3 手術 vs 保守：證據群

| 研究 | 對象 | 結果 |
|---|---|---|
| 🆕 **2022 英國 RCT** | 500 人：閉鎖復位石膏 vs 經皮 pin＋石膏（都 6 週），79% 完成 | **1 年 PRWE 無差**；石膏組 **13%（33 人）6 週內因復位喪失轉 pin** |
| 🆕 **WRIST** | 304 人、多為女性、**>60 歲** | **volar locked plate 早期恢復最快**；**外固定 6 週最慢**；**12 個月、24 個月各組無有意義差異** |
| 🆕 **WRIST 再分析（2023）** | 依活動量（生理年齡）校正 | **手術組 MHQ 在 6 週與 1 年有臨床意義的改善** |
| 🆕 **2023 meta（14 RCT）** | — | 手術 **DASH、PRWE 較好**；**60–80 歲：握力較好、併發症較少**（1、2 年） |
| 🆕 **2022 meta** | >60 歲：volar plate vs cast | 1 年：**握力 +8.32%**、伸腕、旋前旋後（小但顯著）、**EQ-VAS +2.73** |

- 結論：**依病人個別化治療**。

### 1.4 手術時機與特殊型態 🆕

- 🆕 **2023（1,189 人、平均 58 歲、>1 年）：受傷 2 週內手術 → 頻率加權平均 DASH 明顯較好（21 vs 4）**，其他參數相近 → **建議盡可能 2 週內手術**。
- 術前仔細看 X 光、必要時高階影像 → 辨識問題型態並準備輔助工具。
- 🆕 **Volar rim 骨折（2023 SR、617 例）：術後併發症 14%，其中 44% 為屈肌腱問題；拔內固定 22%（54% 為例行拔除）** → 衛教用。

### 1.5 外固定與 dorsal spanning plate 🆕

- 🆕 **2023 PRCT：外固定牽引力垂直於正常（橈傾、掌傾）關節面 → X 光結果優於沿橈骨幹或前臂軸牽引**。
- 🆕 **Temporary dorsal spanning plate**：用於複雜遠端橈骨骨折，也作為其他內固定與各種腕外傷的輔助穩定。
  - **meta（310 例）：計畫取出中位 17 週（平均 119 天）；最終屈 45°、伸 50°；併發症 13%（內固定失效 3%、malunion 或 nonunion 3%、取出後持續痛 2%）**。

### 1.6 術後活動與治療 🆕

- 🆕 **volar locked plate 穩定後可安全早期主動活動**：
  - **2022 PRCT（116 人）：1 週可拆副木 vs 5 週石膏後同一活動計畫 → 1 年 ROM +10.2°、握力 +5.1 kg、Mayo Wrist +7.9，短期副木組較好**。
  - **Mayo PRCT（33 人）：14 天 vs 5 週開始主被動活動 → 6 週多項較好，1 年無差**。
  - **2022 世代：術後軟敷料下立即全弧主動活動 = 副木 2 週**（各時間點相當）。
- 🆕 **WRIST：病人在達到對側握力 59%、腕 ROM 79% 時區分滿意與不滿意 → 超過此門檻後繼續治療可能不必要**。

### 1.7 技術 🆕

- **複雜骨折 → column-specific 入路、fragment-specific 固定、依序建立穩定**；**年輕活躍者建議使用**。
- 例：55 歲機車事故慣用手複雜關節內遠端橈骨與尺骨骨折 → 依序以柱為單位，恢復關節面、radial height、radial inclination、volar tilt（hybrid fragment-specific）。

## 2. Perilunate 骨折脫位 🆕

### 2.1 機轉與型態

- 🆕 **PLD 佔腕傷 7%（2022）**；最常因伸手撐地。
- 🆕 **機轉：腕伸＋尺偏下的進行性 intercarpal supination**：
  1. radial styloid 骨折、scaphoid 骨折或 **SL 韌帶斷**（最早）
  2. → scaphocapitate、capitolunate 韌帶斷
  3. → **LT 韌帶斷** → **PLD**
  4. → 周圍韌帶全斷＋腕骨復位 → **典型 volar lunate dislocation**
- 任一階段可改走骨頭 → **greater arc**（radius、scaphoid、capitate、triquetrum、ulna 骨折）vs **lesser arc**（純軟組織）。
- **Radial styloid 骨折**常見於 radiocarpal 骨折脫位與 greater arc PLD；🆕 **固定 radial styloid → 恢復其上外在韌帶（掌側 RSC、long 與 short RL；背側 DRC）→ 間接穩定腕骨**；同理 🆕 **固定 scaphoid → 恢復仍完整的內在韌帶（DIC、STT 複合體、dorsal ST）的穩定**。骨性修完要再評估持續的腕骨間不穩或其他骨折（2023）。
- 🆕 **2024：lesser arc（純軟組織）主要併發症（X 光復位喪失）較多：24.2% vs greater arc 7%（RR 3.5）**。（原文句子寫「greater arc 併發症較低」後接 24.2% vs 7%）
- 急性 SL 斷裂若及時適當處理，臨床結果可以很好。

### 2.2 SL 不穩定的觀念與分期 🆕

- 🆕 **Scaphoid、lunate 與 SL 複合體 = capitate 的「acetabulum」；DIC = 這個 socket 的「labrum」**；臨床 SL 不穩 = 整個複合體失效，破壞越多越不穩（2023）。
- 晚期後遺症（手術或保守）傳統上結果差、重建結果不一。
- 🆕 **最多 25% SL 傷延遲就醫** → **依臨床不穩定表現討論修補與重建，而非嚴格依急性 vs 慢性**。
- 🆕 **修正 Garcia-Elias（ligament-based algorithm）**：**無法 primary repair 的結構都要重建**；依受傷進程**先恢復內在、再恢復外在 perilunate 穩定結構**：

| Stage | 病理 | 處理 |
|---|---|---|
| **1** | 部分傷 | **保守固定** |
| **2** | 完全傷、無 X 光 diastasis（有症狀） | 動態應力照或關節鏡診斷 → **dorsal SLIL 修補** |
| **3** | dissociative、**無旋轉不穩**（STT 完好） | 傳統背側修補或重建 |
| **4** | 🆕 **scaphoid 旋轉不穩**（另傷 dorsal ST、DIC、SC 或部分 STT） | 🆕 **建議穩定 STT 韌帶** |
| **5** | 🆕 **lunate 旋轉不穩**（**STT 或 LRL 全斷**） | 🆕 **掌側 radiolunate 韌帶修補或重建** |
| **6** | 不可復位 DISI＋靜態 DST | salvage |
| **7** | SLAC | salvage：**RSL 融合、CL 融合、3 或 4 角融合、PRC** |

- 🆕 **動態旋轉不穩：屈腕側位可看到 DST**。

### 2.3 急性 PLD 修補結果 🆕

- 技術：**錨釘修補每個找到的腕骨間韌帶 → 常加 dorsal capsulodesis → K-wire 暫時跨修補段固定** → 石膏到拔 pin → 漸進活動。
- 🆕 **2023 meta（急性治療）併發症**：

| 併發症 | 比例 |
|---|---|
| **關節炎** | **30%** |
| **持續腕骨不穩** | **15%** |
| **lunate 骨壞死** | **12%** |
| **CRPS** | **11%** |
| **scaphoid nonunion 或骨壞死** | **9%** |

- 閉鎖組平均複合活動弧與 Mayo Wrist Score 較好；SL gap 閉鎖 vs 開放 2.3 vs 1.7 mm（原文如此；異質大，難推論）。
- 🆕 **急性治療的 PLD 結果一致優於慢性治療**；**dorsal spanning plate** 可作嚴重 greater 與 lesser arc 的輔助穩定。

### 2.4 重建比較 🆕

- 重建結果一般較差；依參數不同結果不一、文獻**高度異質**。
- 🆕 **2023 生物力學（3LT vs 全合成 dorsal suture anchor vs 複雜生物 front-back）：只有 dorsal suture anchor 恢復到正常的 SL 與 RL 角**（但依演算法，dorsal-only 應只用於旋轉穩定型）。
- 🆕 **2022（改良 Brunelli 3LT vs 合成補強的掌背 360° vs 雙肢 dorsal anchor）：只有 360° 減少伸腕時的掌側 SL gap**；旋轉參數（SL、RL 角）各組無差。
- 🆕 **ANAFAB 中期（12–38 個月、21 人）：SL 角恢復好、SL gap 4.2–5.9 mm、DST 0.2–1.2 mm、RL 角 1.8–13.5°、PROMIS 改善；併發症約 10%**。

### 2.5 PLD 與 CTS 🆕

- 🆕 **術前急性 CTS 最多 28%；手術時未做腕隧道鬆解 → 術後 CTS 57%（2024）**。
- 🆕 **但同時掌側＋背側入路整體併發症較高（17.4% vs 8.4%、RR 0.5）；關節鏡輔助也較高（17.4% vs 4.8%）**。
- 作者建議：**有症狀時盡快做開放腕隧道鬆解；沒症狀不在預定手術時例行做**。

### 2.6 合併遠端橈骨骨折 🆕

- radiocarpal 骨折脫位與 perilunate 骨折脫位兩譜系會交會。
- 🆕 **2024 meta（4 篇、128 人、平均 70 個月）：遠端橈骨骨折手術時的 SLIL 傷修 vs 不修 → 主客觀結果無顯著差異**。
- 技術例：年輕高能量 **transradial perilunate 骨折脫位（Mayfield 3）** → 先處理 greater arc 骨折 → 靜態維持解剖腕骨對位 → **無張力修補韌帶**。

## 3. 掌骨骨折 🔄

### 3.1 適應症 🔄

- 過去十年**適應症沒什麼變**：
  - 🆕 **絕對**：**開放傷（骨或鄰近關節）、合併肌腱裂傷或損傷、旋轉畸形**。
  - 🆕 **相對**：**短縮 >5 mm**、多發骨折、關節內骨折、**掌骨頭在掌心變形突出**。
- ❌ OKU 14 的角度容許（第 2、3 掌骨 <10–15°；第 4 掌骨頸 30–40°、第 5 掌骨 40–50°）本版未列。

### 3.2 固定選擇 🔄

- 🆕 **髓內固定帶來手術與術後照護的典範轉移**。
- 🆕 **手術或保守的併發症（僵硬、malunion、內固定症狀）最高 50%（2023）** → 要謹慎。

| 方法 | 優點 | 缺點 |
|---|---|---|
| **K-wire**（1952 起；橫向、髓內、bouquet） | 易取得、熟悉、便宜、結果可靠 | **術後需固定**、pin-site 感染、刺激伸肌腱 |
| **Plate**（locking 或 nonlocking；長斜或螺旋可加 lag screw 做 neutralization） | **可立即主動活動**、骨幹大量缺損時穩定、nonunion 的 salvage | 貴、手術久、**刺激伸肌腱**、常需 **tenolysis 與拔除** |
| 🆕 **髓內裝置**（近 10 年；最初用現成 headless compression screw，現有空心、無頭、全螺紋寬螺距 nail、部分螺紋光滑骨幹段等） | **無外露內固定、不刺激伸肌腱、不需計畫拔除**；**可立即主被動活動**、常可**立即負重**（2024） | **價格、取得性、技術要求較高** |

### 3.3 技術 🆕

- 🆕 **K-wire 尺寸**：

| 尺寸 | 用途 |
|---|---|
| **0.035 in** | 兒童、關節周圍 |
| **0.045 in** | 多數髓內或 bouquet pinning |
| **0.054 in** | 橫向 pinning |

- Plate：一般 **1.5 或 2.0 mm** nonlocking 做加壓；locking 可配合 lag screw 做 neutralization；直、H、L、T 形與可變角度。
- 🆕 **髓內**：術前 X 光量髓腔直徑與長度；順行或逆行。
  - **手指掌骨最易逆行**；**拇指近端寬，常需合併技術**。
  - 🆕 **逆行起點 = 掌骨頭背側 1/3**（減少影響 key pinch 時的關節面）。
- 🆕 例：年輕人小指掌骨槍傷骨缺損 → 傳統：經皮 pin＋固定、6–8 週 Masquelet 植骨，拔除前無法全弧活動；作者：**逆行髓內固定貫穿分期 Masquelet 植骨 → 立即全弧活動＋保護下部分負重**（6 週 iliac crest 植骨、3 個月癒合、ROM 全程維持）。

## 4. 指骨骨折 🆕

### 4.1 適應症

- 🆕 **最常見的骨骼傷之一，估計 >10% 所有骨折；近節最多（2024）**。
- 🆕 **絕對**（所有指骨）：**開放傷、合併肌腱傷、合併軟組織傷、旋轉畸形、移位關節內骨折、不可復位或不穩定型態（明顯粉碎、螺旋、斜）**。
- 🆕 **近節、中節**：**角度 >10° 或短縮 >2 mm**（會造成伸直遲滯）。
- 🆕 **遠節**：
  - **背側底骨折 >25% 關節面合併 DIP 半脫位（bony mallet）**。
  - **中節掌側底骨折合併 PIP 骨折脫位**。
  - **遠節掌側大骨片合併 FDP（jersey finger）**。

### 4.2 固定選擇

- pinning、plating、髓內固定；🆕 **嚴重 PIP 骨折脫位 → 動態牽引外固定**（自製 K-wire 架或廠商的暫時迷你內固定）。
- 遠節：**背側底（bony mallet）→ extension block pinning**；掌側底合併 FDP → ORIF 和／或 zone 1 屈肌腱修補。
- 🆕 **DIP 最常手術的骨折 = bony mallet 累及遠節背側底 >50%** → extension block pinning 或之後拔除的 K-wire。
- K-wire：可穿過關節面（易復位、起點好找）或關節外（起點與方向較難，但避免傷關節面）。
- 🆕 **關節外長斜骨折：閉鎖復位經皮 pin 與 ORIF 的臨床結果、ROM、癒合率相近，伸直遲滯較少**。
- 🆕 **Lag screw → 長斜骨折；髓內固定 → 短斜或橫骨折**；plate（背側或橈尺側）→ 明顯骨缺損或粉碎。
- 髓內固定趨勢同掌骨：剛性與強度好、併發症與內固定刺激少、結果佳。
- 技術：小空心螺絲組合可固定基底、骨幹、頸與頭；🆕 **髓內植入物在骨折處要寬分開 → 抗旋轉**；簡單型單根或兩根即可，複雜型加 interfragmentary 固定；**目標 = 穩定的 load-sharing 結構、可早期全弧主動活動**。

### 4.3 復健 🆕

- 不論保守或手術，結果取決於**手部治療的可近性與品質**；屈伸肌與骨關係密切 → **僵硬常見**。
- **及早請認證手部治療師、依傷型盡早開始早期主動活動**。

## 6. Key Study Points（OKU 15）

- **複雜遠端橈骨骨折可用依序、以柱為單位（column-based）的方式有效處理**。
