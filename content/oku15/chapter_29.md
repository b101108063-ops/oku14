## 1. 投擲運動員的肩傷

### 1.1 病史與檢查 🆕
- 了解急性程度、失能、期望與職涯目標
- **投手要問**：球速、控球與球種的變化、投球局數、賽前準備與賽後恢復
- **年輕運動員的可改變危險因子**：**全年持續打球沒休息**、**同時當投手和捕手**（2023）
- 檢查**整條 kinetic chain**：
  - 脫上衣比較雙側；投擲側**肌肉肥大可能是適應**，**肩胛周圍萎縮 → 肌肉功能異常**
  - 主動活動時觀察肩胛 → scapular dyskinesis（課本圖：右側肩胛內下角突出、前引內旋）
  - 頸椎 ROM＋神經血管檢查
  - 投擲者常見 **ER 增加、IR 稍減**（適應），但**總活動弧應約 180°**
  - 核心與下肢：**單腳蹲、平衡**
  - Cuff 與 biceps → 痛或無力可能是 cuff 撕裂、biceps 或 SLAP

### 1.2 GIRD 🔄
- 一定程度的 IR 減少是**生理適應**
- 🔄 **病理性：比對側少 >20°–25°**；但**有研究在 11°–18° 就發現相關損傷**
- 🆕 **機轉**：投擲者總活動弧後移 → **後關節囊緊（含 IGHL 後束）** → 肱骨在 glenoid 的接觸點改變
  - **屈曲時 → 前上方移**
  - **ABER（late cocking、early acceleration）→ 後上方移**
- 🆕 **治療**
  - **Sleeper stretch**：側躺患側、**往後滾約 20°–30°**（保持肩胛平面）、**肩外展 90°** 下內旋
  - **Cross-body stretch**：側躺、穩定肩胛、水平內收手臂並保持中立旋轉
  - **RCT（24 位大學棒球員）**：每天兩種一起做 → **IR 顯著增加、infraspinatus 與 teres minor 僵硬度下降**
- 保守失敗 → **關節鏡後下關節囊放鬆**（重點：**IGHL 後束**）；少見；**16 位過頭投擲者中 11 人回到原等級**
- Key Study Point：**未治療的 GIRD 會讓其他結構受傷，包括 UCL**

### 1.3 Scapular Dyskinesis 🔄
- 定義：**肩胛運動與力學異常** → 肩部活動效率下降 → 其他結構壓力增加 → **subacromial impingement**、**cuff 肌力下降**
- 成因：多為軟組織
  - 肩胛周圍肌肉活化改變
  - **GIRD**
  - **Pectoralis（minor）與 biceps 緊繃拉 coracoid → 肩胛前傾**
- 診斷（靜態與動態）：**內側或內下緣突出**、**抬手時肩胛過早上抬**、**放下時快速下旋**
- 治療：針對性復健，恢復肩胛與肩活動、加強肩胛周圍、盂肱、核心、下肢肌群；**目標是讓 kinetic chain 以整體運作**；同時處理 GIRD、internal impingement
- **治療期長，要告知病人**

### 1.4 SLAP 撕裂 🔄

**🆕 分型（I–X）**

| Type | 描述 |
|---|---|
| I | 上唇**退化** |
| **II** | **biceps anchor 剝離** |
| III | **bucket-handle**，biceps 完整 |
| IV | bucket-handle **延伸到 biceps** |
| V | SLAP＋**前下**（Bankart）延伸 |
| VI | bucket-handle（type III）合併**瓣狀** |
| VII | 延伸到 **MGHL** |
| **VIII** | **往後延伸**（涉及 PIGHL） |
| IX | **環狀撕裂** |
| X | 延伸到 **rotator interval** |

- 投擲者機轉：**late cocking 極度外旋時 biceps anchor 應力增加 → peel-back mechanism**
- 🆕 **2024（>1,200 位過頭運動員）：type VIII 最常見，其次 type II**（符合後上唇應力增加、GIRD 常見的生物力學資料）
- 表現模糊：**球速下降、容易疲勞、投球時卡住或彈響感、後上關節線疼痛**
- **O'Brien active compression**：前屈 90°、**內收 20°**、**最大內旋**抗阻下壓 → 再於外旋重複；**內旋痛、外旋緩解 = 陽性**；**最具預測力**
- 🆕 **保守**：後關節囊伸展、停投、安全使用消炎藥 → 疼痛緩解後加強
  - **2022 SR（244 位過頭運動員）：完成復健者回原等級 72%；整體只有 42.6%**（很多人中途改手術）
- 🆕 **手術**
  - **Type VIII**：修補後方延伸；不穩定的 biceps anchor → **直接修 vs tenodesis 仍有爭議**
  - **>16,000 人資料庫（2022）**：**>50 歲較常做 tenodesis**；**SLAP 修補翻修率 6.8% vs tenodesis 5.7%**
  - **菁英過頭運動員**

| 研究 | 結果 |
|---|---|
| 24 位菁英過頭運動員 type II 修補 | **RTP：棒球 38% vs 非棒球 75%** |
| **27 位職業棒球投手** SLAP 修補 | **整體 RTP 48%，回原等級僅 7%** |
| **17 位職業棒球員** biceps tenodesis | **回原等級 35%；投手僅 17%** |

- **結論**：**SLAP 修補適合年輕非過頭運動員**；**tenodesis 適合較年長有症狀者**；**菁英過頭運動員仍是難題**

### 1.5 Internal Impingement 🆕
- **ABER 時大結節碰到後上 glenoid rim = 正常生理現象**
- 重複投擲 → 後上 cuff 被夾在大結節與 glenoid rim 之間 → 疼痛 → **cuff 關節面撕裂＋後上唇撕裂**
- 病因多因子：**後關節囊攣縮（接觸點後上移）、前關節囊鬆弛、scapular dyskinesis、kinetic chain 失衡**
- 表現：**漸進的表現下降**（球速、準度），非急性
- 🆕 **Posterior impingement sign**：ABER、最大外旋時**深部後方疼痛**；**69 人（非接觸損傷）敏感度 95%、特異度 100%**
- X 光（AP、axillary、scapular Y）排除骨性原因 → **MRI = gold standard**：**supraspinatus 或 infraspinatus 關節面病變＋後上唇病變**
- 治療：**停投** → 止痛、消炎 → 同時處理 GIRD、dyskinesis → **監督下投擲計畫**
- 手術：處理後上唇（找 SLAP 或往後延伸）與 cuff
  - **清創或修補後上唇後，投手回原等級可低至 10%**
  - Partial articular cuff 撕裂：清創、transtendon 修補、完成撕裂後單排或雙排 → 最佳方式未定
  - **82 位職業投手清創：RTP 76%，回原等級 55%**

## 2. 盂肱不穩定

### 2.1 前方不穩定 🔄
- 🆕 **MOON Shoulder Instability Study：多為 <25 歲男性**
- 過去前方最多可達 **80%**，但後方越來越被重視

**🆕 靜態與動態穩定**
- 靜態：**glenoid labrum、關節囊、rotator interval、SGHL、MGHL、IGHL**
- **IGHL → 90° 外展＋最大外旋時維持穩定**（**前方脫位最常見的姿勢**）
- 動態：rotator cuff、肩胛穩定肌、LHBT
- **concavity-compression**：cuff 收縮把肱骨頭壓入 glenoid

**🆕 盂肱韌帶功能**

| 韌帶 | 功能 |
|---|---|
| **SGHL** | **0° 外展**時的前方平移限制 |
| **MGHL** | **45° 外展**（＋外旋）時的前方平移限制 |
| **AIGHL** | **90° 外展＋外旋**時的前方平移限制 |
| **PIGHL** | **屈曲＋內旋**時後方平移的**主要**限制 |

### 2.2 病史與檢查 🆕
- 受傷時間與機轉、運動與活動量、不穩病史、之前的手術或復健、**長期運動目標**
- 視診：**deltoid 輪廓消失、肩峰突出**
- 測試：
  - **Apprehension → relocation**
  - **Load-and-shift**：仰臥，在**中立、45°、90° 外展**三個姿勢做；**症狀重現或前移 >25% 肱骨頭直徑 = 陽性**
  - **Anterior drawer**：與 load-and-shift 類似，但**不先施軸向壓力**；apprehension 不確定時使用
- 🆕 **中度外展、低外旋就出現 apprehension → 懷疑較嚴重病變（盂骨或肱骨骨缺損）**

### 2.3 盂骨缺損（GBL）🔄
- **Circle method**：3D CT en face，沿後下 glenoid（約 **5 點到 9 點鐘**）畫 best-fit circle → GBL% = 最大缺損處的寬度與圓直徑的比
- **CT 為 gold standard**，但**同方法可用於 sagittal T1 MRI，MRI 與 CT 相關性極好** → 真正的 gold standard 可能不存在
- 🔄 **Critical GBL**（超過則軟組織手術失敗率無法接受）
  - **過去高達 25% → 近年低至 13.5%**
  - **>20% 普遍認為需骨性增強**
  - **Subcritical bone loss：13.5%**（某些族群做軟組織手術的失敗風險已升高）

### 2.4 Bipolar Bone Loss 🆕

| 名詞 | 定義 |
|---|---|
| **Glenoid track（GT）** | **0.83 × D − d**（D = sagittal CT 或 MRI 上 glenoid 的 best-fit circle 直徑；d = GBL 寬度） |
| **Hill-Sachs interval（HSI）** | Hill-Sachs 內緣到 cuff 關節面止點的距離 |
| **On-track** | **GT > HSI** |
| **Off-track** | **GT < HSI** → Hill-Sachs 在較低外展外旋就卡住 → **復發風險顯著增加** |
| 🆕 **Distance to dislocation（DTD）** | **GT − HSI**；**<0 = off-track；>0 = on-track** |
| 🆕 **Near-track** | **on-track 但 DTD <8 mm** → **單純關節鏡 Bankart 失敗率較高** |

- MRI、3D CT、2D CT 都可量 GT 與 HSI
- 🆕 **2023：hyperlaxity＋near-track → 復發顯著增加**
- 🆕 **2023：on-track 加 remplissage → 復發顯著下降**，尤其 **near-track 或接觸、碰撞運動**的高風險者

### 2.5 保守治療
- 適用：**年長、無其他復發危險因子**（低需求、**非接觸或碰撞運動**、**首次脫位且無明顯骨缺損或外傷性 cuff 撕裂**）
- 短暫固定 → 早期復健恢復 ROM、加強動態穩定
- **對稱肌力、無痛 ROM、無 apprehension** → 可回場（± 護具）
- 🆕 **反覆不穩的長期傷害**：GBL 增加（最後需骨性手術）、glenoid 軟骨缺損增加、手術結果變差、**長期盂肱 OA**

### 2.6 首次脫位 🔄
- 個別化決策；保守 → 同季回場率高，但復發率也高
- 🆕 **2023：首次脫位後就做關節鏡 Bankart，失敗率低於第二次脫位後才修**
- 🔄 **多個 RCT：關節鏡穩定術 vs 保守 → 復發約 10% vs 70%**；PRO、無事件存活、回場率都較好；**高風險運動差距更大**
- 需權衡延遲手術的風險 vs 本季繼續比賽

### 2.7 手術

**前方 Bankart 修補** 🔄
- 適用：**GBL 很少或 subcritical**
- 🆕 **復發 4%–19%**，各等級運動員回場率高
- 🆕 **建議使用 4 顆適當間隔的錨釘**
- 🆕 評分：**Instability Severity Index Score（ISIS）**、**Glenoid Track Instability Management Score（GTIMS）**（因子：手術年齡、運動類型〔接觸或強迫過頭〕、競技等級、**前下 hyperlaxity**、3D CT 骨缺損評估；總分 10）

**肱骨骨缺損：Remplissage** 🔄
- 把 **infraspinatus 腱與關節囊固定到 Hill-Sachs 缺損** → 變成關節外缺損、不再卡住
- 🔄 **off-track＋GBL <25% → 復發低至 5%**
- 🆕 **on-track 高風險者（接觸運動、near-track DTD <10 mm）加做也能顯著降低復發**
- 🆕 **缺點：90° 外展時外旋減少，最多 11°**（2022）
- 🆕 **Hill-Sachs >40% 關節面 → 肱骨頭結構增強（allograft）或 hemiarthroplasty**

**盂骨缺損：Latarjet、Distal Tibial Allograft** 🔄
- **GBL >20% → glenoid 增強是首選**；coracoid 轉移包括 **Bristow、Latarjet**
- **Latarjet 三重機轉**
  1. **骨性重建**（固定 coracoid）
  2. **Conjoined tendon 在前下 glenoid 的 sling effect**
  3. 關節囊修補到 **CA ligament 殘端**，進一步抵抗前移
- 🔄 **復發低至 0.8%**
- 🔄 **技術要求高，併發症可達 30%**：神經血管損傷、固定失敗、**骨塊 nonunion、吸收**、術後僵硬、**OA（最多 20%）**；**骨塊放太外側 = 最強危險因子**
- 🆕 **Osteoarticular distal tibial allograft**：技術較容易、可**真正重建關節面與存活軟骨**；**大型比較（≥2 年）：與 Latarjet 的 PRO、失敗、併發症無差異**

**🆕 回場標準**
- **43 位運動員 Bankart 術後 6 個月：38 人仍有肌力或功能缺陷**
- **Criteria-based**（等速、等長、功能測試）信效度佳
- **復發：criteria-based 5% vs time-based 22%**

### 2.8 後方不穩定 🔄
- 與前方不同：**症狀模糊、表現下降、常無明確外傷**
- 🆕 **2024（>1,700 位連續病人）：後唇病變 64.9%** → 需高度懷疑
- 測試：**Kim、jerk、posterior load-and-shift**
  - 🆕 **Dynamic posterior instability test**：模擬投擲姿勢，**肘伸直、肩屈 140°**，檢查者給阻力 → **後方疼痛 = 陽性**
  - 🆕 **Modified 版**：檢查者拇指放後關節線給前向力，**疼痛改善 = 陽性**；**敏感度 94.4%、特異度 95%**（2022）
- MRI：後唇撕裂、後關節囊損傷；少見 **reverse Hill-Sachs**、**reverse HAGL**
- **保守（非外傷性第一線）**：活動調整、消炎、復健 → **加強 subscapularis 與肩胛周圍肌**、**避免再拉後關節囊**
  - 🆕 **Voluntary posterior dislocator → 保守**（手術失敗率高）
- **手術：關節鏡 capsulolabral repair**

| 研究 | RTP | 回原等級 | 翻修 |
|---|---|---|---|
| 🆕 2023（53 人） | **60%** | **35%** | **13%** |
| 🆕 32 人 | **82%** | **56%** | — |

- 少見：卡住的 **reverse Hill-Sachs → reverse remplissage**；**後方 GBL >20% → 骨性增強（iliac crest autograft、scapular spine autograft、distal tibial allograft）**

### 2.9 多方向不穩定（MDI）🔄
- 定義：**至少 2 個方向的症狀性不穩**
- 症狀模糊：表現下降、非特異疼痛、**臂神經叢反覆牽拉造成的神經症狀**
- 常（但不一定）合併**全身關節鬆弛** → **所有人用 Beighton 篩檢**
- **Sulcus sign 與 MDI 高度相關**
- MRA：**寬鬆的關節囊**；排除唇或關節囊撕裂
- **第一線：PT**，加強動態穩定以改善 concavity-compression
- 長期復健仍有症狀 → **open capsular shift** 或**關節鏡錨釘 capsular plication**
- 🆕 **預後保守**：回場率低於前方或後方不穩、復發率較高；**女性與高 Beighton 分數 = plication 後結果差的強預測因子**

## 4. Key Study Points（OKU 15）

- 詳細的**投擲史與理學檢查**是投擲運動員肩痛診斷的關鍵
- **GIRD** 在投擲者常見，未治療會讓其他結構（包括 **UCL**）受傷；第一線 = **後關節囊伸展計畫**
- **Scapular dyskinesis** = 肩胛運動與力學異常，處理困難；需告知治療期長；第一線 = 恢復正確肩胛與肩活動的復健
- 前方不穩在年輕運動員常見；治療取決於**脫位次數、活動量、雙極骨缺損量化**
- 後方不穩較少見但可造成投擲者肩功能障礙；從復健到**後方 capsulolabral 修補**，**骨缺損大才做骨性重建**
