## 1. Sport specialization 與 burnout 🆕

- 🆕 **早期專項 → 受傷風險增加、時間負擔增加、可能 burnout → 妨礙長期表現**。
- 🆕 **2024 SR：早期專項與年幼時表現提升相關，但與長期表現負相關**。
- 🆕 **2024 橫斷調查（1,283 名運動員）：overuse 傷病史、私人教練 → 焦慮與憂鬱疑慮**。
- 🆕 **另一 SR：專項 vs sport sampling → burnout 徵象較多（成就感下降、耗竭、貶值感）**。

## 2. 肩 🔄

### 2.1 Little Leaguer's shoulder 🆕

- 🆕 **過頭投擲運動員常見 overuse；男性青少年，平均約 13 歲**；多保守。
- 🆕 **SR：平均 12.8 歲（7.4–17 歲）**。
- 🆕 **主訴：投擲時優勢側近端肱骨痛**；🆕 **PE：66.6% 前外或後外近端肱骨壓痛**。
- 🆕 **MRI：96% 陽性（physis 變寬、骨膜水腫）**。
- 🆕 **GIRD 約 16–30%**。
- 🆕 **治療：停止投擲 ± PT（尤其 GIRD）；休息 2–3 個月後 return-to-throwing program**；🆕 **約 93% 回到受傷前水準**；GIRD 者可能較易（OCR 截斷）。

### 2.2 GIRD 🆕

- 🆕 **青少年過頭運動員發生率增加（2022）**。
- 🆕 **定義：ER 增加、IR 喪失 → 總弧度減少；優勢側比非優勢側 IR 少約 15–25°**。
- 過去被視為肩傷（包括 Little Leaguer's shoulder）的危險因子；🆕 **SR：GIRD 病人受傷風險增加**。
- 🆕 **治療以保守為主：sleeper stretch、cross-body adduction、關節鬆動**。

### 2.3 前方肩不穩 🔄

- 🆕 **過頭與碰撞運動：不穩發生率 15–20%，接近骨骼成熟時最高**。
- 🆕 **因素：韌帶鬆弛、肌肉收縮模式、GH 關節結構改變（2024）**。
- 評估：病史（既往次數、機轉）；**anterior apprehension、relocation、sulcus sign、load-and-shift**；**Beighton score**。
- 影像：**AP、Grashey、axillary、scapular Y**；CT（骨結構、骨缺損）；MRI（labrum、韌帶、軟骨）。
  - 🆕 **首次脫位 → MR arthrogram 區分 MDI 與真正外傷性結構傷**。
  - 🆕 **兒童可用 MRI 替代 CT 評估 Hill-Sachs 與 glenoid 骨缺損（避免輻射）**。
- 🆕 **治療演變：證據傾向早期手術**。
  - 初步：場邊或急診閉鎖復位（鎮靜或囊內局麻）。
  - 🆕 **骨骼未成熟 → 復位前先照片排除近端肱骨幹骺或 physis 骨折（2023）**。
- 🆕 **12–16 歲：外傷性前脫位後復發率最高**。
- 🆕 **14–18 歲首次脫位保守 → 復發風險高；反覆不穩 → glenoid 與肱骨頭骨缺損 → 手術失敗率上升**。

| 首次脫位（14–18 歲） | 復發 |
|---|---|
| 🆕 **保守** | **70%** |
| 🆕 **手術穩定** | **13%** |

- 🆕 **保守高風險：首次脫位即有 Hill-Sachs、首次脫位 <16 歲**。
- 🆕 **無明顯骨缺損 → 關節鏡前下方修補＋capsulorrhaphy**：結果好、回原水準率高。
- 🆕 **術後復發危險因子：碰撞運動、年齡（最具預測性）、術前 >1 次不穩**。
- 🆕 **2023：Hill-Sachs 病人中，復發者 Hill-Sachs interval 較大**。
- ✅ **engaging Hill-Sachs（外展外旋時咬住前 glenoid）→ remplissage**（尤其年輕活躍非投擲者）。
- **開放 Bankart**：無骨缺損、關節鏡失敗。
- 🆕 **CT 顯示明顯骨缺損 → glenoid 增強：Latarjet 或 allograft bone block**。

### 2.4 Multidirectional instability（MDI）🆕

- 從半脫位到多方向脫位；🆕 **年輕運動員可無痛、就診時常已自行復位**。
- 🆕 **評估：Beighton、PE 顯示中段 ROM 不穩（外傷性為端點不穩）、不穩事件史、家族史（結締組織病）**；影像：MR arthrogram。
- 🆕 **2023 review：初始 PT（囊周強化、姿勢、rotator cuff）至少 6 個月**。
- 🆕 **持續不穩、保守失敗 → 手術（結果可期）**：
  - **開放 inferior capsular shift**。
  - **關節鏡 capsulorrhaphy（較能看與處理關節內病變）**。
  - 🆕 **關節鏡 vs 開放的優勢仍有爭議；無比較研究，兩者都有良好報告（2024）**。

### 2.5 SLAP 🆕

- 年輕過頭運動員常以肩痛表現；🆕 **影像證據：無症狀者 SLAP 常見**。
- 🆕 **初始 PT；2022 SR：回場前完成復健 → 成功**；🆕 **保守失敗因子：年長、過頭運動、外傷、症狀期較長**。
- 🆕 **手術：SLAP repair、biceps tenodesis、biceps tenotomy**；傳統年輕人偏好 repair。
  - 🆕 **2024 meta（年輕病人）：tenodesis 與 repair 功能與翻修率相似**。
  - 🆕 **過頭運動員 primary tenodesis（平均 19.8 歲）：休閒過頭運動員結果佳；精英過頭運動員較差**。

## 3. 肘 🔄

### 3.1 Little Leaguer's elbow 🔄

- valgus 主導運動員的肘痛光譜受骨骼成熟、投擲或翻騰力學、同側肩病變（GIRD）、overuse 影響。
- ✅ **內上髁 apophysitis，通常 ≤10 歲，幾乎只在投擲側**。
- 🆕 **flexor-pronator 比鄰近 physis 強 → apophysis 生長中心是反覆 valgus 力的弱點，最常在 late cocking 期**。
- 臨床診斷：內上髁痛、投擲時漸進內肘痛；**AP、側位、斜位 X 光排除骨折**。
- 🆕 **治療**：

| 步驟 | 內容 |
|---|---|
| 1 | **嚴格停投**；GIRD → **sleeper stretch、cross-body adduction** |
| 2 | **PT 4–8 週** |
| 3 | **症狀完全緩解，且肩 ROM 恢復到非投擲側 5–10° 內** |
| 4 | **4–8 週漸進回投** |

- 🆕 **未衛教預防（遵守 pitch counts）且症狀再現時未調整活動 → 高復發**。

### 3.2 內上髁骨折 🔄

- 🆕 **2022 review：9–14 歲棒球投手好發**。
- ✅ **絕對手術適應：骨片卡入關節、開放骨折、尺神經感覺異常或傷**。
- 🆕 **相對適應：肘不穩、明顯移位（文獻 2–10 mm 不等）**。
- 🆕 **valgus 負荷運動員（投擲：棒球、壘球、標槍；翻騰：體操、啦啦隊、tumbling）需要肘穩定 → 移位且有不癒合或 malunion 風險者較常手術（2022）**。
- 無或輕移位 → 保守。
- ✅ **擺位：prone 改善後方骨片暴露；止血帶時間無差，但擺位平均多約 30 分鐘**。
- 🆕 **手術是否改善結果？**

| 研究 | 結果 |
|---|---|
| 🆕 **2024 propensity score 配對** | **回運動能力、中位回場時間、疼痛、PT 需求、併發症皆無差** |
| ✅ **AP 片配對、平均 2.5 年、兩組約 8 mm** | **保守：疼痛較少（PedsQL Pediatric Pain）、外觀較好（VAS 95 vs 87，P = 0.007）**；🆕 **保守全部回到原運動參與；手術 15% 需降低運動** |

- 🆕 **結論：手術未改善結果；移位如何量測（AP 會低估）未來仍可能重要**。

### 3.3 UCL 傷 🆕

- 🆕 **內肘主要穩定結構；valgus 負荷運動員高度依賴**。
- 🆕 **青少年 UCL 傷與治療穩定增加**；治療：**保守 ± biologics（PRP）、UCL repair、UCL reconstruction**。
- 🆕 **SR（414 名青少年棒球與標槍）：同級或更高 RTP 84.3%**；🆕 **重建（8 篇）併發症 3.9%、再手術 1.8%**。
- 🆕 **2022 SR：三種回場標準 — return-to-throwing program、投手回投手丘、術後時間**；仍待釐清。

### 3.4 Capitellar OCD 🆕

- 🆕 **青少年運動員（13–16 歲）外側肘痛最常見原因**。
- 🆕 **發生率比較**：

| 部位 | 發生率（／100,000） |
|---|---|
| **肘（capitellum）** | **2.2** |
| **膝** | **9.5–29** |
| **踝** | **2–4.6** |

- 🆕 **棒球投手、體操常見；特殊 valgus 負荷＋多因素（遺傳、軟骨不匹配、血管中斷、微創傷，2024）**。
- 影像：capitellum 透亮；🆕 **45° radiocapitellar tunnel view 較標準 AP、側位更穩定顯示**；🆕 **MRI = 辨識、大小、穩定性與分期的金標準**。
- 🆕 **肘為非負重關節 → 最常表現為疼痛＋鎖住（代表不穩病灶）**。
- 🆕 **治療**：

| 病灶 | 處置 |
|---|---|
| **穩定** | **活動調整、減負（不負重、停投）、hinged elbow brace 約 3–6 個月**；無改善或惡化 → **軟骨仍完整則關節鏡 drilling** |
| **不穩、可修補（骨量足）** | **in situ 固定，通常＋植骨** |
| **不穩、不可修補，<2 cm²** | 🆕 **OAT（取自外側 trochlear flange）** |
| **不穩、不可修補，>2 cm²** | 🆕 **OCA transplantation** |

- 🆕 **保守不癒合危險因子：骨齡較大、病灶較大、囊狀病灶、橈骨頭增大、不穩跡象**；關節對位與穩定也影響。
- 🆕 **結果（皆明顯優於單純 débridement）**：
  - **in situ 固定癒合 77%（20/26）**。
  - **OAT：7 篇中 4 篇 RTS 100%，3 篇 83–94%**。
  - **OCA：兩研究 6/6 癒合、RTS 100%（回場後至少 2 年）**。

## 4. 骨盆撕脫 🔄

- 傳統保守：**活動調整、保護負重、PT（ROM 與伸展）**。
- 🆕 **移位 >3 cm → 不癒合率較高，常為手術適應；手術結果良好到極佳**。
- 🆕 **2023 回溯（719 例）**：

| 項目 | 數值 |
|---|---|
| **平均年齡** | **14.6 歲** |
| **男性** | **78%** |
| **足球** | **38%** |
| **最常部位** | **AIIS** |

- 🆕 **較高 BMI 可能增加撕脫風險；可能有解剖傾向**。

## 5. 膝 🔄

### 5.1 ACL 🔄

- 🆕 **早期專項增加 → 兒童青少年 ACL 傷與手術增加**。
- 🆕 **延遲手術 >12 週或保守 → 進行性關節內傷（不可修補半月板、後續軟骨傷）**；加上保留 physis 技術進步 → 手術結果較好。
- 🆕 **兒童術後併發症風險高（活動量、physis 未閉）；生長障礙仍是主要擔憂 → 保留 physis 技術降低風險，但需密追（2024）**。
- ✅ **allograft 增強 vs 加大 autograft：前者失敗率較高**；✅ **約 7% 對側 ACL 傷**。
- 🆕 **ACL repair 重新興起**：
  - 🆕 **Bridge-enhanced ACL repair（BEAR）：縫線修補＋特定細胞外基質支架；早期證據 2 年非劣**。
  - 年輕人癒合潛力大，但活動與需求也高 → 結果有爭議。
  - 🆕 **2024 SR：primary repair vs reconstruction → 再斷與取內固定較多；功能分數與不良事件無差**。
- 🆕 **冠狀或矢狀面結構性不良對位 → guided growth（plate 或 cannulated screws）代替成熟者的截骨**；需密追與取出；🆕 **與 ACLR 合併結果良好**。
- 🆕 **Lateral extra-articular 輔助手術（LET、ALL reconstruction）**：
  - 🆕 **physis 未閉 → 股骨固定點需在 physis 遠側**。
  - 🆕 **早期證據：與 ACLR 同時做改善穩定**。
  - 🆕 **2023 屍體：加 LET → ACL 移植物受力與脛骨前移減少，不論後傾增加**。
  - 🆕 **適應（演變中）**：

| 高風險因子 |
|---|
| **年幼** |
| **膝 recurvatum >10°** |
| **hyperlaxity（Beighton >5）** |
| **碰撞運動** |
| **高級 pivot shift** |

- 🆕 **功能性 brace：小兒運動醫學專家調查一半建議、一半不建議；功能與移植物再斷無差**。

### 5.2 多韌帶傷 🆕

- 🆕 **兒童罕見；骨骼未成熟的獨特解剖 → 常為 physis 傷，或 physis＋韌帶合併，而非純多韌帶傷** → 多依成人文獻。
- 🆕 **physis 未閉、疑韌帶不穩 → 應力 X 光：區分 physis vs 韌帶傷，並量化不穩以決定手術**。
- 🆕 **2022 review：膝脫位需詳細神經血管 PE ± 進階血管影像；長期追蹤 physis 障礙與生長停止；早期辨識與考慮手術有益**。
- 🆕 **MRI 研究（50 人、平均 13.3 歲）**：
  - **ACL 傷合併 PLC 傷 52%**；**不完全 PLC 傷常見（可能比以往認知更多）**；**完全 PLC 傷少（14%）**；無型態可預測 PLC 傷。
- 🆕 **2024 大型回溯（5,174 例、20 年）：年齡增加（P <0.02）、BMI 增加、接觸傷史 → 預測合併半月板與韌帶傷**。

### 5.3 Tibial spine（eminence）骨折 🔄

- 移位者少見，多為兒童青少年；開放與關節鏡技術。
- 依移位分類：**I、II（無移位或後鉸鏈完整）→ 伸直石膏；III、IV（完全移位或粉碎）→ 開放或關節鏡固定**。
- 🆕 **最常術後併發症：arthrofibrosis、ACL laxity**。
- 🆕 **2024 SR：多為男性、平均 12 歲；開放或關節鏡、縫線或螺釘 → 整體結果都好；arthrofibrosis 為最常併發症（不論技術）**。
- 🆕 **2023 兒童屍體：兩支 4.0 mm cannulated screws vs 兩條 No. 2 FiberWire → 生物力學相當**；🆕 **兒童骨破壞負荷低於成人骨與豬骨**。
- 🆕 **復位品質：2023（328 例 <18 歲，手術與保守）→ 前緣殘餘移位與伸直或屈曲喪失、主觀殘餘鬆弛皆無關 → 只要膝穩定與功能 ROM 達成，不一定需要解剖復位**。
- 🆕 **合併傷**：**半月板撕裂 40–70%（類似 ACL 傷）**；🆕 **多中心：35% 有合併傷；外側半月板傾向；近 90% 合併傷需介入 → 建議術前 MRI**。
- ⚠️ Ch.70 寫 **MRI 合併傷約 45%，其中 87% 需治療**，數字略有差異。

### 5.4 半月板 🔄

- ✅ **discoid 第一步：膝 AP 片；外側股骨髁 squaring 傳統上為特徵性**。
- 🆕 **外側關節間隙增寬、腓骨頭高度較高與外側 discoid 相關；腓骨頭高度跨年齡可用、評估者間可信度好**。
- 🆕 **術時平均約 10 歲：PE 與 PRO 都無法區分撕裂 vs 不穩的 discoid；MRI 對撕裂只有 75% 敏感、50% 特異 → 關節鏡為判斷病理（撕裂或不穩）的標準**；有助於向家屬說明術後過程。
- 🆕 **非 discoid 的半月板傷**：運動兒童較常；🆕 **目標保留半月板組織 → 修補比例上升、減少切除，以保護軟骨**。
- 🆕 **880 例（平均 13.4 歲）：男女在慢性、位置、撕裂型態有差異**。

### 5.5 膝 OCD 🆕

- 多因素特發性；局部軟骨下骨改變 → 不穩、相鄰軟骨傷 → 關節退化。
- 🆕 **發生率 9.5／100,000／年；男 15.4、女 3.3；12–13 歲最常**。
- 🆕 **2022 多中心（1,004 膝、903 人，男 68.9%，中位 13.1 歲，6.3–25.4 歲）**：**多項運動 68.1%；男最常籃球（27.3%）、女最常足球（27.6%）**。
- 穩定病灶：模糊間歇膝痛或跛行，衝擊活動加重；🆕 **不穩：喀啦、彈響、鎖住等機械症狀，子片分離形成 loose body（2024）**。
- 治療依穩定度、大小、位置、對其他治療的抗性：

| 病灶 | 處置與結果 |
|---|---|
| 🆕 **穩定、未成熟** | **保守至少 3–6 個月：活動調整、限制負重、固定（hinged 到減負 brace）、石膏** → **成功 49–100%，年幼較好** |
| | 🆕 **早期 drilling（初診 6 週內）：QALY 較佳，但對付費者與社會較貴** |
| | 🆕 **2022：保守 RTS 平均 8.1 個月 vs 手術 3.7 個月（無統計顯著）→ 共享決策參考**；🆕 **MFC 病灶結果較可靠** |
| 🆕 **不穩、可救** | **內固定 ± 植骨**；🆕 **2023 長期（11.3 ± 4 年）in situ：最終癒合 72%，不受骨骼分期影響；LFC 位置為獨立失敗危險因子** |
| 🆕 **不穩、不可救** | **microfracture、débridement、ACI／MACI ± 植骨、OAT、OCA（較大 >2–3 cm²）**（依大小、深度、位置） |

### 5.6 踝 OCD 🆕

- 🆕 **兩類：內側 talar dome OCD；外側 talar dome osteochondral defect 或骨折（與踝不穩相關）**。
- 🆕 **處理類似肘與膝；穩定度與骨骼成熟度最有效決定治療**。
- 🆕 **保守（活動調整、不負重、brace 或石膏）成功約 46–67%**。
- 🆕 **2022 回溯：未成熟距骨 OCD 保守成功 67%；年長（P = 0.034）與診斷時完全分離但未移位的 grade III（P <0.001）→ 保守失敗預測**。
- 🆕 **保守失敗但仍穩定 → subchondral drilling（功能明顯改善）**。
- 🆕 **不穩且小（<150 mm²）→ microfracture**；🆕 **不穩且大 → ACI、MACT、OAT、OCA**。
- 🆕 **2022 橫斷追蹤（中位 72.5 個月）**：

| 組別 | 無限制 RTS | 無 OCD 進展或關節退化 |
|---|---|---|
| **穩定 → drilling** | **79%** | **29%** |
| **不穩 → fixation 或 repair** | **50%** | **12.5%** |
| **不穩 → reconstruction** | **20%** | **10%** |

## 6. 心理準備與回場 🆕

- 多數受傷兒童與青少年計畫回場。
- 🆕 **ACLR 後：約 55% 年輕運動員因生活狀況或心理原因未能回場**。
- 🆕 **SR：怕再傷（fear of reinjury）= 最常見的不回場心理因素 → 建議 ACLR 後 RTP 流程納入心理評估**。
- 🆕 **青少年翻修 ACLR：怕再傷也是回到較低水準的最常見原因**。

## 8. Key Study Points（OKU 15）

- **肩不穩與 ACL 傷的手術很重要**：保守治療短期與長期結果明顯較差；這些手術持續演進以追求更好結果。
- **全身各部位 OCD 病因仍不明** → 針對病因的治療「好但不完美」；但新方法使骨骼未成熟與成熟者的結果與 RTS **過去 20 年明顯改善**。
- **心理回場準備**是演進中的領域，應成為小兒與青少年 ACL 及其他運動傷術後評估的一部分。
- **膝脫位雖少見，任何兒童膝脫位都應評估神經血管傷並做應力影像評估 physis 傷**；因有 physeal arrest 風險需長期追蹤。
