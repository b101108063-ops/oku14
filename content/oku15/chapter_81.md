| **手術原則** | — | 🆕 **評估局部進展風險；已完成病理骨折不像外傷骨折那樣癒合**；🆕 **三類：（1）即將骨折內固定 ± 刮除與局部輔助（2）已完成骨折內固定 ± 刮除（3）切除＋重建**；🆕 **是否刮除依組織學與皮質破壞；甲狀腺與 RCC 對輔助放療反應較差 → debulking 較有益**；✅ **甲狀腺、RCC、MM 等富血管 → 術前經皮栓塞；🆕 48–72 小時內手術（減少再血管化）**；🆕 **切除：單發、寡轉移、RCC（切除 vs 固定有存活益處）**；🆕 **已完成骨折內固定併發症高：局部進展、不癒合、植入物失敗、感染、VTE、bone cement implantation syndrome** | 🔄 |
| **上肢** | 上肢 <20% | 🔄 **約 20% 骨轉移在上肢**；🆕 **肩胛、鎖骨、橈尺骨少、多可非手術；acral 轉移罕見，多為肺癌**；🆕 **肱骨 = 第二常見長骨**；即將骨折痛、已完成骨折妨礙使用助行器；🆕 **證據弱；唯一：近端肱骨重建 reverse TSA 優於 conventional 與 hemi（ROM、穩定，低等級）**；🆕 **骨幹或幹骨幹（不涉關節）：plate、IM nail 或 photodynamic polymer；刮除＋骨水泥＋內固定；en bloc＋intercalary 金屬（防節段局部進展但機械失敗高、多 aseptic loosening，2024）**；🆕 **ER＋乳癌肱骨幹骨折 → IM nail＋放療＋全身治療 → 癒合**；🆕 **關節受累或先前固定失敗致骨量喪失 → endoprosthesis 或 APC（近端、遠端、全肱骨）；遠端肱骨 → 初次 TEA；短期存活、併發症高，但提供上肢功能與助行穩定** | 🔄 |
| **下肢** | — | 🆕 **股骨為轉移、MM、lymphoma 常見部位**；🆕 **股骨頸（尤其合併退化）→ 切除＋關節置換**；🆕 **轉子周或轉子下 → CMN；明顯局部進展或癒合差 → PFR 或 calcar-replacing arthroplasty**；🆕 **已完成骨折或先前 nail 周圍進展 → 切除置換；壽命較長者即使感染較高也受益（2023）**；🆕 **骨幹 → IM nail 或 intercalary（2023）**；🆕 **遠端股骨幹骺或幹骨幹（未行 DFR）→ 刮除＋骨水泥＋nail 或 plate**；🆕 **打破全股骨保護教條：長 stem 骨水泥與長 nail 增加複雜度、時間、翻修難度、心肺併發症；單灶 → 無近端病灶可 retrograde nail；無遠端病灶的轉子間 → 短 CMN（進展時較易轉 PFR）**；🆕 **2022：nail vs plate 或 arthroplasty → 肺轉移發生或進展未增加** | 🆕 |
| **骨盆** | 四支 6.5 mm 部分螺紋後柱螺釘＋骨水泥＋骨水泥髖臼杯；部分骨盆籠架＋骨水泥 THA 4 年再手術 16% | 🔄 🆕 **非負重部位多可非手術（放療、BMA）；常見骨通道內固定強化 → 改善生活品質與活動**；🆕 **經皮 photodynamic nail：安全微創緩和、減痛與鴉片、改善功能（髖臼周，2024）；可單獨或配 THA；可用於非包含缺損（骨水泥可能外滲傷神經血管）**；🆕 **經皮 cannulated screw＋熱消融＋骨水泥＋輔助放療組合**；🆕 **開放：resection arthroplasty、標準 THA、revision 髖臼組件 THA、Harrington cement rebar、pedestal cup（嚴重髖臼骨缺損，2024）**；🆕 **開放失血較多 → 保留給耐受者、寡轉移、預期長存活** | 🔄 |

## 1. 流行病學 🔄

- 🆕 **與癌共存的人比以往更多**：分子與基因檢測 → 更精準標靶治療；轉移病人存活改善 → 骨轉移處置也在改變；幾乎所有骨科醫師都會遇到。
- 🆕 **2024 美國 >200 萬新癌；終生罹癌機率：男 1/2、女 1/3**；癌症死亡率下降、轉移病人存活 >5 年機率增加。
- ✅ **骨 = 第三常見轉移部位（肺、肝之後）**。
- ✅ **最常轉移到骨的癌：乳、肺、甲狀腺、腎、攝護腺 → 「BLT with a Kosher Pickle」**；另一口訣：**「Kinds of Tumors Leaping Primarily to Bone」**。
- 也可來自膀胱、肝、GI、子宮；血液惡性（**MM、lymphoma**）也造成破壞性骨病灶。
- 🆕 **2024：乳癌 >30 萬新診斷（女性最常）；攝護腺 <30 萬（男性最常）；兩者最易骨轉移**。
- 🆕 **2030 年：近 20 萬美國男性帶轉移性攝護腺癌，約 89% 為骨轉移**。
- 🆕 **標靶生物治療與 ICI 使 NSCLC 與 RCC（過去對傳統化療反應差）存活提升**；但全身治療成功時**骨轉移仍可局部進展**，威脅骨或先前固定的機械完整性。

## 2. 評估與影像 🔄

### 2.1 臨床與影像特徵 🆕

- 🆕 **肺癌與腎癌病人可以轉移、甚至以骨病灶為首發症狀**。
- 🆕 **骨轉移病人常同時有內臟轉移；初診單發轉移少見（多處較常）**。
- 🆕 **軸骨多於四肢：椎體、肋骨、骨盆、近端肢帶最常**。
- 🆕 **X 光型態依組織**：

| 型態 | 原發 |
|---|---|
| **溶骨（radiolucent）** | **乳、肺、甲狀腺、腎、血液、GI**（乳、肺也可成骨） |
| **成骨（radiodense）** | **攝護腺、膀胱** |
| **混合** | 依組織而定 |

### 2.2 >40 歲未知病灶 🔄

- ✅ **>40 歲、無癌史、破壞性邊界不清病灶 → 鑑別順序：轉移癌 > multiple myeloma > lymphoma**。
- 🆕 **原發骨腫瘤可能性小得多，若是 → chondrosarcoma、primary lymphoma of bone（多為 DLBCL）、UPS of bone、plasmacytoma**。
- 🆕 **>40 歲未知病灶＋病理骨折 → 轉移病灶的可能性約為原發骨肉瘤的 500 倍**。
- 檢查：病史與 PE（個人與家族癌史、全身症狀）→ **整根骨雙平面 X 光** → 🆕 **高度懷疑原發骨病 → MRI 或 CT 描述範圍與鄰近解剖** → 切片前常規檢驗縮小鑑別。
- ✅ **標準病史、PE、檢驗、全身影像 → 85% 找到原發癌**；🆕 **單靠切片 → 65% 無法找出原發部位**。
- 🆕 **完整評估提高切片後組織診斷準確度，也可能找到更易切片的部位或免除切片**。

### 2.3 全身影像 🆕

| 影像 | 用途 |
|---|---|
| **CT chest／abdomen／pelvis** | **找出多數內臟原發** |
| **全身 bone scan** | **成骨活性、多處骨轉移**；🆕 **MM 常為冷 → skeletal survey** |
| 🆕 **FDG PET-CT** | **可一次取代：找原發＋評估整體轉移** |

- 🆕 **標準流程（>40 歲、無癌史、未知骨病灶）**：
  - **整根受累骨 X 光＋病史 PE → 疑原發骨腫瘤或需規劃 → 全骨進階影像**。
  - **實驗室：CBC；CMP（肝酶、電解質、LDH、ALP → 惡性、Paget）；凝血（PT、PTT、INR）**；SPEP／UPEP 等。
  - **CT CAP＋全身 bone scan，或 FDG PET-CT**；🆕 **MM、甲狀腺、RCC 在 bone scan 可為冷**。
  - 🆕 **甲狀腺超音波、乳房攝影（乳癌）**。
  - 🆕 **單發骨病灶 → 考慮轉介骨腫瘤科＋影像引導 core 切片；其他部位有病灶 → 切最易取得處**。
  - 🆕 **確認組織診斷 → 多專科決策；若骨部位未切 → 手術時做 frozen 確認**。

### 2.4 常見臨床情境 🔄

| 情境 | 處置 |
|---|---|
| 🆕 **有癌史或現有癌、無已知轉移** | **走完整流程（可能為第二原發）** |
| 🆕 **已知內臟轉移＋新單發骨病灶** | **確認切片** |
| 🆕 **已知骨轉移＋新的相似邊界不清病灶** | **可安全視為已知轉移進展** |
| 🆕 **已完成病理骨折需固定（止痛、早期行走）** | **權衡及時診斷與早期安全固定 vs 若為原發骨肉瘤會汙染大範圍**；🆕 **已找到可能原發或已知轉移 → frozen 最終確認後 IM nail** |

- 🆕 **frozen 有限制（診斷工具、取樣、病理專業）→ 確定性規劃應較依賴最終 permanent 病理**。
- 🆕 **等待切片結果：長骨骨折可用有限內固定或 brace＋活動調整，代替確定性長 IM nail（2023）**。
- 脊椎轉移另有處置流程。

## 3. 病理機轉 🆕

- 🆕 **RANK-RANKL 交互作用 = 骨轉移病理核心**：正常骨微環境中 **osteoblast 分泌 RANKL → 結合 osteoclast 前驅細胞的 RANK → osteoclastogenesis → 骨吸收**；各原發腫瘤以不同方式劫持此系統。

| 原發 | 機轉 | 臨床意義 |
|---|---|---|
| 🆕 **乳癌** | **PTHrP → RANKL → 骨轉換 → osteocyte 釋放 TGF-β → 刺激更多 PTHrP → 骨破壞惡性循環** | 溶骨 |
| 🆕 **肺癌** | **類似，PTHrP 影響 RANKL** | 溶骨 |
| 🆕 **腎、甲狀腺** | **明顯血管新生（部分 VEGF）等** | 🆕 **術前栓塞減少失血** |
| 🆕 **MM、lymphoma** | **RANKL＋VEGF** | 溶骨 |
| 🆕 **攝護腺** | **endothelin-1 直接刺激 osteoblast 造骨** | **成骨（sclerotic）** |

## 4. 各癌別考量 🆕

### 4.1 乳癌 🆕

- 🆕 **通常晚期才轉移；只有約 5% 初診即轉移**；轉移時骨常見。
- 🆕 **只有骨轉移者預後優於內臟轉移**。
- 🆕 **受體**：**ER＋或 PR＋ → 較可能對內分泌治療反應；HER2＋ → 較侵襲，但可標靶（trastuzumab）**。
- 🆕 **ER＋ 不成比例地與骨轉移相關，帶骨轉移者壽命相對長**。

### 4.2 肺癌 🆕

- 🆕 **NSCLC 比 SCLC 更易骨轉移**。
- 🆕 **基因分型 → 針對特定致癌驅動的標靶治療與 ICI 已成標準**。
- 🆕 **2024 多中心回溯（573 名轉移 NSCLC 接受 ICI，42.4% 有骨轉移）：骨病灶對 ICI 反應比其他部位差 → 需額外介入**。
- 🆕 **即使全身反應良好，骨轉移仍可局部進展 → 多專科溝通**。

### 4.3 甲狀腺 🆕

- 🆕 **多數局限、長期存活佳；出現遠處轉移 → 5 年存活大幅下降**。
- 🆕 **follicular 比 papillary 更易骨轉移**。
- 🆕 **轉移處置：放射碘＋甲狀腺素抑制＋甲狀腺切除（若尚未）；寡轉移手術結果通常好**。

### 4.4 RCC 🆕

- 🆕 **約 1/3 初診即轉移；初診局限者 20–40% 會發生轉移，通常在診斷後 2 年內**。
- 🆕 **臨床行為與生物異質性高；clear cell 最常，其次 papillary**。
- 🆕 **傳統認為抗傳統放療、易局部進展與病理骨折**。
- 🆕 **單中心（43 人、13 年）：轉移 RCC 病灶內切除＋術中冷凍治療取代輔助放療 → 局部控制 100%、止痛良好**。
- 🆕 **多研究：單發轉移 RCC 完整切除 → 改善存活、減少局部進展**。
- 🆕 **VEGF tyrosine kinase inhibitors 與 ICI 改善結果；無病間隔較長 = 預後好（2023）**。

### 4.5 攝護腺 🆕

- 🆕 **多為 adenocarcinoma；骨轉移常見，但成骨 → 病理骨折相對少**。
- 🆕 **castrate-sensitive → ADT（限制睪固酮對腫瘤的合成作用）**。
- 🆕 **有症狀 castrate-resistant 轉移 → radium-223（2013 核准，結合成骨基質中的無機質）→ 改善整體存活、減少 SRE**。
- 🆕 **SRE（skeletal-related event）= 病理骨折、脊髓壓迫、需手術或放療的骨痛、高血鈣**。
- 🆕 **PSA 可長期追蹤；PSA 倍增時間 <6 個月 → 發生骨轉移風險增加**。

### 4.6 MM、lymphoma、melanoma 🆕

- 🆕 **MM：骨髓單株漿細胞疾病；lymphoma：可侵犯任何肌骨部位 → 兩者骨病灶對全身治療與放療反應佳**。
- 🆕 **MM 常接受 ASCT → 即將骨折的預防固定需與團隊協調時機**。
- 🆕 **Melanoma：傳統不列入常見骨轉移原發，但 11–17% 有骨轉移、存活持續改善**。
  - 🆕 **2024 多中心（481 名骨轉移 melanoma）：約一半 1 年內發生 SRE、1/3 病理骨折**。

## 5. 治療策略 🔄

### 5.1 決策要素 🆕

- 🆕 **多專科頻繁清楚溝通＋與病人誠實的共享決策**。
- 🆕 **五要素**：

| # | 要素 |
|---|---|
| **1** | **原發診斷與整體預後（含先前治療、復發）** |
| **2** | **受累骨的完整性與功能重要性** |
| **3** | **轉移負荷** |
| **4** | **骨病灶局部進展可能** |
| **5** | **症狀、痛、功能、社會支持、生活品質、可靠度、期待** |

- 🆕 **目標：止痛、優化功能與活動、減緩進展、監測骨骼機械穩定、預防骨折或 SRE**。

### 5.2 預後與存活估計 🆕

- 🆕 **即使專家多專科討論仍難預估（2024）**。
- 🆕 **預後差：內臟或腦轉移；肺、結直腸、膀胱癌的特定臨床特徵**。
- 🆕 **Sarcopenia（腹部 CT 橫切面肌肉衰減）→ 長骨轉移手術後 90 天與 1 年死亡率增加（2022）**。
- 🆕 **多種已驗證線上決策工具；SORG 機器學習預測存活，但全身治療快速演變 → 預測效能隨時間下降；可能高估脊椎 SRE 後存活（2024）**。
- 🆕 **依預期存活選擇（不過度、不不足）**：

| 預期存活 | 處置 |
|---|---|
| **<4–6 週** | **非手術** |
| **6 週–6 個月** | **微創但較不耐久（股骨幹 IM nail、股骨頸 hemiarthroplasty）** |
| **>6 個月** | **較耐久的重建（2023）** |

### 5.3 骨折風險預測 🔄

- 🆕 **impending pathologic fracture = 生理負荷下高急性病理骨折風險，除非預防固定**。
- ✅ **預防固定 vs 已完成骨折後固定：術後痛較少、恢復較快、併發症與成本較低、存活較好**。
- 主觀判斷困難（只放療止痛 vs 需加預防固定）→ 客觀評分。
- ✅ **Mirels criteria（部位、痛、X 光特徵、大小）→ ≥9 分建議預防固定**。
  - 🆕 **缺點：未考慮原發診斷與局部進展風險差異**。
- 🆕 **MM 專屬修正 → 敏感度提高；近端股骨加入病灶位置資訊 → 準確度提高（2023）**。
- 🆕 **無強證據顯示股骨 MRI 等進階影像可預測骨折風險**。

### 5.4 轉移負荷 🆕

- 🆕 **廣泛轉移通常不可治癒；寡轉移或單發 → 以達無病證據為目標處理**。
- 🆕 **oligometastatic 無共識定義，通常 ≤3–5 個轉移**；治癒性策略需全團隊與病人事先確認。
- 🆕 **例：RCC 單發或寡轉移於近端股骨 → 轉移切除＋重建改善長期存活**。
- 🆕 **synchronous（同時發現）vs metachronous（診斷後 ≥3 個月）**。
- 🆕 **其他原發的切除 vs 內固定 → MSTS 研究重點，計畫 RCT**。

## 6. 非手術處置 🆕

### 6.1 一般原則 🆕

- 🆕 **brace（例：肱骨病灶用 Sarmiento brace）**。
- 🆕 **保護步行、防跌，但嚴格限制活動可能有害 → 鼓勵安全、可控的運動（2024）**。
- 🆕 **多專科多模式止痛；長效止痛藥需團隊協調**。
- 🆕 **脊椎轉移多以 BMA、放療、全身治療非手術處理；手術保留給神經受損或機械不穩**。

### 6.2 骨修飾藥物（BMA）🆕

- 🆕 **所有骨轉移病人都應評估輔助 bisphosphonate 或 denosumab → 預防 SRE、減痛，部分改善存活**。

| | **Bisphosphonate（zoledronic acid、ibandronate、pamidronate）** | **Denosumab** |
|---|---|---|
| **機轉** | **被 osteoclast 吸收、破壞 mevalonate 合成 → 直接抑制骨吸收** | **抗 RANKL 單株抗體 → 間接抑制 osteoclastogenesis** |
| **共同** | **需牙科評估（罕見 ONJ）、長期 → 非典型股骨骨折、常需補維生素 D**；🆕 **近期證實每 12 週給藥（取代每 4 週）安全** | 同左 |
| **差異** | 腎毒性較需注意 | 🆕 **較貴、低血鈣、停藥後反彈骨折；但腎較安全、延後 SRE 與存活優於 bisphosphonate** |

- 🆕 **長期證據：乳、肺、castrate-resistant 攝護腺；近期研究：bisphosphonate 也減少轉移 RCC 與 medullary thyroid carcinoma 的 SRE**。
- 🆕 **無 drug holiday（防 AFF）或長期管理指引**。
- 🆕 **非典型近端股骨應力反應 → 考慮預防內固定（已完成骨折不癒合與延遲癒合率高，2023）**。

### 6.3 放療 🆕

- 🆕 **止痛機轉不明：部分為 DNA 損傷殺腫瘤，部分為改變局部微環境（osteoclast、osteoblast、化學介質）**。
- 🆕 **止痛可需 4–8 週**。
- 🆕 **單次 vs 多次：止痛相近，但多次分次 → 骨折風險較低（2024）**。
- 🆕 **EBRT = 標準；SBRT → 少分次、聚焦高劑量、毒性較低**。
  - 🆕 **SBRT 高效 → 可能使傳統「抗放療」腫瘤（甲狀腺、RCC、NSCLC）觀念過時**。
  - 🆕 **2024 共識：SBRT 為 RCC 骨寡轉移首選**。
- 🆕 **手術後應給輔助 EBRT 減少局部進展；盡量涵蓋整個病灶；長骨 IM nail 後應涵蓋全骨**。

### 6.4 經皮介入 🆕

- 🆕 **傳統：緩和止痛、改善機械穩定 → 現在擴展到寡轉移的局部控制**；也用於**不再適合放療或手術、放療後仍痛者**。
- 🆕 **影像引導經皮消融**：

| 類型 | 方式 |
|---|---|
| **熱** | **RFA、microwave ablation、HIFU** |
| **冷** | **cryoablation** |
| **血管** | **embolization** |

- 🆕 **證據有限：熱消融與放療的局部控制與止痛相近（2023）**。
- 🆕 **Electrochemotherapy**：**IV cytotoxic（cisplatin 或 bleomycin）＋經皮電極 electroporation → 減少腫瘤血流、藥物滯留較久、增加通透進入細胞內**；🆕 **不影響骨的成骨性與機械完整（不同於放療與熱消融，2023）**；多用於表淺，擴展到較深骨病灶。
- 🆕 **經皮骨水泥：脊椎 vertebroplasty、kyphoplasty；骨盆骨水泥＋內固定組合（2024）**。

### 6.5 確定性非手術 🆕

- 🆕 **無法承受手術生理負荷或長期復健 → 放療＋多模式止痛、BMA 優化骨健康、brace 或助行器促進安全步行**。

## 7. 手術處置 🔄

### 7.1 原則 🔄

- 🆕 **評估腫瘤局部進展風險；已完成病理骨折不會像非病理外傷骨折一樣癒合**。
- 🆕 **三類**：

| # | 類型 |
|---|---|
| **1** | **即將病理骨折內固定 ± 刮除與局部輔助** |
| **2** | **已完成病理骨折內固定 ± 刮除與局部輔助** |
| **3** | **即將或已完成病理骨折的切除＋重建** |

- 🆕 **是否刮除 debulk：依組織學與術前皮質破壞量；甲狀腺與 RCC 對輔助放療反應較差 → debulking 較有益**。
- ✅ **富血管腫瘤（甲狀腺、RCC、MM）→ 術前經皮栓塞**；🆕 **48–72 小時內手術（減少再血管化）**。
- 🆕 **切除保留給：單發轉移、寡轉移策略、RCC 等已證實切除比內固定有存活益處的組織**。
- 🆕 **已完成病理骨折內固定 → 併發症高：局部進展、不癒合、植入物失敗、感染、VTE、bone cement implantation syndrome**。

### 7.2 上肢與肩帶 🔄

- 🔄 **約 20% 骨轉移在上肢**。
- 🆕 **肩胛、鎖骨、橈骨、尺骨少見，多可非手術；acral（手足）轉移罕見，多為肺癌**。
- 🆕 **肱骨 = 第二常見受累長骨**；即將骨折通常痛；已完成骨折可妨礙使用助行器。
- 🆕 **證據弱；唯一（低等級）：近端肱骨重建時 reverse TSA 優於 conventional TSA 與 hemiarthroplasty（ROM、減少不穩）**。
- 🆕 **肱骨幹或幹骨幹（不涉肩肘關節）**：

| 選擇 | 特點 |
|---|---|
| **內固定** | **plate-and-screw、IM nail、photodynamic polymer fixation** |
| **病灶內刮除＋骨水泥＋內固定** | — |
| **en bloc 切除＋intercalary 金屬 prosthesis** | 🆕 **可防節段局部進展，但機械失敗高（多 aseptic loosening，2024）** |

- 🆕 **例：新診斷廣泛轉移 ER＋乳癌的肱骨幹病理骨折 → IM nail＋輔助放療＋全身治療 → 病灶癒合、骨重建**。
- 🆕 **肩或肘關節受累、或局部進展致先前固定失敗與骨量喪失 → endoprosthesis 或 APC（近端、遠端或全肱骨置換）；遠端肱骨 → 初次 TEA**；🆕 **短期存活、併發症高，但提供上肢功能與助行穩定**。

### 7.3 下肢 🆕

- 🆕 **股骨 = 轉移、MM、lymphoma 常見部位；依解剖區域決定**：

| 區域 | 處置 |
|---|---|
| **股骨頸（尤其合併退化）** | **切除＋關節置換** |
| **轉子周、轉子下** | **CMN**；🆕 **明顯局部進展或癒合差 → PFR 或 calcar-replacing arthroplasty** |
| **已完成骨折、先前 nail 周圍進展** | **切除＋置換**；🆕 **預期壽命長者即使感染風險較高也受益（2023）** |
| **骨幹** | **IM nail 或 intercalary 切除重建（2023）** |
| **遠端股骨幹骺或幹骨幹（未行 DFR）** | **刮除＋骨水泥增強＋nail 或 plate** |

- 🆕 **打破「保護整根股骨」教條**：長 stem 骨水泥置換與長 nail 可能不必要地增加手術複雜度與時間、翻修難度、心肺併發症（單灶時）。
  - 🆕 **無近端股骨病灶 → 股骨幹即將骨折可用 retrograde nail**。
  - 🆕 **無遠端病灶 → 轉子間即將骨折可用短 CMN；局部進展時較易轉 PFR**。
- 🆕 **髓內操作可能栓塞腫瘤的理論擔憂；2022：nail vs plate 或 arthroplasty → 肺轉移的發生或進展未增加**。

### 7.4 骨盆 🔄

- 🆕 **非負重部位多可非手術（放療、BMA）；常見骨通道內固定強化 → 改善生活品質與活動**。
- 🆕 **經皮 photodynamic nail**：安全微創緩和 → **減痛、減少鴉片、改善髖臼周缺損功能（2024）**；可單獨或配合 THA 強化；🆕 **可用於非包含性缺損（傳統骨水泥可能外滲傷及鄰近神經血管）**。
- 🆕 **經皮 cannulated screw 固定＋熱消融＋骨水泥＋輔助放療的各種組合 → 處理痛性髖臼周轉移或病理骨折**。
- 🆕 **傳統開放（破壞性髖臼周病灶）**：**resection arthroplasty、標準 THA、使用 revision 髖臼組件的 THA、Harrington 式 cement rebar 增強 THA、嚴重髖臼骨缺損用 pedestal cup 假體（2024）**。
- 🆕 **開放失血較多 → 保留給能承受較大手術者、寡轉移、預期長存活者**。

## 9. Key Study Points（OKU 15）

- **>40 歲、邊界不清的破壞性骨病灶：鑑別為轉移、骨髓瘤、淋巴瘤，以原發癌轉移最可能**。
- **骨轉移最常五種原發：乳、肺、甲狀腺、腎、攝護腺（BLT with a Kosher Pickle）**；病灶處置與局部進展可能依組織、病灶範圍與目前治療而定。
- **依情境可非手術或手術**；**BMA、放療、活動調整、影像監測**的組合常可作確定性治療。
- **即將病理骨折的手術處置**，比已完成骨折的處置**臨床結果較佳且更省成本**。
