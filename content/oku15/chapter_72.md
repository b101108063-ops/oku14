## 0. 考點變更總表

| 主題 | OKU 14 CH64 | OKU 15 Ch.72 | 類型 |
|---|---|---|---|
| 🆕 **旋轉變異** | — | 🆕 **foot progression angle = 股骨＋脛骨＋足總和**；🆕 **femoral version：俯臥或仰臥髖內外旋；內旋 > 外旋 → anteversion 較大；出生約 40°，8–10 歲前下降**；🆕 **tibial torsion：thigh-foot angle；出生約 5° 內旋 → 8 歲約 10–15° 外旋**；heel-bisector line；🆕 **中立 FPA 不代表各段正常（anteversion＋外旋脛骨 → 髕股壓力）**；步態退化 → 找潛在病；🆕 **影像通常不需；CT（輻射）、MRI（不需鎮靜者）、雙平面直立 slot scanning 越來越常用**；🆕 **安撫與觀察為主；殘餘扭轉與成人髖膝 OA 無關；PT 或 orthosis 不改變自然史**；🆕 **手術：接近成熟仍未改善、功能問題或嚴重外觀；股骨：近端或遠端截骨；脛骨：supramalleolar osteotomy；guided growth 控旋轉證據不足**；🆕 **股骨版本異常 → FAI、髖不穩、發育不良、髕骨不穩；脛骨扭轉 → 髕骨不穩、絆倒、步態力量下降；CP 與 spina bifida 合併無力影響更大** | 🆕 |
| **冠狀面發育** | MAD 正常 1–15 mm、理想 0 ± 3 mm、內側 >15 mm varus | 🔄 🆕 **出生 10–15° genu varum → 18–24 個月中立 → 3 歲約 10–15° valgus → 6–8 歲降到成熟時 7–8° valgus**；族群可有差異；🆕 **之後明顯改變 → 懷疑 physis 異常**；🆕 **股骨髁間距（varum）、內踝間距（valgum）**；🆕 **影像：站立全長片、patellae 朝前（減少旋轉扭曲）；找到變形處再加正交片看矢狀面**；✅ **機械軸（股骨頭中心 → 距骨中心）距膝中心 0–3 mm 理想；外側 → valgus；內側 >15 mm → varus**；🆕 **保守角色有限（除 infantile Blount brace）；guided growth（tension-band plate、transphyseal screw、hemiepiphysiodesis）vs 截骨（急性或漸進）** | 🔄 |
| **Genu valgum** | Cozen：初始 >4° 加同側腓骨骨折或內側幹骺 gap 須密追 | 🔄 🆕 **8 歲前視為生理性**；🆕 **病理：代謝、骨骼發育不良、先天肢差（外髁發育不全）、外側遠端股骨或外側近端脛骨 physis 傷**；🔄 **Cozen：持續臨床顯著變形風險低，近期研究反對常規 X 光篩檢；初始骨折處 valgus >4° 加內側幹骺 gap → 密追**；>8 歲排除他因 → 特發性；🆕 **orthotics、brace 不改變自然史**；🆕 **傳統手術適應：不可接受外觀或 MAD 超過外側脛骨平台；較輕者只在有痛或功能受限時（證據不支持會導致 OA）**；guided growth（遠端股骨及／或近端脛骨）或截骨；🆕 **中重度急性矯正 → peroneal nerve palsy** | 🔄 |
| **Genu varum** | — | 🆕 **嬰兒輕度 varus 約 1 歲最高 → 1.5–2 歲趨中立；>2 歲仍 varus → 非典型需檢查：持續生理性、rickets、骨骼發育不良、physis 傷、infantile Blount**；🆕 **2 歲後走向 valgus，3–4 歲最高，約 7 歲成人值**；之後改變少（除外傷、感染、adolescent Blount）；🆕 **系統評估：長度、各段長度、機械軸、遠端股骨與近端脛骨關節線角 → 找出變形骨**；🆕 **adolescent Blount 常合併遠端股骨 varus；infantile 常合併遠端股骨 valgus** | 🆕 |
| **Infantile Blount** | MDA ≤9° 95% 自癒；≥9° 95% 病理；約 50% 雙側 | 🔄 ✅ **<5 歲發病**；病因不明，推測易感者機械因素抑制後內 physis → 可形成 bar；🆕 **危險：早走、高 BMI、非裔與拉丁裔**；✅ **約半數雙側**；🆕 **PE：脛骨為中心 varum ± 屈曲與內旋、步態 lateral thrust**；X 光：varus ± procurvatum；🔄 **MDA <10° 可能自癒、>16° 可能進展、11–16° 密追**；✅ **Langenskiöld（幹骺 beaking → 內側幹骺缺損 → 內側 bar）**；🆕 **<3 歲、Langenskiöld 1–2 → brace（效果有爭議）或 guided growth（需 4 歲前完全矯正，否則常復發）**；🆕 **>3 歲或 3–6 期 → 脛骨截骨過矯 10–15°**；🆕 **年長或嚴重復發 → hexapod；高期別骨骺下陷 → hemiplateau elevation** | 🔄 |
| **Adolescent Blount** | — | 🆕 **>10 歲；肥胖、非裔**；機械過載抑制內側近端脛骨生長；🆕 **多單側、較常合併遠端股骨 varus、physis 與骨骺異常較輕**；🆕 **brace 無效 → 手術為主**；🆕 **hemiepiphysiodesis 可試，但失敗率較高（難以減負、內側 physis 不健康）；失敗因子：變形較重、BMI 較高、選 tension-band 時用 cannulated screws**；🆕 **較小變形、不需長度或旋轉矯正 → 急性截骨；嚴重多平面 → 截骨＋hexapod 漸進**；處理明顯遠端股骨 varus | 🆕 |
| **Juvenile Blount** | — | 🆕 **5–10 歲，特徵介於兩者**；依嚴重度、生長潛力、physis 傷選 guided growth、急性或漸進矯正 | 🆕 |
| 🆕 **先天肢差總論** | — | 🆕 **多為偶發；somatic mutation 影響肢體發育路徑（如 ZPA 的 Shh）；症候群或遺傳型多為 germline**；🆕 **同一肢體常多種差異並存**；🆕 **治療：功能肢體 → 重建 vs 截肢＋義肢，依最終差距、關節可重建性、能否無痛 plantigrade 足、家屬偏好** | 🆕 |
| **CFD** | — | 🆕 **1–2／100,000**；🆕 **包含 congenital short femur 到 PFFD；遠端股骨 valgus、股骨後傾、coxa vara、髖臼發育不良、長度不足、膝或髕骨不穩**；🆕 **約 50% 伴 fibular hemimelia；近 15% 雙側（較可能遺傳或 germline）**；🆕 **重度：漏斗狀大腿、髖屈曲外展外旋**；X 光預測最終差距；MRI 3D 規劃；🆕 **Aitken（股骨頭與髖臼；骨化延遲時不準）、Gillespie（A 足在對側脛骨中點以下、B 股骨 <50% 且髖不穩、C 只剩遠端股骨小段且無髖臼）、Paley（1A1 valgus、1A2 後傾、1A3 coxa vara；1B 骨化延遲：轉子下、頸、兩者；2A 可動股骨頭假關節、2B 融合股骨頭、2C 無股骨頭；3A 骨幹缺損膝可動、3B 膝僵；4 膝處遠端缺損）**；🆕 **Paley 1、2A → 關節重建（SUPERhip、SUPERknee）＋延長，或重建＋截肢義肢；2B、3 → pelvic support osteotomy、Paley sling 等救援＋延長 vs 截肢及／或融合** | 🆕 |
| **Fibular hemimelia** | — | 🆕 **1／40,000–135,000**；腓骨輕短至完全缺如；🆕 **脛骨前內彎、膝 valgus、膝韌帶不足不穩、踝 valgus、tarsal coalition、外側列缺如；脛骨彎頂皮膚凹陷；動態 valgus 或固定 equinovalgus；也有 clubfoot 變異**；🆕 **年幼 coalition 未骨化 → MRI**；🆕 **Birch：足可保留 = ≥3 rays；依腿長差從觀察、epiphysiodesis、延長到截肢＋延伸 orthosis；不可保留 → 截肢（除非上肢也有變形，保留足的功能）**；🆕 **Achterman-Kalamchi：1A 部分缺如穩踝、1B 缺 30–50% 不穩踝、2 腓骨缺如＋外側列缺＋重脛骨彎**；🆕 **Paley：1 穩踝、2 動態 valgus、3 固定 equinovalgus（踝、距下或兩者）、4 equinovarus**；🆕 **重建關鍵：無痛、穩定、plantigrade 足；Paley 1 → 延長；2 → SHORDT（縮短＋重排脛骨恢復腓骨支撐）；3 → SUPERankle**；膝不穩比 CFD 少；常需 guided growth 矯 genu valgum | 🆕 |
| **Tibial hemimelia** | — | 🆕 **最罕見：1／1,000,000；較常伴遺傳症候群**；🆕 **從脛骨輕短 → 近端脛骨缺如＋無伸肌 → 脛腓分離＋踝不穩**；腓骨頭突出、固定 equinovarus、🆕 **preaxial polydactyly**、膝屈曲攣縮；🆕 **關鍵：伸肌機制是否完整**；MRI 看未骨化軟骨 anlage；🆕 **Jones（嚴重度遞減）：1a 全缺、1b 未骨化 anlage、2 近端正常遠端缺、3 遠端有近端缺、4 遠端脛腓分離**；🆕 **Paley（嚴重度遞增）1–5**；🆕 **有伸肌 → 延長到 fibular transfer；無伸肌 → 目前標準為膝離斷＋義肢** | 🆕 |
| **Posteromedial bowing** | 平均內彎 43°、後彎 35°；生長抑制 14% | 🔄 🆕 **子宮內擺位、後內頂點、calcaneovalgus 足、肢體短；無遺傳傾向**；足變形可真實或表觀；🆕 **第一年快速改善；4 歲後自癒有限**；🆕 **持續變形少，可踝 hemiepiphysiodesis 或罕見截骨**；🆕 **最常需手術的是腿長差（與初始變形相關）：epiphysiodesis 或延長；>50% 需手術處理腿長差**；年長角度＋長度並存 → 截骨＋nail 或 frame 漸進延長 | 🔄 |
| **Anterolateral bowing 與 CPT** | 50% 伴 NF1 | 🔄 🆕 **1／150,000–200,000**；🆕 **骨膜 hamartomatous 病灶 → 破骨／成骨失衡 → 彎曲 → 骨折；「congenital」pseudarthrosis 其實為病理組織骨折後發生 → 名稱不當**；骨折後不癒合、骨端萎縮；🔄 **50–80% CPT 病人有 NF1；NF1 病人中 2–10% 有前外彎**；🆕 **查 NF 徵象、轉介遺傳**；🆕 **舊分類不太指導治療；最重要：有無骨折或假關節，以及初次骨折年齡（越早越差）**；🆕 **傳統 brace 防骨折（不矯正、須至成熟）；🆕 guided growth 可矯正並降低骨折風險**；🆕 **Paley cross union：diphosphonate 前處理、廣泛切除、骨與骨膜植入形成 synostosis、穩定固定 → 癒合率佳、防再骨折**；diphosphonate 圍術期；多次失敗 → 截肢 | 🔄 |
| **Clubfoot** | 約 1／1,000、男多、50% 雙側 | ✅ **1／1,000；midfoot cavus、forefoot adductus、hindfoot varus、equinus（CAVE）＋細腿；男多、約 50% 雙側**；🆕 **伴 spina bifida、arthrogryposis、amniotic band → 結果較差**；🆕 **complex clubfoot：第一蹠骨短、嚴重蹠屈、僵硬 equinus、深後內皺褶 → 復發較高**；✅ **Ponseti（每週石膏 3–6 次 → Achilles tenotomy → 外展 brace）或 French method（PT）**；🆕 **brace 時間有爭議；4–5 歲後復發風險下降**；🆕 **復發：先再石膏；未走 → 變形與僵硬復發；會走 → equinus 或步態動態 supination**；✅ **TATT 至外側（最常 lateral cuneiform）**；🆕 **避免關節內手術；嚴重復發可能需 posterior 或 posteromedial release；年長 → valgus calcaneal osteotomy、hindfoot arthrodesis、ex-fix**；🆕 **flat-top talus 致背屈受限 → 前遠端脛骨 hemiepiphysiodesis 或 supramalleolar osteotomy（2023）** | 🔄 |
| **CVT** | — | 🔄 🆕 **1／10,000；rocker-bottom；navicular 自 talus 背外脫位；equinus、hindfoot valgus、forefoot 背屈與外展**；🆕 **常伴他病 → 詳細檢查與遺傳轉介**；🆕 **鑑別：calcaneovalgus foot（柔軟、無僵硬 equinus）、oblique talus（後足可動）**；🆕 **強制蹠屈側位：oblique talus → 距骨與第一蹠骨軸連續；CVT → 中斷**；🆕 **由大範圍 release、舟骨切除、距下融合 → 微創：蹠屈內翻連續石膏 → pin TN＋Achilles tenotomy → brace；特發與症候群型皆有效，症候群型較易復發** | 🔄 |
| **Tarsal coalition** | — | 🔄 纖維、軟骨或骨性；痛或反覆扭傷、後中足 ROM 減少、僵硬扁平足；✅ **CN（斜位、anteater sign）與 TC（側位 C sign）最常**；CT、MRI 確認與範圍、排除其他；🆕 **保守：固定、orthotics、NSAID、PT、鞋、活動調整**；🆕 **切除依關節受累範圍與無關節炎；脂肪或肌肉插入防復發；切除失敗或累及大部分距下 → 融合**；🆕 **3D 切割導板、關節鏡切除、CT 導航** | 🔄 |
| **Cavovarus** | 挽救手術只有 58% 良好（Wicart-Seringe） | 🔄 🆕 **第一列蹠屈、縱弓過高、後足 varus**；🆕 **單側 → 懷疑脊髓內病變 → MRI；雙側進行性 → HMSN（CMT）→ 神經科（2024）**；病史：外側過載痛、應力骨折、扭傷、足位改變、感覺運動、家族；PE：高弓、前足與第五蹠骨外側胼胝、爪趾、後足 varus；✅ **Coleman block：後足 varus 矯正 → 由 cavus 驅動（只處理 cavus 即可）；不矯正 → 後足本身病變**；負重 X 光：calcaneal pitch、Meary、metatarsal stacking、drive-through sign；🆕 **保守：凹陷第一列並墊高外側的 orthosis**；🆕 **手術：plantar fascia release、肌腱轉移、截骨、融合**；🆕 **生長足夠 → 第一蹠骨背側 hemiepiphysiodesis＋plantar fascia release（改善 heel varus、胼胝、功能）** | 🔄 |
| 🆕 **Flatfoot** | — | 🆕 **多出生即有；縱弓發育與 orthotics 或矯正鞋無關**；🆕 **柔性：非負重或踮腳時足弓重現；僵硬或 rocker-bottom → 神經肌肉或 CVT**；檢查 equinus、後足僵硬（coalition）、posterior tibial tendon；🆕 **負重片：AP navicular 在 talus 周圍外展；側位 Meary angle 頂點向蹠側（正常中立）；calcaneal pitch；查 coalition、CVT、accessory navicular、關節炎**；🆕 **無症狀 → 安撫；2022 SR：orthotics 不優於病人自選鞋**；🆕 **手術：持續頑固痛、鞋或 orthotics 無效、無法調整活動；內側胼胝、內弓痛、calcaneofibular abutment**；Achilles 延長、lateral column lengthening、medial column osteotomy、TN imbrication＋PTT advancement、距下融合；結果難評估 | 🆕 |
| 🆕 **Juvenile hallux valgus** | — | 🆕 **拇趾外偏＋第一蹠骨內偏，頂點在第一 MTP**；內側突起痛、鞋加重、bursa 或胼胝；🆕 **問家族史與過度鬆弛（Ehlers-Danlos、Marfan）**；🆕 **負重片；juvenile vs adult：DMAA（正常 <10°）；DMAA 增加 = juvenile hallux valgus 的 hallmark**；🆕 **保守為主：寬或高 toe box；趾間墊與副木不矯正但可緩解症狀**；🆕 **手術盡量延後：早期手術復發與僵硬高；physis 未閉 → 可過矯成 hallux varus**；無最佳術式共識（蹠骨截骨） | 🆕 |

## 1. 旋轉變異 🆕

### 1.1 評估 🆕

- 🆕 **foot progression angle（步態中足內外向）= 股骨、脛骨、足三段的總和**。
- 🆕 **Femoral version**（股骨頸與遠端股骨 transcondylar axis 的軸向夾角）：
  - 臨床：**仰臥或俯臥、骨盆水平，量髖內外旋；內旋弧 > 外旋 → anteversion 較大**。
  - 🆕 **出生約 40°，通常在 8–10 歲前下降**。
- 🆕 **Tibial torsion**（近遠端脛骨關節面的旋轉關係）：
  - 臨床：**thigh-foot angle**（仰臥或俯臥，膝屈、踝中立）。
  - 🆕 **出生約 5° 內旋 → 生長中轉外旋，8 歲約 10–15°**。
- 病史：疼痛、行走、平衡；絆倒需依步態發育階段判讀；🆕 **步態退化 → 懷疑潛在疾病**。
- PE：**髖旋轉 ROM、thigh-foot angle、heel-bisector line、步態 FPA**。
- 🆕 **中立 FPA 不代表各段正常**：如 **femoral anteversion＋external tibial torsion → FPA 中立，但增加髕股關節壓力**。
- 🆕 **影像通常不需**：CT（量化，輻射）；MRI（可不鎮靜者）；🆕 **雙平面直立 slot scanning（兼顧兩者）越來越流行**。

### 1.2 處置 🆕

- 🆕 **安撫與觀察為主（自然史隨生長改善）**。
- 🆕 **殘餘扭轉與成人膝或髖 OA 無關**。
- 🆕 **PT 或 orthosis 不改變扭轉發育自然史** → 應告知家屬。
- 🆕 **手術**：典型發育兒，**接近骨骼成熟仍未改善**，且有功能問題或嚴重外觀異常。
  - 適應：髖及／或膝痛或功能障礙、步態偏差。
  - 🆕 **股骨版本異常 → FAI、髖不穩、髖發育不良、髕骨不穩**。
  - 🆕 **脛骨扭轉 → 髕骨不穩、絆倒、步態力量產生下降**。
  - 🆕 **神經肌肉病（spina bifida、CP）合併肌無力 → 異常扭轉影響更大**。
- 🆕 **術式**：
  - **股骨：截骨＋固定，近端或遠端（依偏好，或同時矯冠狀面）**。
  - **脛骨：supramalleolar osteotomy 為主**。
  - 🆕 **guided growth 控制旋轉：興趣增加但需更多證據**。

## 2. 膝冠狀面 🔄

### 2.1 正常發育 🔄

| 年齡 | 對位 |
|---|---|
| **出生** | 🆕 **10–15° genu varum**（約 1 歲最高） |
| **18–24 個月** | **中立** |
| **3 歲（3–4 歲最高）** | 🆕 **約 10–15° valgus** |
| **6–8 歲（約 7 歲）** | 🆕 **降至成熟值：平均 7–8° valgus** |

- 族群間可有差異；🆕 **之後明顯改變 → 懷疑 physis 異常或其他疾病**。
- 病史：對位變化、影響骨或 physis 的疾病、身高、營養、外傷或感染等 physis 傷。
- PE：靜態與動態、負重與非負重；🆕 **股骨髁間距（varum）、內踝間距（valgum）**；同時評估旋轉、矢狀面與腿長差。

### 2.2 影像 🔄

- 🆕 **站立全長下肢片、patellae 朝前（減少旋轉扭曲）**。
- 評估：機械軸、變形位置、physis 異常、腿長差；🆕 **找到變形處 → 加該段正交片評估矢狀面**。
- ✅ **機械軸：股骨頭中心 → 距骨中心**：

| 機械軸位置 | 意義 |
|---|---|
| **膝中心 0–3 mm** | **理想** |
| **偏外** | **valgus** |
| **偏內 >15 mm** | **varus** |

### 2.3 治療原則 🔄

- 🆕 **保守角色有限（除 infantile Blount 的 brace）**。
- **生長足夠 → guided growth（tension-band plating、transphyseal screws、hemiepiphysiodesis）**。
- **生長不足或成熟 → 截骨（急性或漸進）**。

### 2.4 Genu valgum 🔄

- 🆕 **8 歲前視為生理性**。
- 🆕 **病理原因**：**代謝、骨骼發育不良、先天肢差（外側股骨髁發育不全）、外側遠端股骨或外側近端脛骨 physis 傷**。
- 🔄 **Cozen phenomenon**：近端脛骨幹骺骨折後晚發 valgus；🆕 **持續臨床顯著 genu valgum 風險低，近期研究反對常規 X 光篩檢**；🔄 **初始骨折處 valgus >4° 且有內側幹骺 gap → 風險較高、需密追**。
- >8 歲排除其他 → **特發性**。
- 🆕 **orthotics 或 brace 不改變自然史**。
- 🆕 **手術適應**：傳統為**不可接受的外觀變形，或機械軸偏到外側脛骨平台以外**；🆕 **較輕者只在合併疼痛或功能受限時（證據不支持會導致 OA）**。
- 術式：**遠端股骨及／或近端脛骨 guided growth，或截骨（急性或漸進）**；🆕 **中重度急性矯正 → 考慮 peroneal nerve palsy 風險**。

### 2.5 Genu varum 🆕

- 🆕 **嬰兒輕度 varus 約 1 歲最高 → 1.5–2 歲趨中立**。
- 🆕 **>2 歲仍 varus → 非典型需檢查**：**持續生理性 varus、rickets、骨骼發育不良、physis 傷、infantile Blount**。
- 2 歲後多走向 valgus（3–4 歲最高）→ 約 7 歲成人值；之後少變，除非 physis 傷（外傷、感染、adolescent Blount）。
- 🆕 **系統性評估**：直接與間接肢長、各段長度、機械軸、遠端股骨與近端脛骨關節線角 → 找出變形骨。
  - 🆕 **Blount 通常在脛骨；adolescent Blount 常合併遠端股骨 varus，infantile 則合併遠端股骨 valgus**。

### 2.6 Blount disease 🔄

#### Infantile（<5 歲）🔄

- 病因不明；推測**易感者的機械因素抑制後內側 physis 生長 → 可進展為 bar**。
- 嚴重變形、早期關節炎、步態受損、明顯失能。
- 🆕 **危險因子：早走、同齡 BMI 高、非裔或拉丁裔**；✅ **約半數雙側**。
- 🆕 **PE：以脛骨為中心的 genu varum，常伴屈曲與內旋變形；步態 lateral thrust**。
- X 光：脛骨 varus ± procurvatum。
- 🔄 **Metaphyseal-diaphyseal angle（MDA）預測進展**：

| MDA | 意義 |
|---|---|
| **<10°** | **可能自行緩解** |
| **11–16°** | **需密切觀察** |
| **>16°** | **可能進展** |

- ⚠️ OKU 14：**≤9° 95% 自癒、≥9° 95% 病理且進行**。
- ✅ **Langenskiöld**：幹骺 beaking 增加 → 內側幹骺缺損 → 內側 physeal bar；定義嚴重度並指導治療。
- 🆕 **治療**：

| 情況 | 處置 |
|---|---|
| **<3 歲、Langenskiöld 1–2** | **brace（效果有爭議）**；或 **guided growth（需 4 歲前完全矯正，否則常復發）** |
| **>3 歲或 Langenskiöld 3–6** | **脛骨截骨，過矯 10–15°**（減負異常 physis、預期部分復發） |
| **年長或嚴重復發** | **hexapod frame** |
| **高期別＋骨骺下陷** | **hemiplateau elevation 恢復關節線** |

#### Adolescent（>10 歲）🆕

- 🆕 **危險因子：肥胖、非裔**；推測**機械過載 → 內側近端脛骨生長抑制**。
- 🆕 **多單側；較常合併遠端股骨 varus；physis 與骨骺異常較輕**。
- 🆕 **brace 無效 → 手術為主**：
  - **有生長潛力 → hemiepiphysiodesis（guided growth）**；🆕 **失敗率較其他疾病高（難減負、內側 physis 可能不健康）→ 告知可能再手術**。
  - 🆕 **失敗危險因子：變形較重、BMI 較高、選用 tension-band 技術時使用 cannulated screws**。
  - 🆕 **較小變形、不需長度或旋轉矯正 → 急性截骨**。
  - 🆕 **嚴重多平面 → 截骨＋hexapod 漸進矯正**。
  - 明顯遠端股骨 varus 也需處理。

#### Juvenile（5–10 歲）🆕

- 🆕 **較少見，特徵介於 infantile 與 adolescent**；依嚴重度、生長潛力、physis 傷選擇 guided growth、急性矯正或 frame 漸進矯正。

## 3. 先天肢體差異 🆕

### 3.1 總論 🆕

- 罕見，推測為肢體胚胎發生的錯誤；🆕 **多為偶發**。
- 🆕 **主流理論：somatic mutation 影響肢體發育路徑（如 ZPA 的 Shh 訊號）；症候群或遺傳型多為 germline mutation**。
- 🆕 **同一肢體常有多種差異並存、互相關聯**。
- 🆕 **治療目標：功能肢體 → 肢體重建 vs 截肢＋義肢**；決定因素：**最終差距大小、關節可重建性、能否形成無痛 plantigrade 足、家屬與病人偏好**。

### 3.2 Congenital femoral deficiency（CFD）🆕

- 🆕 **1–2／100,000 出生**。
- 🆕 **光譜：congenital short femur → proximal femoral focal deficiency（PFFD）**。
- 🆕 **表現：遠端股骨 valgus、股骨後傾、coxa vara、髖臼發育不良、長度不足、膝及／或髕骨不穩**；最重：無髖關節、近端股骨，甚至整根股骨。
- 🆕 **約 50% 伴 fibular hemimelia；近 15% 雙側（較可能遺傳或 germline）**。
- 🆕 **臨床**：輕者只有長度不足或輕度 valgum 或後傾；🆕 **重者：漏斗狀大腿、髖固定在屈曲外展外旋**；評估髖膝 ROM 與穩定。
- X 光多足以診斷、預測最終差距；**MRI → 3D 規劃與分類**。
- 🆕 **分類**：

| 分類 | 要點 |
|---|---|
| **Aitken** | 股骨頭有無＋髖臼缺損程度；**骨化延遲時股骨頭評估不準** |
| **Gillespie** | **A：足在對側脛骨中點以下；B：股骨 <50% 對側、髖多不穩；C：只剩遠端股骨小段、無髖臼** |
| 🆕 **Paley（目前較流行，可指導治療）** | **1A：近端骨化正常＋長度不足 ± valgus（1A1）、後傾（1A2）、coxa vara（1A3）**；**1B：骨化延遲：轉子下（1B1）、頸（1B2）、兩者（1B3）**；**2：假關節＋可動股骨頭（2A）、融合股骨頭（2B）、無股骨頭（2C）**；**3：骨幹缺損＋膝可動（3A）或膝僵（3B）**；**4：膝處遠端缺損** |

- 🆕 **治療**：

| Paley | 處置 |
|---|---|
| **1、2A** | **不同程度關節重建（SUPERhip、SUPERknee）＋延長；或關節重建＋截肢義肢**（依差距與家屬偏好） |
| **2B、3** | **救援型手術（pelvic support osteotomy、Paley sling procedure）＋延長，或截肢及／或融合後義肢**（個別化） |

### 3.3 Fibular hemimelia 🆕

- 🆕 **1／40,000–135,000**。
- 腓骨輕微縮短到完全缺如。
- 🆕 **表現：肢段短、脛骨前內彎、膝 valgus、膝韌帶不足致不穩、踝 valgus、tarsal coalition、外側足列缺如**；PE：腿長差、**脛骨彎頂皮膚凹陷**、踝或後足**動態 valgus 或固定 equinovalgus**；亦有 clubfoot 變異；評估足柔軟度與膝穩定。
- 影像：全長片（目前與預測最終差距、genu valgum、踝 valgus、脛骨彎）；足片（外側列缺、equinovalgus、距下 coalition）；🆕 **年幼骨化不足 → MRI 判斷 coalition 與分類**。
- 🆕 **分類**：

| 分類 | 要點 |
|---|---|
| **Birch** | **足可保留 = ≥3 rays**；可保留 → 依腿長差：觀察、epiphysiodesis、延長，甚至大差距時截肢＋延伸 orthosis；**不可保留 → 截肢**（除非同時有上肢變形而需保留足功能） |
| **Achterman-Kalamchi** | **1A：部分缺如、踝穩；1B：缺 30–50%、踝不穩；2：腓骨缺如＋外側列缺＋較重脛骨彎** |
| 🆕 **Paley** | **1：踝穩；2：動態踝 valgus；3：固定 equinovalgus（踝、距下或兩者）；4：equinovarus** |

- 🆕 **重建成功的關鍵：無痛、穩定、plantigrade 足**；一般包括重排、延長、± 對側 epiphysiodesis；做不到 → 足截肢＋義肢。

| Paley | 重建 |
|---|---|
| **1** | **單純延長** |
| **2** | 🆕 **SHORDT：縮短並重排脛骨，恢復腓骨的支撐功能** |
| **3** | 🆕 **SUPERankle：踝與距下全面重排＋矯正脛骨彎＋延長** |

- 🆕 **膝不穩症狀比 CFD 少見，但延長時需監測；常見 genu valgum 需 guided growth**。

### 3.4 Tibial hemimelia 🆕

- 🆕 **最罕見：1／1,000,000；較可能伴遺傳症候群**。
- 🆕 **光譜：脛骨輕短 → 近端脛骨缺如＋無膝伸肌 → 脛腓分離＋踝不穩**。
- 表現：肢段短、**腓骨頭突出** ± 前外彎；🆕 **足常固定 equinovarus，可有 preaxial polydactyly**；不同程度**膝屈曲攣縮**。
- 🆕 **關鍵：伸肌機制是否完整 → 決定治療**。
- X 光多可診斷；**MRI 看解剖、分類、有無未骨化軟骨 anlage**。
- 🆕 **Jones（嚴重度遞減）**：

| Type | 定義 |
|---|---|
| **1a** | **脛骨完全缺如** |
| **1b** | **未骨化 anlage** |
| **2** | **近端脛骨正常、遠端缺如** |
| **3** | **遠端存在、近端缺如** |
| **4** | **遠端脛腓分離（diastasis）** |

- 🆕 **Paley（嚴重度遞增）**：1 縱向缺損 ± genu valgum；2 近遠端存在但踝發育不良；3 膝與近端脛骨、內踝存在但遠端 plafond 缺；4 無遠端脛骨；5 完全無脛骨。
- 🆕 **治療**：
  - **有伸肌 → 依缺損與解剖：從單純延長到 fibular transfer（遠端脛骨缺如）**。
  - **無伸肌 → 目前標準：膝離斷＋義肢**（新重建技術發展中）。

## 4. 脛骨彎曲 🔄

### 4.1 Posteromedial bowing 🔄

- 🆕 **推測子宮內擺位 → 頂點後內的彎曲、calcaneovalgus 足、肢體短；無已知遺傳傾向**。
- 足變形可為真實，或因脛骨彎曲造成的表觀。
- 出生即明顯；足呈背屈外翻；X 光確認。
- 🆕 **第一年快速改善；4 歲後自然矯正有限**。
- 🆕 **4 歲仍持續少見 → 踝 hemiepiphysiodesis 或罕見截骨**。
- 🆕 **最常需手術的是持續腿長差**（與初始變形相關）→ **epiphysiodesis 或延長**；🆕 **>50% 需手術處理腿長差**。
- 年長角度與長度並存 → **截骨＋nail 或 frame 漸進延長**。

### 4.2 Anterolateral bowing 與 congenital pseudarthrosis of the tibia（CPT）🔄

- 🆕 **1／150,000–200,000**。
- 🆕 **病理：局部脛骨發育不良，骨膜 hamartomatous 病灶 → 破骨／成骨失衡 → 骨變弱 → 彎曲 → 骨折**。
- 🆕 **「congenital」pseudarthrosis 為誤稱：假關節不是先天的，而是病理組織骨折後才發生**；骨折後異常骨膜阻止癒合 → 假關節與骨端萎縮。
- 🔄 **50–80% 前外彎與 CPT 病人有 NF1；NF1 病人中 2–10% 有前外彎**。
- 嬰兒期出現；🆕 **評估 NF 徵象並轉介遺傳**。
- 🆕 **舊分類多無法指導治療或預測；最重要：有無骨折或假關節，以及初次骨折年齡（越年幼預後越差）**；病灶組織不會癒合。
- 🆕 **治療**：

| 情況 | 處置 |
|---|---|
| **彎曲、無骨折** | **傳統 brace 防骨折或進展（不矯正，需持續到成熟）**；🆕 **guided growth：可矯正並降低骨折風險 → 成功者不進展為假關節** |
| **骨折或假關節** | 多種方法成效有限；🆕 **Paley cross union：diphosphonate 前處理＋廣泛切除病理組織＋骨與骨膜植入形成 synostosis＋穩定固定 → 癒合率佳、防再骨折** |
| **多次手術失敗** | **截肢＋義肢** |

- 目標：**移除 hamartomatous 組織、形成穩定寬廣的癒合骨基底抗再骨折**；🆕 **diphosphonate 圍術期改善骨轉換失衡**。

## 5. 足部疾病 🔄

### 5.1 Clubfoot 🔄

- ✅ **1／1,000；midfoot cavus、forefoot adductus、hindfoot varus、hindfoot equinus＋細腿**；✅ **男多、約 50% 雙側**。
- 多特發；🆕 **伴 spina bifida、arthrogryposis、amniotic band → 結果較差**。
- 🆕 **complex clubfoot：第一蹠骨短、嚴重蹠屈、僵硬 equinus、深後方與內側皺褶 → 復發率較高**。
- ✅ **嬰兒標準：連續操作 — Ponseti（每週石膏）或 French method（PT 取代石膏）**。
- ✅ **Ponseti：每週石膏（常 3–6 次）→ Achilles tenotomy（門診或開刀房）→ 外展 brace**；全球最常用，已大致取代 posteromedial release。
- 🆕 **brace 時間有爭議；復發風險隨年齡下降，尤其 4–5 歲後**。
- 🆕 **復發**：
  - 先**再石膏**。
  - 🆕 **未會走：變形與僵硬復發；會走：equinus 或步態中動態 supination = 早期復發**。
  - ✅ **動態 supination → tibialis anterior tendon transfer 至外側（最常 lateral cuneiform）**。
  - 🆕 **個別處理各變形成分，盡量避免關節內手術；嚴重復發可能需 posterior 或 posteromedial release**。
  - 🆕 **接近成熟 → valgus-producing calcaneal osteotomy、hindfoot arthrodesis、ex-fix**。
- 🆕 **flat-top talus 與背屈受限 → 使遠端脛骨背屈：前方遠端脛骨 hemiepiphysiodesis 或 supramalleolar osteotomy（2023）**。

### 5.2 Congenital vertical talus（CVT）🔄

- 🆕 **1／10,000**；嬰兒 **rocker-bottom**。
- 🆕 **navicular 自 talus 脫位 → 中足相對後足在背外側**；伴 **equinus、hindfoot valgus、forefoot 背屈與外展**。
- 🆕 **常伴其他疾病 → 詳細 PE，考慮遺傳轉介**。
- 🆕 **鑑別**：

| 疾病 | 後足 | 強制蹠屈側位（距骨軸 vs 第一蹠骨） |
|---|---|---|
| **Calcaneovalgus foot** | 柔軟、無僵硬 equinus | — |
| **Oblique talus** | **可動** | **連續** |
| **CVT** | **僵硬固定** | **中斷（navicular 持續脫位）** |

- 嬰兒 navicular 未骨化 → 以**第一蹠骨與距骨軸的共線性**判斷。
- 🆕 **治療演變：大範圍 release、舟骨切除、距下融合 → 微創**：
  - **溫和蹠屈＋內翻連續石膏（拉軟組織、讓 navicular 對回距骨頭）→ 手術 pin TN 關節＋Achilles tenotomy → brace**。
  - 🆕 **特發與症候群型都有效；復發仍是挑戰，尤其症候群型**。

### 5.3 Tarsal coalition 🔄

- 兩骨間異常連結：**纖維、軟骨或骨性**。
- 表現：**痛或反覆踝扭傷（足僵硬）**；後足或中足 ROM 減少；可為僵硬扁平足。
- ✅ **最常：calcaneonavicular（斜位最佳、anteater sign）與 talocalcaneal（側位 C sign）**。
- **CT、MRI**：確認（尤其未完全骨化）、評估範圍、排除其他 coalition。
- 🆕 **保守：固定、orthotics、NSAID、PT、鞋、活動調整**。
- 🆕 **手術**：
  - **切除：依關節受累範圍與無關節炎**；**脂肪或肌肉插入防復發**。
  - **融合：切除失敗，或累及大部分距下關節**。
  - 🆕 **完整切除困難 → 3D 切割導板、關節鏡切除、CT 導航**。

### 5.4 Cavovarus foot 🔄

- 🆕 **第一列蹠屈、縱弓過高、後足 varus**。
- 🆕 **單側 → 懷疑潛在神經異常（脊髓內病變）→ 考慮 MRI**。
- 🆕 **雙側進行性 → HMSN（如 Charcot-Marie-Tooth）→ 轉神經科（2024）**。
- 病史：外側過載足痛、應力骨折、踝扭傷、足位改變、感覺運動改變、家族史。
- PE：高內弓、前足蹠側胼胝、第五蹠骨外側胼胝、爪趾、後足 varus。
- ✅ **Coleman block test**：墊高足跟與外側柱 → **後足 varus 矯正 → 由 cavus（前足）驅動 → 只處理 cavus 即可**；**不矯正 → 後足本身病變**。
- 負重 AP、斜位、側位：**calcaneal pitch、Meary angle、metatarsal stacking**；**drive-through sign（距下關節正面可見）**。
- 🆕 **保守：凹陷第一列、墊高外側的 orthosis（後足柔軟時）**。
- 🆕 **手術**：依成分、程度、柔軟度 → **plantar fascia release、肌腱轉移平衡、截骨（僵硬）、融合**；目標改善對位與著地。
- 🆕 **生長足夠的兒童：第一蹠骨背側 hemiepiphysiodesis＋plantar fascia release → 改善 heel varus、蹠側胼胝與功能（較微創）**。

### 5.5 Flatfoot 🆕

- 🆕 **家屬常見擔憂；多數出生即有；需了解足弓自然發育**。
- 🆕 **內側縱弓發育與 orthotics 或矯正鞋無關**。
- 病史：足位變化、家族類似、症狀。
- PE：負重與非負重；內側中足距地高度、內側胼胝、足相對脛骨外旋；踝與後足 ROM（**equinus 攣縮、後足僵硬 → coalition**）；平衡與 posterior tibial tendon 肌力。
- 🆕 **柔性扁平足：非負重或主動蹠屈（heel rise）時足弓重現**；🆕 **僵硬扁平足或僵硬 rocker-bottom → 懷疑神經肌肉病或 CVT**。
- 🆕 **負重 X 光**：
  - **AP：navicular 在 talus 周圍外展**。
  - **側位：Meary angle（距骨軸與第一蹠骨）頂點向蹠側；正常足弓為中立**；calcaneal pitch。
  - 查 **coalition、CVT、accessory navicular、關節炎**。
- 🆕 **無症狀 → 安撫：屬可視為正常的足型，多不致功能限制**；🆕 **2022 SR（證據品質低）：orthotics 不優於病人自選鞋**。
- 🆕 **手術適應與時機有爭議**：保留給**持續頑固疼痛、鞋或 orthotics 無效、無法調整活動者**；典型有**內側胼胝、內弓痛、及／或 calcaneofibular abutment**。
- 🆕 **術式**：**Achilles 延長、lateral column lengthening、medial column osteotomy、TN imbrication＋posterior tibial tendon advancement、距下融合**；技術多樣、結果難評估。

### 5.6 Juvenile hallux valgus 🆕

- 🆕 **拇趾外偏＋第一蹠骨內偏，頂點在第一 MTP**；症狀或外觀求診。
- 痛在第一蹠骨頭內側突起，鞋加重 → bursa 發炎或內側胼胝。
- 🆕 **病史：家族史、過度鬆弛症候群（Ehlers-Danlos、Marfan）**。
- 🆕 **負重片定義頂點**；🆕 **juvenile vs adult bunion 的差別：distal metatarsal articular angle（DMAA）**：
  - 正常 **<10°**；🆕 **DMAA 增加（關節相對骨幹 varus）= juvenile hallux valgus 的 hallmark**。
- 🆕 **保守為主**：**較寬或較高 toe box**；🆕 **趾間墊與副木無法矯正變形，但可緩解症狀**。
- 🆕 **手術盡量延後：早期手術復發與僵硬率高；physis 未閉時可能過矯成 hallux varus**。
- 🆕 **最佳術式無共識（多為蹠骨截骨重排關節）**；復發與術後僵硬仍是挑戰。

## 7. Key Study Points（OKU 15）

- **了解下肢正常發育的自然史**是評估與治療的關鍵。
- **先天肢差常合併多種變形** → 不論重建或截肢，都需長期追蹤與處理。
- **Hemiepiphysiodesis 是生長中兒童可修正下肢變形的有力工具**。
- **Clubfoot 或 CVT**：現代建議為**連續石膏＋有限軟組織 release**。
- **青少年足部變形**多以症狀處理為主；重建保留給**骨骼成熟且持續活動受限**者。
