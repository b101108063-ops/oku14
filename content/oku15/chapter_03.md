## 1. 品質、安全與價值 🆕

### 1.1 定義
- **醫療品質（IOM）：safe、timely、effective、efficient、equitable、patient-centered** 六個面向。
- **Value = 健康結果的改善 ÷ 達成改善所花的成本。**降低醫療成本最有效的方法是**改善病人的健康結果**；健康沒有改善，就創造不出 value。
- **社會契約：**社會給予醫師自主、地位、自律的權利；醫師則要回報專業能力、利他、誠信、當責與透明。**ABOS 認證**就是履行這份契約的機制之一。

### 1.2 QC、QA、QI 🆕（定義題）

| 概念 | 評估對象 | 骨科例子 |
|---|---|---|
| **Quality control** | **最終產品或服務**是否符合標準 | 驗證腔室壓力計與 gold standard 的量測是否一致 |
| **Quality assurance** | **產生產品或服務的流程** | 評估術後器械與紗布清點流程，是否能減少異物遺留 |
| **Quality improvement** | 整合 QC 與 QA，**系統層級**主動找出可改善之處、介入並修正標準 | 定期檢討不良結果，查證文獻後改進照護的會議或計畫 |

- 起點是 *To Err is Human*：醫療錯誤無法完全避免，但可以靠領導、資料收集與系統設計來減少。
- QI 也是醫院評鑑與 CMS 合約的要求。

### 1.3 QI 的方法 🆕
- 常用框架：**Lean（A3）、Six Sigma、Agile、IHI method**。共同目標是減少錯誤、消除浪費、改善流程、降低變異。
- 常用工具：**root cause analysis**、**PDCA 或 PDSA** 循環。
- **Lean（A3）在骨科的流程：**
  1. 組成跨領域團隊（sponsor、leader、communicator、成員）
  2. 寫出 problem statement、分析現況、找出浪費、畫 **process map**
  3. 訂 **SMART** 目標：Specific、Measurable、Achievable、Relevant、Timely
  4. 找出根本原因與 key drivers，設計對策（checklist、clinical pathway、CPG、簡化流程、教育）
  5. 用 **process、outcome、balancing measures** 評估，並以 PDCA／PDSA 反覆測試
  6. 制定**維持計畫**（指定負責人，持續監測）

> **Balancing measure** 是用來確認「改善 A 時沒有傷到 B」的指標。

## 2. M&M conference 🆕
- 現代的 M&M 重點**從追究個人責任，轉向找出系統問題**。ACGME 要求住院醫師接受病人安全與 QI 訓練。
- **SBAR 格式的 M&M 報告：**
  - **S**ituation：問題、入院診斷、手術、不良結果
  - **B**ackground：病史、適應症、檢查、手術細節、病程、併發症如何被發現與處理
  - **A**ssessment：發生了什麼、為什麼發生（root cause analysis），並回顧文獻
  - **R**ecommendation：避免再發的具體做法
- **Fishbone diagram：**把原因分成個人、團隊、病人、環境、規則與政策、組織幾類。
- **Five Whys：**至少連問五次「為什麼」，追到根本原因。
- 根本原因的歸類方式：**4M（methods、manpower、materials、machinery）**或 **4P（policies、procedures、people、plant）**。

### 2.1 Clavien-Dindo 分級 🆕（高頻）

| Grade | 定義 | 骨科修訂版的例子 |
|---|---|---|
| 0 | 沒有傷害（near-miss） | — |
| **I** | 偏離正常術後病程，但不需要藥物以外的處置（止吐、退燒、止痛、利尿、電解質、PT 都允許）；床邊打開傷口也算 | 無症狀 HO、術後發燒、輕微 UTI |
| **II** | 需要 Grade I 以外的藥物治療，**含輸血與 TPN** | 表淺感染、可恢復的 neurapraxia、trochanteric delayed union |
| **III** | 需要手術、內視鏡或放射介入（**IIIa：非全身麻醉；IIIb：全身麻醉**） | Trochanteric nonunion、骨折、深部感染、血腫、需切除的 HO、**DVT（住院加抗凝）** |
| **IV** | 危及生命、需住 ICU（**IVa：單一器官衰竭，含洗腎；IVb：多重器官衰竭**） | Osteonecrosis、永久神經損傷、大血管損傷、**PE**、CNS 併發症 |
| **V** | 死亡 | — |

> 骨科修訂版的觀察者內與觀察者間信度都很高。注意修訂版把**抗生素也列入 Grade I 可用的藥物**，而且 **Grade II 包含計畫外的門診回診**。

## 3. AAOS 的工具 🆕

### 3.1 CPG vs AUC
- **CPG：**彙整現有證據、權衡各種介入的利弊，提出**實證建議**。
- **AUC（appropriate use criteria）：**範圍更窄，結合證據、臨床判斷與病人價值觀，在**特定臨床情境**下選擇最適合的診斷或治療。**通常用於證據有限的時候。**
- AAOS 也會背書其他學會（AAHKS、ASH、AACE、MSTS、OTA 等）的 CPG，並依一份 23 項的檢核清單審查，涵蓋範圍與目的、利害關係人參與、嚴謹度、清晰度、可行性與編輯獨立性。
- 近期的 AAOS CPG 主題（年份）：**carpal tunnel（2024）、急性單純半月板病變（2024）**、髖 OA（2023）、OCD（2023）、ACL（2022）、膝 OA 手術（2022）、DDH（2022）、clavicle 骨折（2022）、四肢重大創傷後 SSI 預防（2022）、distal radius（2020）、GH 關節炎（2020）、老年髖部骨折（2021）、PJI 診斷與預防（2019）、limb salvage 或截肢（2019）、compartment syndrome（2018）等。

### 3.2 Performance measures 🆕
| 類型 | 評估什麼 | 例子 |
|---|---|---|
| **Structural** | 基礎設施 | EMR 能否減少給藥錯誤 |
| **Process** | 照護流程中的步驟是否有效 | 轉介到骨質健康計畫後，骨鬆治療率是否提高 |
| **Outcome** | 照護帶來的結果 | SSI 發生率、骨折癒合率 |
| **Patient experience** | 照護品質對病人經驗的影響 | 滿意度調查 |

### 3.3 PROMs 🆕
- 用途：量化疼痛與功能改善，評估 MCID、PASS、SCB（substantial clinical benefit）。
- **ABOS 已把 PROMs 納入認證與再認證**，從自願逐步改為必要。
- **CMS 強制特定術式申報 PROMs，包括 THA 與 TKA。**
- **AAOS 建議的 PROMs（重點）：**

| 部位 | PROM |
|---|---|
| 肩 | M-ASES、Oxford Shoulder Score；不穩定用 **WOSI** |
| 肘、腕、手 | **QuickDASH** |
| 足踝 | **PROMIS**（physical function、pain、depression） |
| TKA | **KOOS JR** |
| 運動膝傷 | **IKDC**、KOOS |
| THA | **HOOS JR** |
| 髖關節鏡 | HOOS、HOOS JR |
| 脊椎 | **ODI**（腰）、**NDI**（頸） |
| 通用 | VR-12、PROMIS 10；單題：PASS、**SANE** |
| 下肢活動量 | **Marx activity rating scale** |

## 4. 團隊合作：TeamSTEPPS 🆕
- 由 **AHRQ** 開發，已證實能改善團隊表現、知識與態度。
- **四大技能：communication、leadership、situation monitoring、mutual support。**
  - Communication：完整、清楚、簡潔、正確、及時、尊重。
  - Leadership：分派角色、建立 shared mental model、做 brief、huddle、debrief。
  - Situation monitoring：持續注意病人、隊友與環境，維持 shared mental model。可用 **STAR**（stop、think、act、review）避免技術性錯誤。
  - Mutual support：互相協助與回饋；病人安全受威脅時**堅定發聲**（assertive statement、**two-challenge rule**、**CUS**），衝突時用 **DESC**。
- **常用工具：**

| 工具 | 內容 |
|---|---|
| **Brief、huddle（time-out）、debrief** | 術前說明計畫與分工；術中重新確認；術後檢討 |
| **SBAR** | Situation、Background、Assessment、Recommendation |
| **CUS** | I am **C**oncerned、I am **U**ncomfortable、this is a **S**afety issue；**任何成員都可以提出** |
| **Check-back、read-back** | 複誦確認 |
| **交班工具** | **I-PASS**（Illness severity、Patient summary、Action list、Situation awareness 與應變計畫、Synthesis by receiver）、I-PASS the BATON、ANTICipate、SHARQ |

## 6. Anki 候選題

1. IOM 定義的醫療品質六面向？→ Safe、timely、effective、efficient、equitable、patient-centered。
2. Value 的公式？→ 健康結果的改善 ÷ 成本。
3. QC、QA、QI 各評估什麼？→ QC 看最終產品；QA 看產生產品的流程；QI 從系統層級整合兩者並持續改善。
4. SMART 目標的五個字母？→ Specific、Measurable、Achievable、Relevant、Timely。
5. QI 中 balancing measure 的用途？→ 確認改善某項指標時沒有造成其他問題。
6. M&M 報告的 SBAR 代表什麼？→ Situation、Background、Assessment、Recommendation。
7. Root cause analysis 常用的兩個工具？→ Fishbone diagram、Five Whys。
8. 4M 和 4P 分別指什麼？→ 4M：methods、manpower、materials、machinery；4P：policies、procedures、people、plant。
9. 術後需要輸血，屬於 Clavien-Dindo 第幾級？→ Grade II。
10. 全身麻醉下回開刀房清創，屬於 Clavien-Dindo 第幾級？→ IIIb。
11. 術後 PE 需要住 ICU，屬於 Clavien-Dindo 第幾級？→ Grade IV（單一器官為 IVa）。
12. CPG 與 AUC 的差別？→ CPG 是彙整證據的建議；AUC 針對特定臨床情境，常用在證據有限時。
13. Performance measures 的四種類型？→ Structural、process、outcome、patient experience。
14. AAOS 建議 TKA 和 THA 使用哪些 PROM？→ KOOS JR、HOOS JR。
15. CMS 強制哪些術式申報 PROMs？→ THA、TKA。
16. TeamSTEPPS 的四大技能？→ Communication、leadership、situation monitoring、mutual support。
17. CUS 代表什麼？→ I am Concerned、I am Uncomfortable、this is a Safety issue。
