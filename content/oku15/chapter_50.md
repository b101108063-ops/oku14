## 1. 背景與流行病學 🔄

- **膝 = 關節炎最常見部位**；高齡化與肥胖 → 盛行率持續上升 → **美國 TKA 預期大幅增加**。
- 🆕 負擔不只疼痛與失能：活動減少 → **心血管疾病、高血壓、骨鬆、憂鬱** 及相關死亡率增加。
- 直接（診斷與治療）＋間接（工作失能、生產力損失）成本。
- 🆕 **目前沒有任何治療能逆轉或停止結構性損傷**；治療目標為減痛與改善功能。

## 2. 病理生理與危險因子 🔄

### 2.1 OA

- **最常見**；個體化，**基因＋機械＋生化**。
- 細胞層次三要素：**關節軟骨退化、滑膜發炎、軟骨下骨病理變化**（Key Study Point）。
- 生化或機械刺激 → **MMP 與發炎激素上調** → 軟骨破壞。
- 軟骨下骨異常訊號 → 水腫、硬化、囊性骨流失；🆕 **PDGF、PGE2（軟骨下骨重塑）可能為未來標靶**。
- 滑膜：**macrophage-like cells** 增加分解與發炎。

### 2.2 危險因子

- ✅ **年齡、性別、BMI、舊傷、基因**。
- 年齡相關 **DNA 損傷與 cellular senescence**（含軟骨細胞）；軟組織改變與肌肉量下降 → 負荷異常。
- 🆕 **女性較易**：生物力學與荷爾蒙（負荷、肌力、骨量、營養、代謝差異）。
- **肥胖**：機械負荷＋發炎反應（代謝失調）；🆕 **呈劑量關係**：BMI 越高 → 風險、嚴重度、臨床後果越大。
- **創傷後 OA**：發病較年輕。
- **反覆負荷**：職業（跪、重體力、反覆彎腰）、跑跳；但難歸因於單一運動；🆕 **活動增加肌肉與骨健康，也可能有保護作用**。

### 2.3 發炎性關節炎 🆕

| 類型 | 重點 |
|---|---|
| **自體免疫**（RA、PsA、seronegative spondyloarthropathies） | 慢性全身發炎、多關節痛；**DMARD 改善生活品質與存活**；但**免疫抑制＋多系統共病 → 術後併發症風險增加** |
| **結晶性**（gout = MSU；pseudogout = CPPD） | 膝為常見部位；除軟骨流失外，**結晶沉積可造成關節周圍骨破壞 → TKA 術前需辨識** |
| **感染後** | 細菌、病毒、黴菌感染 → 蛋白酶破壞軟骨；**可做置換，但 PJI 與失敗風險增加** |

## 3. 診斷評估 🆕

### 3.1 病史

- **疼痛、僵硬、腫脹**；依病因差異大；問**位置、持續時間、舊傷、創傷、手術**。

### 3.2 理學檢查 🆕

- **站立檢視**冠狀與矢狀對位：varus、valgus、**flexion contracture**、少見 **recurvatum**。
- 股四頭與小腿**萎縮**（失能、循環或神經問題）。
- **步態**：antalgic、limp、**varus thrust**。
- 觸診：**關節積液、後方飽滿 ± cyst** → 持續發炎。
- **特徵：內側、外側或 PF joint line 壓痛**（軟骨磨損、半月板傷、軟組織夾擠）；🆕 **需與 pes anserine 或 ITB 附著處壓痛（tendinitis）區分**。
- 主動與被動 ROM（屈伸常下降，術前規劃需記錄）。
- **冠狀穩定**：varus／valgus stress 看韌帶鬆弛、**deformity 是 fixed 還是 correctable**；**矢狀不穩 = 十字韌帶不足**。
- **髕骨**：tracking、crepitus；🆕 **grind test（外推髕骨活動）可重現症狀但不敏感**。
- 遠端運動、感覺、血管。
- 🆕 **檢查同側與對側整個下肢：疼痛可能轉移自腰椎、髖、踝**。

### 3.3 X 光 🔄

- **首選**；🆕 **標準 X 光敏感 91%、特異 86%**，越嚴重越準。
- 🆕 **標準片：weight-bearing AP、flexed PA、lateral、patellofemoral**。
- **雙腳站立 long-leg AP**：量解剖與機械軸。
  - 🆕 原生對位因人而異；**原文：mechanical HKA 約 6° valgus 常被視為平均**。

> ⚠️ **註**：一般教科書通常把 mechanical HKA 平均描述為接近中立（約 1–2° varus），6° 左右多指**解剖軸（anatomic）外翻**。OCR 文字確實寫 mechanical；考試時請依題目語境判斷。

  - 🆕 **CPAK（Coronal Plane Alignment of the Knee）**：依 constitutional limb alignment 與 **joint line obliquity** 分 phenotype，可引導 TKA 對位目標。
- **側面**：膝中心於靜態負重時**略在負重軸後方**。
- **PF view**：trochlea 深度與對位、髕骨 tracking；**髕骨偏外**（骨性或股四頭失能）→ 蹲、爬樓梯痛。
- ✅ **Kellgren-Lawrence 0–4**：osteophyte、JSN、cyst、subchondral sclerosis。
  - 🆕 **術前較少痛、KL 較高 → 短期術後結果較好**。
  - 🆕 **2023：保險公司把 KL 納入 prior authorization，未記錄嚴重 OA 者可能被拒 TKA**。

### 3.4 進階影像 🆕

- **MRI**：半月板、韌帶、骨水腫；X 光正常時診斷早期 OA；🆕 **但普遍過度使用 —— X 光已見 OA 時多數不改變治療**。
- **CT**：診斷價值有限；🆕 **用於機器人 TKA 與客製植體規劃；可可靠預測植體尺寸 → 手術室效率、減少浪費**；**axial 對位（評估疼痛或功能差 TKA 的元件位置）**。
- **超音波**：軟骨厚度、滑液、骨刺。

## 4. 非手術治療 🔄

- 目標：**減痛、維持或改善功能**；無通用策略。
- 常見：生活型態調整、運動與 PT、全身或外用藥、關節內注射、替代療法。

### 4.1 三大指引 🔄

| 項目 | 重點 |
|---|---|
| 指引架構 | 🆕 **OARSI：有演算法（主要、次要選項＋檢查點評估症狀是否可接受）**；🆕 **ACR：刻意不分階層**，承認個別病人適用不同 |
| **Topical NSAID**（diclofenac、ketoprofen） | ✅ 普遍推薦（有效、副作用低） |
| 🆕 **Topical capsaicin** | 🆕 **ACR 條件推薦；OARSI 不推薦**（療效差；短暫痛、癢、紅） |
| 口服 acetaminophen、NSAID | ✅ 無禁忌時推薦；**NSAID 各指引強烈推薦**；長期需監測交互作用、GI、CV、腎 |
| 🆕 **口服 opioid（含 tramadol）** | 🆕 **AAOS 強烈反對**；tramadol 具爭議（依賴），可考慮於非 opioid 失敗、藥物交互作用或共病、非手術候選者 |
| 其他口服 | 🆕 duloxetine、gabapentinoid、glucosamine、chondroitin、turmeric、vitamin D：**無強證據** |
| **IA 類固醇** | ✅ **所有指引推薦短期止痛**；betamethasone、methylprednisolone、triamcinolone 皆有效，**無單一藥物或劑量較優** |
| **IA HA** | 🔄 增加潤滑與滑液黏度；核准 >20 年；**療效 vs placebo 存疑；最新 AAOS CPG 反對常規使用** |
| **PRP、幹細胞** | 🔄 symptom-modifying；**無組織癒合或再生證據；止痛與症狀改善僅有限支持** |

- ❌ OKU 14 的 **DMOAD**（IL-1／TNF 抑制、senolytics、**lorecivivint（CLK2／DYRK1A → Wnt）**、**M6495（anti-ADAMTS-5）**、**sprifermin（FGF-18）**、metformin）與 **PRP 優於 HA（18 篇 Level I）、MSC 止痛無顯著（25 篇）** 本版未列。

## 5. 手術治療 🔄

- 年輕、退化有限 → **軟組織修補、軟骨置換、矯正截骨**（見 Ch.48、52）。
- **晚期症狀性 OA、保守無效 → 置換**；🆕 **權衡共病風險，時機由醫病共享決策（2023 CPG）**。

### 5.1 UKA vs TKA 🔄

- 單一內側或外側腔室 OA → UKA 優點：**微創、保留骨與韌帶、恢復快、滿意度較高**。
- 🆕 **AJRR 2023：美國 UKA 約佔初次膝置換 4.2%，十年來穩定**。
- 🆕 **1989 原始標準（>60 歲、<180 lb、低活動需求）已演進放寬**；理想病人未定，**無重大禁忌即可考慮**。
- 🆕 **禁忌：發炎性關節炎、敗血性關節炎、曾 HTO**。
- 🆕 **mobile vs fixed bearing、cemented vs noncemented：皆未證明優劣**。
- ✅ **缺點：翻修率高於 TKA，尤其術後早期**。
- 🆕 **UKA 失敗原因：無菌性鬆脫、OA 進展、不明疼痛、不穩、感染、PE 磨耗**。
- 科技輔助 UKA：存活與 PRO 佳，需長期追蹤。
- ❌ OKU 14 的「flexion contracture >10° 為禁忌」「<65 歲 UKA 翻修較高」本版未列具體數字。

### 5.2 Cemented vs cementless TKA 🔄

- ✅ **cement = 金標準**；早期 noncemented：**早期失敗、下沉、鬆脫、osteolysis**。
- **modern porous metal＋keel 與 peg** → 生物固定有前景；**中期結果與存活相當**，**理論上長期固定較持久**。
- 🆕 **優點：保留骨量、翻修容易、減少骨水泥碎屑、手術時間短**。
- 🆕 **AJRR：cementless 佔初次 TKA 由 4%（2015）升到 20%（2023）**。
- 🆕 植體較貴，但**手術時間縮短與省去骨水泥用品 → 總成本抵銷**。
- 成功關鍵：**病人選擇、骨質評估、精準切骨、仔細置入**；現代設計尚無長期資料。

### 5.3 Bearing design 🆕

- 🆕 **all-polyethylene 或 modular 脛骨元件都有強證據**。
- modular 可 fixed 或 mobile；🆕 **mobile bearing 理論上改善 tracking、減少長期磨耗，但 AJRR 2023：最長 8 年全因翻修風險增加**。
- ✅ **CR 與 PS：結果與長期存活相當**。
- 🆕 **Conforming PE**（**raised anterior lip**、PE 與股骨元件吻合度增加）越來越流行：增加穩定、較生理運動；名詞與設計哲學不一致、難直接比較，但目前**存活、穩定、滿意度佳**。

### 5.4 Alignment philosophy 🆕

- 🆕 **趨向個人化**：傳統 **mechanical**、**functional**、不同程度的 **kinematic alignment**。
- 手動或科技輔助（navigation、robot、AR／VR）提高精準度。
- 多種冠狀對位分類（考慮變形方向與嚴重度）；**理想目標未定 → 無共識**。

### 5.5 科技與導航 🔄

- 🆕 **AAOS CPG：反對使用 PSI 與 computer-assisted navigation**（結果、功能、疼痛與傳統無差）。
- 🆕 **Accelerometer-based navigation**：位置感應器依髖與踝中心回饋 → 引導冠狀、矢狀切骨；**提高對位精準度，但不改善結果**。
- **Robotic TKA**：空間註冊＋ **passive、semiactive、active** robot 放置切骨導板或執行切骨；✅ **目前未顯著改善結果**。
- 🆕 **AR／MR**：術中疊加 3D 影像；THA 已引入，**TKA 尚不常用**。

## 7. Key Study Points（OKU 15）

- 膝 OA 是退化性疾病，特徵為**關節軟骨退化、滑膜發炎、軟骨下骨病理變化**。
- 診斷通常靠**臨床表現＋X 光**。
- 非手術治療：觀察、活動調整、減重、藥物、注射等。
- **嚴重失能＋X 光 OA → 應考慮膝置換**。
