## 1. 顯微外科基礎 🆕

### 1.1 歷史與應用

- 複式顯微鏡 **1590** 發明 → **1921 首次用於手術（耳科）** → **1922 雙目顯微鏡**。
- 現代顯微鏡：穩定支架、照明、工作距離、放大範圍、多人觀看、影像與攝影、高機動性。
- 骨科應用：**再植、軟組織重建、神經修補、交感神經切除、targeted muscle reinnervation**。

### 1.2 放大

| | Loupe | 手術顯微鏡 |
|---|---|---|
| 常用倍率 | **2.5×**（另有 3.0、3.5、4.5×，兒童手術） | **10×**（最高 **63×**，但不實用） |
| 優點 | 機動、視野可隨意選 | **底座鎖定 → 穩定**、視野可調、高倍、**多人同視野**（教學）、攝影錄影 |
| 缺點 | 靠頭頸穩定與桌高維持工作距離、單一視野大小、他人看不到 | — |

- loupe 與顯微鏡做 free flap 存活相近；loupe 也有成功的指與手再植，但**沒有指再植的直接比較 → 顯微鏡仍是標準**。
- 🆕 **掌弓及其遠端的血管修補 → 顯微鏡；掌弓近端 → loupe 可能足夠**。

### 1.3 縫線

- **非吸收單股**；依血管口徑選：

| 部位 | 縫線 |
|---|---|
| **指動脈** | **10-0 nylon** |
| **腕、遠端前臂動脈** | **8-0 nylon** |
| **兒童指再植與 revascularization** | 最小可到 **12-0**（11-0 或 12-0） |
| **神經** | 🆕 **9-0 最佳**（10-0 易張力斷、8-0 易拉脫） |

- 🆕 **Fibrin glue**：某些情況（含腕與前臂的正中、尺神經）單用時臨床結果與強度可接近縫線；但**作為縫合的補強較有用**。

### 1.4 吻合技術

1. 準備受區：盤點受傷結構，游離神經血管使其可**無張力**前移。
2. 🆕 **解剖時可用止血帶，但血管吻合時不用**（才能評估修補處血流）。
3. **Acland microvascular clamp** 控制兩端。
4. **剝除斷端外膜**；必要時直剪修平。
5. 缺損大 → **同側肢體靜脈移植**（口徑相近）；🆕 **revascularization 比 replantation 更常需要靜脈移植（2022）**。
6. 兩端取栓、**heparin 生理食鹽水沖洗** → 近端要有**強順向血流**（否則再切除取栓或改靜脈移植）；一條指動脈恢復後，對側動脈遠端應有**逆向血流**。
7. 可用 **1% lidocaine 或 papaverine** 沖洗修補處 → 血管擴張、管腔變大較好縫。
8. 🆕 **高倍下進針；進針距斷緣 = 血管壁厚度**（動脈壁厚較大）→ 避免管壁堆疊或重疊。
9. 降倍打結；🆕 **6–8 針間斷縫合**（足以不漏，但不多到造成層流擾亂、血小板凝集）。
10. 🆕 **先放遠端 clamp**；**Acland strip test** 確認通暢。
11. 🆕 **動脈吻合後可 IV heparin 5,000 units bolus**。
12. free tissue transfer 可用 **vein coupler** 免縫靜脈。

### 1.5 輔助藥 🆕

- **Heparin 生理食鹽水**：取栓後沖洗。
- **1% lidocaine 或 papaverine（1:20 稀釋）**：修補前或後**在管外沖洗術野（不是打進管腔）** → 擴張、減少血管痙攣與修補處凝血。
- 🆕 **不可使用含 epinephrine 的藥物**。

## 2. 再植 🔄

### 2.1 衛教與成功率 🆕

- 要說明：**恢復期長（6–12 個月）**、常需再手術、可能持續**僵硬、冷不耐、感覺下降、疼痛**。
- 🆕 **現代成功率：成人 84.2–89%、兒童 74.1–97%**。

### 2.2 適應症 🔄

- 🆕 **主要目標：恢復拇指＋至少兩指的 prehension（夾捏抓握）**。
- **拇指截肢**：幾乎所有情況都是**絕對適應症**。
- **多指截肢**：希望至少一指存活；**先接最有活力的指**；必要時把較有活力的指**移位到較有功能的位置**。
- **屈肌腱鞘近端**截肢：血管較大易修、截肢後功能損失遠大於指層級、**肌腱粘連風險較低** → 值得再植。
- **兒童**：癒合潛力大、對殘餘缺損適應好 → 建議再植；遠端更難，需 **11-0 或 12-0** 縫線；🆕 **極幼兒進入 supermicrosurgery：吻合 0.3–0.8 mm（300–800 µm）血管**。
- **Revascularization**（部分截斷、遠端灌流受損）：🆕 **多數情況一條指動脈就夠** → 受傷動脈不一定要修；急性因固定骨、修腱或神經而開刀時可順便修；延遲手術且灌流足夠 → 不必修；**嚴重 degloving 或 ring avulsion → 可能無法 revascularize，最終截肢**。

### 2.3 5P／8S 口訣（Table 1）🆕

| 適應症（5 P） | 意義 | 禁忌（8 S） | 意義 |
|---|---|---|---|
| **Pollux** | 拇指 | **Single** | 單指（非拇指） |
| **Poly-** | 多指 | **Starved** | 超過可用缺血時間 |
| **Proximal** | 屈肌腱鞘近端 | **Segmental** | 節段性截肢 |
| **Pediatric** | 兒童 | **Smashed** | 壓砸、毀損、撕脫 |
| **Profundus** | 屈肌腱 zone 1 | **Sublimis** | FDS 止點近端 |
| | | **Sick** | 醫療不穩定 |
| | | **pSych** | 精神不穩定 |
| | | **Soiled** | 嚴重汙染 |

### 2.4 缺血時間（Table 2）✅

| 截肢位置 | 熱缺血 | 冷缺血 |
|---|---|---|
| **手與手指（intrinsic 肌以遠）** | **<12 小時** | **<24 小時** |
| **腕、前臂、更近端** | **<6 小時** | **<12 小時** |

- 🆕 **冷缺血最晚 96 小時仍有成功報告**。
- 🆕 **沒有放冰 → 上述時間減半**。
- 越近端肌肉越多、越不耐缺血；手指沒有肌肉 → 較能耐受。

### 2.5 禁忌 🔄

- **絕對禁忌**：
  - **節段性傷**。
  - 🆕 **單指截肢位於 FDS 止點近端（但在屈肌腱鞘近端範圍以遠）**。
  - **嚴重壓砸或毀損**。
  - **嚴重汙染**（感染風險）。
  - **危及生命的合併傷**或共病使長時間麻醉不適合。
  - **該部位原本功能就受損**。
  - **精神疾病**使病人無法保護再植指或配合復健。
- **相對禁忌**：
  - **超過最大缺血時間**。
  - **只有單指（尤其邊緣指）**：單指喪失功能影響小、手可適應。
  - **壓砸或撕脫機轉**：血管壁傷重 → 易凝血失敗；靜脈移植增加複雜度與兩個吻合處。
  - 🆕 **運送中意外冷凍**。

### 2.6 病人因素 🆕

- 老人嚴重動脈硬化 → 血管壁硬、順應性差 → 吻合困難。
- 🆕 **≥3 個共病 → 再植失敗、住院延長、併發症增加（2024）→ revision amputation 可能較好**。
- **抽菸**降低成功率；**大量尼古丁或血管收縮性毒品 = 禁忌**。
- 🆕 **極幼兒存活率略低**：可能因嘗試較多、壓砸傷較多、血管小技術難。
- 考慮**職業、嗜好**（例如**鋼琴家**單指也可能考慮再植）。
- 🆕 **未嘗試再植的案件較常發生訴訟** → 依適應症與禁忌仔細評估在法律上也有益。

### 2.7 斷指本身的預後徵象 🆕

- 🆕 **Ribbon sign**：一或兩條動脈斷端**扭轉捲曲**（受傷時被牽拉）→ 管壁創傷、痙攣、易凝血 → **預後差**；可在檢查斷指時看到（動脈斷端長）或解剖時才發現；要成功 → **整段捲曲血管切除＋反轉並擴張的適當口徑靜脈移植**。
- 🆕 **Red-line sign**：手指側緣的紅色條紋（不需解剖即可見）→ 牽拉撕脫指動脈分支造成出血 → **血管與分支廣泛內傷 → 成功率下降**。

### 2.8 受傷型態 🆕

- **Guillotine 式銳利、垂直於肢體或手指機械軸的截斷 → 最有利**（組織學損傷區小）。
- **斜切 → 損傷區較長，常需靜脈移植**。
- **壓砸或撕脫 → 損傷區廣、組織學傷害大**（代謝廢物與發炎介質多）→ 預後差，**通常為禁忌**。
- **節段性傷**：至少兩處血管吻合都要通暢 → 禁忌。
- **Barnyard 型（農場）嚴重汙染傷**：即使積極抗生素與清創，感染風險仍高。

### 2.9 術前處理 ✅

- **迅速冷卻 → 延長可用時間**。
- ✅ **斷指以生理食鹽水或 LR 浸濕的紗布包好 → 放入密封袋 → 再放到另一個裝冰的容器**運送。
- 🆕 **絕不可直接放進冰水**：冷暴露熱傷害和／或泡水浸軟 → 無法再植。
- **兩組團隊**（一組準備受區、一組在後檯處理斷指）縮短恢復血流時間；🆕 **只有一位醫師時，可先把斷指帶進手術室準備**（盤點結構、確認血管是否撕脫、必要時先取靜脈移植、了解幾何與可用靜脈）→ 縮短麻醉時間。
- **區域神經阻斷**：交感阻斷擴張血管 → 管腔較大、血流較好、較少痙攣；通常**合併全身麻醉**（時間難預估）。
- **Foley catheter**。
- 🆕 **術初或術中 IV heparin** → 減少斷端凝血與取栓需要。

### 2.10 手術策略 ✅

- 🆕 **structure-by-structure（每種結構一次修完）比 digit-by-digit 有效率**（Key Study Point）。
- 🆕 **缺血時間不足以救所有手指 → 改 digit-by-digit，順序：拇指 → 中指 → 無名指 → 食指 → 小指**。
- ✅ **順序**：
  1. **骨骼固定**（提供支架、減少神經血管修補的牽拉；**必要時短縮骨頭**以利無張力吻合）。
  2. **伸肌腱 → 屈肌腱**。
  3. **血管**（推入顯微鏡；動脈先 vs 靜脈先有爭議：動脈先 → 盡早恢復灌流，但靜脈流血難修；靜脈先 → 較好看清楚脆弱的靜脈）。
  4. **神經**（同一次顯微鏡完成所有血管與神經 → 效率）。
  5. **皮膚**。

### 2.11 手術技術 🆕

- **切口**：掌側 **Bruner**（納入傷口，暴露屈肌腱與神經血管）；背側弧形斜或直縱切口（伸肌與靜脈）；🆕 **random flap 長度不可超過基底寬度（1:1 規則）**；考慮受傷機轉與未來轉截肢時的切口方向。
- **骨固定**：
  - **Pin**：快，但活動恢復慢、需再拔除。
  - **Lag screw 和／或 plate**：較早活動，但粘連與僵硬。
  - 🆕 **掌指骨髓內螺絲**：早期主動活動 → 減少水腫與長期僵硬。
  - **經關節截肢**：pin ± 韌帶修補；軟骨無法挽救 → **一期融合**（同時短縮、方便修其他結構）。
- **肌腱**：🆕 **zone 2 屈肌腱：減少體積、優化滑動，結埋在肌腱內**；其他區滑動較好可不必低輪廓；伸肌依區與切口方向，**PIP 附近的伸肌機構平衡最重要**。
- **靜脈**：🆕 **盡可能至少修 2 條靜脈**（結果優於 1 條或 0 條）。
  - 無靜脈可修（創傷或撕脫）→ 🆕 **拔甲＋切開甲床，或在指腹做 crater** 讓其出血（術後抗凝）。
  - **水蛭**：貼在甲床切口；🆕 **唾液中的 hirudin 直接抑制 thrombin**、增加組織通透與血流、可能抑制血小板凝集。
- **神經**：🆕 **手指全伸直時要無張力**；🆕 **缺損 <5–10 mm → conduit；>10 mm → nerve graft**；通常 epineural 修補，**腕部正中與尺神經可做 group fascicular 修補**。
- **閉合**：細非吸收單股線；跨過血管修補處的傷口 → 腫脹後要避免機械壓迫；🆕 **預期明顯腫脹 → 首次手術不在血管修補上方閉合**，消腫後再閉；無法無張力閉合 → 局部、區域或游離 flap。
- 🆕 **近端截肢再植**：
  - **血管修補處以遠的所有肌肉隔間都要做筋膜切開**（減少再灌流症候群）。
  - **預防性腕隧道鬆解**。
  - **手部筋膜切開要釋放全部 10 個隔間**。

### 2.12 術後照護 🔄

- 🆕 **ICU 或 step-down unit 至少前 48 小時**；護理密切注意抗凝、止痛、斷指變化。
- **抗凝**：
  - 🔄 🆕 **建議術後 IV heparin 或 dextran 40**：heparin 可依個人反應調整但需規律抽血；**dextran 40 不需規律抽血**。
  - 🆕 **出院時或之前轉 aspirin 81 mg/day，持續 1–3 個月**。
  - 🆕 爭議：**抗血栓藥與再植後焦慮與憂鬱分數增加相關**，後者又影響成功率；🆕 **2023：術後 IV heparin 可能與較高併發症與失敗率相關**。
  - 對照 OKU 14：「Level II 隨機（101 指）與 propensity 研究：術後全身性抗凝（heparin、dextran）不提升存活；aspirin 81 mg 為標準輔助」。
- **監測**：
  - 臨床：**微血管回充、顏色、turgor** 為第一線。
  - **甲床切口有血流出 = 有動脈流入**。
  - 適當情況（多為較近端再植）：**pulse oximetry** 客觀記錄氧合。
- 🆕 **病房溫度維持 ≥80°F**（約 27°C）→ 減少冷誘發血管痙攣與吻合處凝血。
- 🆕 **術後 3 個月避免尼古丁、咖啡因、巧克力**（血管收縮、促凝血）。
- 🆕 **再植部位保持與心臟同高**：抬高會減少血流、下垂會阻礙靜脈回流。
- **水蛭療法**：🆕 **靜脈鬱血是再植失敗的主要併發症** → 水蛭促進缺氧血與代謝廢物排出。
  - 要了解藥局取得水蛭流程（訂購到送達可能延遲）。
  - 🆕 **Aeromonas 感染 → 成人給 ciprofloxacin**（兒童風險較不利）。
  - 🆕 **密切監測 Hb，可能需要輸血**。
- 擔心灌流喪失 → 考慮再手術（切除原修補處＋靜脈移植）；🆕 **最多 10% 再植指會灌流喪失並在二次手術成功救回**。
- 🆕 **2024：住院監測的成本效益在單指與拇指再植 1 天後、多指再植 2 天後下降**。

## 3. OKU 14 CH38（再植部分）中 OKU 15 不再列出或說法不同的內容 ❌

- 🔄 **抗凝**：OKU 14「**Level II RCT（101 指）與 propensity 研究：術後 heparin／dextran 不提升存活；aspirin 81 mg 為標準**」→ OKU 15 改為「**建議 IV heparin 或 dextran 40 → aspirin 81 mg 1–3 個月**」，並補上 2023 研究 IV heparin 併發症較多。
- ❌ 毀損手的處置與重建四原則（**穩定的拇指最優先**、穩定手腕＋兩根可對捏的手指、維持指蹼、有感覺無痛的手指）；**life over limb**。
- ❌ 急診破傷風：5 年內未追加者加 TIG。
- ❌ 再植適應症「掌骨或更近端」的表述（OKU 15 改為「屈肌腱鞘近端」與 5P 口訣）；**ring avulsion 列為相對適應症**（OKU 15 改為嚴重時可能無法 revascularize）。
- ❌ Dermal pocketing（OKU 15 只列甲床切開、指腹 crater、水蛭）。
- ❌ 大肢體熱缺血 >6 小時導致肌肉壞死、再灌流傷害的 danger zone 敘述（OKU 15 改為筋膜切開、預防性 CTR）。

## 4. Key Study Points（OKU 15）

- **現代手術顯微鏡**讓外科醫師能處理肉眼無法處理的眾多結構。
- **徹底了解並謹慎應用再植適應症** → 最佳的病人選擇與結果。
- **再植時 structure-by-structure 修補比 digit-by-digit 有效率**。
- **適當的術後照護與密切監測**對顯微手術成功至關重要，可減少凝血與再植或 revascularize 部位的存活喪失。
