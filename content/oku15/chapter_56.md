## 1. 踝與軟組織 🔄

### 1.1 Plantar fasciitis 🆕

- 🆕 **最常見門診疾病之一，「足部的下背痛」**。
- 🆕 **解剖：起於 medial calcaneal tubercle → 遠端廣泛附著近節趾骨基底與第五蹠骨基底，三束（medial、lateral、central）**；功能：支撐足弓、toe-off 吸震。
  - 🆕 **central band（plantar aponeurosis）最強，通常是致病主因**。
- 🆕 **病理：反覆微撕裂造成的「退化」，不是發炎**；組織學：**myxoid degeneration、fascia 碎裂、骨髓血管擴張**。
- 族群：**中年女性最常**；跑者與非運動者皆可。
- 🆕 **症狀：start-up pain（早晨第一步痛）**，之後改善，白天又復發。
- 檢查：**medial calcaneal 附著處壓痛**；🆕 **Silfverskiöld test 陽性 → 腓腸肌緊**。
- 影像通常不需要；可見 cavovarus、跟骨刺。
- 🆕 **保守 3–6 個月成功率 >90%**：伸展、NSAID、貼紮、夜間副木、鞋墊或 orthotics、ESWT。
  - 🆕 **不建議類固醇注射：fascia 斷裂、足底脂肪墊萎縮（反覆注射）**。
  - 🆕 **2023：placebo effect 對 PRO 有重要角色**。
- 🆕 **保守 >6–12 個月失敗 → 手術**：
  - 🆕 **endoscopic fasciotomy = 標準**（開放亦為有效技術）；**內視鏡早期疼痛與 PRO 改善較快，長期結果相同**。
  - 🆕 併發症：**足弓塌陷、切口疤痕**。
  - 🆕 **percutaneous ultrasonic tenotomy**：用 **phacoemulsification** 清除抽吸病變組織；證據少，保守失敗可考慮。
  - **腓腸攣縮 → 腓腸延長（Strayer、Baker、Hoke、Baumann）**。

### 1.2 外側踝扭傷與慢性不穩 🔄

- 🆕 **美國每年約 200 萬踝扭傷**。
- 韌帶：ATFL、CFL、PTFL；機轉：**蹠屈位內翻**。
- ✅ **約 90% 傷 ATFL；🆕 約 40% 傷 CFL**。
- 多數 RICE＋PT（本體感覺、ROM、神經肌肉訓練）即可。
- 🔄 **約三分之一最後發展為 CAI**（定義：**>1 年反覆不穩**）（OKU 14：最多 20%）。

> ⚠️ **OKU 15 內部數字不一致**：Ch.53 寫外側扭傷轉慢性 **20–30%**，本章寫**約三分之一**。

- 🆕 **CAI 分 functional（本體感覺、神經肌肉）vs mechanical（韌帶鬆弛、關節力學）**。
- 🆕 **易感：cavovarus、廣泛韌帶鬆弛、tarsal coalition**。
- 臨床：外側痛、giving way、反覆積液、外側韌帶壓痛。
- 🆕 **前抽屜**：**與對側比較；CFL 在中立位測、ATFL 在蹠屈位測；比對側多 >6 mm = 陽性**。
- 🆕 **評估 Beighton**；超音波：Beighton 越高與前抽屜正相關。
- 常合併 peroneal 病變；急性符合 **Ottawa rules → WB X 光**（找 syndesmosis 傷、**Maisonneuve**）；真不穩 → **varus stress 下 talar tilt**。
- 🆕 **保守：至少 6–12 週 PT（神經肌肉、peroneal 強化、本體感覺）**＋護具、貼紮、orthotics。
- **手術：解剖重建**：
  - **Brostrom**：以 anchor 或骨隧道修補鬆弛的 ATFL 與 CFL。
  - ✅ **Brostrom-Gould = 最常用**：**Gould 修飾 = 加入 inferior extensor retinaculum 補強**。
  - 🆕 **modified Brostrom 成功率 >90%**。
  - 🆕 **all-inside 或全關節鏡 modified Brostrom = 開放**。
  - 🆕 **suture tape augmentation**：生物力學較強；適合**韌帶鬆弛、翻修**等失敗風險高者；🆕 **高品質證據：可加速復健、提早回場**。
- ❌ OKU 14 的「Brostrom 22 例 26 年 91%、150 例 11 年」未列。

### 1.3 Syndesmosis 🔄

- 🆕 字源 **sundein = 綁在一起**；🆕 **AITFL、PITFL、interosseous ligament、transverse tibiofibular ligament** → 防止腓骨離開 tibial incisura（軸向、旋轉、平移）。
- 常伴踝骨折；少數無明顯骨折。
- 臨床：韌帶足印處痛（**比 ATFL 更近端**）；**squeeze test**（小腿中段擠壓 → syndesmosis 痛）。
- 🆕 **X 光**：**MCS >5 mm**、**tibiofibular overlap 減少（AP <6 mm 或 mortise <1 mm**；OCR 原文寫「>6 mm／>1 mm」，指 overlap 不足）；**WB＋與對側比較**。
- 🆕 **分級**：

| Grade | 定義 | 處置 |
|---|---|---|
| **1** | **AITFL 部分撕裂**，脛腓關係正常 | 保守（保護負重＋本體感覺 PT） |
| **2** | **AITFL 完全撕裂、無 diastasis** | 部分可保守；**保守失敗 → 手術**；高階運動員可考慮手術提早回場 |
| **3** | **完全撕裂＋diastasis** | **手術** |

- 固定：**static（螺釘）或 dynamic（flexible suture button）**；目標 = **腓骨復位於 fibular notch**。
- ✅ **文獻趨勢偏好 flexible suture fixation**：**較準確、再手術率低**；🆕 **2023：局部刺激較少、非計畫翻修較少**。
  - 🆕 **flexible 的「寬容性」**：螺釘復位不良 → 創傷後 OA 風險明顯增加。
  - 🆕 **靜態固定通常需 6–8 週後才負重**。
- 🆕 **神經病變或骨鬆老人仍偏好靜態固定**。
- ❌ OKU 14 的「**約 13% 踝骨折合併 syndesmosis 傷**」「**螺釘復位不良最高 40%**」「tightrope RCT 103 例」本版未列數字。

### 1.4 Peroneal tendinopathy 🔄

- 功能：**蹠屈與外翻**、踝動態穩定；🆕 **癒合差；疑似無血管區：retromalleolar groove、peroneal groove**。
- 解剖：同在腱鞘內 → 腓骨後溝 → **SPR**；**PB 走 IPR 淺層 → 第五蹠骨基底外側**；**PL 在 peroneal tubercle 深層 → cuboid 外側 → 轉入足底 → 第一蹠骨基底與內楔骨**。
- 臨床：沿肌腱外側痛；**抗阻外翻痛**；X 光多良性，常見 cavovarus。
- 🆕 **MRI：縱裂（PB split tear）、low-lying muscle belly；敏感約 80%、準確 78%；正常不能排除**。
- 保守：NSAID、PT（peroneal 強化、本體感覺）、護具。
- 🆕 **手術**：處理合併問題（**CAI、韌帶鬆弛、舊跟骨骨折、cavovarus**）；評估整條肌腱（尤其低血供區）。
  - 病變清創到健康邊緣；小撕裂修補＋tubularize。
  - 🆕 **>50% 肌腱留存 → tubularize 或修補**。
  - 🆕 **一條 <50% 完好、另一條完好 → tenodesis 到另一條**。
  - **兩條皆無法重建 → FHL 或 FDL 轉移，或 allograft 重建**。
  - 🆕 **清創修補（tubularization）比肌腱轉移滿意度高**。
- 演算法（Figure 4）：無症狀 → 保守；有症狀 → 保守 → 疼痛 → 手術：可修 → tubularize 與修補；一條可修一條不可 → tenodesis；兩條不可修 → FHL／FDL 或 allograft。

### 1.5 Achilles 斷裂 🔄

- 🆕 **體內最粗肌腱，可承受 >10 倍體重**；soleus＋內外側 gastrocnemius。
- 🆕 **血供：PTA＋peroneal artery；低血供區 = 跟骨附著點近端 2–6 cm → 多數病變發生處**。

> ⚠️ **OKU 15 內部不一致**：Ch.53 寫低血供區在插入點近端 **3–5 cm**；本章與 Key Study Point 寫 **2–6 cm**。

- 族群：**中年週末戰士**；機轉：**突然蹠屈，或蹠屈足突然背屈**。
- 🆕 **危險因子：fluoroquinolone、Achilles tendinopathy 史、CKD、DM、長期類固醇**。
- 臨床：「啪」一聲、跟痛、腫、瘀、行走障礙；**可觸及缺口、靜止背屈增加**。
- 🆕 **Thompson test：擠壓小腿無蹠屈 = 陽性；必須俯臥**。
- 插入點或肌腱肌肉交界、部分撕裂 → MRI 或超音波。
- **急性斷裂處置**：
  - 高風險（**吸菸、DM 控制差、皮膚問題**）→ **保守較安全**。
  - 🆕 **2022：12 個月時手術不比保守好**；手術併發症可能較高（也有研究無差）。
  - 🆕 **不論哪種，可能留下 end-range 蹠屈無力**。
  - 🆕 **保守：蹠屈位副木、石膏或 boot；通常至少 2 週限制負重＋嚴格復健**；🆕 **作者：立即負重 boot＋3 heel wedges 4 週 → 2 週內逐步拿掉 → 加速復健**。
  - 🆕 **手術：mini-open 或經皮 → 傷口併發症少、手術時間短，優於開放；但有醫源性 sural nerve 傷風險**；無一方法明確較優。

### 1.6 慢性 Achilles 斷裂 🆕

- 🆕 **>8 週 = 慢性 → 通常手術，依缺損大小**：

| 缺損 | 處置 |
|---|---|
| **<2 cm** | **end-to-end repair** |
| **2–5 cm** | **V-Y lengthening＋FHL transfer** |
| **>5 cm** | **FHL transfer＋allograft** |

### 1.7 Achilles tendinopathy 🔄

- 低血供區的退化：**插入性**（跟骨附著處）vs **非插入性**（低血供區）。
- 🆕 **組織學：angiofibroblastic hyperplasia（密集纖維母細胞、膠原紊亂、血管增生）**。
- 影像：**Haglund deformity（跟骨上後外側突出）**、calcaneal enthesophyte。
- 保守：PT（**eccentric**）、固定、ESWT、orthotics。
- 手術：
  - ✅ **插入性：清創＋切除 Haglund exostosis＋重新附著；清創後剩餘 <50% 截面積 → FHL 轉移或增強**。
  - **非插入性：開放、mini-open、經皮**，同急性斷裂，但**修補前要先清除病變組織**。
  - 🆕 **成功率 >80%**（2023）。

## 2. 後足 🔄

### 2.1 PCFD 🔄

- **舊名 PTTD**；過去認為 PTT 漸進失能所致。
- 🆕 **舊分期（PTTD）**：

| Stage | 表現 |
|---|---|
| **1** | PTT 腱鞘炎，對位正常 |
| **2a** | **內側弓塌陷、後足柔軟、無法單腳踮腳** |
| **2b** | 2a＋**前足外展（too-many-toes sign）** |
| **3** | **後足僵硬＋前足外展＋距下 OA** |
| **4** | 3＋**距脛病變（deltoid 不足或踝 OA）** |

- ✅ **WBCT 研究 → 重新定義為 PCFD**：不只 PTT，還包括 **spring ligament、deltoid、TMT、naviculocuneiform 關節**（Key Study Point）。
- ✅ **新分類（Myerson 2020，修改版）**：

| Class | 位置 | 臨床 | X 光 |
|---|---|---|---|
| **A** | 後足 | **後足 valgus（too-many-toes）** | 後足 valgus |
| **B** | 中足 | **前足外展** | **距骨頭覆蓋減少、TN 未覆蓋增加** |
| **C** | 前足 | **前足 varus、內側柱** | **第一 TMT 與 NC 蹠側開口、talus–第一蹠骨角增加** |
| **D** | Peritalar | **subfibular impingement** | **明顯距下半脫位** |
| **E** | 踝 | **踝不穩** | **踝 valgus tilt** |

- 🆕 **病程**：**PTT＋spring 先鬆弛 → 內側弓與中足塌 → 跟骨代償性 valgus → 距骨頭未覆蓋＋前足外展 → peritalar → 外側 subfibular impingement → 最後距脛：OA 或 deltoid 鬆弛**。
- 臨床：內側足痛（沿 PTT）；部分 **subfibular 外側痛**。
- 🆕 **heel raise 時後足矯正到中立 → flexible；不變 → rigid**。
- 內側弓消失、前足外展、腓腸緊。
- 影像：X 光 **Meary angle 減少、TN 未覆蓋、後足 valgus**；✅ **WBCT 對重建極有價值**；MRI 可看 peritalar、距脛、距下 OA。
- **保守**：NSAID、PT（PTT 強化）、鞋墊、護具或 orthotics（🆕 **medial heel post、UCBL**）。
  - 🆕 **PTT 一旦開始鬆弛，保守無法逆轉**。
  - 🆕 **2023：orthotics 不改善後足 valgus 或 PCFD 3D 變形；最多支撐並抬高內側縱弓**。
- 🆕 **手術（由後足往遠端）**：

| 部位 | 柔軟 | 僵硬 |
|---|---|---|
| **後足** | **medial displacing calcaneal osteotomy（MDCO）** | **雙或三關節融合** |
| **中足** | **切除病變 PTT＋FDL 轉移到 navicular ± spring 重建** | **TMT 融合（外側柱不融合）** |
| **前足外展** | ✅ **TN 未覆蓋 >50% → Evans lateral column lengthening** | — |
| **殘留前足 varus／supination** | 🆕 **Cotton osteotomy（內楔骨 opening wedge）或蹠屈 Lapidus** | — |
| **腓腸／Achilles 攣縮** | 適當延長 | — |
| **踝** | **距脛關節面保留 → deltoid 重建** | **踝 OA → 融合或置換** |

- 🆕 **不論分期，手術重建都改善 PRO**。

### 2.2 Cavovarus 🔄

- 🆕 **cavus = 以蹠屈第一列為中心 → 內側弓高；varus = 軟組織失衡 → 後足內翻**。
- 🆕 **Force couples**：**PL 拮抗 TA；PB 拮抗 PTT**。
- 單或雙側；🆕 **病因：CVA、漏診腔室症候群、最常 = 神經疾病如 CMT**。
- 🆕 **CMT（motor sensory neuropathy）：type 1 髓鞘流失、type 2 軸突萎縮或流失**。
  - 🆕 **先影響遠端分支 → 足內在肌 → 往近端 → TA 弱 → PB 弱**。
  - 🆕 **PL 勝過 TA → 第一列蹠屈 → cavus**；🆕 **PTT 勝過 PB（＋PL）→ 後足內翻 → varus**。
  - 前足：爪趾、metatarsalgia、**外側柱應力骨折**。
- 臨床：一定有**高內側弓＋後足 varus**；常見踝不穩、步態障礙、Achilles 或腓腸攣縮。
- 🆕 **外側柱過載 → 應力骨折、胼胝、peroneal 病變、甚至 plantar fasciitis**。
- ✅ **Coleman block test**：**木塊墊在外側半足**：
  - **後足矯正到中立或輕 valgus → flexible**（PL 驅動的前足可矯正）。
  - **不矯正 → rigid**。
- Silfverskiöld；X 光：**calcaneal pitch 增加、Meary angle 增加、後足 varus**；MRI、WBCT 非必要（臨床診斷）。
- 🆕 **疑 CMT → 基因檢測、NCS／EMG、肌肉切片**。
- 🆕 **保守 orthotic：內側弓支撐＋第一列凹陷（recessed first ray）＋lateral heel post**；NSAID、PT；**無高階證據**。
- 🆕 **手術**：
  - **僵硬後足 → Dwyer osteotomy（lateral displacing calcaneal osteotomy）**。
  - **柔軟後足（代表前足僵硬是主因）→ 第一蹠骨背屈截骨或背屈 TMT 融合**。
  - 🆕 **PL → PB 轉移**矯正 PL 過強。
  - **固定變形或 OA（踝、中足、距下、NC）→ 雙或三關節融合**。
  - 🆕 **爪趾 → Jones procedure（伸肌腱移到蹠骨頸＋IP 融合）**。
  - plantar fascia、Achilles、腓腸視需要處理。
- 🆕 **不可漏診**：與 **CMT、復發踝不穩、第五蹠骨骨折、外側柱應力骨折**相關。

## 3. 中足：Lisfranc 🔄

- 🆕 **Lisfranc complex = TMT（第二蹠骨與內楔骨）、intermetatarsal（第一二蹠骨）、intertarsal 關節**。
- ✅ **冠狀面蹠骨基底呈 Roman arch；第二蹠骨基底內凹 = keystone**。
- 🆕 **Lisfranc ligament（最強、最關鍵）：第二蹠骨基底 → 內楔骨；dorsal、interosseous、plantar 三部分；interosseous 與 plantar 最強**。
- 機轉：**蹠屈足軸向負荷**（車禍、高處跌落、運動）。
- 🆕 **典型 plantar foot ecchymosis → 在證明之前都當作 Lisfranc 損傷**。
- ✅ **最多 40% 初始 X 光漏診**；🆕 **漏診 Lisfranc 是醫療訴訟主要原因之一**（Key Study Point）。
- 🆕 **雙側 WB X 光對位線索**：
  - **AP：第二蹠骨內緣對齊中楔骨內緣**（OCR 寫 medial cuneiform，一般為 middle cuneiform）。
  - **第一與第二蹠骨基底間距 <2 mm**。
  - **Oblique：第四蹠骨內緣對齊 cuboid 內緣**。
  - **Lateral：第一蹠骨與內楔骨背側皮質連線**。
  - **fleck sign**（第二蹠骨基底撕脫）。
- MRI、WBCT 對細微 Lisfranc 有用（2024）。
- 🆕 **處置**：分骨性與韌帶性。
  - **一般不建議保守**，除非手術候選差或**真正無位移、無不穩** → **CAM walker 或石膏 6 週** → 漸進完全負重。
  - **任何不穩或韌帶傷 → 手術**（避免創傷後 OA）。
  - 🆕 **皮膚撐起的脫位要先復位固定；軟組織腫脹消退前不手術**。
  - 🆕 **ORIF vs primary arthrodesis**：文獻少；**目前偏好 primary arthrodesis**；**韌帶傷、慢性或延遲 Lisfranc → 考慮 primary arthrodesis**；✅ **不融合外側柱（第 4、5 TMT）**。
  - 🆕 **>2 mm 不穩可 ORIF**；多用於**年輕運動員（保留內側柱功能）**；成功取決於**解剖復位**；缺點：**需回手術室取內固定**。
  - 🆕 **2023：兩者長期功能與再手術率無差**。
- ❌ OKU 14 的「不穩情形下保守可致高達 30% 創傷後 OA」未列數字。

## 4. 前足 🔄

### 4.1 Hallux valgus 🔄

- 🆕 **定義：大拇趾在 MTP 外偏＋pronation**（Key Study Point：複雜 3D 變形）。
- 病因：緊鞋、家族史、廣泛韌帶鬆弛、神經肌肉病。
- 🆕 **病理順序**：
  1. **內側囊與 MCL 失效** → 第一蹠骨向內移、離開 sesamoids。
  2. **近節趾骨被 sesamoids 與 adductor hallucis 拴住 → 外偏**。
  3. **屈伸肌腱軸移到 MTP 外側** → 加重外展。
  4. **abductor hallucis 移到 MTP 蹠側 → 失去對抗 valgus 與 pronation 的能力**。
  5. 內側突起痛 → **transfer metatarsalgia** → 末期僵硬＋MTP OA。
- 🆕 臨床：內側突起痛、小蹠骨頭痛；🆕 **dorsal medial cutaneous nerve（SPN 分支）neurapraxia → 大拇趾神經痛**；TMT 不穩 → 第一二蹠骨間過動；Beighton 高。
- 🆕 **WB X 光**：**HVA >15°、IMA >10°、DMAA >10°**。

| 嚴重度 | HVA | IMA |
|---|---|---|
| 🆕 **輕** | **15–20°** | **9–13°** |
| 🆕 **中** | **20–41°** | **14–20°** |
| 🆕 **重** | **>40°** | **>20°** |

- 🆕 **AP 看第一蹠骨頭與近節趾骨吻合度（congruity）**；🆕 **lateral：第一蹠骨與內楔骨間蹠側開口 → TMT 不穩**。
- 保守：**寬頭鞋**、鞋墊或 orthotics、活動調整。
- 🆕 **手術演算法**（無單一 gold standard）：

| 步驟 | 判斷 | 處置 |
|---|---|---|
| 1 | **無痛（不論外觀）** | **一律保守** |
| 2 | **MTP OA** | **MTP 融合** |
| 3 | **第一二 TMT 不穩或過動** | **Lapidus（第一 TMT 融合）** |
| 4 | **輕度** | **遠端蹠骨截骨** |
| 5 | **中到重度** | **較近端截骨** |
| 6 | **重度＋第一蹠骨頭與近節不吻合** | **多平面截骨或 Lapidus** |
| 7 | **DMAA 異常** | **biplanar osteotomy** |
| 8 | **殘留 hallux interphalangeus >10°** | **Akin（近節趾骨截骨）** |

- 開放 vs MIS 仍爭議；MIS 支持者：**恢復快、外觀好、止痛**（2024）。

### 4.2 Bunionette 🆕

- 🆕 **第五蹠骨頭外側突出 ± 蹠骨偏斜**；窄頭鞋；外側足痛。
- 🆕 **X 光：4–5 IMA >8°、5th MTP angle >14° 為異常**。
- 🆕 **分型**：

| Type | 特徵 |
|---|---|
| **1** | **第五蹠骨頭增大** |
| **2** | **第五蹠骨幹外弓** |
| **3** | **4–5 IMA 增加** |
| **4** | **IMA 增加＋頭增大或外弓** |

- 保守：活動調整、避免緊鞋、鞋墊、NSAID；🆕 **滑囊炎 → 滑囊類固醇注射效果佳**。
- 🆕 **手術**：
  - **單純外側突出 → lateral eminence resection（只減壓、不矯正變形）**。
  - 🆕 **矯正 → diaphyseal 或 proximal osteotomy；越近端矯正力越強**。
  - 遠端截骨通常用於 type 2（OCR 原文）；**type 2 或 3 → diaphyseal osteotomy**。
  - 🆕 **極近端截骨可矯正 IMA，但該區血供差 → 不癒合風險高**。
  - MIS（2024）PRO 與變形矯正改善。

### 4.3 小趾變形 🆕

| 變形 | 定義 |
|---|---|
| 🆕 **Hammer toe** | **PIP 病理性屈曲攣縮；MTP 與 DIP 伸直** |
| 🆕 **Claw toe** | 肌肉失衡（原文：內在肌勝過伸屈肌腱）→ **MTP 伸直、PIP 與 DIP 屈曲** |
| 🆕 **Mallet toe** | **遠節趾骨固定屈曲於中節** |

- 病理核心：**plantar plate、內在肌、屈伸肌腱**。
- 保守：**silicone sleeve、Budin splint**、鞋墊。
- **柔軟 → 軟組織釋放及／或肌腱轉移；僵硬 → 融合或關節切除＋pinning**。

### 4.4 Turf toe 🔄

- 🆕 **機轉：蹠屈足軸向負荷＋第一 MTP 過伸 → plantar plate complex 斷裂**。
- 🆕 **分級：grade 1 輕度伸展、grade 2 部分撕裂、grade 3 完全撕裂**。
- 臨床：大拇趾痛腫、**push-off 痛**。
- 🆕 **X 光：sesamoid 骨折；更重要是 sesamoid 回縮 >3 mm → plantar plate 斷裂**；X 光不明 → **MRI 準確確診與分級**。
- 🆕 **處置**：

| Grade | 處置 |
|---|---|
| **1** | 輕蹠屈貼紮＋硬底鞋或 carbon fiber plate；**可早回場** |
| **2** | **蹠屈位石膏 4–6 週** → 漸進回場 |
| **3** | 可保守但**需 ≥6 個月**；**高階運動員 → 手術修補 capsuloligamentous complex** 以更快回場 |

- 🆕 **2023：高等級 turf toe 的運動員 70% 能維持傷前表現**。

### 4.5 Morton neuroma 🔄

- 🆕 **misnomer：實為第二或第三蹠骨間隙趾神經的纖維化**。
- 🆕 **最常第三間隙，位於 medial 與 lateral plantar nerve 匯合處**。
- 族群：**中年女性、緊鞋**。
- 🆕 **病理：慢性壓迫 → 水腫、神經周纖維化、去髓鞘**。
- 症狀：第二或第三間隙蹠骨頭處痛；🆕 **「走在彈珠上」**；🆕 **Mulder click（擠壓蹠骨）可有但非診斷必需**。
- 不確定 → **web space 麻醉注射**、MRI、超音波。
- 類固醇可考慮；🆕 **反覆 → 脂肪墊萎縮、皮膚反應**。
- 保守：鞋子調整、**metatarsal bar**、NSAID。
- 🆕 **手術：切除病變神經；關鍵 = 至少切到 intermetatarsal ligament 近端 3 cm；送病理確認**。
- 🆕 **切除不足 = 最常見失敗原因**。

## 6. Key Study Points（OKU 15）

- **Achilles 病變多因低血供區（插入點近端 2–6 cm）**；從急性斷裂到插入與非插入 tendinopathy；手術核心 = **對合 Achilles**，嚴重退化 → **肌腱轉移或 allograft**。
- **PCFD** 是內側縱弓退化；過去以為由 PTTD 造成，**現證實可包含 spring、deltoid、TMT、NC 關節**；重建依**病變位置與柔軟度**。
- **最多 40% Lisfranc 損傷初始 X 光漏診**，是醫療訴訟常見原因；手術 ORIF 或 primary arthrodesis，**多數醫師偏好 primary arthrodesis（免取內固定）**。
- **Hallux valgus 是複雜 3D 變形（外偏＋pronation）**；需遵循清楚演算法。
