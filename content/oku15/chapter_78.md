## 1. 骨病灶影像 🔄

### 1.1 X 光 ✅

- ✅ **正交 X 光 = 評估骨腫瘤的第一個檢查**。
- ✅ **四個基本問題**：

| 問題 | 判讀重點 |
|---|---|
| **1. 位置？** | 軸骨 vs 長骨；骨骺、幹骺、骨幹 |
| **2. 病灶對骨做什麼？** | 破壞型態（permeative vs geographic）、過渡區 |
| **3. 骨對病灶做什麼？** | 硬化邊、骨膜反應（Codman）、皮質 |
| **4. 有無基質？** | 骨樣 vs 軟骨樣 vs 透亮 |

- 🆕 **physis 是否開放雖不在四問題內，但需考慮：多數骨腫瘤有年齡傾向**。
- 🆕 **位置與鑑別**：

| 位置 | 鑑別 |
|---|---|
| **骨骺** | **成人 giant cell tumor；兒童 chondroblastoma** |
| **骨幹** | **adamantinoma、eosinophilic granuloma、infection、osteoid osteoma、Ewing sarcoma、fibrous dysplasia**；🆕 **HEALED：histiocytosis、eosinophilic granuloma、adamantinoma、lymphoma、Ewing、dysplasia** |
| **幹骺** | **良性：osteochondroma、enchondroma、NOF、ABC；惡性：osteosarcoma、chondrosarcoma** |
| **任何位置** | 🆕 **轉移，最常見於 >40 歲** |

- ✅ **破壞與反應**：
  - **permeative＋寬或不清楚過渡區 → 侵襲性、快速過程（骨來不及反應）**。
  - **geographic＋窄或清楚過渡區＋硬化邊 → 骨已反應形成新骨 → 較不侵襲**。
  - **皮質破壞、骨膜反應（Codman triangle）、合併軟組織腫塊 → 侵襲、應懷疑惡性**。
- ✅ **基質**：
  - **骨樣：有組織、放射狀或雲狀**。
  - **軟骨：較無結構，鈣化呈點狀、stippled 或環狀**。
  - **無基質 → radiolucent，鑑別較廣**。

### 1.2 CT 🆕

- 🆕 **3D 呈現：更清楚的位置、破壞型態、宿主反應、基質**；可發現**病理骨折、X 光未顯的軟組織腫塊**；協助評估骨折風險。
- 🆕 **osteoid osteoma（小、皮質型）→ CT 最能顯示 nidus**。
- 🆕 **胸壁、脊椎、骨盆等複雜部位 → CT 較佳**；骨細節優越。

### 1.3 MRI 🆕

- 🆕 **評估髓內範圍與骨外延伸**。
- 🆕 **T1：髓內範圍與解剖（多數骨腫瘤取代骨髓 → T1 暗）；T2：液體與水腫（腫瘤與軟組織成分 → T2 亮）**。
- 🆕 **除非禁忌，應加 IV gadolinium：區分水腫、壞死、存活腫瘤；有強化 → 有血供**。
- 🆕 **疑轉移一般不需 MRI**：X 光足以評估病理骨折風險，MRI 額外資訊通常不改變處置；**多數即將病理骨折以預防性固定（非廣泛切除）處理**。
  - 🆕 **例外：疑 renal cell carcinoma（易出血、需了解完整範圍）**。

### 1.4 核醫 🆕

- 🆕 **bone scan（Tc-99m diphosphonate，結合 hydroxyapatite → 骨轉換快）：最常用於找其他骨受累部位**。
  - **非特異：腫瘤、外傷、退化、發炎都可熱**。
  - 🆕 **陰性不排除侵襲；multiple myeloma 可為冷**。
- 🆕 **PET（FDG）**：代謝活性；侵襲腫瘤依賴葡萄糖 → 較易 PET avid；亦非特異。
  - 🆕 **非骨腫瘤初始常規；多保留給已確診惡性者，評估轉移與化放療反應**。

## 2. 軟組織腫塊影像 🆕

### 2.1 X 光 🆕

- 🆕 **價值較低：多只見與肌肉或脂肪等密度的軟組織陰影**。
- 🆕 **鈣化**：

| 發現 | 想到 |
|---|---|
| **phleboliths** | **hemangioma** |
| **壞死組織鈣化** | **synovial sarcoma、mesenchymal chondrosarcoma** |
| **外傷史＋周邊骨化** | **myositis ossificans** |
| **中央骨化** | **骨外 osteosarcoma 疑慮** |

- 🆕 **vascular malformation、desmoid 鄰骨 → 反應性骨膜抬起，甚至慢性外壓變形**。

### 2.2 超音波 🆕

- 🆕 **可作為初始影像，尤其表淺腫塊**：可靠判斷是否有腫塊、與周邊構造關係、**實心 vs 囊性**。
- 🆕 **良惡性重疊大 → 多數仍需 MRI**。
- 🆕 **另一重要角色：觀察中病灶的大小變化追蹤**；容易取得、耐受佳。

### 2.3 CT 🆕

- 🆕 **MRI 之後的次要工具**；多只顯示與肌肉或脂肪等密度。
- 🆕 **優點：偵測腫塊、大小與鄰近解剖、不受 MRI 視野限制；看礦化、鄰骨侵犯**。
- 🆕 **MRI 絕對禁忌 → 顯影 CT 作為第二線**。

### 2.4 MRI ✅

- ✅ **含與不含 gadolinium 的 MRI = 軟組織腫塊首選**：大小、表淺或深部、與周邊關係優於 CT。
- ✅ **惡性提示：>5 cm、深於筋膜、侵犯鄰近構造**。
- 🆕 **訊號特性**：

| 組織 | MRI |
|---|---|
| **脂肪（lipoma）** | **各序列與脂肪等訊號 → MRI 可診斷 lipoma** |
| **纖維組織** | **T1、T2 皆暗** |
| **軟組織肉瘤** | **T1 大致均勻低訊號、T2 高訊號、顯影後強化、周邊水腫** |
| **實心 vs 囊性** | **實心整體強化；囊性只周邊強化** |
| **水腫 vs 存活腫瘤** | **T2 兩者皆亮；T1 顯影後水腫暗、存活腫瘤亮** |
| **壞死** | **不強化 → 切片時避開** |
| **myxoma、軟骨病灶** | **相對無血管 → 強化少** |

### 2.5 PET 🆕

- 🆕 **初始評估少用**：可能區分低級別與高級別肉瘤，但**無法可靠區分低級別惡性與良性 → 不助診斷**。
- 🆕 **可找出異質腫瘤中代謝最活躍的部分 → 作為切片目標**。
- 🆕 **特定族群偵測惡性轉化：neurofibromatosis → 葡萄糖代謝增加可能代表 neurofibroma 轉為 MPNST**。

## 3. 切片 🆕

### 3.1 適應與原則 🆕

- 🆕 **並非所有病灶都需切片：臨床與影像提示良性 → 可不切即擬定治療**。
- 🆕 **適應：影像為良性侵襲、惡性或不確定 → 治療前確認診斷**。
- 🆕 **切片做不好 → 延誤診斷或犧牲局部控制選項 → 影響結果**。
- 🆕 **理想由將做最終切除的同一位醫師執行 → 應考慮早期轉介骨腫瘤科**。
- 🆕 **目標：取得診斷組織，同時減少周邊污染與病人病率**。

### 3.2 技術原則 🆕

- 🆕 **穿刺點或切口：位置要能減少鄰近污染，且在最終切除時能輕易切除切片道**。
- 🆕 **開放切片**：
  - **安全前提下最小的縱向切口**。
  - **最直接路徑到腫瘤**。
  - **避開神經血管束與 internervous planes**。
  - **少剝皮瓣、避免廣泛分離、仔細止血**。
  - 🆕 **避免橫切口（最終手術需更寬軟組織切除、常需皮瓣覆蓋）**。
  - 🆕 **放引流時，靠近切口且與切口同線**。
- 🆕 **骨病灶特別考量**：
  - **切片道為 stress riser → 病理骨折風險**。
  - **有合併軟組織腫塊 → 優先切軟組織部分**。
  - **純骨內病灶 → burr 開小圓孔或較大長圓孔，以骨水泥填補 → 減少腫瘤溢出與骨折風險**。

### 3.3 三種技術 🆕

| 技術 | 特點 | 適用 |
|---|---|---|
| 🆕 **FNA** | **小號針抽吸細胞；可細胞學但組織量少、無組織結構**；門診局麻、污染與病率極少 | **只限小、易觸、皮下軟組織腫塊** |
| 🆕 **Core needle** | **較大口徑＋取樣機制；保留組織結構 → 準確度較高**；污染與病率低 | **表淺或大而深但可觸 → 門診局麻；需精準 → IR 影像引導**；🆕 **骨病灶 → 通常在開刀房透視下或由 IR** |
| 🆕 **Open** | **金標準；樣本較大較好**；可送 **frozen section**（不足可再取） | 🆕 **主要用於 core 無法診斷，或 frozen 若與術前臨床影像診斷相符可同次麻醉完成最終處置**；🆕 **缺點：污染風險高、骨 stress riser、快速生長惡性未及時處理或治療無效 → 經切片道 fungation** |

## 4. 病理分級與分子 🆕

### 4.1 分級 🆕

- 由肌肉骨骼病理醫師判讀；報告應含**組織型、分級、分子等輔助結果**。
- 🆕 **分級 = 侵襲性與局部復發或轉移可能**：高級別骨與軟組織腫瘤 → **手術＋輔助化療或放療**；低級別 → **多單純手術**。
- 🆕 **FNCLCC 最廣用：壞死、mitotic activity、分化程度三項**。
- 🆕 **部分肉瘤分級主要由亞型決定**：**傳統 osteosarcoma 與 Ewing sarcoma 一律高級別；parosteal osteosarcoma 低級別**。
- 高級別 → 壞死比例較高、mitosis 較多、分化較差。
- **dedifferentiation**：分化良好腫瘤轉為未分化。

### 4.2 分子檢測 🆕

- 🆕 **形態學與 IHC 仍為基礎，但部分腫瘤組織學無法區分、無特異抗原 → 分子研究（DNA、RNA）**。
- 🆕 **FISH：螢光 DNA 探針找易位與擴增；PCR、RT-PCR：放大特定突變或融合轉錄**。
  - 🆕 **兩者都依賴病理醫師在鑑別中先懷疑某亞型並針對該異常（2024）**。
- 🆕 **常見分子標的**：

| 腫瘤 | 異常 | 基因 |
|---|---|---|
| **Ewing sarcoma** | **t(11;22)** | **EWS-FLI1** |
| **Myxoid liposarcoma** | **t(12;16)** | **TLS-CHOP** |
| **Alveolar rhabdomyosarcoma** | **t(2;13)** | **PAX3-FKHR** |
| **Clear cell sarcoma** | **t(12;22)** | **EWS-ATF1** |
| **Synovial sarcoma** | **t(X;18)** | **SYT-SSX1** |
| **Extraskeletal myxoid chondrosarcoma** | **t(9;22)** | **EWS-CHN** |
| **Atypical lipomatous tumor** | **MDM2 amplification** | **MDM2** |

- 🆕 **新方法**：
  - **NGS：平行定序大量 DNA 或 RNA，可找替代融合；不需事先知道異常；但較貴、較久 → 審慎使用（2022）**。
  - **Methylation profiling：將未知腫瘤的甲基化型態與已知腫瘤參考資料庫比對分類（2024）**。
  - **Liquid biopsy：血中腫瘤標記；ctDNA 與 CTC 可用於部分肉瘤的診斷、治療反應監測、復發偵測（2022）**。
- 🆕 **治療標靶**：
  - **NTRK fusion 陽性肉瘤 → tropomyosin receptor kinase inhibitors**。
  - **ALK 易位的 inflammatory myofibroblastic tumor → ALK inhibitors**。
  - 免疫治療在肉瘤的角色發展中。

## 5. 分期 🔄

### 5.1 原則 🆕

- 分期 = 依分級與局部、遠處範圍分類 → 估預後、訂治療。
- 🆕 **分級：組織學；局部範圍：MRI 最佳；區域擴散：部分腫瘤可用 PET；遠處轉移：胸部 CT（多數轉移到肺）**。
- RMS 與 MM 各有獨立分期。

### 5.2 良性骨腫瘤：Enneking ✅

- ✅ **良性用阿拉伯數字，惡性用羅馬數字**。

| Stage | 名稱 | 特徵 |
|---|---|---|
| **1** | **Latent** | **常無症狀、偶然發現；休眠、可自行癒合；邊界清楚＋厚反應骨邊** |
| **2** | **Active** | **生長中、可有症狀；皮質變薄但仍被包含** |
| **3** | **Aggressive** | **較具破壞性、穿破皮質、可延伸到軟組織；常有症狀** |

### 5.3 惡性：Enneking（MSTS）✅

| Stage | 分級 | 部位 | 轉移 |
|---|---|---|---|
| **IA** | 低 | 腔室內 | — |
| **IB** | 低 | 腔室外 | — |
| **IIA** | 高 | 腔室內 | — |
| **IIB** | 高 | 腔室外 | — |
| **III** | 任何 | 任何 | 區域或遠處 |

- ✅ **骨：腔室內 = 未超出皮質；軟組織：未超出解剖腔室筋膜**。
- 🆕 **Enneking 將影像特徵與組織學一併納入分級**；骨腫瘤科仍廣用，但**整體腫瘤學界多用 AJCC**。

### 5.4 AJCC ✅

- ✅ **以腫瘤大小取代腔室；T（大小）、G（分級）、N（淋巴）、M（遠處）**。
- ✅ **骨（門檻 8 cm）**：

| Stage | 定義 |
|---|---|
| **IA** | **低級別、<8 cm** |
| **IB** | **低級別、>8 cm 及／或 skip metastases** |
| **IIA** | **高級別、<8 cm** |
| **IIB** | **高級別、>8 cm** |
| **III** | **高級別＋skip metastases** |
| **IV** | **淋巴或遠處轉移** |

- ✅ **軟組織（門檻 5 cm、10 cm）**：

| Stage | 定義 |
|---|---|
| **IA** | **低級別、<5 cm** |
| **IB** | **低級別、>5 cm** |
| **II** | **高級別、<5 cm** |
| **III** | **高級別、>5 cm（5–10 cm vs >10 cm 再細分）** |
| **IV** | **淋巴或遠處轉移** |

- ⚠️ 尺寸門檻：**骨 8 cm、軟組織 5 cm**，不可互換。

### 5.5 Rhabdomyosarcoma 🆕

- 🆕 **風險組依 TNM 分期＋clinical group＋PAX/FOXO1 融合基因（2022）**。
- 🆕 **TNM 分期**：

| Stage | 定義 |
|---|---|
| **1** | **有利部位起源** |
| **2** | **不利部位、<5 cm** |
| **3** | **不利部位＋鄰近淋巴結，或 >5 cm** |
| **4** | **轉移** |

- 🆕 **Clinical group（範圍與切除完整度）**：**I 局部、完整切除；II 顯微切緣陽性；III 肉眼切緣陽性；IV 轉移**。
- 🆕 **風險組**：**低風險 stage 1（融合陰性）；中風險 stage 2 或 3（融合陰性，依 group）；PAX/FOXO1 陽性 → 歸入較高風險**（依表）。

### 5.6 Multiple myeloma：R-ISS 🆕

- 🆕 **四因子：albumin、β2-microglobulin、LDH、cytogenetics**。

| Stage | 條件 |
|---|---|
| **I** | **albumin >3.5 g/dL、β2M <3.5 mg/dL、LDH 正常、無高風險染色體異常** |
| **II** | **不符合 I 或 III** |
| **III** | **β2M >5.5 mg/dL、LDH 升高、及／或高風險：del(17p)、chromosome 13 deletion、t(4;14)、t(14;16)、t(14;20)** |

## 6. Restaging 🔄

- 🆕 **新輔助化療及／或放療後再評估局部與遠處範圍**：治療效果（或無效）可能改變最終處置。
- 🆕 **局部：重做顯影 MRI**。
- 🆕 **反應型態**：

| 腫瘤 | 新輔助後 |
|---|---|
| **Osteosarcoma** | **多數不縮小（大量結構性基質）；反應好 → 礦化增加** |
| **軟組織腫瘤** | **可縮小、內部壞死** |
| **Ewing 軟組織腫塊、myxoid liposarcoma** | **特別敏感、常明顯縮小** |
| **放療後軟組織腫瘤** | **形成纖維 rind 或 capsule → 利於切除** |

- 🆕 **新輔助期間明顯局部進展 = 預後差；若包覆神經血管 → 可能不再適合保肢**。
- 🆕 **術前重評遠處轉移，最好用與初次分期相同的影像**；新的或進展的區域或肺轉移 → 預後變差 → 病人可能選擇較小手術、化療、放療或安寧。
- ❌ OKU 14 的「**壞死率 ≥90% 為良好反應**」本章未列。

## 7. 追蹤 🆕

- 🆕 **國家共識指引**：

| 族群 | 時程 | 內容 |
|---|---|---|
| **高級別骨肉瘤** | **前 2 年每 3 個月；第 3 年每 4 個月；第 4–5 年每 6 個月** | **PE＋原發部位 X 光＋胸部 CT** |
| **高級別軟組織肉瘤** | **前 2–3 年每 3–6 個月；之後 2 年每 6 個月；之後每年至 5–10 年** | **PE＋胸部影像** |
| **低級別軟組織肉瘤** | **前 2–3 年每 3–6 個月；之後每年** | PE＋影像 |

- 🆕 **局部復發高風險（切緣陽性）或 PE 不易追蹤部位 → 定期顯影 MRI 手術床**。
- 🆕 **頻率與方式（胸部 X 光 vs CT）仍有爭議；RCT 進行中**。
- 🆕 **胸部影像不足的特例**：
  - **epithelioid sarcoma、synovial sarcoma、angiosarcoma → 區域淋巴結轉移頻率高 → 至少臨床檢查淋巴區**。
  - **myxoid liposarcoma → 罕見地偏好轉移到骨、軟組織、後腹腔 → 部分建議胸部 CT＋whole-body MRI（2024）**。

## 8. OKU 14 CH70 中 OKU 15 不再列出的內容 ❌

- ❌ **GCT 最高 95% 帶 H3F3A 突變**（移至 Ch.79 相關）。
- ❌ **新輔助化療壞死率 ≥90% 為良好反應**；**EURAMOS：壞死 <90% 隨機繼續 MAP 或加 MAPIE → 不常規加**。
- ❌ **Ewing 每 2 週間隔壓縮 vs 每 3 週：5 年 EFS 73% vs 65%**。
- ❌ **cisplatin 耳毒性永久聽損 40–80%**。
- ❌ **滑膜肉瘤化療敏感、ifosfamide＋doxorubicin**；**NCDB 化療＋放療存活**。
- ❌ **放療相關肉瘤風險 0.06%、平均潛伏 15 年、5 年存活 45%**；**轉移疾病 20–30 Gy**。
- ❌ **術前 vs 術後放療：傷口併發症 35% vs 17%、局部復發無差**；**>5 cm 通常考慮放療**。
- ❌ **傳統寬邊界 >1 cm 正常組織**；**現代約 95% 原發骨腫瘤可保肢**。

## 9. Key Study Points（OKU 15）

- 任何骨病灶或軟組織腫塊的影像都應**從正交 X 光開始**；X 光看不清、需進一步描述或手術規劃 → **CT 或 MRI**。
- 切片必須遵守**規劃與執行的關鍵原則**；**疑骨或軟組織肉瘤 → 切片前考慮轉介骨腫瘤科**。
- 組織型與分級由肌肉骨骼病理醫師決定；**高級別 → 通常新輔助治療＋手術；部分低級別 → 單純手術**。
- 依分級與局部、遠處範圍分期；**AJCC 最常用於肉瘤**。
- 肉瘤治療後追蹤依**國家共識指引：定期 PE＋胸部影像**。

## 10. Anki 候選題

1. 骨腫瘤第一個影像？→ 正交 X 光。
2. X 光四問題？→ 位置、病灶對骨、骨對病灶、基質。
3. 骨骺病灶成人 vs 兒童？→ GCT；chondroblastoma。
4. HEALED 代表？→ histiocytosis、eosinophilic granuloma、adamantinoma、lymphoma、Ewing、dysplasia。
5. 幹骺良性與惡性病灶？→ osteochondroma、enchondroma、NOF、ABC；OS、chondrosarcoma。
6. 轉移最常見年齡？→ >40 歲。
7. Permeative＋寬過渡區代表？→ 侵襲性、快速過程。
8. 惡性的 X 光特徵？→ 皮質破壞、Codman triangle、軟組織腫塊。
9. 骨樣 vs 軟骨基質？→ 雲狀放射 vs 點狀環狀鈣化。
10. 顯示 osteoid osteoma nidus 最佳影像？→ CT。
11. MRI T1 與 T2 分別看？→ 髓內範圍；液體與水腫。
12. 疑轉移是否需 MRI？例外？→ 通常不需；RCC。
13. Bone scan 可能冷的惡性腫瘤？→ multiple myeloma。
14. PET 在骨腫瘤的角色？→ 已確診惡性者評估轉移與反應。
15. Phleboliths 代表？→ hemangioma。
16. 會鈣化的軟組織肉瘤？→ synovial sarcoma、mesenchymal chondrosarcoma。
17. 周邊 vs 中央骨化？→ myositis ossificans vs 骨外 OS。
18. 超音波在軟組織腫塊的角色？→ 表淺初始、實心或囊性、追蹤大小。
19. 軟組織腫塊首選影像？→ MRI（含與不含 gadolinium）。
20. 軟組織惡性提示三項？→ >5 cm、深於筋膜、侵犯鄰近構造。
21. 哪種腫塊 MRI 可直接診斷？→ lipoma。
22. 纖維組織 MRI 訊號？→ T1、T2 皆暗。
23. 水腫 vs 存活腫瘤在 T1 顯影後？→ 水腫暗、腫瘤亮。
24. 強化少的軟組織腫瘤？→ myxoma、軟骨病灶。
25. PET 在軟組織腫塊的用途？→ 找切片目標、NF1 MPNST 轉化。
26. 誰應執行切片？→ 將做最終切除的醫師。
27. 切片切口方向？→ 縱切口（避免橫切口）。
28. 切片時應避開？→ 神經血管束與 internervous planes。
29. 引流管位置？→ 靠近且與切口同線。
30. 骨病灶有軟組織成分時切哪？→ 軟組織部分。
31. 純骨內病灶切片後處理？→ 骨水泥填補開窗。
32. FNA 適用？→ 小、易觸、皮下腫塊。
33. Core needle 優於 FNA 之處？→ 保留組織結構。
34. Open biopsy 的現代適應？→ core 不足、frozen 可同次最終手術。
