## 1. 轉移性脊椎腫瘤 🔄

### 1.1 流行病學 🆕

- 🆕 **脊椎 = 最常見的骨轉移部位**；**20–70% 癌症病人在病程中會發生脊椎轉移**；盛行率因癌症治療進步、存活延長而上升。
- 🆕 **原發來源**：

| 原發 | 比例 |
|---|---|
| **乳癌** | **20–30%** |
| **肺癌** | **15–20%** |
| **攝護腺癌** | **5–10%** |
| **腎細胞癌** | **5–10%** |
| 其他 | GI、甲狀腺、黑色素瘤；multiple myeloma、lymphoma 也常廣泛侵犯 |

- 🆕 **部位：胸椎 60–70%、腰椎 20–25%、頸椎 10–15%**（與各區骨髓量與血管相關）；**常多節**。
- 通常代表晚期、預後差。
- 🆕 **脊髓壓迫：5–10% 癌症病人 → 腫瘤急症**，未即時處理可致永久癱瘓。

### 1.2 病史與檢查 🆕

- 全身與神經症狀、詳細癌症病史與治療史；完整脊椎與神經檢查（**步態、大小便**）。
- 🆕 **良好 H&P 可避免手術延遲（常 >3 個月）；延遲 → 結果較差、併發症較多**（2023）。
- 🆕 **評估演算法（Figure 1）**：
  - 神經急速惡化？疑 **lymphoma** → **先切片，再給類固醇**；其他 → 類固醇＋完成檢查。
  - 亞急性：**CT CAP／spine、全脊椎 MRI（打與不打）、X 光、實驗室（感染、術前、SPEP 等）**。
  - 孤立病灶且可能 en bloc 候選 → 開放切片等特殊路徑；已知轉移 → 減壓／重建，或不穩以外考慮緊急放療；腫瘤委員會。

### 1.3 影像 🆕

| 檢查 | 重點 |
|---|---|
| **X 光** | 初始；快速但**敏感度低：需 >50% 骨小樑破壞才可見**；可見明顯骨破壞、病理骨折、對位；🆕 **winking owl sign = AP 上一側 pedicle 消失** |
| **CT** | 比 X 光敏感；皮質破壞程度、**穩定性**；🆕 **評估後方元素最佳**；CAP 可同時找內臟轉移；缺點：輻射、軟組織對比差 |
| **MRI** | ✅ **金標準；敏感 98.5%、特異 98.9%**；骨髓置換在骨破壞前即可見；**硬膜外延伸與脊髓壓迫最佳**；椎旁軟組織與跳躍病灶；🆕 **初始應做全脊椎打與不打顯影**；缺點：時間長、貴、植入物禁忌 |
| **骨掃描（Tc-99m diphosphonate）** | **成骨性轉移敏感、可看全身**；缺乏特異性與解剖細節；**純溶骨可漏**；🆕 **對 multiple myeloma、甲狀腺癌、RCC 敏感度低** |
| **FDG-PET** | 骨與軟組織代謝活性；骨骼與內臟轉移；🆕 **骨轉移敏感 62–100%、特異 96–100%**；貴、不普及、發炎可偽陽 |

### 1.4 切片 🆕

- 🆕 **適應**：**原發不明、初步檢查不確定、疑感染**；已知癌症但病灶**影像或位置非典型**時仍可能需要。
- 🆕 **應在最終治療中心、由將執行最終治療的團隊進行** → 規劃不影響後續治療；技術不良 → **沿切片路徑播種**，需更大範圍切除。

| 方法 | 重點 |
|---|---|
| 🆕 **FNA** | 細針抽細胞做細胞學；組織破壞少、併發症低；**組織量少、可能不足以確診** → **最適合已知癌症確認轉移** |
| 🆕 **Core needle** | ✅ **骨病灶診斷金標準**；🆕 **11–14 G、至少 3 針**；🆕 **脊椎病灶診斷準確率約 90%**；多數脊椎病灶優於 FNA |
| 🆕 **Open** | 直視、組織多；較侵入、併發症多；**needle 切片無法診斷或技術困難時**；🆕 **切片路徑須與最終手術切口同線；椎體病灶偏好 transpedicular** |

- 影像導引：透視或 CT。

### 1.5 分類與決策 🔄

#### SINS 🔄

- ✅ **Spine Oncology Study Group 發展；評估腫瘤脊椎的機械穩定性；六項、總分 0–18**。

| 項目 | 給分（高 → 低） |
|---|---|
| **位置** | **junctional（occiput–C2、C7–T2、T11–L1、L5–S1）3**；**mobile（C3–6、L2–4）2**；**semirigid（T3–10）1**；**rigid（S2–S5）0** |
| **疼痛** | 機械性痛 3；偶爾非機械性 1；無痛 0 |
| **骨病灶** | 溶骨 2；混合 1；成骨 0 |
| **脊柱對位** | 半脫位或平移 4；新發 kyphosis 或 scoliosis 2；正常 0 |
| **椎體塌陷** | >50% 3；<50% 2；無塌陷但 >50% 椎體受累 1；無 0 |
| **後外側受累** | 雙側 3；單側 1；無 0 |

- 🆕 **判讀（OCR 原文）：<6 穩定；>13 通常需手術穩定；7–12 不確定**（標準切點為 0–6 穩定、7–12 潛在不穩、13–18 不穩）。
- 🆕 **不確定區（7–12）：平躺時疼痛是否緩解可協助決定是否需穩定；分數較低者可能經皮骨水泥強化即足夠，而非開放固定**。
- 可客觀提早辨識即將不穩，避免災難性事件；協助非外科醫師判斷何時轉介。

#### ESCC（Bilsky）🆕

| Grade | 定義 | 處置 |
|---|---|---|
| **1a** | 硬膜外擴散，**未壓迫硬膜囊** | 🆕 **通常放療** |
| **1b** | 壓迫硬膜囊，**未碰到脊髓** | 同上 |
| **1c** | **碰到脊髓但未壓迫** | 同上 |
| **2** | **壓迫脊髓，仍可見 CSF** | 🆕 **高度放射敏感 → 可單放療；否則多建議手術**（依放射敏感度） |
| **3** | **壓迫脊髓，看不到 CSF** | 🆕 **放療前緊急手術減壓**（延遲 → 不可逆神經缺損） |

#### NOMS ✅

- **Neurologic（神經缺損）、Oncologic（可用的腫瘤治療、是否放射敏感）、Mechanical（穩定性）、Systemic（整體預後、能否耐受手術）** → 多學科整體決策。

#### 預後模型 🆕

- 🆕 **New England Spinal Metastasis Score（NESMS）**：預測**術後 3、6、12 個月存活**；變數：**BMI、術前行走狀態、血紅素、原發腫瘤類型**；🆕 **預測準確度優於 Tokuhashi 等早期系統**。
- 🆕 **SORG machine learning 演算法**：預測 **90 天與 1 年死亡**；
  - **內部驗證 AUC：0.83（90 天）、0.85（1 年）**。
  - **美國獨立外部驗證：0.75、0.77**。
  - **台灣與中國族群驗證有希望，但略低估死亡**。
  - Key Study Point：**ML 預後模型表現優於傳統評分**。

### 1.6 手術技巧 🆕

- 主要目標：**減壓神經、穩定脊柱、部分情況切除腫瘤**；個別化。
- 🆕 **MIS**：軟組織傷少、失血少、住院短、恢復快、**感染率低**，穩定與止痛結果一致；🆕 **但廣泛切除或減壓能力有限 → 需大範圍切除或重建時，開放仍為標準**。
- 🆕 **入路**：**能只做後方就只做後方**（減少罹病）；前方直達椎體但技術困難（尤其胸椎）；🆕 **頸胸與腰薦交界常需前後合併**（時間、失血、併發症增加）。
- 🆕 **Margin**：**轉移 → intralesional 或 marginal 即可（姑息目標）**。
- 🆕 **Separation surgery（配合 SRS）**：
  - 目標：**減壓脊髓、在腫瘤與脊髓間創造 2–3 mm 空間**、必要時穩定。
  - **後方 laminectomy ± facetectomy、環狀減壓；把腫瘤從硬膜剝離 debulk，不嘗試 en bloc** → 之後可安全給高劑量放療。
- 🆕 **植入物**：
  - **fenestrated pedicle screws → 骨水泥強化 → 明顯增加 pull-out 強度**（骨鬆或溶骨），減少內固定失效。
  - **CFR-PEEK（碳纖維強化 PEEK）**：**減少 CT／MRI 偽影、減少後續放療劑量擾動**；較貴、長期資料少。
- 🆕 **血管**：
  - **術前 spinal angiogram** → 找穿過腫瘤可能需犧牲的血管、可**術前栓塞**以減少出血。
  - 犧牲動脈必須保留腦與脊髓血流；🆕 **原發腫瘤包覆椎動脈 → 只有對側足以供應後腦時才可犧牲**。
  - 🆕 **注意 Adamkiewicz 位置；2022 研究顯示常可安全犧牲**。
- 🆕 **神經根犧牲**：為暴露、切除或 margin 所需 → 事先告知風險與可能缺損。

### 1.7 輔助治療 🆕

#### 放療

| 類型 | 重點 |
|---|---|
| 🆕 **CEBRT** | **最普及**；多次分次數週；🆕 **典型 30 Gy／10 次**；止痛與局控；**適合放射敏感腫瘤（lymphoma、myeloma、乳癌、攝護腺癌）**；可治大範圍；**受脊髓耐受限制無法給高劑量**；需多次；**放射性脊髓病風險** |
| 🆕 **SBRT** | **1–5 次高劑量精準照射**；🆕 **適合寡轉移、放射抗性腫瘤、曾放療者**；🆕 **生物等效劑量較高 → 局控 80–90%**、次數少、鄰近組織毒性低；較不普及、需設備與經驗；🆕 **可因 osteoradionecrosis 造成椎體骨折** |
| 🆕 **Brachytherapy** | **放射性種子（通常 I-125）直接置入腫瘤**；**放療後復發的救援**或輔助；**放射抗性腫瘤**特別有用；需侵入性操作 |

#### RFA 🆕

- 高頻交流電產熱；CT 或透視導引。
- 🆕 **80–90% 病人疼痛明顯減輕，但未證實可控制腫瘤**。

#### 骨調節藥 🆕

- 🆕 **Bisphosphonates**：抑制破骨細胞 → 預防實體腫瘤骨轉移的 **SRE（skeletal-related events，如病理骨折）**；🆕 **降低 SRE 30–40%**、輕度止痛、可能抗腫瘤（2024）。
- 🆕 **Denosumab（RANKL 單株抗體）**：預防 SRE；🆕 **優於 zoledronic acid；大型研究再降低 SRE 17%**。

## 2. 原發脊椎腫瘤：總論 🆕

- 🆕 **發生率約 0.9／100,000／年**。
- 常見良性：**hemangioma、osteoid osteoma、osteoblastoma、ABC、GCT**；常見惡性：**chordoma、chondrosarcoma、osteosarcoma、Ewing sarcoma**。
- 良性可無症狀；惡性常有疼痛、神經缺損、不穩。
- 檢查：病史、影像、切片；**MRI 首選（病灶特性、脊髓或根壓迫）**；CT（骨破壞與穩定）；**CT 導引切片**常需。
- 🆕 **Table 2：常見脊椎腫瘤特徵與建議 margin**：

| 腫瘤 | 特徵 | 建議 margin |
|---|---|---|
| **Chordoma** | 惡性、慢長、復發高、少轉移；T1 暗 T2 亮增強；🆕 **brachyury 基因重複**；需與 benign notochordal cell tumor 區別（增強較少、CT 較硬化） | **En bloc** |
| **Osteosarcoma** | 惡性；T1 暗 T2 亮增強；成骨；可肺轉移 | **En bloc** |
| **Chondrosarcoma** | 惡性；**CT ring-and-arc 鈣化**；骨掃描可能 cold | **En bloc** |
| **Ewing sarcoma** | 惡性；前 20 歲較常；**EWS 基因** | **En bloc** |
| **ABC** | 良性侵襲；多在後方元素；膨脹溶骨；T1 暗帶亮點、T2 亮 | **En bloc（可行時），否則 gross total** |
| **GCT** | 良性侵襲；🆕 **2–7.5% 肺轉移**；可很富血管；膨脹溶骨；**denosumab** 可用 | **En bloc（可行時），否則 gross total** |
| **Osteochondroma** | 良性；皮質與髓腔與骨連續；**軟骨帽 >2 cm 擔心惡性變** | **Intralesional** |
| **Hemangioma** | 良性；常見（10%）；T1、T2 亮；CT trabeculae 或 honeycomb | **Intralesional**（即使侵襲性通常亦然） |
| **Osteoid osteoma／osteoblastoma** | 良性；**<2 cm／>2 cm**；CT nidus；夜痛、NSAID | **Intralesional；侵襲性則 en bloc** |
| 轉移（腎、肺…） | 🆕 **腎臟富血管 → 術前必須栓塞、切除前血液備在手術室**；攝護腺可成骨、難置針 | **需手術時 intralesional** |
| Myeloma、lymphoma | 對放療反應快；myeloma 可比 lymphoma 更具破壞性 | **需手術時 intralesional；考慮緊急放療** |

## 3. 原發良性腫瘤 🔄

### 3.1 Enneking 分期 ✅

| Stage | 行為 | 處置 |
|---|---|---|
| **1 latent** | 不活動、通常無症狀 | **觀察** |
| **2 active** | 慢長、輕微症狀 | **curettage＋植骨** |
| **3 aggressive** | 快速生長、局部破壞、症狀明顯 | **en bloc resection** |

### 3.2 Osteoid osteoma 🆕

- 🆕 **佔良性原發骨腫瘤約 10–14%**。
- 🆕 **脊椎多在後方元素，僅約 10% 在椎體**。
- **局部夜痛、NSAID 緩解**。
- 🆕 **CT 診斷關鍵：<2 cm 透亮 nidus＋周圍反應性硬化**。
- 治療：NSAID 緩解；持續痛或無法耐受藥物 → 切除。
- 🆕 **RFA**：流行的微創選項，但**脊椎受鄰近神經熱傷害限制**；🆕 **病灶與神經結構距離 ≥1 cm 時通常安全；更近 → 開放切除較安全**。
- 🆕 **電腦導航＋內視鏡** → 小切口精準切除、可能減少術後痛、加快恢復。

### 3.3 Osteochondroma 🆕

- 🆕 **頸椎最多（50%）**，其次胸腰；**多起於後方元素（次發骨化中心）**。
- 🆕 **表現：myelopathy（27–64%）**、根病變、局部痛、可觸腫塊；即使小腫瘤長入椎管也可致神經症狀。
- **CT**：病灶與底下骨皮質及髓腔**連續**。
- 🆕 **MRI 軟骨帽厚度 >1–3 cm → 懷疑惡性變**（Table 寫 >2 cm）。
- 手術：神經症狀、痛、活動受限、疑惡性變；🆕 **關鍵 = 完整移除軟骨帽以防復發**；多為後方 laminectomy，必要時前方或合併；🆕 **需切 facet → 融合**；結果多極佳、復發低。

### 3.4 Aneurysmal bone cyst 🆕

- 良性但局部侵襲的溶骨病灶；🆕 **好發腰椎後方元素**。
- X 光、CT、MRI：**膨脹性溶骨＋薄緣**；🆕 **CT 或 MRI fluid-fluid level 55–85%**；MRI 利手術規劃；影像常已足夠（可切片確診）。
- 治療：**curettage ± 植骨、完整切除、動脈栓塞、病灶內類固醇或 calcitonin 注射、放療**。
- 🆕 **完整切除局控最佳；整體復發 10–44%，完整切除遠低於部分切除**。
- 大範圍切除後常需穩定融合；**大出血與神經傷風險 → 術前栓塞**；**放療只用於無法手術**（併發症）。

### 3.5 Hemangioma 🔄

- 🆕 **最常見原發脊椎腫瘤：10–12% 人口**；多無症狀、偶然發現；🆕 **只有約 1% 會有症狀**。
- 病理：**椎體內薄壁血管＋脂肪細胞**。
- 🆕 **影像：axial CT「polka dot」；MRI T1 與 T2 皆高訊號（高脂肪）**；🆕 **較侵襲性病灶 T1 可低 → 似惡性**。
- 處置：
  - 無症狀 → 觀察＋定期影像。
  - **疼痛、無神經缺損 → 放療或 sclerotherapy**。
  - **進行性神經缺損或不穩 → 手術**：減壓 ± vertebroplasty、部分切除、complete spondylectomy；**術前栓塞**減少出血。
  - 🆕 **高級別侵襲性（NCDB 102 例）→ 早期手術切除＋高劑量輔助放療存活最佳**。

### 3.6 Giant cell tumor 🆕

- 罕見、局部侵襲良性；背痛、神經缺損、病理骨折。
- 影像：**膨脹性溶骨、皮質破壞**；MRI 評估軟組織延伸與脊髓壓迫。
- **切片必需**：**單核基質細胞＋散在 osteoclast-like 巨細胞**。
- 🆕 **en bloc = 可行時的金標準**；技術困難、罹病率高；🆕 **en bloc 復發較 intralesional 或 piecemeal 低，但不一定改善總存活**；為保神經可選 intralesional curettage。
- 🆕 **Denosumab（RANKL 抑制）**：**neoadjuvant 可縮小腫瘤、利後續手術**；可控制生長、減痛、改善神經功能（即使硬膜外延伸）；🆕 **最佳療程未定；停藥後復發是疑慮**。

## 4. 原發惡性腫瘤 🔄

### 4.1 AJCC 第 8 版：脊椎骨肉瘤 T 分期 🆕

| T | 定義 |
|---|---|
| **T1** | 侷限於 **1 節或 2 相鄰節** |
| **T2** | 侷限於 **3 相鄰節** |
| **T3** | **≥4 相鄰節，或任何非相鄰節** |
| **T4a** | **侵入椎管** |
| **T4b** | **大血管明顯侵犯或腫瘤血栓** |

- 🆕 **儘管有新的 T 描述，第 8 版仍未定義脊椎骨肉瘤的整體分期**。

### 4.2 Osteosarcoma 🆕

- 🆕 **佔脊椎惡性腫瘤 3–5%**。
- X 光：邊界不清的溶骨＋硬化；🆕 **CT：80% 溶骨型可見基質礦化**；MRI：T1 低、T2 不均。
- **切片確診**。
- 🆕 **不良 OS 預測：≥60 歲、高級別、診斷時區域或轉移期、未手術**；疾病特異存活較差：**男性、高級別、晚期、使用放療**。
- 🆕 **中位 OS 僅 15 個月；5 年存活 16.8%**。
- 🆕 **標準：neoadjuvant 化療 → 手術切除 → adjuvant 化療**。
- 🆕 **total en bloc spondylectomy（寬緣）可行時首選**（局控優於 intralesional）；**頸椎等常無法真正 en bloc → total piecemeal spondylectomy（局部復發風險較高）**。

### 4.3 Ewing sarcoma 🆕

- 罕見、侵襲性；**兒童與年輕人**。
- 🆕 **病理：小圓藍細胞、高核質比**；EWS 基因。
- MRI（OCR）：邊界清楚、均勻增強的腫塊；**切片確診**。
- **多模式：手術＋化療＋放療**；手術盡量 gross total（常富血管、黏附神經）；腫瘤床可放療。
- 結果仍差：復發高、長期存活有限。

### 4.4 Chondrosarcoma 🔄

- 🆕 **佔原發脊椎腫瘤 6.5–10%**。
- 局部痛；🆕 **約 50% 有神經症狀**。
- ✅ **CT：破壞性腫塊＋典型 ring-and-arc 鈣化**。
- 🆕 **CT 導引 core needle 優於 FNA（準確度較高）**。
- ✅ **標準 = en bloc＋陰性 margin**（局控與總存活明顯優於 intralesional）。
- 🆕 **高級別或不可切除 → 輔助放療 ≥60 Gy 漸增使用**（改善局控；對存活影響有爭議）。
- 🆕 **化療多無效（慢長、抗藥），mesenchymal subtype 可能例外**。
- 🆕 **預後依級別、margin、年齡；5 年 OS 約 52–64%**。
- ❌ OKU 14 的**整塊 vs 刮除復發（7.5% vs 100%、3% vs 21%）、10 年 OS（約 90% vs 60%）**未列。

### 4.5 Chordoma 🔄

- ✅ **胚胎 notochord 殘餘**；罕見、慢長；**薦骨、活動脊椎、顱底**。
- 🆕 **組織學：physaliphorous cells，排成索或片狀於 myxoid stroma**。
- X 光：溶骨＋鈣化；**CT 導引切片**確診。
- ✅ **en bloc＋寬陰性 margin = 可行時的金標準**；靠近重要神經血管 → 難達陰性 margin。
- 🆕 **術前 3D 列印模型＋術中導航 → 精準截骨規劃**；高位薦骨或腰薦腫瘤重建需複雜器械；🆕 **整形外科肌皮瓣關閉 → 減少傷口併發症**。
- 🆕 **陽性 margin → 輔助放療，尤其質子或碳離子**；**不可切除 → 根治性高劑量放療**。
- 🆕 **新系統治療：TKI 試驗中；免疫治療 checkpoint inhibitor（如 nivolumab）對復發或轉移有初步希望**。
- 🆕 **5 年 OS 約 65–80%；寬陰性 margin = 最重要預後因子**。
- ❌ OKU 14 的「年發生率約每百萬 1 例」未重述。

## 5. En bloc resection 🔄

- 目標：**整塊移除原發脊椎腫瘤＋健康組織 margin** → 局控與存活優於 intralesional（Key Study Point）。
- 常需切除鄰近未受累結構：**神經根、椎動脈、肌肉**。
- 主要併發症：**大量失血、神經缺損、CSF 漏、內固定失效**。
- 🆕 **術前 CT 與 MRI 規劃**（範圍、重要神經血管、穩定性，2022）。
- 常需**前後合併（有時分期）**以環狀接近腫瘤與重建 → 需血管、胸腔、一般外科協助。
- 🆕 **應在專門中心由經驗豐富的多學科團隊執行**。
- ❌ OKU 14 的「**圍術期併發症 42%**」「**內固定失效 3–40%（cage 塌陷、假關節）**」未列。

## 7. Key Study Points（OKU 15）

- **SINS 與 ESCC** 是評估轉移病人機械穩定與脊髓壓迫的關鍵，協助手術決策。
- **機器學習**改善了脊椎轉移的預後模型，表現優於傳統評分。
- **SBRT** 以較少次數精準給予高劑量 → 放射抗性腫瘤與（寡轉移等）情況的局控較好。
- **En bloc** 整塊切除原發腫瘤＋健康 margin → 局控與存活較好；需仔細規劃，**最好在專門中心執行**。
- 脊椎腫瘤（尤其轉移）需**多學科**：手術、放療、骨調節藥（bisphosphonate、denosumab）。
