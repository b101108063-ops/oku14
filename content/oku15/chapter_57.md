## 1. 胚胎與發育 🔄

### 1.1 時程 🆕

| 時間 | 事件 |
|---|---|
| **day 18** | **gastrulation 完成**（三胚層、primitive streak、notochord） |
| **day 19** | **notochord 誘導 ectoderm → neural plate** |
| **day 22** | neural folds 內摺 → **neural tube**（頭尾 neuropore 暫開） |
| **day 23–25** | **開始閉合** |
| **day 25** | 🆕 **anterior（cranial）neuropore 閉合** |
| **day 28** | 🆕 **posterior（caudal）neuropore 閉合** |
| **10 週** | 🆕 **椎體軟骨內骨化最早見於下胸椎** |

- neural tube 頂端分出 **neural crest cells** → Schwann cells 等。
- **閉合失敗**：cranial → **anencephaly**；caudal → **spina bifida occulta → meningocele → myelomeningocele** 光譜。

### 1.2 Somites 與 sclerotome 🆕

- 🆕 **somites：4 occipital、8 cervical、12 thoracic、5 lumbar、5 sacral、8–10 coccygeal；成熟胎兒保留 31 對**。
- epithelial-mesenchymal transition → **sclerotome**：
  - **ventral sclerotome → 椎體（centra）**。
  - **central 與 dorsal sclerotome → 椎弓（pedicle、lamina、spinous process）**。
  - **椎間盤 → ventral sclerotome 細胞（notochord 訊號誘導 perinotochordal sheath）**。
- **resegmentation**：每節椎骨來自相鄰 somite 的頭端與尾端。
- 脊髓：**neural tube 背側 → 傳入感覺；腹側 → 傳出運動**。
- Key Study Point：**脊髓由 neural tube 發育（ectoderm 受 notochord 影響內摺）；notochord 之後成為脊柱**。

### 1.3 Conus medullaris 位置 🆕

| 時間 | Conus 位置 |
|---|---|
| **妊娠 3 個月** | 脊髓填滿椎管，與椎間孔對應 |
| **出生** | 🆕 **L3** |
| **3 歲** | 🆕 **L1 或 L2** |

- 脊柱生長速度超過脊髓。

## 2. 脊髓與神經根 ✅

- ✅ **31 對脊神經**以出口椎節命名。
  - **頸椎：從同號 pedicle 上方出**（C6 根在 C6 pedicle 上）。
  - **8 條頸神經、7 節頸椎 → 從 C8 起改從同號 pedicle 下方出**（T1 在 T1 pedicle 下）。
- **腦脊髓膜**：
  - **dura**：脊柱內與骨分離 → **epidural space**（靜脈叢、動脈分支、小韌帶）。
  - **arachnoid**：緊貼 dura，包覆出孔神經根。
  - **pia**：緊貼脊髓，與 **denticulate ligaments**（連接脊髓與 dura）相連。
  - 根入孔處 **arachnoid＋pia 融合 → leptomeninges（subarachnoid angle）**。
- 🆕 **CSF（arachnoid 與 pia 之間）：成人 140–270 mL；每日約完全更換 4 次**；浮力、緩衝、局部恆定。
- 灰質（細胞體）比例由頭往尾遞減。
- ✅ **傳導束**：

| 傳導束 | 功能 |
|---|---|
| **Dorsal columns** | **深壓、本體感覺** |
| **Lateral spinothalamic** | **痛、溫** |
| **Ventral spinothalamic** | **輕觸** |
| **Lateral corticospinal** | 運動；**上肢纖維較深、下肢較淺 → central cord syndrome** |

- 前後 rootlet → 共同節段神經根；**DRG 在後根上**。

## 3. 骨性解剖 🔄

### 3.1 通則

- 椎體（皮質環＋鬆質）→ 兩條 pedicle → 椎弓（lamina、spinous process）。
- **facet（zygapophyseal）joint = 尾側椎 SAP＋頭側椎 IAP**；兩者之間、lamina 外側 = **pars interarticularis**。

### 3.2 頸椎 🔄

- 主要定位頭部、負重較小 → **椎體小薄、內外徑大於前後徑**。
- **Craniovertebral junction**：foramen magnum（後枕骨緣、前 clivus、兩側枕髁）。
- **C1（atlas）**：
  - 🆕 **後弓 sulcus arteriosus（椎動脈溝）最內側平均距後結節 1 cm → 超過此範圍切骨易傷椎動脈**。
  - 無真正 IAP；**前弓內面與齒突形成滑膜關節** → 穩定旋轉、抗水平平移。
  - **Transverse ligament**：附著 C1 內壁、壓在齒突後方；🆕 **屍體 400–1,100 N 斷裂**；實為 **cruciform**（上連枕骨、下連 C2 椎體）。
  - **Apical ligament（齒突尖 → basion）**、**alar ligaments（C2 → 枕髁內側）**。
  - 其他：tectorial membrane（PLL 延續）。
- **下頸椎（C3–C7）**：
  - 橫突有 **transverse foramen**（椎動脈）與前後結節。
  - 🆕 **C6 前結節 = carotid tubercle of Chassaignac**：較大、分隔頸總動脈與椎動脈、前頸觸診標記。
  - 🆕 **C7 可有孔，但很少含椎動脈；11–35% 含椎靜脈與椎神經** → 術前看影像確認個體變異。
  - **Uncinate process → uncovertebral（Luschka）joints**（是否為含滑液的真關節有爭議）。
  - 🆕 **facet 冠狀方向、軸面角度 ≥60°**；🆕 **內側 facet 到硬膜囊外緣約 3 mm**。
  - **lateral mass（articular pillar）** = 頸椎的 pars；pedicle 與 lamina 薄。
  - **棘突分叉（bifid）**。
  - **C7 = 移行節**：棘突長而突出；上終板前後徑小於下終板。
  - **神經孔**：頭尾 pedicle、背側 facet、腹側椎間盤與 uncovertebral joint；**神經根位於椎動脈後方、SAP 前方**（C6 以上）。
  - 背根 rootlet 硬膜內相連 → dermatome 重疊。

### 3.3 胸椎 🆕

- 相對剛性；**costovertebral（pedicle、椎體、肋）** 與 **costotransverse（橫突、肋）** joints。
- 🆕 **肋骨頭位於同號 SAP 腹側、鄰近橫突（T7 肋在 T7 SAP 腹側）**。
- **T11、T12 缺乏真正 costotransverse 關節**。
- 🆕 **T4–T8 椎管由心形轉為圓形**。
- 🆕 **T4 lamina 為全脊柱最窄，平均寬 5.8 mm**。
- 🆕 **pedicle 橫向角：T1 平均 27.4° → T3–T8 接近直向，平均 7.9°**（螺釘方向）。
- 🆕 **橫突中點與 pedicle 的頭尾關係：上胸椎在 pedicle 頭側；T6–T7 齊平；以下在尾側**。
- facet **冠狀**（屈伸穩定、防前後平移）→ **T11–T12 轉為較矢狀**。

### 3.4 腰椎 🆕

- **最大椎骨、承受最大負荷**；內外徑大於前後徑；pedicle 與 lamina 厚。
- 無橫突孔與肋關節；橫突退化；**mammillary process**（multifidus、intertransverse 附著）。
- 🆕 **pedicle 為全脊柱最大；橫向角 14–52°**（介於頸與胸之間）。
- 🆕 **pars：下腰最寬、往上變窄**。
- **facet 矢狀方向 → 屈伸與側彎、限制軸向旋轉**；facet 寬，**SAP（外側）完全覆蓋 IAP（內側）**。
- 🆕 **胸椎（小、冠狀、剛性）→ 腰椎（大、矢狀、活動）的轉換使胸腰交界易受傷**。
- **L5–S1**：前凸區傳遞體重 → 機械應力大。
- 🆕 **移行椎（lumbarized sacral 或 sacralized lumbar）盛行率 12.7–35.6%**。
- 🆕 **腰神經根**：出硬膜後需走到孔：
  - 約在**頭側椎間盤層級**離開硬膜 → 經 **lateral recess**（**前：PLL；後：facet 與 ligamentum flavum；內：pedicle**）下行 → **在 pedicle 正下方出孔**。
  - **dorsal ramus 分 2–4 支**（含 facet joint 神經支配）。
  - 🆕 **出口根緊貼下方 pedicle → pedicle 螺釘偏下易傷根**。

### 3.5 薦尾椎 🆕

- **5 節融合三角形 = 尾側脊柱的 keystone**，連接兩側 hemipelvis 與軸骨骼；**屈曲位**；頭側為 **sacral ala** → SI joint。
- **S1–S3 雖融合，仍保留殘留椎間盤與神經孔**。
- **Sacral hiatus**：S5 缺 lamina 與棘突；含 **filum terminale**（脂肪與纖維）→ 附著尾骨為 **coccygeal ligament（filum terminale externum）**。
- 尾骨：退化殘留、無負重，作為肌肉韌帶附著。

## 4. 韌帶 🔄

- 🆕 **spinopelvic ligaments 是人體最強的韌帶**。

| 韌帶 | 重點 |
|---|---|
| 🆕 **ALL** | **C1 前結節 → 薦骨腹側**；側緣緊貼椎體與椎間盤；🆕 **淺層跨 3–4 節、中層 2–3 節、深層 1 節；深層與 anulus 附著最強，與椎體較鬆** |
| 🆕 **PLL** | **C2 → 薦骨，與顱底 tectorial membrane 連續**；**防止椎體過屈**；🆕 **深層（腹側、貼 anulus）與淺層（背側），中間鬆散纖維＋外側靜脈叢**；最外側附著 pedicle、與 periradicular sheath 相連 |
| 🆕 **Ligamentum flavum** | 分節、位於椎板間；🆕 **附著頭側椎板腹面中段（覆蓋約 60%）與尾側椎板頭緣**；外側到 facet 囊內側；中線 raphe；**彈性蛋白多 → 黃**；抗過屈；**胸腰最厚、頸最薄**（但頸部在椎板尾緣附著強） |
| Supraspinous | 連接棘突最背側；ligamentum nuchae → 薦骨 |
| Interspinous | **腰椎較明顯**；斜行於 supraspinous 與 flavum 之間 |
| Intertransverse | 橫突間（腰較明顯）；**分隔後腹膜與 paraspinal 肌** |
| **Iliolumbar** | **L5 橫突 → 髂骨（SI 關節腹面）** |
| **Sacroiliac** | 🆕 **三區：ventral（薄）、dorsal（主要張力穩定）、interosseous（dorsal 深層）** |
| Sacrotuberous | 後下髂骨、薦骨、尾骨 → ischial tuberosity |
| Sacrospinous | 外側薦骨與尾骨 → ischial spine |

## 5. 肌肉 ✅

- ✅ **固有肌（intrinsic）：穩定並活動軸骨骼、由 dorsal rami 支配**；**外在肌（extrinsic）：活動四肢帶、由 ventral rami 支配**。
- **Suboccipital（C2 與顱骨間）**：rectus capitis posterior major／minor、obliquus capitis superior／inferior → **頭伸展**；前方 rectus capitis（屈）、rectus capitis lateralis（側彎）。
- 🆕 **後頸肌解剖如「吊橋」**：
  - **splenius capitis**（下頸上胸棘突 → 乳突附近）、**splenius cervicis**（胸棘突 → 頸橫突）：伸、側彎、旋轉。
  - **semispinalis capitis**（下頸關節突與上胸橫突 → 上下項線間）、**semispinalis cervicis**（胸橫突 → 頸棘突）。
- 前方：**longus capitis**（屈）；**longus colli**（垂直纖維、小屈曲力臂、同側與對側旋轉）；🆕 **longus colli 截面積與頸椎前凸成反比**。
- **Erector spinae（內 → 外）：spinalis、longissimus、iliocostalis**：
  - spinalis 頸部缺、腰部只剩腱膜。
  - longissimus capitis（頸橫突 → 乳突）、cervicis、thoracis。
  - iliocostalis cervicis、thoracis、lumborum（L1–L4 橫突尖 → 髂嵴與 thoracolumbar fascia）。
- 🆕 **Multifidus**：起於棘突與椎板、附著尾側 2–4 節到薦骨；**密度高、彈性高、sarcomere 短 → 屈曲時提供較大力與穩定**。
- 外在肌：SCM（屈、對側旋、側彎）、strap muscles（舌骨、吞嚥、呼吸道）、scalenes 與 serratus posterior（呼吸）、trapezius、rhomboids、levator scapulae、latissimus dorsi。

## 6. 血管 🔄

### 6.1 動脈 🔄

- 脊髓：**anterior spinal artery（1 條）＋兩條 dorsolateral posterior spinal arteries**；接受 segmental artery 的 medullary 分支。
- ✅ **ASA：主要供應皮質脊髓束、佔脊髓內在血管 80%**；由發育中節段動脈上下吻合支融合而成。
  - 🆕 **腰薦區最粗**（供應近端 cauda equina 與腰薦根）。
  - 🆕 **三區：cervicothoracic（C1–T3）、midthoracic（T3–T8）、thoracolumbar（T8–conus）**；管徑與連續性變異大。
  - 🆕 **Artery of Adamkiewicz（arteria radicularis magna）**：
    - **最大的 anterior segmental medullary artery**；🆕 **由左側第 9–12 肋間動脈分出**（OCR：left posterior 9th and 12th intercostal）。
    - **供應 ASA 下三分之二；conus 與 T6–L4 脊柱的主要血供**。
    - 多重吻合通常保護犧牲，但**左側胸椎入路若未了解個體解剖，結紮或損傷可造成嚴重神經傷**。
  - 頸部與中胸各有約 3 條與 2 條主要 anterior medullary arteries。
  - 動脈中膜與內膜肌層 → **自動調節**；🆕 **背側骨刺壓迫腹側 ASA → 狹窄症的後果**。
- **Posterior spinal arteries**：來自顱內椎動脈或 PICA；較細、叢狀、兩側吻合。
- **Segmental（medullary）arteries**：主動脈分支，沿椎體側面中段由腹往背走 → **入孔後分三支**：
  - **dural branch**（硬膜）。
  - **radicular branch**（穿硬膜，供前後根）。
  - **medullary branch**（上下環，接 ASA）。
- 🔄 **Vertebral artery（V1–V4）**：

| 段 | 走行 |
|---|---|
| **V1** | 鎖骨下動脈或主動脈弓 → scalene 深層上行 |
| **V2** | **C6 橫突孔 → 經各橫突孔 → C2（原文寫 atlas）**；🆕 **前方入路最易醫源傷（與神經根同在附著 uncinate 的纖維韌帶帶內）** |
| **V3** | 出 C2 橫突孔 → **C1 後弓溝內 dural-periosteal ring** |
| **V4** | 穿 posterior atlanto-occipital membrane → 硬膜內 → basilar artery |

- 🔄 **進入變異：5.4% 由 C7、6.6% 由 C5、0.4% 由 C4**（OKU 14：7.5% 由 C7）。
- 🆕 **Ponticulus posticus（dural-periosteal ring 完全骨化）7.1–9.8%** → 後方解剖時可遮蔽椎動脈位置（C1 側塊螺釘注意）。
- 上頸椎另有 lateral spinal arteries（來自硬膜內椎動脈）。

### 6.2 靜脈 🔄

- 🆕 **兩大系統：intradural（硬膜囊內）與 extradural**。
- **Intradural**：
  - **intrinsic**（脊髓本身；徑向＋縱向，複雜吻合）。
  - **extrinsic**：pial 網路（🆕 **頸部背側較明顯、腰薦腹側較明顯**）、縱向靜脈（→ anterior median vein 伴 ASA、posterior median vein）、radicular veins（接硬膜外）。
  - 🆕 **不同於動脈以前方為主，背腹靜脈系統相對平衡**。
- **Extradural**：
  - 接受硬膜內與椎骨回流，🆕 **並參與 CSF 再吸收**。
  - ✅ **Batson plexus**：**無瓣**；Batson 證明骨盆靜脈與顱內靜脈竇直接相通 → **癌症或感染繞過腔靜脈散播**（Key Study Point）。
  - 🆕 **三組：basivertebral vein（椎體）、internal vertebral venous plexus（epidural，椎管內硬膜外脂肪中；側方與椎體中段橫向較密）、external vertebral venous plexus（椎體前方）**。
  - → intervertebral 與 segmental veins → **azygos 系統與 ascending lumbar veins**。

## 7. 椎間盤 🔄

- 組成：**cartilaginous end plates、nucleus pulposus、anulus fibrosus**；功能 = 吸震。
- 🆕 **仰臥 → 站立：腰椎間盤吸收軸向負荷而變扁、變寬**（2024）。

### 7.1 Nucleus pulposus ✅

- **proteoglycan matrix＋不規則 II 型膠原與彈性纖維** → 抗壓。
- 兒童期 **notochordal 細胞 → 類軟骨圓形細胞**：維持低氧、合成 proteoglycan 與 II 型膠原（回應靜水壓）。
- ✅ **aggrecan**（最常見 proteoglycan）有數百條**陰離子 GAG 側鏈** → 吸水。
- 🆕 **健康椎間盤每日可失去並回收最多 25% 水分**。
- proteoglycan／GAG 濃度隨年齡、位置、姿勢改變 → 滲透壓與緩衝力改變；靜水壓依賴 anulus 反壓。

### 7.2 Anulus fibrosus 🔄

- 🆕 **10–20 層高度有序的 I 型膠原同心環**。
- 🆕 **外層：細長類纖維母細胞；內層：球形類關節軟骨細胞**；**徑向彈性纖維**連接各層。
- ✅ **同一層內纖維平行、與椎體成 30°；相鄰層之間彼此 120°**。
- 外層附著椎體周邊；內層直接附著終板；高張力強度。
- ✅ **外 1–2 mm：交感血管周圍神經**；ALL 與 PLL 內**機械受器**（本體感覺）。
- 🆕 **微血管與感覺神經長入 anulus → neuropeptide Y、substance P 等 → discogenic pain**。

### 7.3 血供與營養 🔄

- 🆕 **出生後前 5 年有血管通道穿過終板**。
- 成人靠**兩組微血管叢**：
  - **外 1–2 mm anulus**。
  - **椎體中央 → 骨軟骨交界**。
- 成人營養 = **葡萄糖與氧從椎體微血管擴散** → nucleus 處於**低氧、酸性環境 → 無氧代謝**。

### 7.4 終板 🔄

- ✅ **類似 epiphyseal plate = 椎體生長中心**。
- 🆕 **成人透明軟骨變薄 → 約 1 mm 無血管軟骨（圓形軟骨細胞、II 型膠原）**；**半透性**供養分與廢物交換。

## 9. Key Study Points（OKU 15）

- **脊髓由 neural tube 發育**（ectoderm 受相鄰 notochord 影響內摺）；**notochord 之後成為脊柱**。
- 脊柱分**頸、胸、腰、薦**四區，各有因應負荷與鄰近神經血管的特化解剖。
- **脊髓動脈主要來自 ASA**，輔以兩條背側動脈；**靜脈由硬膜內 intrinsic／extrinsic → 與椎骨靜脈匯成無瓣 epidural plexus（Batson）→ 轉移與感染的通道**。
- **椎間盤 = anulus fibrosus＋nucleus pulposus＋軟骨終板**；nucleus 的動態親水性使椎間盤能吸震並兼顧活動與穩定。
