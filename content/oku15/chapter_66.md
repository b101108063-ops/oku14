## 1. 胸鎖關節（SCJ）🆕

### 1.1 流行病學與解剖

- 🆕 **少見，<5% 肩帶傷**；高能量：**車禍、接觸運動（美式足球、冰球、摔角）**。
- 🆕 **後脫位佔 SC 脫位 3–5%；前方不穩較常見**。
- 🆕 **後脫位約三分之一延遲診斷** → 高度懷疑，常需進階影像。
- SCJ：胸骨柄與內側鎖骨的 diarthrodial joint；吻合度低，卻是**軸骨與附肢骨唯一的關節**。
- 穩定結構：前後囊韌帶、interclavicular、costoclavicular、intra-articular disk ligament；🆕 **最強 = posterior capsular ligament 與 costoclavicular ligament**。
- 🆕 **內側鎖骨骺 18–20 歲骨化、23–25 歲才與鎖骨融合** → 小兒與年輕成人常見的失效點。
- 🆕 **多數小兒「SC 脫位」實為內側鎖骨骨骺骨折（pseudodislocation）**：≤18 歲後方 SC 傷 → **81% 為骨骺骨折、7% 為真脫位**。

### 1.2 表現與影像

- 痛、腫、活動受限（尤其肩外展）。
- 🆕 **後方移位危險：縱膈結構（innominate 血管、內頸靜脈、主動脈弓、迷走與膈神經、氣管、食道）**。
  - 🆕 **約 50% 有呼吸困難、吞嚥困難或咳嗽**；壓迫大血管 → 手臂靜脈鬱血、脈搏隨手臂位置變化。
- 🆕 **Serendipity view（40° 頭向傾斜）**：後脫位時**內側鎖骨較低**。
- 🆕 **雙側 SCJ 進階影像；顯影 CT 優於 MRI**（評估縱膈壓迫）。

### 1.3 治療 🆕

| | 處置 |
|---|---|
| **前方** | **多數吊帶保守**；真脫位可局麻或鎮靜閉鎖復位（肩胛下墊高、往後外推或 towel clip）；🆕 **不穩者不建議開放，告知易復發**；骨骺骨折可重塑 → 可不復位 |
| **後方** | 閉鎖或開放；🆕 **延遲 >2–10 天 → 閉鎖治療失敗與併發症增加**；🆕 **開放 → 減少復發、改善 ROM** |

- 🆕 **<25 歲後方 SC 脫位研究：進階影像最常見 = brachiocephalic vein 受壓 50%；90% 需開放復位；復位固定時無需處置的血管或縱膈傷**。
- 🆕 **血管併發症罕見但致命 → 復位時胸腔或創傷外科待命**。
- 真脫位：縫合撕裂韌帶與囊。
- 🆕 **pseudodislocation 最廣接受 = 縫線固定**（非吸收縫線穿骨骺、從前方幹骺鑽孔穿出，或 suture anchor）。

## 2. 鎖骨骨折 🆕

- 🆕 **佔小兒骨折 7–15%**（最常見之一）。
- 🆕 **新生兒產傷（肩難產）0.2–3.5%**：
  - 重塑極強 → **包裹或袖子別在胸前，數週癒合**。
  - 可先表現 **pseudoparalysis**（自我保護不動）。
  - 🆕 **肩難產合併臂叢麻痺 4–40%** → 初診與癒合後都要仔細檢查。
- 🆕 **年長兒與青少年發生率加倍**（運動與高風險活動）；接觸、直接撞擊、跌倒撞外側肩。
- 🆕 **中段佔 90%**。
- 🆕 **絕對手術適應：皮膚受威脅、血管傷、開放骨折**。
- 其他青少年中段骨折 → **保守**（癒合與重塑力強）：
  - 🆕 **肩固定 3–6 週；10 週內恢復解剖 X 光參數；不癒合 0.6–1.6%**。
  - 🆕 **成人 RCT（移位中段手術不癒合、畸形癒合較少、功能較好）→ 近 20 年青少年手術增加**；🆕 **但 2023 研究：手術增加，翻修率高（多因內固定突出），功能無差**。
  - 🆕 **多篇近期研究：青少年移位中段骨折手術 vs 保守結果相似；保守症狀性畸形癒合少、功能好（包括明顯短縮與粉碎）**（Key Study Point）。
  - 手術時：**precontoured superior plate ± 骨折間螺釘**。
- 🆕 **外側鎖骨骨折 5%**：青少年多為**骨骺分離**（physis 比 CC 與 AC 韌帶弱）。
  - 🆕 **絕對手術：皮膚受威脅（尤其骨幹穿過 trapezial fascia 卡住）、開放、AC 關節內移位**。
  - 🆕 **遠端鎖骨 physis 約 25 歲才閉合 → 重塑強 → 多可保守**；手術：骨膜修補、經骨縫線、plate。

## 3. 肩關節脫位 🔄

- 🆕 **約 20% 外傷性 GH 脫位發生於 ≤20 歲；<2% 發生於 ≤10 歲**。
- **多為前脫位、男性較多**；機轉：**外展外旋時上臂受向後力**（接觸運動）→ labral tear 或骨折。
- 後脫位：**內收內旋上臂受向後軸向力**，或**癲癇**。
- 🆕 **外傷性前脫位腋神經傷最高 42%** → 完整神經血管檢查。
- **復位前後 AP、scapular Y、axillary**；評估近端肱骨 physis（骨折脫位）。
- 急診鎮靜閉鎖復位；🆕 **固定 1–6 週，多為內收內旋**；1–2 週後痛減 → PT 漸進強化。
- 持續痛或 apprehension → 懷疑關節內傷 → MRI。
- ✅ **首次外傷性前脫位後復發 ≥70%**。
- 🆕 **近端肱骨 physis 已閉合者復發較高**（未成熟者囊較有彈性、附著於 glenoid 較外側）。
- 🆕 **2024：10–15 歲 vs 20–29 歲（皆關節鏡）→ 小兒前方鬆弛與復發較高，但關節內傷較少**。
- 年輕成人高品質研究支持首次即關節鏡穩定，🆕 **但青少年無標準演算法**。
- 🆕 **PRiSM（Pediatric Research in Sports Medicine）共識**：
  - **男 <14 歲、女 <13 歲 → 偏好保守**。
  - **首次脫位＋接觸運動＋Bankart＋physis 閉合或將閉合 → 穩定手術**（open physis 或非接觸運動者則否）。
  - **復發前脫位 → 不論 physis 皆穩定手術**。

## 4. 近端肱骨骨折 🔄

- ✅ **約 2% 小兒骨折**；🆕 **佔小兒上肢骨折 14%**。
- 機轉：**FOOSH（肘伸、肩外旋）**或直接撞擊；產傷（同新生兒鎖骨處理）。
- 🆕 **非產傷、<18 個月 → 考慮 NAT**。
- 🆕 **UBC、ABC 可致病理骨折**。
- 腫、壓痛、肩 ROM 受限；**AP、scapular Y、axillary 或 Velpeau**。
- 🆕 **多可保守：85% 無或輕度移位，移位者幼童也重塑良好**。
- ✅ **近端肱骨 physis 提供肱骨 80% 縱向生長**；🆕 **閉合：女 14–17 歲、男 16–18 歲**。
- 🆕 **Neer-Horowitz（遠端片移位）**：

| Grade | 移位 |
|---|---|
| **I** | **<5 mm** |
| **II** | **≤ 1/3 骨幹寬** |
| **III** | **≤ 2/3 骨幹寬** |
| **IV** | **> 2/3 骨幹寬** |

- 可接受範圍依年齡與移位，**無 RCT 或共識**；🆕 **<12 歲冠狀與矢狀成角可重塑到 60°**。
- 保守：**吊帶、shoulder immobilizer 或 hanging arm cast 3–4 週**。
- 🔄 **剩餘生長 <2 年＋成角 >40°，或 Neer III／IV → 強烈考慮手術**（Key Study Point；OKU 14：>13 歲、>40°、Neer IV）。
- 🆕 **2022 SR：嚴重移位青少年保守結果較差；≥12 歲嚴重移位以 K-wire 固定結果極佳**。
- 手術：先閉鎖復位（牽引、外展、內外旋）；🆕 **約 10% 需開放（deltopectoral）**：卡入 **periosteum 及／或長頭二頭肌腱**（或粉碎骨、囊、deltoid）。
- 🆕 **經皮 2.5 mm K-wire（避腋神經，可用 pin-to-pin clamp）；術後 4 週拔**；或 **ESIN**。

## 5. 肱骨幹骨折 🔄

- 🔄 **佔小兒骨折 2–5%**；🆕 **雙峰：<3 歲與 >10–12 歲**。
- 幼兒：產傷或 NAT（包裹或袖子別胸前）。
  - 🆕 **產傷骨折診斷可延遲最多 1 週；但 NAT 佔延遲診斷肱骨幹骨折最多 14%，尤其 <6 個月（2023）**。
- 年長：高能量、運動、高處跌落、**病理骨折（ABC、UBC、fibrous dysplasia）**。
- 🆕 **保守為主：coaptation splint、functional thermoplastic brace、hanging arm cast 約 6 週**。
- 🆕 **手術適應**：**開放、雙側、多重創傷、腔室症候群、神經傷、floating elbow、骨囊腫預防性穩定或病理骨折穩定、不可接受對位**。
- 🔄 **可接受成角**：
  - **<3 歲：最多 45° 可良好重塑**。
  - **>12 歲：中段 >15°，或近端 physis 附近 >20–25° 可能不重塑**。
  - **兩組皆接受 1–2 cm 短縮**（上肢耐受良好）。
- 🆕 手術 vs 保守：手術 X 光較好、固定時間較短，疼痛無臨床差異。
- 🆕 **手術選擇**：ex-fix、plate、閉鎖復位經皮 pin、IM 固定：
  - **接近或已成熟 → plate**。
  - **最近端或最遠端 → 經皮 pin**。
  - **length-stable 骨幹 → flexible IM nail（逆行或順行）**；入口突出有症狀 → **6–12 個月取出**。

## 6. 肱骨髁上骨折 🔄

### 6.1 分類 🔄

- ✅ **小兒最常見肘部骨折**；🆕 **5–7 歲最多、佔所有小兒骨折 3%**。
- 🔄 **extension type 約 98%**（OKU 14：>90%）→ **Gartland**（以側面片為主，AP 提供冠狀對位與內側粉碎資訊）。

| Type | 定義 |
|---|---|
| **I** | 無移位；**anterior humeral line 通過已骨化 capitellum**；🆕 **<5 歲因 capitellum 未成熟可能不通過** |
| **II** | 前皮質斷、**後皮質完整為鉸鏈**；anterior humeral line 在 capitellum 前方 |
| 🆕 **IIa（Wilkins）** | **只有伸直，無旋轉或冠狀不良** |
| 🆕 **IIb（Wilkins）** | **伸直＋旋轉或冠狀不良** |
| **III** | **雙皮質斷、骨膜破** |
| **IV** | **大範圍軟組織破壞，屈與伸皆不穩** |

### 6.2 神經與合併傷 🆕

- 🆕 **神經傷最高 11%**：

| 型 | 神經 | 比例 |
|---|---|---|
| **Extension** | **AIN（最常）** | **5.3%** |
| | **Radial** | **4.5%** |
| | **Median** | **3.3%** |
| | **Ulnar** | **2.3%** |
| **Flexion** | **Ulnar** | **16%** |

- 多數觀察即恢復。
- 🆕 **floating elbow（同側前臂或腕骨折）3–13%**；過去擔心神經血管傷較多，🆕 **2024 大型多中心：腔室症候群低、神經血管傷與單純髁上相同**。

### 6.3 治療 🔄

- ✅ **AAOS 2011 CPG：type I 保守、移位（II、III）閉鎖復位＋pinning（moderate 建議）**。
- **Type I → 石膏 3–4 週**，之後 ROM。
- 🆕 **旋轉或冠狀變形 → 保守失敗增加 → IIb 常規手術**。
- 🆕 **2023：IIa >90% 可保守，X 光與功能結果良好，輕度殘餘變形會隨時間重塑** → 計畫保守時**仔細看 AP 冠狀對位**。
- 🆕 **遠端肱骨重塑潛力差的傳統觀念受質疑，尤其幼童**。
- 🆕 **IIa 保守 → 上石膏約 1 週後追蹤對位**（早期流失可能改變治療）。
- 手術：
  - 多可閉鎖復位；骨膜或軟組織卡入 → 經 antecubital fossa 向近端延伸的切口開放復位。
  - 🆕 **外側入針 2–3 支**；**粗針、多針、內側柱固定、發散（非平行）→ 增加穩定**。
  - 🆕 **type II 兩針、type III 三針**。
  - 🆕 **旋轉不穩（最內側針無法跨過內側柱）或內側粉碎 → 加內側針**；避 ulnar nerve：**小切口＋K-wire 震盪推進**。
  - 🆕 **3–4 週拔針開始 ROM；PT 通常不需（多數 2 個月內恢復 ROM）**。

### 6.4 血管與腔室 🆕

- 🆕 **兩類無脈手**：
  - **無脈但灌流良好（粉紅或原膚色）→ 緊急進手術室（urgent）**。
  - **無脈且缺血（蒼白）→ 骨科急症（emergency）**。
- 肱動脈可能**痙攣、披掛在骨折上、內膜瓣傷或撕裂**。
- 🆕 **約 3% 手術治療的髁上骨折無脈；其中 14% 有需介入的血管傷**。
- 復位 pinning 後重新評估：
  - 灌流良好 → 密切觀察脈搏恢復。
  - **仍缺血＋復位後骨折間隙 → 動脈卡入** → 開放。
  - 無法復位或閉鎖嘗試後仍缺血 → **開放復位並檢查軟組織**。
  - **復位良好仍缺血 → 緊急血管外科會診**。
- 血管傷＋腫脹與再灌流 → 腔室症候群風險。
- 🆕 **兒童腔室症候群的三 A：anxiety、agitation、analgesia 需求增加**。
- 🆕 **復位固定後石膏肘屈 <90°** → 降低腔室壓、避免進一步血管危害。

### 6.5 其他併發症與亞型 🆕

- 冠狀面低估或復位不良 → 畸形癒合：
  - 🆕 **cubitus varus（gunstock）較 cubitus valgus（與 tardy ulnar nerve palsy 相關）常見（2024）**。
  - 多為外觀問題，嚴重者可伴**後外側不穩**。
- 🆕 **青少年類成人型：T 型關節內遠端肱骨骨折 → 開放復位＋pin、螺釘或 plate**。

## 7. 外髁骨折 🔄

- ✅ **小兒肘部第二常見**；🔄 **佔 12–20%**。
- 難處：**關節面復位品質影響結果，但幼童外髁多為軟骨，X 光不易評估**。
- 🆕 **以幹骺端骨折間隙作為關節軟骨移位指標分類；internal oblique 片量最準**。

| 幹骺端移位 | 處置 |
|---|---|
| ✅ **<2 mm** | **閉鎖治療＋石膏 4–5 週** |
| 🆕 **2–4 mm** | **評估關節完整性（多為術中關節攝影）：可復位且關節面吻合 → 閉鎖復位即可；不穩 → 加經皮 pin** |
| 🆕 **>4 mm，或閉鎖無法復位關節軟骨** | **ORIF** |

- 🆕 **外側入路；勿向後剝離 → 增加 capitellum ON 風險**。
- 關節面復位後以 **K-wire 或螺釘**固定；🆕 **關節內 → 比髁上骨折癒合慢；K-wire 約 4 週拔**。
- 🆕 **併發症**：

| 併發症 | 比例 |
|---|---|
| **ON** | **1.4%** |
| **Malunion（fishtail 或 cubitus valgus）** | **<1%** |
| **Nonunion** | **1%** |
| 🆕 **Lateral spur（最常見）** | **73%**（骨膜掀起；可有外觀變形但**無功能缺損**） |

---

## 8. 內上髁骨折 🔄

- 可單獨或伴肘脫位；運動傷或跌倒時大 valgus 力。
- **屈肌旋前肌群＋UCL 附著於骨片 → 向前下移位**。
- 🆕 **前移難以在正交片上看清 → distal humerus axial view 量位移較準**。
- ✅ **伴脫位時，復位後片要仔細看：內上髁骨片可能卡入關節**。
- 🆕 **治療有爭議**（手術未被證明較優）；考量：**初始位移、是否伴脫位、年齡、慣用手、過頭運動**。
- 🆕 **處置**：

| 情況 | 處置 |
|---|---|
| **無移位、不伴脫位** | **長臂石膏 3–4 週**後 ROM |
| 🆕 **移位 >0.5 cm，或伴肘脫位** | **考慮手術** |
| ✅ **脫位復位後骨片卡入關節** | **開放復位＋螺釘或 K-wire** |

- 🆕 **部分中心伴脫位者依 AO 原則剛性固定、早 ROM 防僵硬；但肘脫位只是相對適應，許多中心保守**。
- 🆕 **最常見併發症：僵硬、內固定突出**。
- 🆕 **保守 nonunion 最高 70%，但 fibrous union 多足以日常活動、很少有症狀**。
- ❌ OKU 14 的「**8 mm 多數醫師手術、≥19 mm 所有醫師手術**」未列。

---

## 9. 鷹嘴骨折 🔄

- 🔄 **約 5% 小兒肘部骨折**（OKU 14：約 7%）。
- **triceps 撕脫機轉**或直接撞擊。
- **輕移位、無明顯關節台階 → 長臂石膏，約 4 週輕柔 ROM**。
- **移位 → 手術**（維持 triceps 功能、恢復關節面）：**tension band（18-gauge wire 或粗非吸收縫線）、IM screw、plate**；考量內固定突出。
- 🆕 **輕微外傷、雙側、年幼 → 懷疑 osteogenesis imperfecta**。

---

## 10. 近端橈骨骨折 🔄

- ✅ **小兒橈骨頸比橈骨頭骨折常見**；AP＋lateral。
- ✅ **>10 歲可容忍 30° 成角，更年幼可更多**（重塑）。
- 不可接受 → **閉鎖復位**：
  - 直接推壓。
  - 🆕 **Patterson：伸直、旋後、varus＋直壓橈骨頭**。
  - 🆕 **Israeli：Esmarch 繃帶纏繞前臂與肘**。
  - 閉鎖後石膏 **2–3 週**。
- 閉鎖失敗 → 🆕 **經皮 K-wire 於骨折處撬回**；🆕 **Métaizeau：逆行 flexible IM rod，用尖端旋回橈骨頭**。
- 再失敗 → **開放（外側入路保護 PIN）**；多數復位後穩定，不穩 → K-wire，少數需 plate。
- 🆕 **開放治療併發症約 40%**：**僵硬最常**；PIN 傷、HO、radioulnar synostosis。
- 🆕 **閉鎖或開放術後都要告知僵硬風險與可能需 PT**。

---

## 11. 肘脫位 🔄

- ✅ **約 3% 小兒肘部傷**；多為初始 valgus 力 → 內側結構失效 → 可伴內上髁骨折。
- 🆕 **約 90% 後或後外；64–78% 合併骨折；33–55% 合併內上髁骨折**。
- 正交片；🆕 **嬰幼兒要區分 ulnohumeral 脫位 vs distal humerus transphyseal separation**。
- 急診鎮靜閉鎖復位 → 復位後片：**內上髁卡入、關節間隙增寬（osteochondral 傷）**。
- 🆕 **單純脫位 → 長臂石膏或副木 2 週 → 早期 ROM**。
- 多數良好到極佳；🆕 **多重骨折、手術、長期固定 → 結果較差；每多固定一天，excellent 結果的 odds 下降 4%**。

---

## 12. 遠端肱骨經骨骺骨折（transphyseal separation）🆕

- 🆕 **少見，<約 3 歲**；**常被誤為肘脫位或延遲診斷**（幼兒遠端肱骨全為軟骨）。
- 原因：**產傷、NAT、高處跌落**。
- 🆕 **懷疑 NAT → skeletal survey＋社工介入**。
- 🆕 **2022：小兒肘骨折 NAT 整體盛行 0.4%，但 <1 歲高達 30%**；<1 歲中 **髁上（58%）比 transphyseal（18%）常見，但 transphyseal 83% 為 NAT**。
- 嬰兒常表現 **pseudoparalysis**。
- 影像：專門肱骨、肘、前臂 AP＋lateral：
  - 🆕 **前臂與肱骨幹不對齊；多為後內側移位（ulnohumeral 脫位多為後外側）**。
  - 🆕 **capitellum 骨化中心出現後（女約 2 歲、男約 3 歲），capitellum 與橈骨幹對齊，而非與遠端肱骨對齊**。
  - 🆕 **超音波**：capitellum、trochlea 與遠端肱骨、capitellum 與橈骨頭的關係，以及**遠端肱骨幹骺未被骨骺軟骨覆蓋的裸露面**。
- 🆕 **多為移位 → 閉鎖復位＋肘關節攝影＋經皮 pinning（多外側入針）**。
- 併發症同髁上，🆕 **另有較特有的生長障礙**（造成移位的力量傷及軟骨與其血供）→ 🆕 **典型表現為進行性 cubitus varus**。

## 13. OKU 14 CH58 中 OKU 15 不再列出的內容 ❌

- ❌ **內上髁：8 mm 時多數醫師手術、≥19 mm 時所有醫師手術**。
- ❌ **橈骨頸 <10 歲可接受 45°；>10 歲可接受 2 mm 平移**（本版只寫 >10 歲 30°、更年幼可更多）。
- ❌ **近端肱骨「>13 歲、Neer IV」手術門檻**（改為 <2 年生長、Neer III／IV）。
- ❌ 肘部神經學危險區與骨化中心時序的獨立段落（本版只在 transphyseal 提 capitellum 骨化年齡）。

## 14. Key Study Points（OKU 15）

- **多數鎖骨骨折（含青少年移位中段骨折）可保守**；多篇近期研究顯示手術與保守結果相似。
- **多數近端肱骨骨折可保守**（重塑力）；**剩餘生長 <2 年＋>40° 成角或 Neer III／IV** 可能受益於手術（多為閉鎖復位＋pinning）。
- **髁上骨折**從良性 type I 到伴神經血管危害甚至腔室症候群的 III／IV；**及早辨識已發生或即將發生的神經血管危害並適當處置**至為重要。
- **外髁骨折易發生延遲併發症** → 急性期及時診斷與適當處置可避免。
- **內上髁骨折處置有爭議**；考量位移、慣用手、過頭運動、伴脫位、骨片卡入關節等。
