## 1. Rotator Cuff 撕裂

### 1.1 盛行率與自然史 🆕
- 範圍：bursitis、partial、full-thickness、massive irreparable；**退化性最常見**（盛行率隨年齡上升）
- **無症狀肩 MRI（96 人）**

| 年齡 | 全層 | 部分層 |
|---|---|---|
| **40–60 歲** | **4%** | **24%** |
| **>60 歲** | **28%** | **24%** |

- 無撕裂者平均 **48.7 歲**、單側撕裂者 **58.7 歲**
- **≥66 歲有症狀撕裂 → 對側有撕裂的機率 50%**
- **超音波（413 肩）**：**脂肪退化幾乎只見於全層撕裂**（部分層只有 2 肩）；**撕裂每大 5 mm（任一方向），supraspinatus 與 infraspinatus 脂肪退化 odds 加倍**；**anterior cable 斷裂 → 脂肪退化風險較高**
- 另一研究：**cable 斷裂 → 進展 67% vs cable 完整 52%**（趨勢、不顯著）
- **Rotator cable**：從 biceps tendon 延伸到 infraspinatus 下緣，跨 supraspinatus 與 infraspinatus 止點；**suspension bridge 概念**：cable 完整時即使有全層撕裂，仍能壓住肱骨頭維持穩定
- 解剖：傳統看 **acromion 型態（type I、II、III）**；🆕 **critical shoulder angle（CSA），尤其外側突出；CSA >35° → 退化性撕裂較多**

### 1.2 保守治療 🔄
- 低進展風險者 + 衛教自然史 → 可保守
- 🆕 **美國有症狀撕裂只有 5% 接受手術**
- PT、CSI、NSAID
- 🆕 **前瞻多中心（422 人）：74% 靠 PT，2 年內不需手術**

## 2. Partial-Thickness 撕裂 🆕

### 2.1 Articular vs Bursal
- 多由 MRI 診斷、常為偶然發現 → 依症狀與檢查決定
- **Intratendinous 最常見**；**articular-side 比 bursal-side 多 2–3 倍**

| | Bursal-side | Articular-side |
|---|---|---|
| 機轉 | **外在 impingement**（acromion、CA ligament、distal clavicle）；關節鏡可見**肩峰下表面病灶** | **內在因子**：**低血供、張力強度下降**、cuff overload |

- **195 人無症狀撕裂**：**<50% 厚度 → 無進展**；**>50% → 4% 進展**
- 多數 **6 個月保守**（活動調整、NSAID、CSI、cuff PT）會改善

### 2.2 手術
- **保守失敗 >6 個月**考慮手術
- **<50% 厚度＋CSA 增加 → 關節鏡清創＋acromioplasty**：45 人 **22 年追蹤**，未修補者只有 3 人出現 cuff arthropathy，**多數 partial tear 維持不變、功能好**
- **Articular-side partial tear**

| 術式 | 結果 |
|---|---|
| **In situ（transtendon）repair** | 100 人：24 個月 ROM 與對側無差異；80 人：62 個月滿意 **92.5%** |
| **Takedown（完成撕裂後修補）** | 94 vs 59（in situ）：Constant、SST、滿意度無差異；**retear 13.5% vs 13.9%** |

- 🆕 **Patch augmentation**：33 例 **onlay bovine collagen patch** → 1 年 MRI **肌腱增厚 2 mm、24% 完全癒合、70% 撕裂縮小**；但 **2022：術後僵硬增加**

## 3. Full-Thickness 撕裂

### 3.1 Retear 危險因子 🆕
- **整體癒合失敗約 25%**
- **MA（14 篇、5,693 人）**

| 類別 | 危險因子 |
|---|---|
| 病人 | **年齡↑、BMI↑、症狀時間↑、BMD↓、糖尿病** |
| 影像 | **subscapularis 與 infraspinatus 脂肪退化**、**撕裂大小與回縮↑**、**CSA↑**、**acromiohumeral interval↓** |

- 🆕 **Rotator Cuff Healing Index（RCHI，603 人，失敗 24%）**
  - 獨立危險因子：**>70 歲、前後徑大小、回縮、infraspinatus Goutallier ≥2、低 BMD、高工作活動量**
  - **15 分制**

| RCHI | 癒合失敗率 |
|---|---|
| **≤4 分** | **6%** |
| **≥10 分** | **86.2%** |

### 3.2 修補構型 🔄
- **關節鏡修補 = gold standard**
- **雙排**：較能重建 footprint、生物力學較好；單排支持者在意成本
- 🔄 **2023 MA（10 篇：雙排 404、單排 387）**：**雙排前舉較好、retear 較少**；**>3 cm → 雙排 ASES、UCLA 較好、retear 較少**
- 不是每個撕裂都能做雙排（肌腱缺損、活動度差）→ **單排、不內移 footprint**
- 肌腱品質差 → **rip-stop suture** 防止切穿
  - 🆕 **load-sharing rip-stop：大型與巨大撕裂癒合 53% vs 傳統單排 11%**

### 3.3 補強

**Graft／scaffold** 🔄
- 失敗最常見位置：**suture–tendon interface** 與生物性
- **2023 SR（47 動物、15 臨床）**：動物 **87.2%** 組織學與力學改善；臨床 **66.7%** 功能改善；**補強者 retear 顯著較低**
- 另一 SR：補強可能降低 retear，**沒有哪一種移植物較好**

**細胞補強** 🔄
- 證據最多：**PRP、BMAC**
- **MA（Level I、II，880 人）：PRP retear 16% vs 對照 24%**；Constant、UCLA、VAS 也較好
- 🆕 **Leukocyte-poor PRP 促進癒合的潛力較高**
- 🆕 **BMAC（iliac crest，45 vs 45）**

| | BMAC | 對照 |
|---|---|---|
| 6 個月癒合 | **100%** | 67% |
| **10 年癒合** | **87%** | **44%** |

  - 但對照組癒合率低於現今技術預期 → 需更多研究

### 3.4 合併手術 🔄
- **Acromioplasty**
  - 多項短期研究：有無 acromioplasty 功能無差異
  - 🔄 **2022 多中心 RCT（平均 11 年）：沒做 acromioplasty → 再手術風險增加，尤其 type II 或 III acromion**
- **Biceps**：🆕 **2022 回顧（244 人）：單純修補 vs 合併 biceps 處置，2 年無差異** → 依病史與檢查決定
- **Distal clavicle excision（DCE）**
  - 🆕 **前瞻 497 人（有症狀 AC 關節炎 185、無症狀 312），都不做 DCE** → 平均 28 個月 ASES、Constant **無差異**，**只 5 人之後需 DCE** → **不建議例行 DCE**
  - 但若關節鏡下見鎖骨下表面造成內側 cuff impingement → **coplaning** 幾乎沒有壞處

## 4. 不可修復撕裂 🔄

| 選項 | 重點與數據 |
|---|---|
| 🆕 **Partial repair** | **suspension bridge 概念**：修補撕裂邊緣、重建 rotator cable，恢復 force couple（可用 biceps 重建 cable）；**34 人、前舉功能保留的巨大不可修復撕裂 5 年：PROM 改善、ROM 保留、失敗 29%、滿意 75%** |
| **SCR** | 原始：**fascia lata** 壓住肱骨頭 → **acromiohumeral interval 增加**、功能改善；改良：**LHBT** 或 **human dermal allograft**；🔄 **多中心真皮 SCR：成功約 70%，但 MRI 完全癒合只約 45%**；**常無法恢復肌力**；**併發症 13.9%**（retear、固定失敗、部分癒合） |
| 🆕 **Biologic tuberoplasty** | 發現真皮移植物多在 glenoid 或中段失敗，但只要外側覆蓋維持仍能止痛 → **只把 dermal allograft 固定在大結節**（可合併 partial repair）；2023（10 人、21 個月）ASES、SANE、VAS 改善；**無與 partial repair 的比較資料** |
| **Subacromial balloon** | 🆕 **2012 首次描述、2021 美國核准 ≥65 歲**；充液、數月內吸收；🔄 **2022 IDE（184 人）：balloon vs partial repair → 兩組 ASES 都改善，balloon 前舉較好**；🔄 **2022 雙盲 RCT（24 中心、117 人）：清創＋biceps tenotomy 優於 balloon**（Oxford、Constant、屈曲、外展、WORC） |
| **Latissimus dorsi transfer** | 後上撕裂、**subscapularis 必須完整或可修補**；內旋肌轉為外旋肌；🔄 **115 肩、9.3 年：Constant、ASES、VAS 改善，但只 18 肩完全不痛、臨床失敗 10%** |
| **Lower trapezius transfer** | **Achilles allograft** 接 lower trapezius → 大結節，**拉力線較接近 infraspinatus**；🔄 **2024 MA（7 篇、159 人）：前舉與外旋改善、ER lag 消失，5% 轉 RSA**；短期研究：**很滿意僅 67%、全職回工作 50%、1 年內 20% 轉 RSA** |
| 🆕 **不可修復 subscapularis** | **Pectoralis major 上半經 conjoined tendon 深面轉到小結節**（需游離 **musculocutaneous nerve**，結果不一）；pectoralis minor（excursion 與大小受限）；**latissimus 前轉 → 拉力線比 pectoralis major 更接近 subscapularis** |
| **RSA** | 原為 cuff arthropathy，適應症擴大；**術前功能好 → 滿意度差的危險因子**；併發症高於關節鏡選項；🆕 **無關節炎的不可修復撕裂（60 肩、52 個月）：全部改善，併發症 20%**；🆕 **<55 歲（67 人）：併發症 22.4%、翻修 8.9%**；🆕 **2024 SR（343 primary vs 95 曾修補）：曾修補者併發症 18.2%、翻修 11% vs 2.9%、3%** |

## 5. 鈣化性肌腱炎 🔄

### 5.1 病因與自然史
- **calcium hydroxyapatite** 沉積於 cuff 肌腱；**40–50 多歲**；女性、**非勞力工作者**較多
- 危險因子：**糖尿病、甲狀腺功能低下、自體免疫**等
- 🆕 **幾乎都在肌腱內、距止點平均 1–2 cm**；**supraspinatus 80%**
- 🆕 **影像對應**

| 部位 | 最佳 view |
|---|---|
| Supraspinatus | **AP（中立旋轉）** |
| Infraspinatus、teres minor | **Axillary 或內旋 view** |
| Subscapularis（少見） | **外旋 view 或 axillary** |

- MRI 非必要：**T1 低訊號**；**T2 周圍高訊號帶（水腫）→ 可能被誤判為 cuff 撕裂**
- 超音波可診斷但依賴操作者

**🆕 兩種理論**
- **退化性鈣化**：年齡退化 → tenocyte 壞死 → 肌腱內鈣化
- **反應性鈣化（三階段）**

| 階段 | 內容 |
|---|---|
| **Precalcific** | tenocyte 經 **fibrocartilaginous transformation** 化生 |
| **Calcific — formative** | 鈣晶體沉積形成大塊；血管增加、發炎 |
| **Calcific — resting** | **fibrocollagenous tissue** 包圍 → 沉積停止 |
| **Calcific — resorptive** | **macrophage、多核巨細胞**吞噬鈣 → **最痛** |
| **Postcalcific** | 組織重塑，**通常不痛** |

**Formative vs Resorptive（決定處置）**

| | Formative | Resorptive |
|---|---|---|
| 疼痛 | 慢性或無痛 | **急性**，常合併**發炎性滑囊炎** |
| X 光 | **邊界清楚、緻密、均勻** | **不規則、邊界模糊** |
| 外觀 | **粉筆狀（chalklike）** | **糊狀（paste）** |

### 5.2 治療

| 治療 | 結果 |
|---|---|
| NSAID（口服或外用） | **短期（7–14 天）止痛**；不建議長期（腸胃） |
| PT、CSI | 短期止痛 |
| 🆕 **整體保守成功率** | **60–80%** |
| **US-guided barbotage**（抽吸＋沖洗 ± CSI；微創傷增加血供促吸收） | **成功 50–90%**、併發症低（多為疼痛）；**barbotage＋CSI vs 只 CSI → 1 年 Constant 較好**；非隨機研究：1 年較好，但 **5、10 年趨於相同** |
| **ESWT** | 改善症狀、影像吸收；併發症：**局部血腫**；**134 人 vs placebo：持續改善，高能量優於低能量** |

- **保守失敗危險因子**：🔄 **鈣化 >1 cm → 手術清創機率約 3 倍**；**雙側、前方病灶、肩峰下 impingement**

### 5.3 手術：清創 ± 修補 🆕
- **2025 MA（21 篇、1,172 人、平均 24.7 個月）**：清創 vs 清創＋cuff 修補 → **兩者功能改善效果都非常強**；**修補組併發症較多**
- 但**修補 → 肌腱結構完整性較好**：回顧 44 人 → 修補組術後肌腱完整較好；**2022（46 人）：修補組 2 年以上疼痛較低、功能較好**，MRI（27 人）完整性較好
- 結論：**清創＋修補短期較差、長期（疼痛、功能、肌腱完整）較好**

## 6. 沾黏性肩囊炎（Frozen Shoulder）🔄

### 6.1 病因與自然史
- 定義：**盂肱關節囊增厚造成疼痛與僵硬，且沒有其他肩部病變**；可特發或外傷、手術後
- 🆕 **特發性盛行 2–5%**；**40–60 歲**
- 危險因子：**女性、糖尿病、心臟病、甲狀腺疾病、曾得過、疫苗注射**
- 🆕 **糖尿病族群盛行 13.4%**（18 篇 MA）；發病較年輕；**與糖尿病病程正相關、與 HbA1c 無關**
- 🆕 **手術後（肩或乳房）5–11%**；**乳癌乳房切除後 ≥10%**
- **自限性，1–3 年完全緩解**

**🆕 四期**

| 期 | 特徵 |
|---|---|
| **1. Inflammatory** | 肩痛（**以夜間為主**）、**活動度保留**；cytokine（**TGF-β、TNF-α、COX-1／2、IL**）、白血球（B／T 淋巴球、macrophage、mast cell） |
| **2. 僵硬開始** | **早期纖維化，主要在下關節囊**；**內旋與外旋最先喪失**；**fibroblast → myofibroblast** |
| **3.** | 發炎消退但持續纖維化；**主動與被動 ROM 全面喪失＋疼痛** |
| **4.** | **持續僵硬、疼痛改善** |

- 簡化為三期：**painful、stiff、thawing**
- **典型：主動與被動 ROM 都喪失，X 光正常**
- MRI 非必要；可見**關節囊與 coracohumeral ligament 增厚**、**axillary recess 縮小**、關節囊水腫或血管增加

### 6.2 保守
- NSAID、PT、CSI；低強度 vs 積極 PT 結果不一；CSI 可讓 PT 較能忍受
- 🆕 **雙盲 RCT：關節內 CSI → 6、12 週疼痛較少，26 週後差異消失**；MA 一致：短期有效
- 🆕 **74 人 RCT：CSI vs 口服 diclofenac（都做 PT）→ CSI 8 週較好，12 週後無差異**
- 🆕 **2024：PRP vs CSI → 3 個月都改善，PRP ROM 較好但未達 MCID**
- **糖尿病病人要告知 CSI 會暫時升高血糖**

### 6.3 保守失敗危險因子 🆕
- **1,377 人回顧**
  - **糖尿病女性較常需手術**；非糖尿病者較能只靠 PT 緩解
  - **有打針者較 PT-only 改善**
  - **>1 次關節內注射沒有額外效益**
  - **早期手術（<6 個月）結果不比延遲差，且症狀期較短**
- → **疼痛無法忍受、夜間痛影響睡眠 → 早期手術是安全有效的選項**

### 6.4 介入

| 方法 | 重點 |
|---|---|
| 🆕 **Hydrodilatation** | 加壓液體撐開並撕裂關節囊；安全、成本效益好、立即見效；**RCT（121 人）：hydrodilatation＋interscalene 下操作 vs CSI → <6 週 ROM 與滿意較好，12 個月無差異**；250 人（35 mL 類固醇＋局麻＋生理食鹽水）：34 人需再介入，全部改善 |
| **MUA** | 全麻 ± 區域阻斷；**避免在 painful phase 做**；**stiff phase 最適合**；術後立即 PT；風險：**骨折、cuff 撕裂、盂肱損傷** |
| **Arthroscopic capsular release** | 保守失敗者；可檢查關節內結構、控制性 capsulotomy、**骨折風險較低**；術後立即 PT |

- 🔄 **MUA vs release SR（22 篇、989 人）：疼痛與 ROM 改善相似**
- 🆕 **30 vs 30 配對**：12 個月都改善；**MUA 3 個月 VAS、ASES、ROM 較好**，但 2 人因復發需再打針
- 🆕 **133 人完全 release：ER 1 週平均 +55°；持續極度疼痛 38% → 1 週 30% → 6 個月 2%**
- 🆕 **51 人 limited anterior release＋輕柔操作**：短長期改善；**術後型冰凍肩長期分數有較低趨勢**
- 🆕 **RCT（75 人、18 個月）：limited vs extended release → ASES、SST、VAS、ROM 無差異**
