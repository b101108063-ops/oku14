## 1. 解剖與生物力學 🆕

### 1.1 關節特性

- 影響股四頭力量、步態、足與髖力學。
- 🆕 **髕骨 = 伸肌機轉的 fulcrum**：增加伸肌作用線與膝旋轉中心距離 → 增加股四頭產生的力。
- 🆕 **axial 平面吻合、sagittal 平面接近點接觸** → 幾何特殊。
- **對骨性結構異常極敏感**：滑車變平或凸（dysplasia）→ 非線性 tracking 或不穩；小異常也增加 PF 軟骨負荷。
- 其他結構因素：**髕骨高度、脛骨與股骨旋轉**。

### 1.2 軟組織 🆕

| 結構 | 重點 |
|---|---|
| 🆕 **MPFC（MPFL＋MQTFL）** | **主要靜態 checkrein（抗外移）**；薄：**平均抗張破壞 208 N（ACL 約 1,700 N）**；**strain modulus 49%**；**斷前平均延長 26 mm** |
| 🆕 **VMO** | **內側主要動態穩定；相對髕骨約 60° 向量** |
| 外側 | **vastus lateralis、ITB retinacular expansion** → 外向力；**緊的外側 retinaculum 或 ITB** 增加 lateral tilt 與 tracking |

- **內外動態失衡＋內側限制不足（通常合併骨性異常）→ 不穩與 maltracking**。

### 1.3 發育 🆕

- 步驟未完全建立；資料多來自兒童屍體與動物；**異常是先天還是發育未知**。
- 髕骨最初嵌在股骨前皮質，隨股四頭與髕腱發育而分離、骨化。
  - 🆕 **鼠：股四頭缺如 → 髕骨永不與股骨分離** → 股四頭向量與 PF 壓力對正常發育很重要。
- **Dysplasia 是因還是果？可能互為因果、自我強化**：
  - 🆕 **大鼠早期外移髕骨 → 平坦滑車、外側面軟骨過度生長** → 髕骨位置決定滑車形態。
  - 🆕 **胎兒超音波 348 膝 → 17 例 dysplasia，與臀位（breech）高度相關**；形態與成人類似、新生兒已可見 → **支持先天**。
- 不知道髕骨或滑車何者為起因 → 影響外科醫師偏重滑車或髕骨的治療取向。

### 1.4 命名 🆕

- 🆕 **IPSG：不用 misnomer「patellofemoral syndrome」**（泛指無不穩的前膝痛）。
- 改用具體名稱：**patellar maltracking、Hoffa pad impingement、patellar chondromalacia**。
- 非不穩 PF 問題 → 判斷 **structural 或 dynamic**，以利衛教、復健、與 PT 溝通。

## 2. 評估 🆕

### 2.1 病史（Table 1）

| 項目 | 例 |
|---|---|
| 家族史 | 親屬復發不穩、手術或關節炎 |
| 主訴 | 不穩 vs 痛 vs 兩者 |
| 機轉 | 接觸 vs 非接觸 vs 非外傷 |
| 首次外傷 vs 復發 | — |
| 其他關節不穩 | 復發肩不穩 |
| 先前手術 | loose body 取出、**單獨 lateral release** |
| 加重活動 | 弓步、跪、切轉運動 |
| 影響活動 | ADL、走路、上下樓、運動 |
| 先前治療 | 護具、貼紮、PT |

- 另：**症狀開始年齡、不穩次數與頻率**。

### 2.2 理學檢查 🆕

- **步態**：foot progression angle、limp、lurch、動態變異；**功能測試**：單腳站、蹲、上下台階。
- 對位：**負重與仰臥都看**；兩膝與整個下肢；**髖活動度與肌力**。
- 🆕 **所有髕骨不穩病人都做 Beighton score**（廣泛性過度鬆弛）。
- **視診**：腫、皮膚、萎縮、變形；🆕 **grasshopper eyes（髕骨外傾或半脫位）**。
- **ROM**：被動可能完整但**因無股四頭收縮而掩蓋 maltracking**。
- 🆕 **Tracking：坐床緣、主動屈伸最好**。
  - 🆕 **J sign：接近完全伸直時髕骨病理性外側半脫位，或早期屈曲時突然內移入溝**。
  - 🆕 **Jumping J sign：髕骨外移出溝時突然跳動 → 推測碰到 supratrochlear spur**。
  - 低屈曲角 crepitus：dysplasia＋spur 或近端 chondromalacia。
  - 🆕 **J sign（跳或不跳）與 trochlear dysplasia、patella alta 強相關；穩定手術後結果仍較差**。
  - 🆕 **嚴重度分級無共識、評估者間信度很低**。
- **觸診**：鬆弛、tilt、痛點。
  - 🆕 **內外移以髕骨寬度的 quadrant 計；在完全伸直與早期屈曲（30–60°）都測，觀察 apprehension**。
  - 🆕 **≥3 quadrants = 病理性鬆弛；<1 quadrant = 病理性活動不足**。
  - 🆕 **伸直時不穩 → 韌帶不足；較大屈曲時不穩 → trochlear dysplasia**。
  - **Tilt**：伸直原位，及能否用手把外傾矯正到中立或以上。
- 🆕 **Ober test：ITB 緊 → maltracking、外側壓力增加與痛**。
- 標準膝檢查：雙側 ROM、joint line 壓痛、十字與副韌帶。
- 🆕 **髖：內旋 >60° → 安排 femoral version 檢查**；🆕 **thigh-foot angle（俯臥）→ tibial torsion**。

### 2.3 X 光 🔄

- **一定要照**。
- 🆕 **True lateral：膝 20–30° 屈曲；完美側面 = 後髁完全疊合** → 評估 alta 與滑車形態。
- ✅ **Caton-Deschamps Index**：**髕骨關節面最下緣到前脛骨平台距離 ÷ 髕骨關節面長度**。
- ✅ **Dejour classification**；🆕 **三關鍵徵象**：

| 徵象 | 意義 |
|---|---|
| 🆕 **Supratrochlear spur** | 外側滑車面近端；常見於**高度 dysplasia** |
| 🆕 **Crossing sign** | 滑車底與外側滑車面輪廓相交（正常不會）→ 該處滑車底與外髁齊平；**96% 異常病例出現** |
| 🆕 **Double contour** | 上滑車處內側面輪廓明顯小於外髁 → **內側滑車發育不良**；位於近端（早期屈曲髕骨入溝處） |

- 🆕 **Merchant view 30°**：更深屈曲會**假性隱藏半脫位或 tilt**；多數 dysplasia 遠端仍有溝 → 深屈時髕骨看似置中。
  - 🆕 **標準 sunrise 在中度屈曲（>30°）→ 無法評估早期屈曲**（近端滑車形態與軟組織最關鍵處）。

### 2.4 MRI 與其他 🔄

- 🆕 **首次脫位也應做 MRI：脫位後軟骨傷最高 85%**。
- 評估脛股腔室、PF 軟骨、**MPFC**、滑車形態、**TT-TG**。
  - ✅ **TT-TG**：反映遠端髕骨外向力量；**軸位疊合滑車溝最深點與脛骨結節最突點，與後髁線切線量**。
  - 🆕 其他量測（臨床意義未定）：TT-PCL、sagittal TT-TG、lateral trochlear index、patellar-trochlear index、lateral patellofemoral angle。
- 🆕 **股骨與脛骨旋轉過度 → 不穩且穩定手術結果較差；懷疑時 CT = 量化 torsion 金標準**。
- 🆕 **冠狀不良（genu valgum）→ 單張含髖與踝的全下肢負重片**量測與規劃。

## 3. 非手術治療 🆕

- 🆕 **IPSG 共識：首次脫位（無需取出或修補的 loose body）→ 保守 = 標準（100% 同意）**。
- 依腫、痛、合併傷：**先抗發炎 → 恢復 ROM → 股四頭再啟動與強化 → 逐步回基本功能、劇烈活動、運動**。
- 🆕 **lateral buttress brace 常用，但無明確證據降低復發**。
- 🆕 **復發不穩 → 手術；多數支持 MPFC（MPFL 或 MQTFL）重建為標準（77–86%）**。
- 🆕 **lateral release 不應單獨用於不穩（89%）**。
- 🆕 **何時、何種骨性手術（dysplasia、alta 等）→ 共識較少、無共識**。

## 4. 手術 🆕

- 適應症：**復發不穩**，或**首次脫位但復發風險高或有急性軟骨傷**。
- 依個案病理 → **à la carte**（Key Study Point）。

### 4.1 MPFC 重建 🔄

- 🆕 **重建優於修補**（過去研究＋2022 network meta-analysis）。
- **傳統：無明顯對位不良、alta、dysplasia → 單獨 MPFC 重建（MPFL、MQTFL 或 hybrid）**。
  - 🆕 即使有骨性異常，單獨重建也有可靠結果與 RTS；部分醫師主張骨性手術適應症應更窄。
  - 🆕 **但嚴重骨性異常未處理時結果較差**：**嚴重旋轉不良（femoral、tibial version）、dysplasia（尤其 X 光 spur＋jumping J sign）、alta、TT-TG 增加** → **至少考慮合併手術**。
- 🆕 **技術選擇不影響結果**：
  - **MPFL（髕骨隧道或 anchor）vs MQTFL（固定於遠端內側股四頭腱）vs hybrid → 無差**。
  - **inlay vs onlay（髕骨與股骨）→ 無差**。
  - **autograft vs allograft → 無差**。
- ✅ **真正重要的是解剖附著與正確張力**：
  - ✅ **股骨固定位置最重要；非解剖位置是最常見失敗原因之一**。
  - ✅ **Schöttle point**：透視需 **perfect lateral（後髁疊合）**；解剖上在 **adductor tubercle 與 medial epicondyle 之間的 saddle**。
  - 🆕 **MPFC 股骨附著中心：adductor tubercle 前 6.2 mm、遠 7.6 mm；medial epicondyle 後 5 mm、近 3.1 mm**。
  - 🆕 **張力：解剖附著＋2 N → 恢復正常穩定與 tracking；位置錯誤＋過緊（10 N）→ maltracking、壓力增加**。
  - 🆕 **不加明顯張力，依 ROM 等長測試定長度；於 30–60° 屈曲固定（MPFC 等長、髕骨在溝內）**。
  - 🆕 **髕骨置中，graft 張力允許外移不少於 1、不多於 1.5 quadrant**。

### 4.2 外側 retinaculum 🆕

- 🆕 **release 會醫源性內側不穩，且加在 MPFL 重建上結果更差** → 逐漸放棄。
- 🆕 **明顯外側緊（髕骨無法翻到中立以上）→ open lateral retinacular lengthening**（取代鏡下 release）。
- 慢性外側脫位（部分兒童先天異常）→ 可能需完全 release。

### 4.3 單獨 MPFC 重建何時不夠？🆕

- 🆕 **JUPITER RCT 進行中**。
- 🆕 **再脫位 0–38%；最大 meta-analysis 合併 2%**。
- 🆕 **單獨軟組織重建失敗的預測：patella alta（CDI >1.3）、過度 femoral／tibial version、J sign 陽性**。

### 4.4 TTO（distal realignment）🆕

- **最常用的骨性手術**，可處理多種病理。
- 🆕 **TT-TG >20 mm 常用為適應症，但不應只看 TT-TG**。
- 🆕 **推向骨性手術（TTO 或 trochleoplasty）的因素：低能量或復發脫位、中重度 dysplasia、J sign、alta、先前手術失敗**。
- 🆕 **Roux 1888** 首述直接 medialization；之後可 **medialize、anteriorize、distalize**。
- 🆕 **Fulkerson AMZ（anteromedialization，斜面截骨）**：不只處理不穩，也處理**外側 PF 過載與軟骨病變** → **外側不穩＋lateral facet chondrosis**。
- 🆕 **角度**：**45° → 前移與內移等量**；**較陡 → 前移較多**；較平 → 內移較多。
  - 🆕 **陡截骨時前移不宜超過 15 mm**（傷口癒合問題、結節過突）。
  - 前移量由內移量與截骨角度推算。
- 🆕 **相對禁忌**：
  - **骨骼未成熟、tibial apophysis 開放**（生長停滯、**recurvatum**）。
  - **內側脫位史**。
  - **近端或內側 facet 軟骨病變**（**比整體 OA 程度更能預測不良結果**）。
- 術中：被動 ROM 無半脫位或脫位；🆕 **關節鏡評估 tracking 準確，可作輔助**。

### 4.5 股骨旋轉與外翻 🆕

- 🆕 **未辨識的股骨前傾過大 → PF 外向力增加；>20° 時有意義**。
- 🆕 **Derotational osteotomy**：**前傾過大＋軟組織手術失敗**，或要一次處理所有因子時。
- 外翻對位亦需考慮（見 Ch.52）。

### 4.6 Trochleoplasty 🆕

- 🆕 **症狀性中重度 dysplasia → groove-deepening trochleoplasty**。
- 🆕 **無最佳技術；Dejour 各次型是否需不同技術未定**。

| 技術 | 做法 |
|---|---|
| 🆕 **Proximal spur resection（bumpectomy）** | 單純移除 supratrochlear spur；開放或鏡下 |
| 🆕 **Recession wedge** | 從肥大外側滑車近端移除軟骨下楔形骨 |
| 🆕 **Lateral wall／facet elevation（Albee）** | 抬高外側面，改善平坦溝的包覆 |
| 🆕 **Sulcus-deepening（thick／thin flap）** | 把平或凸的近端滑車重塑為凹 |

- 🆕 **過去擔心 trochleoplasty 後 PF OA；近期長期研究顯示風險相對低**。

### 4.7 未解問題 🆕

- 誰需要 trochleoplasty 及／或 TTO？矯正量未量化。
- 是把滑車中心內移到結節，還是用 TTO 把結節移到滑車中心？兩者並用的角色？
- PF OA：offloading TTO、lateral facetectomy、biologics 的角色。
- 是否能像 clubfoot、DDH 一樣以護具或 guided growth 預防。

## 6. Key Study Points（OKU 15）

- 髕骨不穩**高度複雜、多因子**。
- **完整理學檢查**對了解致病因子最重要。
- 手術技術很多，**骨性矯正的明確適應症仍有爭議**。
- 每個案例都應考慮所有手術選項，**à la carte** 使用。
- （Summary）**MPFC 重建做得正確整體結果好；graft、重建與固定方式影響不大；解剖固定位置最重要**。

## 7. Anki 候選題

1. 髕骨在伸肌機轉的角色？→ fulcrum，增加力臂與股四頭力量。
2. PF 關節在 axial 與 sagittal 平面的接觸特性？→ axial 吻合；sagittal 點接觸。
3. MPFC 的組成？→ MPFL＋MQTFL。
4. MPFC 平均抗張破壞力？與 ACL 相比？→ 208 N；ACL 約 1,700 N。
5. MPFC 斷裂前平均延長？strain modulus？→ 26 mm；49%。
6. 內側主要動態穩定與其向量角？→ VMO；約 60°。
7. 鼠股四頭缺如對髕骨發育的影響？→ 髕骨不與股骨分離。
8. 大鼠早期外移髕骨的結果？→ 平坦滑車、外側面軟骨過度生長。
9. 胎兒超音波 dysplasia 與何者相關？→ 臀位（breech）。
10. IPSG 建議不再使用的名稱？→ patellofemoral syndrome。
11. 所有髕骨不穩病人都應做的全身鬆弛評估？→ Beighton score。
12. Grasshopper eyes 代表？→ 髕骨外傾或半脫位。
13. J sign 的定義？→ 接近完全伸直時髕骨外側半脫位（或早期屈曲突然內移入溝）。
14. Jumping J sign 推測原因？→ 碰到 supratrochlear spur。
15. J sign 與哪些因素相關？預後？→ trochlear dysplasia、patella alta；穩定術後結果較差。
16. J sign 的信度？→ 評估者間信度很低、分級無共識。
17. 髕骨外移幾個 quadrant 為病理性鬆弛？過緊？→ ≥3；<1。
18. 完全伸直時不穩 vs 屈曲時不穩各提示？→ 韌帶不足 vs trochlear dysplasia。
19. 評估 ITB 緊的檢查？→ Ober test。
20. 髖內旋多少應查 femoral version？→ >60°。
21. 評估 tibial torsion 的檢查？→ thigh-foot angle（俯臥）。
22. True lateral X 光的姿勢與判斷標準？→ 20–30° 屈曲；後髁完全疊合。
23. Caton-Deschamps index 計算？→ 髕骨關節面下緣到前脛骨平台 ÷ 髕骨關節面長。
24. Trochlear dysplasia 的三個側面 X 光徵象？→ supratrochlear spur、crossing sign、double contour。
25. Crossing sign 出現於多少異常病例？→ 96%。
26. Double contour 代表？→ 內側滑車發育不良。
27. Merchant view 屈曲角？為何不用更深？→ 30°；深屈會隱藏半脫位或 tilt。
28. 首次髕骨脫位後軟骨傷比例？是否做 MRI？→ 最高 85%；要。
29. TT-TG 的量法？→ 軸位疊合滑車最深點與結節最突點，與後髁線切線量。
30. 量化股骨與脛骨 torsion 的金標準？→ CT。
31. IPSG：首次脫位的標準處置？同意度？→ 保守（無需處理的 loose body）；100%。
32. IPSG：復發不穩的標準手術？同意度？→ MPFC 重建；77–86%。
33. IPSG：單獨 lateral release？→ 不應做（89%）。
34. Lateral buttress brace 是否降低復發？→ 無明確證據。
35. MPFC 修補 vs 重建？→ 重建較好。
36. MPFL vs MQTFL vs hybrid、inlay vs onlay、auto vs allo？→ 皆無差。
37. MPFC 重建最重要的技術因素？→ 股骨解剖附著位置（與正確張力）。
38. Schöttle point 的解剖位置？→ adductor tubercle 與 medial epicondyle 之間的 saddle。
39. MPFC 股骨附著中心距 adductor tubercle？距 epicondyle？→ 前 6.2 mm、遠 7.6 mm；後 5 mm、近 3.1 mm。
40. MPFL graft 張力 2 N vs 10 N？→ 2 N 恢復正常；10 N 過緊致 maltracking 與壓力增加。
41. MPFC graft 固定時的屈曲角？→ 30–60°。
42. MPFC 重建後應允許外移幾個 quadrant？→ 1–1.5。
43. 為何不做 lateral release？替代？→ 醫源性內側不穩、合併 MPFL 結果更差；open lateral retinacular lengthening。
44. 單獨 MPFC 重建後合併再脫位率？→ 約 2%（範圍 0–38%）。
45. 單獨軟組織重建失敗的預測因子？→ CDI >1.3、過度 femoral／tibial version、J sign。
46. 評估單獨 MPFC 是否足夠的 RCT？→ JUPITER。
47. TTO 常用的 TT-TG 閾值？是否唯一指標？→ >20 mm；否。
48. 首述 medialization TTO 的人與年份？→ Roux，1888。
49. Fulkerson AMZ 的適應症？→ 外側不穩＋外側 facet 軟骨病變。
50. AMZ 45° 截骨的效果？較陡？→ 前移等於內移；前移較多。
51. 陡截骨時前移上限？→ 不宜超過 15 mm。
52. TTO 的相對禁忌？→ 開放 tibial apophysis、內側脫位史、近端或內側 facet 軟骨病變。
53. 開放 apophysis 做 TTO 的風險？→ 生長停滯、recurvatum。
54. 股骨前傾多少開始對髕骨不穩有意義？→ >20°。
55. 股骨去旋轉截骨的時機？→ 前傾過大＋軟組織手術失敗，或一次處理所有因子。
56. Trochleoplasty 四種技術？→ bumpectomy、recession wedge、lateral wall elevation（Albee）、sulcus-deepening。
57. Trochleoplasty 後 PF OA 風險？→ 近期長期研究顯示相對低。
