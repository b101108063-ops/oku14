## 1. 關節軟骨生物學

### 1.1 組成（數字題）

| 項目 | 數值 |
|---|---|
| 厚度 | **2–6 mm**（依年齡、性別） |
| 水 | **70%–80%**（濕重） |
| 乾重：collagen | **40%–70%**（主要 **type II**） |
| 乾重：proteoglycan | **15%–40%**（**aggrecan 最大最多**；decorin、fibromodulin） |
| 乾重：chondrocyte | **<5%** |
| Chondrocyte 體積 | **約 2%** |
| ECM 體積 | **約 95%** |

- **Chondrocyte = 唯一細胞種類**；代謝活躍但**不分裂** → 缺乏內在修復力
- 一旦發育完成**不自我更新、轉換極少 → 近乎「永久組織」**
- **Chondron = chondrocyte ＋ PCM**（軟骨結構與功能單位）
  - **PCM 主要成分：type VI collagen、decorin、fibronectin**
  - PCM 與細胞表面受體、ion channel 互動 → mechanotransduction
- ECM 由內而外三區：**pericellular → territorial → interterritorial**
- 保水機轉：GAG 親水＋**帶負電 carboxyl 與 sulfate** → 靜電吸水；**fixed charge density** 固定水分 → 力學強度與形狀；viscoelastic（時間依賴）

### 1.2 分區

| 分區 | Collagen 排列 | Chondrocyte | 功能／特徵 |
|---|---|---|---|
| **Superficial** | **平行表面**、緻密 | **扁平、數量最多**、較不規則 | **抗 shear**、潤滑；**體積最小** |
| **Middle** | **斜向（oblique）** | 圓形、較稀疏 | **體積最大**；壓縮強度 |
| **Deep** | **垂直表面、纖維直徑最大** | **柱狀排列** | **抗 compression**；**proteoglycan 最多、水最少**；體積第二大 |
| **Tidemark** | — | — | 分隔 deep 與 calcified zone |
| **Calcified** | 錨定於 subchondral bone | 少，**hypertrophic chondrocyte** | 固定與傳力至骨 |

- 修復力差的五個原因：**無血管、細胞密度低、無神經、無淋巴、無幹／前驅細胞**（＋高力學需求）

## 2. 骨關節炎

- 全球失能主因之一，**膝最常見**；Global Burden of Disease：**盛行率持續上升、女性受影響較多**
- **無 disease-modifying drug** → 多數病人慢性失能直到關節置換
- 特徵：軟骨退化、**subchondral bone 侵蝕**、骨刺、滑膜腫脹
- 危險因子：**年齡、性別、肥胖、外傷**

### 2.1 OA 疼痛（新）
- 目前沒有有效的止痛治療；止痛藥效果有限且有副作用
- **Nociceptive system 隨疾病進展產生可塑性改變**（結構、生理、基因）
- **Neurotrophin／NGF** = 疼痛產生的關鍵蛋白
- 局部發炎（NGF、cytokine、chemokine）→ **機械性敏感化**、nociceptor 可塑性；**subchondral bone 與 synovium 的神經新生（neuronal sprouting）**；innate immunity 與感覺神經互動

### 2.2 肥胖與減重（新，數字題）
- 2022：**體重每減 1% → 關節置換風險減 3%**
- 2024 SR／network MA（12 RCT、約 3,000 人、7 種介入）：
  - 所有介入皆優於對照
  - **最有效：diet＋exercise、psychological＋diet＋exercise**
  - **不論方法，體重減少 ≥7% → 顯著止痛**
- 2022：**15 份指引中 13 份**建議減重
- **Semaglutide（GLP-1 RA）2024 RCT**：**68 週**、雙盲、**61 個中心、11 國、407 人（81.6% 女性）**，每週一次皮下注射 → 體重↓、OA 疼痛↓、功能↑（vs placebo）
  - 長期效果與持久性仍待研究

> 課本原文把 semaglutide 寫成 GLP-1「inhibitor」，實為 **receptor agonist**。

### 2.3 Gut Microbiome
- 低度發炎可能與菌相有關
- 臨床前：肥胖與**高脂高糖飲食 → dysbiosis → 腸道通透性↑、Firmicutes/Bacteroidetes 比值↑ → 血清 LPS↑ → synovitis**
- 人類：多數研究 OA 病人**菌種豐富度↓**
- **Rotterdam III（約 1,500 人）＋Lifelines-DEEP 驗證（約 900 人）**：OA 的 alpha diversity↓，但**校正 BMI 後不顯著**；同一譜系的 **4 個 clade 與疼痛、腫脹相關**（驗證組亦成立）
- 2025 SR：膝 OA 菌相失衡，特定組成與疼痛、發炎較差相關 → 機轉與治療潛力待研究

## 3. Orthobiologics

- 定義：**刺激或增強組織修復細胞與分子過程**的治療
- 注射從 steroid、viscosupplementation（效果短）擴展到 **PRP、gene delivery、EV、stem cell**
- 現況：**可改善症狀，但少有證據顯示 disease-modifying 或組織再生**
- 主要限制：**方法無標準、產品組成與活性變異、劑量與頻率無指引**

### 3.1 PRP

| 證據 | 結果 |
|---|---|
| 2023 SR/MA（**27 篇 Level I、>1,000 人**） | **PRP、BMAC 的 PROM 優於 HA** |
| 2024 SR/MA（48 篇、約 9,500 人、≥6 個月） | **PRP、BMAC、HA 皆優於 corticosteroid**（疼痛與功能） |
| 2023 SR（多劑） | **3 劑優於 1 劑**（12 個月止痛） |
| **Leukocyte**：2022 雙盲 RCT（3 劑 LR vs LP）、2024 雙盲 RCT、2022 network MA（20 RCT＋3） | **白血球濃度不影響安全與療效** |
| 臨床前 | LR-PRP＋紅血球 → 滑膜細胞死亡與發炎介質↑（但臨床未證實） |
| **Platelet 濃度**：兩篇 SR（34、29 RCT）、2024 cohort | **血小板劑量越高 → 臨床結果越好、失敗率越低** |

**指引與共識（2024）**

| 組織 | 建議 |
|---|---|
| **ESSKA**（consensus, part 1） | PRP 是**有效選項**，可作為**主要用於 KL 1–3 的一線非手術注射選項** |
| **ESSKA–ICRS（RAND/UCLA appropriateness）** | 適用：**≤80 歲、KL 0–3、非注射保守治療失敗後**；**不適合作為一線、不適用於 KL 4** |
| **AAOS technology overview** | PRP 主觀結果**顯著優於 placebo**；與其他生物製劑比較結果不一；需更多高品質研究（最佳配方、重複劑量） |

> **Pitfall**：ESSKA 本身說「可作一線」，ESSKA–ICRS 的 RAND/UCLA 卻說「不適合作一線」——兩份文件結論不同，題目要看問的是哪一份。

### 3.2 Gene Delivery（新）
- 問題：注射的生物製劑**穿不透緻密 ECM**、且很快被**淋巴引流或滑膜下微血管**清除
- 解法：把編碼治療產物的基因送入關節內細胞 → **只要細胞存活且表現 transgene 就持續產生**
- **Viral vector 效率高；non-viral 廣用但效率低、表現不持久**
- **2024 phase 1 first-in-human：scAAV-IL-1Ra**
  - **KL 2–3**、**9 位**病人，低／中／高劑量遞增，追蹤 >1 年
  - 選 **AAV**：parvovirus、**天然無法複製**、能轉導**非分裂細胞**
  - 標的 **IL-1**（軟骨退化關鍵），以天然抑制劑 **IL-1Ra** 對抗
  - 結果：**安全、耐受良好、可長期維持關節內 IL-1Ra 濃度**，可能改善功能與疼痛
  - 後續：**phase 1b dose-ranging** 進行中

### 3.3 Extracellular Vesicles（新）
- 1960 年代首次描述為 **「platelet dust」**
- 細胞間溝通載體；三型：**microvesicle、exosome、apoptotic body**，大小 **40–500 nm**
- 攜帶 miRNA、mRNA、DNA、蛋白、脂質
- 分離：**ultracentrifugation** 最常見，其次 size-based；最佳分離／鑑定方法未定 → 限制臨床轉譯
- 現有證據聚焦 **MSC-derived exosome**（MSC 療效可能來自 **paracrine**）
  - Secretome（28 篇臨床前）：發炎消退、軟骨再生改善
  - Exosome：**collagen II↑、MMP-13 與 ADAMTS5↓**、阻斷 macrophage 活化
  - 臨床前 in vivo SR：減緩退化、細胞增殖↑、基質沉積↑、組織學分數改善
- 尚需機轉、標準化分離與劑量研究才能用於人體

### 3.4 Stem Cell Therapy
- 常用：**bone marrow 或 adipose MSC**
- 結論：**減輕症狀，但無法再生軟骨**

| | Autologous | Allogeneic |
|---|---|---|
| 流程 | 兩步驟：採集、分離、**培養擴增**後回注 → 成本高、延遲 | **Off-the-shelf**、可量產、較便宜方便 |
| 證據 | **最多研究**；SR（**14 RCT、>400 人**）：1 年 PROM 改善、無嚴重不良事件、**影像嚴重度較佳**；2024 network MA（>15 篇、約 600 人）：**autologous bone marrow MSC 對疼痛與功能效果最好** | 早期；近 9 年約 **15 篇**試驗（bone marrow、placenta、adipose）；**最常用 adipose-derived**；安全、改善功能與疼痛、**可能改善軟骨結構** |
| 問題 | — | 劑量、追蹤、注射頻率、KL 分級不一；需長期研究 |

## 4. 陷阱與易混淆

1. **Superficial zone：平行、扁平細胞最多、抗 shear、體積最小**；**middle zone 體積最大**；**deep zone：垂直、PG 最多水最少、抗 compression**
2. **PCM = type VI collagen**（不是 type II）
3. 軟骨修復差的五個原因要背齊（無血管、低細胞密度、無神經、無淋巴、無幹細胞）
4. 減重數字：**1% → 置換風險 3%↓**；**≥7% → 顯著止痛**
5. **Leukocyte-rich vs poor 不影響 PRP 療效**；**platelet 劑量越高越好**；**3 劑 > 1 劑**
6. ESSKA vs ESSKA–ICRS 對「一線」的結論不同；**KL 4 不適合 PRP**
7. scAAV-IL-1Ra 是 **phase 1、9 人、KL 2–3**，只證明**安全性**
8. Exosome 降低的是 **MMP-13、ADAMTS5**
9. **最常用的 allogeneic MSC = adipose**；**效果最好的 autologous = bone marrow**
10. **目前沒有 disease-modifying OA 治療**——兩版共同結論

## 5. Key Study Points（OKU 15）

- 關節軟骨易受傷與病變，但缺乏內在修復與再生能力
- OA 是影響軟骨、滑膜與 subchondral bone 的慢性退化疾病，**目前無 disease-modifying 藥物或治療**
- OA 疼痛可能與周邊神經路徑對關節退化的可塑性改變直接相關；gut microbiome 可能影響 OA
- PRP 與幹細胞治療可調節症狀，但可能無法阻止疾病進展或促進內生性組織再生
- Gene delivery 與 extracellular vesicles 是新興治療，仍需更多研究
