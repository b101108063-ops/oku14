## 1. 末期髖退化 🆕

### 1.1 病因

- **OA、創傷後關節炎、骨壞死、發炎性關節炎、hip dysplasia**。
- 治療依退化與功能障礙程度；**保守失敗的末期病 → THA 為金標準**。

### 1.2 髖 OA

- 全球主要失能原因之一（2024）；壽命延長 → 盛行率上升。
- 機轉：**軟骨退化＋骨侵蝕 → 關節內發炎反應**，影響軟骨、軟骨下骨、滑膜。
- **症狀**：
  - **疼痛**：漸進、活動加重；**多在鼠蹊，可放射到大腿或膝**。
  - **僵硬**：走路、爬樓、跑步時 ROM 下降。
  - **功能障礙**：穿衣、走路、上下車困難。
  - 晚期：**屈曲攣縮**、**膝轉移痛** → 🆕 **不明膝痛且膝影像無明顯結構異常時，要考慮髖病變**。
- **診斷**：X 光（間隙狹窄、軟骨下硬化、骨贅、囊腫）；**Tönnis 0–3**（0 無關節炎 → 3 大囊腫、嚴重狹窄、變形）；檢查：**屈、伸、內旋**減少、ROM 痛、晚期屈曲攣縮。
- **處理**：外用與口服 NSAIDs、PT、活動調整、關節內注射；🆕 **PT 對髖 OA 的改善可能不如其他關節**；保守失敗 → **THA**。

### 1.3 創傷後關節炎 🆕

- 髖臼骨折、股骨頭或頸骨折、脫位、轉子周圍骨折之後。
- 機轉：**受傷時軟骨傷、傷後關節不平整、股骨頭或髖臼血供中斷**。
- X 光診斷；**CT** 評估骨癒合與變形（複雜骨折）。
- 處理依年齡、嚴重度、時機：
  - **年輕：早期解剖復位關節面**；🆕 **ORIF 後關節面不平整 → OA 風險增加**。
  - 🆕 **老人：ORIF，或越來越多的急性 THA，或 ORIF＋急性 THA**（複雜骨折或明顯不平整特別有利）。
  - 🆕 **老人明顯移位與高能量傷 → OA 風險較高（2022）**（該研究另指出低能量、骨鬆、女性結果較差）。
- 🆕 **曾開過髖的病人，THA 後感染風險較高** → 加強預防。

### 1.4 骨壞死 🆕

- 股骨頭血供減少或中斷；原因：**特發、髖外傷、長期高劑量類固醇、凝血亢進、HIV、血管炎**。
- 早期可無症狀；**負重面大病灶**時疼痛嚴重。
- **MRI 對早期最敏感**；🆕 分類：**Steinberg、Ficat-Arlet**。
- 治療：
  - **先處理病因**（停類固醇、治療凝血亢進）。
  - **雙磷酸鹽**：部分研究可防塌陷，**療效仍有爭議**。
  - **Core decompression**：**塌陷前**；鑽入股骨頭降壓、促血流。
  - 🆕 **近端股骨截骨**：重新對位股骨頭、**減少病灶負重**、延後塌陷。
  - 🆕 **血管化游離腓骨移植**：恢復股骨頭血供。
  - **塌陷後 → THA 最可靠**。

### 1.5 發炎性關節炎 🆕

- RA、乾癬性關節炎、ankylosing spondylitis → 慢性發炎破壞軟骨。
- **DMARDs 與 biologics（TNF inhibitor、IL-6 inhibitor）** 改善全身症狀、延後手術；但晚期仍需 THA。
- 🆕 **2022 ACR／AAHKS 指引**：使用 biologics 或 DMARDs 病人的圍術期用藥管理 → 降低感染、最佳化結果。

## 2. THA 🔄

### 2.1 術前最佳化與風險分層 🔄

| 危險因子 | 切點 |
|---|---|
| **BMI** | **>40 kg/m²**（2022） |
| **抽菸** | — |
| **糖尿病** | **HbA1c >8%** |
| **CKD** | — |
| **營養不良** | **albumin <3.5 g/dL** |
| 🆕 **鼻腔 S aureus 帶菌** | 感染、傷口癒合較差 → 🆕 **全面去菌落 protocol 具成本效益** |

- 🆕 **心血管最佳化**：術前抗凝管理、控制心血管病 → 減少心血管事件、出血、輸血。
- 也用於決定**住院 vs 門診**。
- ❌ OKU 14 的 **Hb >10.0 g/dL**、BMI 20–35、ASA >3 為 30 天併發症危險因子、AAHKS 98% 醫師調查，本版未列。

### 2.2 手術入路 🔄

| | **Anterior** | **Posterior** |
|---|---|---|
| 優點 | **術後痛較少、脫位風險較低、植入物位置較好、住院較短、短期結果較好** | **可延伸、術中骨折與其他重大併發症較少、傷口問題較少** |
| 缺點 | **傷口癒合併發症、股骨骨折、學習曲線陡** | **肌肉剝離較多、後脫位風險** |

- 🆕 **2023 network meta：各入路併發症無顯著差異 → 沒有確定證據哪個較好**。
- 🆕 **2024：DAA 6 個月內功能與生活品質改善較快，1 年無差**。
- → **最好的入路是醫師最熟練的那個**。
- ❌ OKU 14 的「單中心 DAA 併發症 8.5% vs 後方 3.1%、DAA PJI 與翻修較高」本版未列。

### 2.3 磨耗面 🔄

**HXLPE** 🆕
- 讓各年齡的 bearing 選擇改變；**降低磨耗與 osteolysis 造成的翻修**；穩定優於傳統 PE。
- **機械強度略低**，但**沒有證據導致較高失敗率**。
- 🆕 **10 年 radiostereometric analysis：股骨頭穿入極低，磨耗幾乎可忽略**。
- 🆕 **製程**：PE 多以 **gamma 照射**滅菌 → 產生**自由基**（富氧環境下）→ 以 **melting** 或 **annealing** 中和：

| | Melting（remelted） | Annealing |
|---|---|---|
| 自由基 | **有效移除** | 移除較差 |
| 機械強度 | **降低** | **保留** |
| 氧化 | 較低 | **較高** |
| 磨耗（>10 年回收件） | **兩者無顯著差異** | |

**各種 bearing**

| Bearing | 優點 | 缺點 |
|---|---|---|
| **Metal-on-PE** | 歷史悠久、成本效益 | 磨耗較高、頭較小 → 撞擊與不穩 |
| ✅ **Ceramic-on-PE（標準）** | 磨耗低於 MoP、機械性質優於 CoC | **陶瓷碎裂（罕見）** |
| **Dual mobility** | 小殼也能用大頭 → ROM、減少撞擊、**高脫位風險者有利** | **背側磨耗、IPD**；modular liner 腐蝕疑慮 |
| **Metal-on-metal** | 低磨耗、大頭、ROM、低脫位 | **金屬碎屑或離子 → ALTR（aseptic lymphocyte-dominant vasculitis）** → 痛、組織破壞、失敗；監測血中 **Co、Cr**；🆕 **比例約 2:1 提示 trunnionosis（head-neck 腐蝕）** |
| **Ceramic-on-ceramic** | **磨耗特性最佳** | **較貴、碎裂、stripe wear、squeaking** |

- ❌ OKU 14 的 2006 → 2016 bearing 使用率表與 DM 使用率（6.7 → 12.0%、翻修 19.5 → 30.6%）本版未列。

### 2.4 固定方式 🔄

- **骨水泥**：
  - 老人廣用：結果可預期、骨質差也能固定（水泥深入骨鬆皮質）。
  - **最常用於股骨組件**：老人**穩定較好、術中骨折較少**。
  - 🆕 **髖臼組件最初用骨水泥，但鬆動率高 → 現在很少**。
  - 🆕 **AJRR（2024）：骨水泥股骨幹 periprosthetic fracture 與早期翻修較少**。
- **無骨水泥**：
  - 依賴 **bone ingrowth 或 ongrowth**（多孔或粗糙表面）；**一般較偏好，尤其年輕人**（長期生物固定）。
  - 🆕 **骨折與翻修率較高（2024）**。
  - 翻修用 extensively porous-coated stem：13 年存活優良。
- ❌ OKU 14 的「**>75 歲和／或骨鬆，強烈考慮骨水泥股骨幹**」「無骨水泥前 3 個月翻修與骨折較高」本版未以數字列出。

### 2.5 門診 THA 與科技 🔄

- 術前最佳化進步 → 更多病人可安全門診。
- 🆕 **需要過夜的危險因子：心血管疾病、COPD、尿滯留、病人偏好** → 慎選病人。
- **導航與機器人**：依病人解剖地標提升植入物位置精準 → 理論上改善穩定、腿長、offset、降低脫位。
  - 機器人：依術前 **CT** 或**術中 surface mapping** 引導骨切等步驟。
  - 🆕 **2022 多中心：機器人比手動與導航更準確達到依 spinopelvic mobility 設定的功能性安全區**。
  - 🆕 **減少 outliers，但尚未證實改善長期病人結果**。
- ❌ OKU 14 的「CMS 2020 年 1 月 1 日將 THA 移出 inpatient-only list」「OARA 98.8%」本版未列。

## 3. 併發症 🔄

### 3.1 PJI 🔄

- **危險因子**：**曾翻修、活動中感染、免疫抑制、發炎性關節炎、肥胖、抽菸**。
- ✅ **最常見菌：S aureus、S epidermidis**。
- **預防**：術前篩檢與最佳化；🆕 **切皮前 30 分鐘內給系統性抗生素**；✅ **初次與翻修後延長抗生素可能降低感染**（AAHKS 獎：高風險者延長口服抗生素；RCT：兩階段後口服抗生素降低再感染）。
- 🆕 **分類**：

| 類型 | 時間 | 特徵 | 處理方向 |
|---|---|---|---|
| **急性術後** | **術後 3–6 週內** | biofilm **尚未成熟** | DAIR 可考慮 |
| **急性血行性** | 原本無感染的關節因遠處感染急性感染 | 行為同急性術後 | DAIR 可考慮 |
| **慢性** | **>6 週** | **biofilm 形成**（保護細菌免於免疫與抗生素） | **通常需取出植入物**（目前無安全方法移除 biofilm） |

- **評估**：X 光可見 osteolysis 或骨吸收（無法確診）；骨掃描、PET 有幫助但非例行；檢查：竇道、熱、紅、腫；**實驗室為核心**。
- 🆕 **2018 International Consensus Meeting 診斷標準（Table 1）**：

| 類別 | 項目 | 分數／判定 |
|---|---|---|
| **Major（任一）** | **同一菌兩次培養陽性**；**與關節相通或看得到植入物的竇道** | **感染** |
| **術前血清 minor** | **CRP 或 D-dimer 升高** | 2 |
| | **ESR 升高** | 1 |
| **術前關節液 minor** | **關節液 WBC 或 leukocyte esterase 升高** | 3 |
| | **關節液 PMN 比例升高** | 2 |
| | **關節液 CRP 升高** | 1 |
| **術前判定** | **≥6 感染；2–5 可能感染；0–1 非感染** | |
| **術中（術前不確定或乾抽）** | 術前分數＋**組織學陽性 3、膿 3、單一培養陽性 2** | **≥6 感染；4–5 不確定；≤3 非感染** |

- **治療**：
  - **兩階段（傳統慢性金標準）**：取出、**抗生素 spacer**、感染清除後再置入；成功率不一。
  - 🆕 **一階段**：**已知低毒力菌、無抗藥性疑慮** → **恢復快、成本低、生活品質好、併發症與死亡率較低**。
  - **DAIR**：**急性術後或急性血行性**；**無法移除植入物的慢性感染**也可；失敗率不一。
- ❌ OKU 14 的「加拿大 15 年 PJI 1.44%」「慢性 PJI 最佳門檻 **WBC >3,966、PMN >80%**」「**vancomycin 粉末 OR 0.44（初次）、0.28（翻修）**」「**VIP protocol（10% 稀釋 povidone-iodine＋vancomycin）**」「高風險 7 天口服抗生素」「兩階段 60–95%、DAIR 20–70%、≤90 天」本版未列。

### 3.2 不穩定 🔄

- 影響因素：**組件設計、位置、軟組織張力、外展肌功能**。
- 🆕 **加大股骨頭 → 改善 head-to-neck ratio、ROM、jump distance → 降低脫位**。
- 🆕 **傳統理想杯位：外展 40°、前傾 15°；現在應依病人個人化（2022）**，尤其腰椎疾病或腰椎融合（2024）。
- **脊椎分類**：

| 參數 | 定義 |
|---|---|
| **正常 spinal alignment** | **PI − LL <10°** |
| **脊椎畸形** | **PI − LL >10°** |
| **正常 spinal mobility** | **站到坐 sacral slope 變化 >10°** |
| **Stiff spine** | **<10°** |

- ✅ **Hip-Spine Classification（Table 2，Vigdorchik）**：

| 組 | 分類 | 病理 | 杯位目標（inclination, anteversion） |
|---|---|---|---|
| **1A** | 正常排列＋正常活動度 | 正常解剖與活動 | **40°, 25°** |
| **1B** | 正常排列＋**stiff spine** | **stuck standing**：需要較多 inclination 與 anteversion | **40°, 25°**；若**站立骨盆後傾 ≥13°** → 目標低於原生解剖 |
| **2A** | **flatback（骨盆後傾）**＋正常活動度 | 前傾來自屈曲攣縮會改善；**脊椎畸形使功能性杯前傾增加** | **40°, 25°**（同上 13° 規則） |
| **2B** | **flatback＋stiff spine** | **stuck sitting**：畸形＋僵硬 → 功能性杯前傾更多 | **40°, 25°**（同上），或 **45°, 25–30°（相對 functional pelvic plane）** |

- 位置錯誤：**前傾過大 → 前脫位；後傾 → 後脫位；外展過大 → 後上脫位、磨耗增加、不穩**。
- **恢復 offset 與適當軟組織張力** → 減少撞擊與關節反作用力、維持外展肌與腿長。
- **外展肌無力**（受傷、疾病、手術）→ 脫位風險增加。
- Spinopelvic 也增加脫位（2022，**尤其脊椎融合**）；🆕 **AJRR 2023：DM 顯著降低腰椎融合或退化病人 90 天與 1 年脫位**。
- 其他危險因子：**曾髖手術、神經肌肉疾病、酒精或藥物濫用、PE 磨耗**。
- 處理：找出病因 → 處理 PE 磨耗、植入物位置不良或軟組織問題。
- ❌ OKU 14 的「DM 總脫位率 4.5%、**71% 閉鎖復位造成 IPD → 需開放翻修**」本版未列。

### 3.3 腿長差 🆕

- 🆕 **THA 後訴訟的常見原因**。
- 術後早期常感覺腿長不等，**常隨時間改善**；🆕 **>6 個月仍存在 → 才可能需要介入**。
- **主觀 LLD 多因外展肌無力或髖攣縮**；也可能因**為了穩定而刻意延長**。
- 🆕 **術中影像可降低 LLD 風險**。
- 處理：**鞋墊**（小差距）；🆕 **很少因 LLD 翻修**。
- 🆕 **Level I 多中心：恢復 global offset 與腿長 → 最佳臨床結果**。

### 3.4 Periprosthetic fracture 🆕

- **術中或術後**；🆕 **無骨水泥比骨水泥風險高**；其他危險因子：**骨鬆、曾放射、hip dysplasia、翻修**。
- **術中骨折多因打入組件時力量過大** → **足夠暴露＋術前 templating**。
- **髖臼骨折（術中或術後）依植入物穩定度**：
  - 穩定 → **觀察＋保護負重**。
  - 不穩 → **翻修**：加大杯、ORIF 髖臼骨折、新組件加螺絲。
- **術中股骨骨折**依 Vancouver 分類；**calcar 骨折 → 取出植入物、鋼絲綁、再置入**，必要時 ORIF。
- 🆕 **Vancouver（術後股骨）**：

| 型 | 次型 | 描述 | 治療 |
|---|---|---|---|
| **A** | **AL** | 小轉子 | 保守（**內側皮質大段**時考慮 ORIF） |
| | **AG** | 大轉子 | 保守＋外展預防措施（🆕 **移位 >2.5 cm 考慮 ORIF**） |
| **B** | **B1** | **植入物固定良好** | **ORIF ± cortical strut allograft** |
| | **B2** | **植入物鬆動** | **翻修＋長幹** |
| | **B3** | **鬆動＋骨量差** | 翻修＋allograft 補骨量，或腫瘤型假體 |
| **C** | — | **骨折遠在植入物尖端以下** | **ORIF** |

- 🆕 **Modular fluted tapered stem 治療 B2、B3（171 例）：10 年累積翻修 10%（多為脫位與 PJI），無無菌鬆動**。

45. 傳統杯位 vs 現在觀念？→ 外展 40°、前傾 15°；現在應個人化。

47. Hip-Spine 1B 與 2B 分別稱為？→ stuck standing；stuck sitting。
48. Hip-Spine 的 13° 規則？→ 站立骨盆後傾 ≥13° 時，杯位目標低於原生解剖。
49. Hip-Spine 2B 的杯位選項？→ 40°／25°，或 45°／25–30°（相對 functional pelvic plane）。
50. 前傾過大、後傾、外展過大各造成什麼？→ 前脫位；後脫位；後上脫位與磨耗。
51. 腰椎融合病人用 DM 的效果？→ 顯著降低 90 天與 1 年脫位。
52. THA 後腿長差的臨床意義與處理時機？→ 常見訴訟原因；>6 個月仍存在才介入。
53. 主觀腿長差的常見原因？→ 外展肌無力或髖攣縮；為穩定刻意延長。
54. 降低 LLD 的術中方法？→ 術中影像。
55. LLD 的一般處理？→ 鞋墊；很少翻修。
56. Periprosthetic fracture 的危險因子？→ 無骨水泥、骨鬆、曾放射、dysplasia、翻修。
57. 術中髖臼骨折：植入物穩定 vs 不穩？→ 觀察＋保護負重；翻修（加大杯、ORIF、加螺絲）。
58. 術中 calcar 骨折處理？→ 取出植入物、鋼絲綁、再置入。
59. Vancouver AG 何時考慮 ORIF？→ 移位 >2.5 cm。
60. Vancouver B1、B2、B3 的治療？→ ORIF ± strut；長幹翻修；翻修＋allograft 或腫瘤型假體。
61. Vancouver C 的治療？→ ORIF。
62. Modular fluted tapered stem 治療 B2／B3 的 10 年翻修率？→ 10%（無無菌鬆動）。
