## 1. 股骨頸骨折

### 1.1 分型 🆕
- **雙峰**：老人低能量、**年輕（18–55 歲）高能量** → 年齡決定治療目標

**Pauwels（復位後 AP 片骨折線與水平面夾角）**

| Type | 角度 |
|---|---|
| I | **<30°** |
| II | **30–50°** |
| III | **>50°** |

- 角度越大 → **shear force 越大** → 移位與固定失敗風險越高

**Garden（移位）**

| Type | 定義 |
|---|---|
| I | 無移位、**valgus impacted** |
| II | 無移位但完全骨折 |
| III | 完全、部分移位 |
| IV | 完全移位 |

- 無移位 → 固定；移位 → 多做置換；**近年老人即使穩定型也越來越常做置換**

### 1.2 年輕高能量股骨頸 🆕
- 目標：**保留骨、預防畸形、降低 osteonecrosis**
- 植入物：fixed-angle device（**SHS**）、多支空心螺絲，加上 **antirotation screw** 或 **femoral neck buttress plate**
- 🆕 **Young Femoral Neck Fracture Working Group（2024，26 個 Level I 創傷中心、18–59 歲）**

| 構型 | 失敗率 |
|---|---|
| **多支空心螺絲** | **55%** |
| **Fixed-angle device** | **36%** |
| **Fixed-angle＋antirotation screw 或 buttress plate** | **11%** |

- → **建議 fixed-angle device＋augmented fixation**，尤其需要開放復位時

### 1.3 老人股骨頸 🔄
- 🆕 目標：**受傷 48 小時內固定**、**立即負重**、早期活動
- Garden I、II → 多做固定；Garden III、IV → 多做置換
- 內固定**再手術 8–23%**
- 🔄 **FAITH**：Garden I、II **後傾 ≥20° → 22.4% 轉為置換** → 可考慮直接置換

### 1.4 THA vs Hemiarthroplasty
- 移位骨折 → 置換是理想選擇
- **HEALTH RCT** ✅：hemi 24 個月內二次手術風險僅略高；**THA 脫位 4.7% vs 2.4%**、**嚴重不良事件 41.8% vs 36.7%**；死亡率無差異
- 🆕 **2023 Medicare 族群研究**：12 個月**脫位 THA 2.9% vs hemi 1.9%**（有統計意義但兩者都低，臨床意義不大）；**二次手術無差異**

### 1.5 骨水泥 vs 非骨水泥柄 🔄
- 🆕 **WHITE 5 RCT（NEJM 2022，≥60 歲囊內骨折 hemi，骨水泥 610 vs 非骨水泥 615）**：非骨水泥組假體周圍骨折風險約 **5 倍**
  - **骨水泥 → 健康相關生活品質略佳**
  - **假體周圍骨折 0.5% vs 2.1%**
  - 死亡率無差異
- 🆕 **THA 1:1 propensity（全國資料庫，90 天）**：原文寫**非骨水泥組假體周圍骨折較少（2.5% vs 4.4%）、但 VTE 較多（2.9% vs 1.2%）**；非骨水泥組 1、2 年**無菌性翻修有增加趨勢**

> ⚠️ 這段原文的方向（非骨水泥假體周圍骨折「較少」）與 WHITE 5 及一般文獻相反，可能是原書筆誤或 OCR 段落拼接問題。**這組數字請對照原書 PDF 確認**；考題若問「骨水泥柄的優點」，以 **WHITE 5：假體周圍骨折較少** 作答較安全。

## 2. 轉子間骨折 🔄

- **囊外骨折**；接受的治療 = 內固定；骨折線在大小轉子之間
- 診斷以 X 光為主；**隱匿骨折 → MRI**；非典型型態 → CT
- 🆕 **Evans 分型**：I 兩部分（移位／無移位）、II 三部分（分離的大轉子或小轉子塊）、III 四部分
- **穩定**：**posteromedial cortex 完整**或粉碎少 → 可抵抗壓力
- **不穩定**：**posteromedial 粉碎、reverse obliquity**
- 現多用 **cephalomedullary nail（CMN）**；長度仍有爭議
  - 🆕 **前瞻 RCT（220 人）：短 vs 長 CMN 的 cutout、深部感染、植入物周圍骨折無差異，即使轉子下延伸達 3 cm**
  - 🆕 **短釘 toggle（2022）**：**TAD 較短、nail-to-canal ratio 較小 → toggle↑**；**toggle >4° → 較多內翻塌陷**

## 3. 轉子下骨折 🔄

- 🆕 **定義：骨折線近端位於小轉子以下 5 cm 內**
- **標準：擴髓 IMN**，偏好 **CMN（股骨頭兩點固定）**
- 變形力強 → **nonunion 4–5%、malunion 10–15%**
- 🆕 復位輔助：**medial start point、Schanz pin、clamp-assisted reduction**
- 61 例 case-control（延遲癒合 32 例，4 例需再手術）：延遲癒合組 **Baumgaertner 復位品質較差**、頭頸幹角異常 ✅
- 🆕 **2024 肥胖（49 vs 181 人）**：肥胖者**開放復位較多（59% vs 11%）**、較常用 fracture table；但**併發症、死亡、再入院、固定失敗、癒合時間無差異**
  - 對比：股骨幹骨折的肥胖與延遲癒合／nonunion 相關

## 4. 股骨幹骨折 🔄

- 雙峰；**標準 = 鎖定 IMN**，依位置選 antegrade 或 retrograde
- 🆕 **旋轉不良常見** → 以對側定性或定量比對；**CMN 本身的已知前傾角**也可作為旋轉檢查
- 🆕 **近端與遠端各兩點固定時，10 或 11 mm 釘即可**（canal-to-nail ratio 增加不影響癒合）
- 🔄 **<50 歲高能量股骨幹骨折合併股骨頸骨折 6–9%**，必須排除
  - 🆕 **2024 多中心（<50 歲）：80 例合併型 vs 412 例單純股骨頸** → 合併型**較多開放復位＋fixed-angle**，**治療失敗、nonunion、malunion 的 odds 較低**
- 🆕 **Atypical femoral fracture（AFF）**
  - 長期 **bisphosphonate**；癒合因骨生物學異常而延遲 → **需解剖復位＋加壓**
  - 典型影像：**外側皮質增厚**
  - **196,129 位女性、277 例 AFF**：用藥越久 AFF 風險越高，**停藥後風險迅速下降**；**效益仍遠大於風險：3 年 2 例 AFF vs 預防 149 例髖部骨折**

## 5. 遠端股骨骨折 🔄

- 雙峰：年輕男性高能量、**老年女性骨鬆脆性骨折**；**幾乎都需手術**
- 🆕 **CT 排除髁間關節內延伸與冠狀面 Hoffa 骨折**（內側或外側）
- 固定：**locked plating** 或 **retrograde IMN**，關節塊另以獨立螺絲固定；原生骨與假體周圍都可靠
- 🆕 **老人：比照髖部骨折的照護目標**
  - **早期手術**
  - **允許立即負重與活動的構型**
  - **跨越整支股骨，預防下一次骨折**
- 🆕 **強化固定構型**：**dual plate**、**nail-plate combination（NPC）**、**distal femoral replacement**
  - 原生、植入物周圍、假體周圍骨折**失敗率較低**（非隨機研究）
  - 力量由外側到內側較平均分布，不會過度剛硬；**可立即負重**
  - 是否成為老人 gold standard 仍需大型研究

## 6. 髕骨骨折 🔄

- 🆕 **無移位或輕微移位且能做 straight leg raise → 可保守**；**移位且無法 SLR → 手術**
- **Tension band wiring**：經典，但**因刺激而移除率高**
  - 改良：**空心螺絲＋鋼絲**、**1.0 mm cable**、**縫線** → 移除率較低、癒合可靠（缺 RCT）
- 骨質差或**下極粉碎**：**partial patellectomy＋tendon advancement** 結果仍好；罕見高能量骨缺損 → total patellectomy＋tenodesis
- 🆕 **Mesh plate、precontoured locking plate**：重建粉碎多塊骨折；作為 **neutralization** 保護 interfragmentary screw → 理論上可較早活動（2022）

## 7. 脛骨平台骨折 🆕

- **Schatzker**＋**三柱模型**；固定除了支撐壓陷與矯正髁寬，**主骨折線 apex** 也需固定（術前 CT 判讀）
- 單髁 → 一個植入物；複雜 → 可能超過雙柱固定；**fragment-specific small／mini-fragment plating** 結果可靠
- 高能量：**暫時外固定＋分期確定性固定**仍是主軸
- 🆕 **降低感染的圍術期措施（METRC）**

| 研究 | 結果 |
|---|---|
| **2022 RCT（1,231 人、29 中心）**：**FiO₂ 80% vs 30%** | **高 FiO₂ 感染較少**（90 天與 1 年）；次分析：主要是**表淺傷口感染減少** |
| **Vancomycin powder 1 g**（VANCO） | 感染**約降 4%**，主要是 **gram-positive** |
| 2025 次分析 | **vancomycin powder＋深部引流管 → 感染再降** |

- 術後：美國多為早期 ROM、**10–12 週**開始負重
- 🆕 **2024（92 人）：6 週早期負重 vs 10–12 週 → 結果、併發症、下沉無差異**（不論骨折型態或 void filler）；需更大 RCT

## 8. 脛骨幹骨折 🆕

- **髕上 vs 髕下釘**：SR → 髕上**透視時間短、入點較好、Lysholm 與膝前痛 VAS 較好** ✅
- 🆕 **2024：旋轉不良無差異**，但**左側傾向內旋、右側傾向外旋**畸形
- 🆕 **遠端螺旋脛骨幹骨折合併後踝骨折**
  - 單一研究（全做 CT）：**92.3%**
  - **SR：遠端 1/3 螺旋骨折，CT 70.4% vs X 光 28%**
  - → 許多作者建議**遠端 1/3 脛骨幹骨折常規 CT**
  - 是否固定：依關節面比例、移位、穩定性；CT 是否增加固定、固定是否改善結果 → 證據不足
- 🆕 **負重**
  - 2022 SR：**早期負重（<6 週）→ 癒合時間、延遲癒合或 nonunion、再手術無差異**；延遲負重組併發症 odds 較高（可能選擇偏差）
  - 2023：**近端關節外脛骨骨折 IMN 後立即負重 → 對位、固定失敗、復位喪失無差異**

## 9. Pilon 骨折 🔄

- 目標：恢復關節面與其與骨幹的對位；開放、共病、嚴重度越高 → 併發症越高
- 🔄 **早期 vs 延遲固定**：**軟組織併發症、癒合、功能分數無差異**；早期組**癒合快約 2 週**、手術時間較短、住院較短 → 軟組織允許時，**早期固定越來越被接受**（相對於傳統分期）
- 🆕 **危險因子（SR）**

| 因子 | OR |
|---|---|
| **局部軟組織狀態** | **3.63（最強）** |
| 病人共病 | 1.82 |
| 吸菸或物質濫用 | 1.69 |
| **開放骨折** | 局部併發症 **3.5 倍** |

## 14. Key Study Points（OKU 15）

- 老人**股骨頸、轉子間、轉子下骨折**：**早期手術並允許立即負重**是標準照護
- 老人**遠端股骨骨折**：單一植入物雖可靠，但**雙植入物（dual plate 或 NPC）**沿中性軸傳遞應力，可**立即負重**並可能有更可靠的癒合率
- **脛骨幹骨折：立即負重是標準照護**；無近端或遠端關節內侵犯者，**延遲負重的 nonunion 與再手術率較高**
