## 1. 神經學評估 🔄

### 1.1 病史與步態 🆕

- 問：**疼痛性質、位置、神經症狀、加重與緩解因素、已試治療、對功能的影響**；🆕 **單側 vs 雙側**可縮小鑑別。
- 🆕 先練習**在影像前用臨床定位病灶層級**。
- 🆕 **所有病人都要看步態**：cadence、手擺動、動作流暢度、姿勢。
  - **矢狀失衡（前傾駝背）→ 嚴重影響 QOL**。
  - **antalgic gait** → QOL 影響。
  - 🆕 **手擺動減少 → Parkinson 等 UMN 神經退化疾病的前兆**。

### 1.2 反射 🔄

- 退化性脊髓或椎管壓迫可緩慢進展、不易察覺 → 反射檢查辨識 **myelopathy**（long tract signs、**hyperreflexia = UMN**）。
- 常規：**biceps、brachioradialis、patellar、ankle jerk＋Hoffmann、clonus**。

| 反射／徵象 | 路徑 | 臨床對應 |
|---|---|---|
| **Hoffmann** | UMN／皮質脊髓束 | **頸椎壓迫（常伴 myelopathy）**；彈中指指甲 → 拇指屈曲內收 |
| 🆕 **Tongue fasciculations** | **hypoglossal 神經或核**／anterior horn | 🆕 **運動神經元病或 ALS** |
| **Clonus** | UMN | **頸或胸髓壓迫** |
| 🆕 **Romberg** | **dorsal columns** | **本體感覺障礙** |
| 🆕 **Lhermitte** | **dorsal columns** | **MS 或頸椎壓迫** |
| Babinski | UMN／皮質脊髓束 | SCI、腦傷、ALS |
| Tinel | median nerve | CTS |
| Biceps、brachioradialis、triceps | — | 頸椎壓迫 |
| **Patellar** | — | **亢進 = 脊髓壓迫；低下或消失 = 腰椎壓迫** |
| **Ankle jerk（L5–S2）** | — | **亢進 = 脊髓壓迫；低下或消失 = 腰或薦壓迫** |

- 異常反射 → 安排影像，或已知 myelopathy 者提早減壓。

### 1.3 肌力與感覺 🔄

- 依 myotome、dermatome；**肌力 5 分制**；感覺記錄為完整或減少。
- 注意 **paresthesia、dysesthesia、allodynia**（不該痛卻痛）。
- 🆕 **pinprick → anterolateral columns；proprioception → dorsal column；但多數情況輕觸檢查已足夠**。

### 1.4 周邊神經 vs 根壓迫 🆕

| 周邊神經 | 易混淆的根 | 鑑別 |
|---|---|---|
| 🆕 **Peroneal**（背屈弱、第一二趾背麻） | **L5** | 🆕 **腓神經壓迫保留足內翻**（L5 內翻亦弱） |
| 🆕 **Median**（握力弱、手痛麻） | **C6（–C7）** | 🆕 **C6 壓迫 biceps 反射減弱；median nerve 壓迫手掌或第三指麻、腕部 Tinel 陽性** |
| 🆕 **Sciatic**（坐骨神經痛） | **S1**（蹠屈弱） | 🆕 **坐骨神經痛保留 ankle jerk** |

- 🆕 **double crush**（同一神經兩處壓迫）→ 影響術後結果。
- 不確定周邊 vs 中樞 → **EMG／NCS**。

### 1.5 Provocative maneuvers 🔄

- 原理：以可控方式**牽拉神經 → 重現症狀** → 定位。

| 測試 | 陽性 | 病理 |
|---|---|---|
| ✅ **Straight leg raise** | 抬直腿 → 腿後側放射痛 | 椎間盤突出或腰薦根壓迫（**確認**腰薦根病變） |
| 🆕 **Tripod test** | 坐姿做 SLR 時**向後撐手**以減痛 | 椎間盤突出或根壓迫 |
| **Femoral stretch** | **俯臥、屈膝抬腿 → 前大腿痛** | 上腰根壓迫 |
| ✅ **Spurling** | 被動頸伸＋側彎＋軸壓 → 患側上肢放射痛 | 頸根壓迫（**確認**頸根病變） |
| **Shoulder abduction** | **患側手放頭上 → 根痛減輕** | 頸根壓迫 |
| Neck distraction | 牽引 → 減輕 | 頸根壓迫 |
| 🆕 **Adson** | **吸氣並將下巴轉向患側 → 橈動脈脈搏改變** | 🆕 **Thoracic outlet syndrome** |

- ❌ OKU 14 的敏感度與特異度（**Spurling 敏感約 30%、ULTT 97%、Valsalva 22%、SLR 30–70°、敏感 92%、特異 28%**、crossed SLR 相反）本版**未列**。

### 1.6 SI joint 🆕

- 區分**薦根坐骨神經痛 vs SI joint 痛** → 多項 SI 誘發測試（如 **sacral thrust**；陽性 = 重現病人原有疼痛）。
- 🆕 **至少 3 項 SI 測試成功定位疼痛 → 可放心進行 SI 麻醉注射或融合**。

## 2. 影像 🆕

### 2.1 X 光

- AP、lateral → **spondylolisthesis、facet arthropathy**。
- **懷疑不穩 → flexion-extension radiographs**。
- 🆕 **站立全長 scoliosis 片（踝 → 枕骨）**：矢狀失衡、冠狀側彎、**spinopelvic parameters、下肢長度差**（可能導致側彎失衡）。

### 2.2 MRI 與 CT myelogram

- 🆕 **神經壓迫症狀超過 6 週，或出現神經缺損 → MRI 或 CT myelography**（Key Study Point：保守治療下長期疼痛或神經缺損才做進階影像）。
- 最適合**軟組織**；可確認**感染、腫瘤、風濕**病因。
- **無法進入磁場者 → CT myelogram**（通常由放射科注射顯影劑）。

### 2.3 CT 與 SPECT-CT 🆕

- **非顯影 CT**：非創傷時多用於**手術規劃**（pedicle 與椎體大小、器械匹配）；🆕 **導航與機器人平台依骨性標記，有時術中掃描**。
- 🆕 **SPECT-CT（2024）**：放射追蹤劑結合 → 顯示 **facet 與椎間盤活性差異**（動作或疼痛）→ **決定注射或融合的節段**；🆕 **也可評估術後持續疼痛**。

## 3. 診斷輔助 🆕

- 🆕 **除少數例外，都應先完成一段 PT**：
  - 反應好 → 可能不需進一步檢查。
  - dry needling、cupping 有效 → 提示肌肉骨骼成分較大。
  - 🆕 **規律、引導式肌肉訓練（prehabilitation）**提高積極 PT 仍無效者的後續成功機會。
- **EMG／NCS**（神經科）：確認神經傷或壓迫；或發現**軸突或肌肉層級**問題（如 **ALS 等 LMN 疾病**）。
- 🆕 **神經注射（復健科）**：類固醇＋局麻 → 暫時到長期緩解。
  - **有效 → 也具診斷意義**：支持該處若長期解除壓迫能帶來有意義改善 → 再注射、神經阻斷、**更永久的燒灼**或**手術減壓**。
  - 🆕 **注射有效也能調整病人期待，提升對較侵入性手術的感受效益（2022）**。
- 外科與復健、疼痛介入醫師反覆溝通轉介。

## 4. OKU 14 CH52 中 OKU 15 不再列出的內容 ❌

- ❌ **紅旗徵狀與必須排除的內科疾病**清單。
- ❌ **ROM 正常值（頸 vs 腰）**：屈 50–60° vs 50–80°、伸 60–70° vs 20–40°、側彎 40–45° vs 30–40°、旋轉 70–75° vs 35–45°。
- ❌ 觸診段落；**四種感覺與定位意義**；**輕觸＋針刺組合足以辨識腰根病變（2021）**。

- ❌ **腰椎特殊檢查表（SLR 30–70°、敏感 92%、特異 28%；crossed SLR 特異高）**。
- ❌ 頸腰神經根運動、感覺、反射完整對照表。

## 5. Key Study Points（OKU 15）

- 脊椎評估通常涉及**神經科、復健科、PT、放射科、骨科**的多學科團隊。
- 診斷與治療依賴**進階影像、誘發手法、定位性處置**（注射等）。
- **進階影像用於保守治療下長期疼痛，或出現神經缺損時**。
- 需區分**急性 vs 慢性**與**病灶層級**，才能以最小侵入性安全及時治療。

## 6. Anki 候選題

1. 手擺動減少提示？→ Parkinson 等 UMN 神經退化疾病。
2. 矢狀失衡（前傾駝背）的影響？→ 嚴重影響 QOL。
3. Hoffmann 陽性提示？→ 頸椎壓迫（常伴 myelopathy）、UMN。
4. 舌肌顫動提示？→ 運動神經元病或 ALS（hypoglossal 核）。
5. Clonus 提示壓迫在哪？→ 頸或胸髓。
6. Romberg 與 Lhermitte 測試的路徑？→ dorsal columns。
7. Lhermitte 的臨床對應？→ MS 或頸椎壓迫。
8. Ankle jerk 的層級？亢進 vs 消失？→ L5–S2；脊髓壓迫 vs 腰薦壓迫。
9. Pinprick 與 proprioception 分別測哪條路徑？→ anterolateral columns；dorsal column。
10. 多數情況感覺檢查用哪種即可？→ 輕觸。
11. 腓神經病變與 L5 根病變的鑑別？→ 腓神經保留足內翻。
12. CTS 與 C6 根壓迫的鑑別？→ CTS 手掌或第三指麻、Tinel 陽性；C6 biceps 反射減弱。
13. 坐骨神經痛與 S1 根病變的鑑別？→ 坐骨神經痛保留 ankle jerk。
14. 什麼是 double crush？→ 同一神經兩處壓迫，影響術後結果。
15. Tripod test？→ 坐姿 SLR 時向後撐手減痛。
16. Femoral stretch test 的姿勢與陽性？→ 俯臥、屈膝抬腿，前大腿痛。
17. Shoulder abduction test 陽性？→ 手放頭上根痛減輕。
18. Adson test 的做法與疾病？→ 吸氣並下巴轉向患側，橈動脈脈搏改變；TOS。
19. SI joint 測試需幾項陽性才可放心注射或融合？→ 至少 3 項。
20. 懷疑脊椎不穩加照什麼？→ flexion-extension X 光。
21. 站立全長片可評估？→ 矢狀失衡、冠狀側彎、spinopelvic parameters、下肢長度差。
22. MRI 或 CT myelogram 的時機？→ 神經壓迫症狀 >6 週或神經缺損。
23. 無法做 MRI 時的替代？→ CT myelography。
24. 非顯影 CT 在脊椎手術的角色？→ 器械尺寸規劃、導航與機器人。
25. SPECT-CT 的用途？→ 定位疼痛來源（決定注射或融合節段）、術後持續痛評估。
26. 神經注射有效的診斷意義？→ 支持該處減壓可帶來改善。
