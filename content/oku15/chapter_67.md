## 1. 雙骨前臂骨折 🔄

### 1.1 流行病學與診斷 🆕

- 🆕 **前臂骨折 = 兒童最常見傷，佔所有小兒骨折 17–22%**。
- 🆕 **0–19 歲年發生率 1.69／1,000；5–14 歲高峰 2.5／1,000**。
- 🆕 **超音波**：許多中心取代傳統 C-arm 與 X 光；🆕 **2023：超音波不劣於 C-arm**；多篇強烈主張以超音波診斷遠端前臂骨折。
- 🆕 **維生素 D**：前臂骨折兒童常缺乏；診治可確保癒合、降低再骨折；🆕 **2023 前瞻 RCT：維生素 D 每升一單位 → 前臂骨折風險下降**。

### 1.2 可接受復位 🔄

- ✅ 標準在歷版本中基本不變（**Noonan & Price**，Table 1；如**女 >8 歲：近中段 <10°**）。
- 🆕 **2024 meta：這些成角標準並非建立在能預測症狀性畸形癒合的高品質研究上**。
- 🆕 **前瞻世代（未復位成角骨折的重塑）**：容忍度可更寬，尤其年幼：

| 年齡 | 可接受成角 |
|---|---|
| 🆕 **女 ≤3 歲、男 ≤5 歲** | **18°** |
| 隨年齡遞減 | … |
| 🆕 **女 ≤11 歲、男 ≤13 歲** | **10°** |

- 依**年齡、重塑潛力、骨折位置**決定殘餘成角容忍度。
- ✅ **≤8 歲 bayonet apposition 可接受**（除非侵占骨間腔、限制旋轉）。
- ✅ **約 80% 橈尺骨生長在遠端**。
- ✅ **剩餘生長 <2 年 → 重塑可忽略 → 同成人處理**。
- **越年幼、越遠端 → 可接受越多成角與旋轉**。

### 1.3 閉鎖治療 🔄

- 移位 → **閉鎖復位**（多在急診鎮靜，也可門診手術中心，多種麻醉皆成功）。
- **遠端 → 短臂石膏；骨幹與近端 → 長臂石膏**。
- 🆕 **防水石膏**：部分中心已擴大到**不穩前臂骨折的初始治療與長臂石膏**（原先只研究於遠端橈骨與不需復位的穩定骨折）。
- ✅ **cast index（骨折處石膏前後寬 ÷ 橈尺寬）≤0.7 → 減少復位流失**。
- ✅ **三點塑形、肘屈 90°、直的尺側緣**。
- 🆕 **2022：防水襯墊 cast index 較高，但病人滿意度較高**。

### 1.4 復位流失 🔄

- 🆕 **閉鎖復位後流失 5–25%，多發生於前 2 週**。
- 🆕 **前 2 週每週追蹤，第 3 週也建議追蹤**。
- 🆕 **危險因子：初始移位較大、復位後殘留 >15° 成角、肥胖**。
- 處置：**再閉鎖復位、IM 固定、經皮 pin、或開放＋plate 或 IM**。

### 1.5 手術與內固定 🆕

- 🆕 **IM 釘留在皮外理論上感染較高，但目前文獻不支持**。
- 🆕 **取出內固定的風險可能比過去認為的高（2022）：肌腱斷裂、感覺異常、再骨折**。
  - 🆕 **遠端橈骨背側入路 → EPL 斷裂較多；橈側入路 → 感覺異常較多**。
- 🆕 **美國骨骼未成熟前臂骨折手術明顯增加**：
  - 多數雙骨骨折可保守；**骨折嚴重度與不穩並未增加** → 適應症與態度可能在改變（醫師或家長驅動未研究）。
  - 🆕 **手術併發症 14.6%**；🆕 **為通過 IM 釘而開放復位 → delayed union 較多**。
  - 多用鈦或不鏽鋼 IM 釘。
- 🆕 **歐洲部分中心用可吸收 IM 釘（免取出）**：成本較高、手術時間較長、學習曲線長；🆕 **美國目前無 FDA 核准的可吸收釘**。

### 1.6 開放骨折 ✅

- ✅ **Type I：IV 抗生素、破傷風、閉鎖復位、床邊清創沖洗、副木或石膏**；是否給門診口服抗生素各中心不同；感染率低，仍缺 Level I。
- **Type II 以上 → 手術室正式清創沖洗，且多需固定**（高能量、較不穩）。

### 1.7 回運動與再骨折 🆕

- 🆕 **閉鎖治療雙骨骨折後再骨折約 1–2%**；🆕 **再骨折 = 相對手術適應**。
- 🆕 **單純、幹骺端、單骨骨折 → 8–10 週回運動**。
- 🆕 **骨幹骨折與完全骨折應比幹骺端與 greenstick 更久避免運動（2023）**。

## 2. Monteggia 骨折 🔄

- ✅ **尺骨幹骨折＋橈骨頭脫位**；只懷疑單純尺骨骨折而未照肘 X 光 → 漏診。
- 🆕 **最常 6–10 歲**，但所有前臂傷都要高度懷疑（Key Study Point：**尺骨幹骨折一定要檢查 radiocapitellar joint**）。
- 閉鎖復位石膏可接受，但 **radiocapitellar 必須復位**。
- 🆕 **前 3 週每週 X 光，確認橈骨頭無半脫位或脫位**。
- 部分主張**急性內固定**以避免 radiocapitellar 復位流失。
- ✅ **慢性或漏診 → 結果明顯較差：肘活動喪失、痛、cubitus valgus、慢性肘不穩**。
- 處置：**尺骨截骨＋radiocapitellar 開放復位，部分加環狀韌帶重建**。
- 🆕 **年幼、橈骨頭明顯變形前治療 → 結果較好**。
- 🆕 **過去主張只對傷後 <1 年者治療；近期文獻顯示更延遲者也可得極佳結果**。

## 3. Galeazzi 骨折 🔄

- ✅ **橈骨幹骨折＋DRUJ 脫位**。
- 🆕 **兒童遠比成人少；多為 9–13 歲**。
- ✅ **閉鎖復位＋旋後位長臂石膏**可成功，但需密切追蹤確認維持。
- 🆕 **很少需要 DRUJ 開放復位；兒童傷後很少有慢性 DRUJ 不穩**。

## 4. 遠端橈骨骨折 🔄

- 🆕 **佔小兒上肢骨折 74%**；🆕 **13 歲男孩每年近 2% 發生前臂骨折（2022）**。
- 🆕 **2024：創傷與手外科醫師比小兒骨科醫師更常手術治療兒童與青少年遠端橈骨骨折**。
- 🆕 **成人有清楚指引，小兒治療變異大、缺 Level I**。
- ✅ **開放骨折、剩餘生長 <2 年 → 同成人**。
- 🆕 **急性骨骺傷（SH I、II）→ 復位恢復對位；不建議反覆嘗試復位或傷後 >10 天才復位（增加 physeal arrest）**。
- 🆕 **傷後 1 年 X 光追蹤 physeal arrest；未重塑 → 可能需矯正截骨**。
- 🆕 **2023：遠端雙骨前臂骨折無手術角色**（遠端約 80% 生長 → 重塑強）；但**距成熟 1–2 年內者不應期待明顯重塑**。

### 4.1 Buckle 骨折 🆕

- 🆕 **共識：穩定的遠端橈骨 buckle 骨折不需骨科醫師治療，也不需回診**。
- 🆕 **放射科醫師可有效判斷穩定或不穩**。
- 🆕 **穩定 buckle：不需石膏、不需回診、不需重照 X 光**。
- 🆕 許多中心已用演算法，結果極佳 → **節省家庭與醫療體系成本**；不必要回診造成的缺工缺課成本不可忽視。

## 5. 舟狀骨骨折 🔄

### 5.1 流行病學與診斷 🔄

- ✅ **小兒少見，但為最常見的腕骨骨折**；🆕 **12–15 歲高峰**。
- 🆕 **骨化由遠往近 → 年幼者多遠端骨折，接近成熟者多近端骨折**。
- 🆕 **舟狀骨直到青少年後期多為軟骨 → X 光敏感 42%、特異 71%（2023）**；🆕 **但他人反駁：急性傷約 93% 至少在一個 view 可見**。
- **MRI** 對診斷與確認很有價值：
  - 🆕 **2022 前瞻（150 例疑似腕傷）：先固定、2 週內做 MRI → 早期診斷；MRI 正常者每 4 位有 1 位可提早停止固定**。
  - 🆕 **2024：MRI 確診；年長與男性 = 真舟狀骨骨折的獨立預測因子**。
  - 可發現需改變治療的**合併傷**。

### 5.2 治療 🔄

- 依**位置（近端、腰部、遠端）與移位**。
- 🆕 **逆行血供 → 遠端平均 4 週癒合；近端可達 8 週**。
- 🆕 **meta：93.5% 急性小兒舟狀骨骨折閉鎖固定成功**。
- 🆕 **長臂 vs 短臂 thumb spica：成人與小兒多篇研究癒合率無差**。
- 🆕 **就醫時間可能最影響癒合**：
  - **254 例回溯：以 21 天為切點 → <21 天癒合 96%，>21 天降至 75%**。
  - **失敗者皆 >11 歲、橫向腰部骨折、移位 >1 mm**。
- ✅ **移位骨折、確診不癒合、近端極骨折 → 手術，癒合 98%**；**螺釘最常用**（經皮或開放 ± 血管化或非血管化植骨）。
- 🆕 **ON 罕見，約 1.5%**；需**固定＋血管化**，傳統用**第一掌骨背側血管骨膜瓣**。

## 6. 掌骨頸骨折 🔄

- 🆕 **掌骨骨折佔小兒手骨折 10–30%**。
- 🆕 **2022 單中心 4,356 例小兒手骨折**：
  - **12–17 歲最多（64%）**。
  - **中節與近節指骨 48%、掌骨 33%**。
  - **掌骨骨折比例隨年齡增加：<5 歲 14% → 12–17 歲 40%**。
- 🆕 **頸部骨折佔掌骨骨折 75%**；最有名 = **小指（第五）掌骨頸骨折（boxer's fracture）**。
- 傳統：閉鎖復位＋石膏。
- 🆕 **2022 回溯：<50° 成角的閉鎖復位對矢狀對位沒有有意義的改善**。
- 🆕 **<70° 成角改用可拆式 ulnar gutter brace、不再骨科或 X 光追蹤 → 每人省約 $916；26 個月共省 $261,846**。

## 7. 指骨骨折 🔄

- 🆕 **兒童與青少年最常見的手骨折；≤19 歲年發生 138.3／100,000（2022）**。
- 🆕 **COVID-19 期間手骨折減少 27–39%**。
- 🆕 **小指近節骨折最常見**。
- 🆕 **多數保守：單中心最高 90.2%**：
  - 🆕 **2024 五年回顧：75% 單純石膏、23% 閉鎖復位＋石膏、只有 2.3% 手術**。
  - 🆕 **2024 多中心 634 例近節基部骨折：2.2% 手術**。
- 保守：**buddy taping、可拆副木、石膏**。
- 🆕 **juxtaepiphyseal 骨折冠狀 ≥10° 或矢狀 ≥30° → 多需閉鎖復位**。
- 🆕 **前瞻 RCT：不需復位的關節外指骨骨折，buddy taping 不劣於副木**。
- 手術適應：**開放、旋轉變形、關節內、多處骨折、粉碎、明顯移位** → 多為**閉鎖復位＋pin**。
- 🆕 **2023：近節基部單針 vs 雙針 K-wire → 併發症、PRO、最終成角無差；單針手術時間較短**。

## 8. Seymour 骨折 🔄

- ✅ **遠節指骨開放、移位的 juxtaepiphyseal 骨折＋甲床傷**；**骨骼未成熟者獨有**。
- 經典：**physeal 骨折＋背側移位**；🆕 也有多種遠節指骨骨折變異 → **常漏診或誤診 → 延遲就醫 → 感染與畸形癒合風險高**。
- 🆕 **66 例（經典＋變異）：併發症經典型 11%、X 光變異型 23%**。
- 🆕 **最常見併發症 = 感染**：
  - **34 例感染 20.6%；主要驅動因子 = 接受適當治療的時間**。
  - 🆕 **24 小時內治療的 11 例：0 感染；>24 小時：近 50% 感染**。
- 🆕 **SR＋meta（352 例）**：

| 處置 | 感染風險 |
|---|---|
| 🆕 **48 小時內手術清創＋移除卡入組織** | **RR 0.28** |
| 🆕 **24 小時內預防性抗生素** | **RR 0.21** |
| 🆕 **兩者合併** | **感染風險降 70%** |

- 🆕 **穩定**：清創、移除卡入組織後，**甲床修補本身提供部分穩定**；仍不穩 → **K-wire（固定入骨骺或穿過 DIP）**。
  - 🆕 **2022 review（8 篇、206 例）：36% 用 K-wire → 二次移位、遠節屈曲變形、感染較少，但 physeal disturbance 較多**。
- Key Study Point：**未急性辨識並以清創＋抗生素治療 → 感染率較高**。
