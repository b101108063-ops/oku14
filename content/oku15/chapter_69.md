## 1. 骨盆骨折 🔄

### 1.1 流行病學 🆕

- 🆕 **美國年發生率 9.8／100,000 兒童**。
- 🆕 **合併傷**：

| 部位 | 比例 |
|---|---|
| **下肢** | **43%** |
| **顱內** | **16%** |
| **胸** | **13%** |
| **腹** | **9%** |
| **泌尿生殖** | **3%** |

- 原因：**車禍、跌倒、運動**。
- 🆕 **多可保守；只有 1.2% 骨盆環傷需手術固定**。
- 🆕 **併發症：下背痛 10%、後天側彎 0.3%、腿長差 1%**。

### 1.2 分類 🆕

- 🆕 **Torode and Zieg（最常用）**：

| Type | 定義 |
|---|---|
| **I** | **撕脫骨折** |
| **II** | **iliac wing 骨折** |
| **IIIa** | **單純前環：恥骨聯合分離或恥骨枝骨折** |
| **IIIb** | **前環＋單側後環** |
| **IV** | **前後環合併、或環＋髖臼、或雙側上下恥骨枝骨折** |

- 🆕 **評估合併傷可能與預期結果，但不預測是否需手術**；🆕 **幾乎所有不穩傷都是 IV → 實用性受限（2023）**。
- 🆕 **Tile**（生物力學不穩）以成人為主，無法一致套用於小兒；🆕 **AO／OTA 與 Young-Burgess 也常不適用（小兒型態常不如描述）**。
- 🆕 **手術治療相關因子：骨折嚴重度上升、ISS 上升、血紅素下降**（亦與輸血相關）。

### 1.3 小兒骨盆特性 🆕

- 🆕 **單純 iliac wing 骨折：向內摺（類似長骨骨幹的 greenstick 或 torus）**，多為直接撞擊、**本質穩定**。
- 🆕 **明顯移位 → 腹壁肌肉分兩層**：
  - **external oblique 隨移位的 iliac wing**；
  - **深層（internal oblique＋transversus abdominis）留在穩定的 iliac apophysis**；
  - 移位越大 → 腹肌間剪切（2024）。
- 🆕 **生物力學：骨盆韌帶緊＋關節鬆 → 塑性變形 → 需更大力才產生移位骨折**；🆕 **但力量傳到骨盆內與腹內器官 → 明顯內臟傷**。
- 🆕 **厚骨膜 → 小兒骨盆骨折大出血較成人少**。
- 🆕 **型態不同於成人：可見不穩後環傷卻無明顯前環骨折**。
- 🆕 **physis 比骨盆韌帶弱 → 多為軟骨骨交界分離，尤其 iliac wing**。

### 1.4 重塑迷思與手術適應 🆕

- 🆕 **傳統認為小兒骨盆重塑力高 → 保守治療少長期後遺症；但多篇研究顯示：不論受傷年齡，骨盆環都不會顯著重塑**。
- 🆕 **2022 meta：保守治療的骨盆環傷 48% 有骨盆不對稱 → 功能結果較差**。
  - 引發疑問：**靜態影像是否足以評估骨盆環不穩？**
  - 🆕 **小兒骨盆能吸收更多力而不骨折 → 只要有骨折，本身就可能代表不穩**。
- 🆕 **手術適應：骨盆不對稱 >1 cm，或薦骨後移 >5 mm**。
- 🆕 **以解剖復位矯正骨盆不對稱 = 長期慢性下背痛與 SI 痛的最重要決定因子**。

### 1.5 急性處置 🆕

- 初始評估與復甦 → 暫時穩定 → 計畫性最終固定（若需要）。
- 🆕 **厚骨膜 → 小兒骨盆骨折大出血較少 → 若有大出血，應評估其他來源**；🆕 **內臟傷風險高很多，需徹底檢查**。
- **下腹瘀青或瘀斑**提示合併傷。
- 🆕 **未控制出血 → binder 復位穩定；binder 無效 → 血管攝影 ± pelvic packing 或栓塞（2024）**。
- 🆕 **骨盆 X 光顯示前環傷 → 做骨盆 CT（對薦骨骨折與 SI 傷較敏感）**。
- 保守者：**活動後密切追蹤延遲移位或不穩**。

### 1.6 髖臼骨折 🆕

- 罕見（**厚軟骨＋強韌帶附著**）。
- 🆕 **套用成人標準（負重頂移位 >2 mm、髖不穩、無法維持同心復位）手術 → 良好到極佳結果**。

### 1.7 骨突撕脫骨折 🔄

- 青少年運動：跑、踢、跌倒；🆕 **男性 78%、平均 14 歲**。
- 機轉：**肌腱附著比骨突強**。

| 部位 | 肌肉 | 運動 |
|---|---|---|
| **ASIS** | **sartorius** | 🆕 **田徑** |
| **AIIS** | **rectus femoris** | 🆕 **足球** |
| **Iliac crest** | **abdominal obliques** | 🆕 **撕脫前約 1 個月有前驅症狀** |
| **Ischial tuberosity** | **hamstrings** | 🆕 **體操** |
| **Lesser trochanter** | **iliopsoas** | — |
| 較少：pubic symphysis | adductor longus | — |
| 較少：greater trochanter | abductors | — |

- 🆕 **發生率大增**（俱樂部與全年運動）。
- 🆕 **保守**：**限制負重 3–4 週＋第一週冰敷與 NSAID → 4 週起漸增阻力訓練 → 6–8 週伸展**。
- 🆕 **無絕對手術適應；一般參考：ischial tuberosity 與 ASIS 移位 >15 mm、AIIS 移位 >2 cm**；依病人而定。
- 🆕 **大型系列：約 86% 3 個月時無症狀，與骨性移位無關**。

## 2. 髖脫位 🆕

- 小兒外傷性髖脫位罕見。
- 🆕 **鎮靜下閉鎖復位屬緊急；>6 小時未復位 → ON 風險增加**。
- 🆕 **復位後 CT 或 MRI**：股骨頭骨折、後壁骨折、是否同心復位。
- 🆕 **acetabular fleck sign → 代表明顯的 labrum osteochondral 撕脫（非同心或同心復位皆可見，2024）**。
- 🆕 **非同心復位或閉鎖失敗 → 緊急開放復位**；入路依脫位方向以減少軟組織傷。
- 🆕 **MRI 偵測 labral 卡入比 CT 敏感**。
- 🆕 **結果取決於：受傷能量、辨識與復位速度、合併傷辨識、復位後關節吻合度**。
- 🆕 **至少追蹤 6 個月–1 年看股骨頭 ON**。

## 3. 股骨頸骨折 🔄

### 3.1 血供與分類 ✅

- ✅ **<1% 兒童骨折**，但造成不成比例的長期不良（主要為股骨頭 ON）。
- 🆕 **小兒股骨頭血供幾乎全來自 MFCA 的 lateral epiphyseal vessels**；🆕 **physis 為機械屏障 → 骨骺與幹骺頸血管間無吻合** → 髖脫位或移位頸骨折傷及 MFCA → ON。
- ✅ **Delbet（由近往遠）；ON 風險與 type 成反比**：

| Delbet | 定義 | ON |
|---|---|---|
| **I** | **epiphyseal-metaphyseal separation（physeal separation）** | **38%** |
| **II** | **transcervical** | **28%** |
| **III** | **basicervical** | **18%** |
| **IV** | **intertrochanteric** | **5%** |

- ✅ **其他併發症：physis 早閉 22%、coxa vara 18.5%**；🆕 **不癒合 11%、chondrolysis 13.5%**。

### 3.2 復位時機與品質 🆕

- 復位時機曾被視為最重要的可修正因子。
- 🆕 **多篇研究：較早復位（<12 小時）不降低 ON，甚至可能增加 ON**。
- 🆕 **復位品質比時機更重要**（預防 ON 與其他併發症）。
- 🆕 **開放 vs 閉鎖**：文獻互相矛盾 → **以復位品質為準，閉鎖無法滿意時改開放**。
- 🆕 **Capsular decompression**（抽吸、開放 capsulotomy、有限 capsulotomy；理論：降低囊內壓、減少骨骺血流填塞）→ **無決定性證據可降低 ON**。

### 3.3 固定 🆕

- 原則：**依不穩程度、年齡與體型給足夠固定；年幼盡量保留 physis，但不犧牲穩定、不冒不癒合風險**。

| 情況 | 固定 |
|---|---|
| 🆕 **<2 歲** | **閉鎖復位＋spica 即可** |
| 🆕 **Delbet I、II（較近端）** | **跨 physis 固定**：**年幼小病人 → 光滑 K-wire；較大或年長、明顯移位 → cannulated screws 跨 physis** |
| 🆕 **Delbet III、IV，輕移位或年幼** | **可考慮保留 physis 固定** |
| 🆕 **年長、遠端型** | **sliding hip screw 或 proximal femoral plate**（單用螺釘易失敗、創傷後 coxa vara） |

## 4. 轉子下骨折 🔄

- 🆕 **成人定義：小轉子下 5 cm 內；兒童因股骨較短，定義較不一致**。
- 🆕 **近端片受 hip girdle 肌肉 → 屈曲、外旋、外展** → 手術技術較難；**外側皮質張力 → 不癒合較多**。
- 🆕 **<5 歲：閉鎖復位＋spica 通常可接受，但石膏內延遲移位風險較高**。
  - 🆕 **橫向或短斜、或初診大冠狀成角 → 需密追；三項都有 → 最多 99% 石膏治療後最終對位不佳**。
- 🆕 **年長**：依年齡與型態 → **ESIN、plate、rigid nail**；多研究顯示 ESIN 成功。
  - 🆕 **ESIN 增穩技巧：5–10 歲可讓釘穿透大轉子骨突或後頸皮質；用 locking eyelets 或 endcaps 增加長度與旋轉穩定**。
  - plate 亦有效，但樣本小、異質。
- 🆕 **青少年 → 同成人 reamed IM nail；小心避免 varus 復位（外側皮質張力 → 不癒合或延遲癒合）**。
- 植入物選擇依骨骼成熟度、骨折穩定性與醫師熟悉度。

## 5. 股骨骨幹骨折 🔄

### 5.1 流行病學與評估 🔄

- ✅ **只佔小兒骨折 1–2%，但是兒童住院最常見原因之一**。
- 🆕 **約 70% 股骨骨折在骨幹**。
- ✅ **<3 歲一定要考慮並調查 NAT，尤其未會走路者**。
  - ✅ **未會走：42% 為 NAT；會走：2.5%**。
  - 🆕 **骨折是兒虐第二常見表現** → 熟悉通報流程。
- 🆕 **同側股骨頸骨折**：成人 **2–9% → 常規 CT**；🆕 **兒童只有 0.70–0.87% → 不常規 CT**；高能量（車禍）或臨床懷疑時考慮。

### 5.2 指引與演算法 🆕

- 🆕 **AAOS 2020 CPG（小兒股骨幹骨折）：七項建議中只有三項為強或中等證據** → 高品質證據不足。
- 🆕 **同年專家共識：分類系統＋已驗證的治療演算法**（年齡、骨折穩定性、病人特性）：

| Class | 年齡／情境 | 處置 |
|---|---|---|
| **1：保護至癒合** | **<6 個月**（所有型態、高度懷疑虐待） | **Pavlik harness 或軟墊** |
| | **6 個月–4 歲**：不完全、或完全但嚴格無移位 | **walking spica 優先** |
| | **神經肌肉、不行走** | **spica、splint cast 或膝 brace** |
| **2：主動治療（10 天內）** | **6 個月–4 歲** | **walking 或一般 spica，早期密追**（輕度短縮偏好 walking spica）；準備 **cast-wedging** |
| | **4–9 歲**：所有 simple（兩片） | **ESIN** |
| | **9 歲至成熟**：simple＋**長度穩定（橫向、短斜）＋低能量＋<50 kg** | **ESIN** |
| | **9 歲至成熟**：**複雜（>2 片）或粉碎、長度不穩（長螺旋或斜）、高能量、>50 kg** | **trochanteric-entry rigid nail、submuscular plate、或 ex-fix** |
| | **骨骼成熟後** | **trochanteric-entry rigid nail、submuscular plate、或 ex-fix** |
| **所有年齡** | **血行不穩、多重傷、毀損肢、高能量或嚴重污染開放、血管傷** | **damage control（通常暫時 ex-fix 分期）** vs 適當早期剛性固定 |

### 5.3 <6 個月與不行走者 🆕

- 🆕 **重塑力極強 → do-no-harm**：**Pavlik harness 或 soft wrap**（常用棉捲＋彈性繃帶的 hip spica wrap）。
- 嚴重神經肌肉或內科病、不行走、無法安全麻醉 → **brace 或 splint 求舒適**。
- 目標：擺位與移動舒適，直到足夠癒合、疼痛減輕。

### 5.4 Spica 與替代 🔄

- 🆕 **6 個月至 4–6 歲：閉鎖復位＋spica 為首選**。
  - 🆕 **塑形成 valgus＋recurvatum（變形力推向 varus＋procurvatum）**。
  - ✅ **spica 上石膏到癒合平均增加 5° varus、10° procurvatum**。
  - 🆕 **3–6 歲對位不佳的獨立危險因子：高能量型態（橫向、粉碎）、初始冠狀成角 >8°、較近端骨幹位置**。
  - 早期 X 光追蹤、腫脹消退後對位惡化 → **cast-wedging**。
- 🆕 **walking hip spica（單腿石膏＋骨盆帶、可負重）：1–6 歲低能量骨折 → 臨床結果相似、照護負擔較低**。
- 🆕 **功能性骨折 brace**：
  - 🆕 **2023 回溯：hip abduction brace → 所有病人對位適當、無需手術；併發症 6.9% vs spica 38.4%**。
- 🆕 **全防水石膏（2024）：癒合與對位相似、石膏併發症較少、可安全洗澡、減輕照護負擔**。

### 5.5 4–6 歲：spica vs ESIN 🆕

- 尤其**橫向或明顯短縮**者爭議大。
- 🆕 **3–6 歲比較：spica 非計畫回手術室 odds 4.4 倍；每增加一歲 odds 1.3 倍**。
- 年幼且型態適合時 spica 仍極佳；缺點：皮膚刺激、長期固定、照顧負擔。
- **ESIN**：初始治療後移位與回手術室風險大幅降低；多數免石膏；減少石膏皮膚問題與照顧負擔。
  - 代價：**感染、內固定症狀、通常需取出（第二次麻醉）**。

### 5.6 ESIN 🔄

- ✅ **傳統最佳 ESIN 對象：5–11 歲、<49 kg、長度穩定骨折**；不完全符合者也可由醫師判斷使用。
- 🆕 **年幼橫向骨折 ESIN 後有時加 spica 以控制旋轉**（醫師決定，對結果影響未明）。
- 🆕 **近期證據：長度不穩型態（螺旋、粉碎、長斜）用 ESIN，併發症與再手術與長度穩定者無差**；🆕 另研究：**沒有任何病人、骨折或治療特性可預測併發症或非計畫手術（包括不穩骨折）**。

### 5.7 Plate、rigid nail 與 ex-fix 🆕

- 🆕 **較年長、較重、極近端或遠端骨折、或長度不穩且不利 ESIN → plate 可減少 ESIN 的對位不良**。
  - 🆕 **盡量 submuscular（近遠端小切口）**；困難復位時才開放。
  - 🆕 **plate 盡量距遠端股骨 physis 至少 20 mm → 減少遠端股骨 valgus（遠端骨幹骨折最高 30%）**。
- 🆕 **Rigid IM nail：通常 ≥11 歲**。
  - 🆕 **使用避開股骨頭血供的專用植入物；lateral entry nail（避開 piriformis fossa、MFCA 及其分支）→ 小兒使用無 ON 報告**。
  - 🆕 **適用年齡下限未知；大轉子骨突約 8–9 歲前對股骨生長有重要貢獻 → 幼童用 lateral entry rigid nail 傷及骨突 → coxa valga**。
- 🆕 **Ex-fix**：
  - **高資源地區不再常規作為最終治療**。
  - 🆕 **需持續處理的肢體（血管傷、嚴重軟組織傷、明顯污染、合併需緊急非骨科處置的傷）→ 暫時 ex-fix 穩定，再轉最終固定**。

## 6. 遠端股骨骨骺骨折 🔄

### 6.1 特性與生長障礙 🔄

- 多為高衝擊創傷或運動傷。
- 🆕 **遠端股骨 physis = 人體生長最快的 physis**，對傷害極敏感 → 立即與長期併發症（生長障礙、關節或肢體變形）。
- ✅ **整體生長障礙 52%（meta）**；隨嚴重度與移位增加、依 SH 型而異：

| Salter-Harris | 生長障礙 |
|---|---|
| 🆕 **I** | **36%** |
| 🆕 **II** | **58%** |
| 🆕 **III** | **49%** |
| 🆕 **IV** | **64%** |

- 這些數字可用於受傷時與早期治療中與家屬諮詢。
- 🆕 **急性期：可伴血管傷 → 移位骨折常規量 ABI**。

### 6.2 診斷 🆕

- 🆕 **運動傷後膝痛時可能漏診 → 高度懷疑**。
- 🆕 **單靠 X 光有時不足 → MRI 越來越常用：隱匿或難診斷骨折，以及評估可能需治療或影響結果的軟組織傷**。
- 🆕 **疑關節受累 → CT** 協助決策與規劃。

### 6.3 治療 🆕

- 目標：**可接受復位＋足夠穩定**，兼顧骨骼成熟度。

| 情況 | 處置 |
|---|---|
| **無或輕度移位** | **閉鎖復位＋長腿石膏**；🆕 **肥胖或較小孩童但軟組織大 → hip spica 防石膏滑脫** |
| 🆕 **移位 SH I，或 SH II 幹骺片很小** | **滿意閉鎖復位後 → 交叉光滑 K-wire＋石膏** |
| 🆕 **SH II 幹骺片較大** | **一或多支橫向幹骺螺釘 ± 光滑 wire** |
| 🆕 **SH III、IV** | **常需開放復位恢復關節面；骨骺 cannulated screws 固定** |

- 🆕 新技術：可吸收材料（減少金屬植入物併發症、利未來翻修）。

### 6.4 長期 🆕

- 結果差異大，取決於初始 physis 傷與處置是否適當。
- 🆕 **規律長期追蹤 → 早期發現生長障礙或關節不吻合**；**過早 physis 閉合、角度變形、腿長差**需警覺與及時介入。
- 關節內傷或關節復位不良 → 長期後果。

## 8. Key Study Points（OKU 15）

- 小兒骨盆骨折**最常見為運動相關骨突撕脫**，除極少例外皆可保守；**高能量不穩骨盆環傷通常需手術復位固定**，避免長期變形與疼痛。
- 小兒**髖脫位或股骨頸骨折最常見且最嚴重的併發症是股骨頭 ON** → **應及時且解剖復位**。
- 小兒股骨骨折治療取決於**骨折型態、位置、年齡、體重、醫師熟悉度**。
- **遠端股骨 physis 骨折 physeal arrest 風險高** → 應與家屬適當諮詢，並準備處理生長障礙或角度變形。
