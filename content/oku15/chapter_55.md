## 1. 流行病學 🆕

### 1.1 糖尿病

- 🆕 **美國 3,840 萬人（11.6%）有 DM，約四分之一未診斷**（CDC 2021 資料；2018 為 3,030 萬、9.4%）。
- 🆕 **全球約 1/10，預估 2050 年成人達 1/3**（IDF）。
- 🆕 **前糖尿病 9,760 萬（成人 38.0%）**。
- 🆕 **≥65 歲：DM 29.2%、前糖尿病再 48.8%**。
- 🆕 **2023 年 11 月：美國 DM 花費 $412.9B**（直接 $306.6B、間接 $106.3B）；**醫療支出為預期的 2.6 倍**。
  - 間接：缺勤 $3.3B、在職生產力下降 $26.9B、未就業 $2.3B、失能 $37.5B。
  - 2021 年約 **40 萬人**死於 DM（直接成本 >$20B）；**2012–2017 成本增加 26%**。

### 1.2 糖尿病足 🆕

- 🆕 **糖尿病足併發症 = DM 病人住院最常見原因**。
- 🆕 **潰瘍：年發生率 6%、終生 19–34%**；美國每年約 160 萬、全球 1,860 萬。
- 🆕 **50–60% 潰瘍感染**（其中 20% 需住院）；🆕 **中重度感染 15–20%（review 寫 20%）導致截肢**。
- 🆕 **2020 年 16 萬下肢截肢**。
- 🆕 **5 年死亡率：潰瘍 >30%；（踝以上）截肢後 >70%**。
- 🆕 **潰瘍照護約佔 DM 總照護成本三分之一**。

## 2. 病理生理 🆕

- 🆕 **>90% 為 T2DM**：胰島 β 細胞分泌漸進下降＋後天胰島素阻抗。
- 現代觀點：從無法分泌胰島素到不足以支持體重增加＋末端器官反應差的**光譜**。
- 🆕 **DM = basement membrane disease**：**基底膜非酶性醣化 → 多系統終末器官損傷**（心血管、神經、血管、腎）。
- 🆕 **HbA1c**：反映**約 3 個月平均血糖**。

| ADA | HbA1c |
|---|---|
| 正常 | **<5.7%** |
| 前糖尿病 | **5.7–6.4%** |
| 糖尿病 | **≥6.5%** |

- HbA1c 升高 → 自由基 → 基底膜蛋白損傷；**非選擇性、全身性**。
- 🆕 **微血管（終末器官微血管）影響最大 → microvascular disease**。
- 與足踝相關的表現：**周邊神經病變、PVD、免疫缺損、中樞神經病變所致認知缺損、結構變化**。

## 3. 評估 🔄

### 3.1 理學檢查 🆕

- 觀察**步態與生物力學**、不對稱負重。
- 🆕 **檢查鞋子**：磨損處提示行走時高壓區。
- 皮膚與毛髮：**浸潤或過乾 → 細菌入口**；🆕 **足部毛髮消失 → PVD**。
- **骨突**：負重時異常剪力 → 易潰瘍。
- 🆕 **神經病變線索**：
  - **乾皮、肥厚甲癬 → autonomic vasomotor neuropathy**。
  - **爪趾、槌狀趾 → motor neuropathy**。
- **DP、PT 脈搏**。
- ✅ **Semmes-Weinstein 5.07（10 g）monofilament**：失去保護性感覺 = 潰瘍與感染的主要危險因子。

### 3.2 血管評估 🔄

- 先摸足部脈搏：🆕 **可摸到＋無跛行 → 大血管病 NPV 96%**。
- 脈搏異常 → 非侵入性檢查：**ABI、toe pressure**。
- **ABI = 踝收縮壓（Doppler）÷ 肱動脈壓**：
  - ✅ **DM 病人因血管鈣化與不可壓縮而不可靠**；且**只反映大血管，不反映微血管組織灌流**。
  - 🆕 **ABI 0.5 = 糖尿病足傷口癒合的最低門檻**。
- 🆕 **Toe pressure 較可靠**：**約 15% 病人 ABI 假性 ≥1.0**；**hallux 趾動脈不會鈣化**。
- ❌ OKU 14 的「**TcPO2 >40 mmHg** 預測癒合」「**血管重建使主要截肢率降約 30%、5 年死亡近 50%**」本版未列。

### 3.3 影像 🆕

| 檢查 | 重點 |
|---|---|
| **WB X 光** | **通常足夠**；評估骨結構完整；🆕 **骨溶解（尤其蹠骨頭）可似骨髓炎 → 高度懷疑時骨切片確認**；🆕 **軟組織氣體常見，需配合臨床與實驗室** |
| **MRI** | 分 Charcot 結構變化 vs 感染；🆕 **與術中所見相比效用有限；骨變化＋軟組織徵象（潰瘍、膿瘍、直接竇道）同時存在時診斷骨髓炎最有效** |
| **CT** | 骨細節佳 → **Charcot 變形矯正規劃**；🆕 **無法準確區分正常與感染組織** |
| **骨掃描、WBC scan** | 🆕 **早期偵測感染與 Charcot 很敏感，但無法區分感染、stress reaction、Charcot**；對決策影響不超過病史、PE、X 光、實驗室 |
| 🆕 **FDG-PET、scintigraphy** | 🆕 **區分感染與神經病變；準確度提升，隨普及與價格下降可能成為金標準（2024）** |

### 3.4 實驗室 🔄

- **CBC with differential、ESR、CRP**。
- 🆕 **DM 病人常無法產生有效的白血球反應 → ESR 與 CRP 更有用**。
- 🆕 **ESR 在早期對骨髓炎特異性較高；ESR 明顯升高時，CRP 較能區分骨髓炎與軟組織感染**。
- 🆕 **骨髓炎最佳切點：ESR 60 mm/hr、CRP 7.9 mg/L**（OKU 14：ESR >70）。
- 🆕 **營養指標（非急迫手術前應優化）**：

| 指標 | 門檻 |
|---|---|
| 淋巴球 | **<1,500 cells/mL** |
| Albumin | **<3.5 g/dL**（OKU 14 寫 <3.0） |
| Zinc | **<5 mg/dL** |
| Transferrin | **<200 mg/dL** |

## 4. 糖尿病足潰瘍 🔄

### 4.1 成因與分類

- **最常見的糖尿病足併發症**；未治療 → 軟組織感染、壞疽、截肢。
- 多因子：**周邊神經病變、變形、血流差、免疫缺損、血糖控制差、反覆創傷**。
- ✅ **Wagner classification**：

| Grade | 定義 | 處置場所 |
|---|---|---|
| **0** | 無病灶 | 🆕 **門診** |
| **1** | 表淺潰瘍 | 🆕 **門診** |
| **2** | 深潰瘍 | 🆕 **門診** |
| **3** | 膿瘍或骨炎 | 🆕 **住院：手術清創＋靜脈抗生素** |
| **4** | 前足壞疽 | 🆕 **住院** |
| **5** | 全足壞疽 | 🆕 **住院** |

- 🆕 **Brodsky classification**：依潰瘍**深度與缺血**（depth-ischemia）。
- ❌ OKU 14 的 **SINBAD** 未列。

### 4.2 處置 🔄

- 原則：**仔細檢查、局部傷口照護、減壓**；**先處理活動性感染與血流不足**。
- 🆕 **銳性移除所有壞死皮膚與周圍厚的無血管胼胝**（細菌溫床）→ 促肉芽與上皮化。
- 🆕 **活動期潰瘍每週清創**維持健康傷口床。
- 減壓：foot orthoses、合適的鞋。
- ✅ **Total contact casting = 傳統減壓金標準**；但**需頻繁回診、技術難、併發症率仍高**。

### 4.3 預防性手術 🆕

- 🆕 **因 pedorthotic 進步而較少使用**（2022）。
- 🆕 **最常見：爪趾或槌狀趾矯正** → 作者偏好 **小趾 IP 關節 excisional arthroplasty＋K-wire 或埋入式可吸收 pin 暫時固定**。
- 🆕 **腓腸-比目魚延長**：**gastrocnemius 肌腱纖維釋放** 或 **經皮 Achilles triple hemisection**。
  - 🆕 **併發症：過度延長 → 跟部壓力過大 → calcaneal pressure ulcer**。

### 4.4 癒合與復發 🆕

- 🆕 **>3/4 一年內癒合**。
- 🆕 **復發常見：約 40% 癒合後一年內復發**。
- 🆕 **潰瘍最強預測因子 = 先前潰瘍史**（危險因子並未消失）→ **衛教**是治療與預防關鍵。

## 5. 感染 🔄

- 🆕 **很少由血行散播，多為直接接種**：骨突上皮膚機械性破損 → 細菌入口（無保護性感覺 → 異常剪力 → 表淺傷口與潰瘍）。
- 免疫缺損＋周邊循環差 → 易深部感染與膿瘍。
- 🆕 **表現：不適、血糖異常升高或胰島素需求增加；疼痛不可靠（無保護感覺）**。
- 檢查傷口：膿性、惡臭分泌物。
- 🆕 **所有病人都應做 probe-to-bone test**：探針碰到骨 → 深部感染可能性高。

---

## 6. 截肢 🔄

- 🆕 **應視為重建手術**：目標 = 維持功能獨立與行走潛能；但有**代謝代價**。
- **選最遠端、能形成功能性負重末端的層級**；考慮癒合能力與最佳功能。
- 🆕 **約 85% DM 下肢截肢由不癒合足部傷口引起**。
- 病態肥胖與截肢風險相關。
- 🆕 **一側截肢是對側截肢的強預測因子：3 年內 30% 接受對側截肢**。
- 層級：partial digital、digital、ray resection、transmetatarsal、Chopart、Syme、transtibial、through-knee、transfemoral。

## 7. Charcot neuroarthropathy 🔄

### 7.1 歷史與流行病學 🆕

- **與周邊神經病變相關的非感染性骨關節破壞**。
- 🆕 **1868 首述（梅毒 tabes dorsalis）；1936 描述 DM 神經性關節；1966 理解破壞過程**。
- 🆕 **發生率 0.3 per 1,000**；**DM 周邊神經病變已超越梅毒成為全球主因**。
- ❌ OKU 14 的「DM 病人盛行率約 0.56%」未列。

### 7.2 機轉 🆕

- 周邊神經病變影響**感覺（afferent）、運動（efferent）、自律神經（sympathetic）**。

| 理論 | 機轉 |
|---|---|
| 🆕 **Neurotraumatic** | **無感覺關節的反覆機械創傷＋持續完全負重 → 骨與關節機械性崩解**；持續負重抑制修復 → 本質上是 **hypertrophic nonunion** |
| 🆕 **Neurovascular** | 自律控制受損：初始創傷或誘因 → **過度反應的血管舒縮 autonomic neuropathy → 失調充血 → 骨吸收、韌帶弱化** → 持續負重下破壞 |

### 7.3 分類 ✅

- ✅ **Eichenholtz（時間病程）**：

| Stage | 名稱 | 臨床 | X 光 |
|---|---|---|---|
| **I** | **Fragmentation** | 急性發炎：**紅、熱、腫** | 骨溶解、碎裂 |
| **II** | **Coalescence** | 早期修復：水腫、熱、紅減少 | 新骨形成 |
| **III** | **Consolidation** | 新骨成熟 | **常留殘餘變形** |

- ✅ **Brodsky**、🆕 **Schon**：X 光解剖分類（廣為接受）。
- ❌ OKU 14 的「Brodsky Type 1（中足）最常見」「抬腳 5 分鐘退紅區分蜂窩性組織炎」「Stage I 禁內固定」本版未重述。

### 7.4 治療 🔄

- 目標：**改善生活品質、降低罹病率**；🆕 **疾病本身併發症率高**。
- 🆕 **現代手術適應症：非 plantigrade 足，且無法以護具或特製鞋容納**。
- 🆕 **成功定義：感染清除、傷口完全癒合、穩定 plantigrade 足 → 可穿市售 depth-inlay 鞋＋客製 orthoses 在社區安全行走**。
- 🆕 **任一術式正確執行，成功率約 90%**：
  - **Tension band plantar plate**。
  - **Charcot 專用 medial column plate**。
  - **Intramedullary beaming → superconstruct**。
  - **截骨矯正後以 static circular external fixator 維持**。
- ❌ OKU 14 的「術後 12–16 週非負重」未列。

## 8. 手術併發症 🆕

- 🆕 **DM 病人踝骨折手術：傷口延遲或裂開、感染、malunion、nonunion、Charcot**（2022）。
- 🆕 **16 萬踝骨折：DM 者住院較久、院內死亡率較高、術後院內併發症較多、非常規出院較多**。

## 10. Key Study Points（OKU 15）
