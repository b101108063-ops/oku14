## 0. High-yield 速覽

| 主題 | 考點 |
|---|---|
| 演進 | 適應症從 OA 與變形矯正 → **合併軟組織重建與軟骨修復的 offloading** |
| 對位 | **mechanical axis：股骨頭中心 → 距骨中心**，中立時通過膝中心；偏內 = varum、偏外 = valgum；anatomic axis 沿股骨與脛骨幹 |
| 正常角度 | **mLDFA 85–90°；mMPTA 85–90°** |

## 1. 解剖與對位

- 膝：遠端股骨、近端脛骨、髕骨；主要屈伸、次要旋轉。
- **Mechanical axis**：**股骨頭中心 → 距骨中心**，中立對位時**通過膝中心**。
  - **偏內 → genu varum；偏外 → genu valgum**（mechanical axis deviation, MAD）。
- **Anatomic axis**：沿股骨幹與脛骨幹中心。
- 最常討論：
  - **mLDFA（mechanical lateral distal femoral angle）正常 85–90°**。
  - **mMPTA（mechanical medial proximal tibial angle）正常 85–90°**。
- 其他：mLPFA、mLDTA、aLDFA、aMPTA、aPDFA、aPPTA、aADTA、NSA 等。
- 例：mLDFA 89°、mMPTA 81° → **主要為脛骨端變形**（varus）。

## 2. 評估與影像

### 2.1 病史與檢查

- **單純對位不良**：問先前**生長障礙**。
- 🔑 **兒童與青少年：骨骼成熟度大幅改變決策**；有疑慮 → **正式骨齡**。
- 症狀時間與型態；**區分痛 vs 不穩（或兩者）**——對位不良常是復發不穩的因子。
- 檢查：外觀是否明顯變形；**步態 thrust**；**完整 ROM（明顯關節攣縮 = 截骨禁忌）**；完整韌帶檢查（尤其主訴不穩）。

### 2.2 影像

- **最少：WB knee AP、lateral、patellar、30° 屈曲 PA＋WB long-leg AP alignment**。
- **懷疑矢狀變形或明顯前脛骨移位 → WB lateral long-leg 或 lateral full-length tibia**。
- 進階影像建議不明確：
  - MRI、CT：**韌帶傷、旋轉變形評估、軟組織問題**。
  - **PSI 技術 → 術前規劃常需 CT**。
  - EOS 可用於站立全下肢。

## 3. 非手術治療

- 慢性病況或**不適合截骨者（久坐、醫療狀況不佳、吸菸）** 優先保守。
- 休息、活動調整、抗發炎藥、注射、PT。
- **Unloader brace**：對抗變形施加機械應力（varus 膝 → **medial unloader**）。
  - **多篇報告含兩個 RCT：對柔軟（flexible）變形有正面結果**。
  - **可作為診斷工具，模擬截骨後可預期的症狀緩解**。
  - 缺點：**機械應力 → 耐受差**；**實際矯正量不清楚**；需正確合身。
- 保守（含護具）應在手術前嘗試。

## 4. 適應症與規劃

### 4.1 種類

| 截骨 | 型態 | 主要用途 |
|---|---|---|
| **HTO** | opening 或 closing | **varus**（多為近端脛骨變形） |
| **DFO** | opening 或 closing | **valgus**（多為遠端股骨變形） |
| **SRO**（slope-reducing） | closing（前方） | **矢狀：慢性 ACL 不足、高 PTS 的 ACLR 失敗** |
| **TTO** | **redirectional**（非 opening 亦非 closing） | **PF 不穩**、PF 軟骨修復 offloading |

### 4.2 三類適應症

1. **OA 或變形**（慢性變形、症狀性步態失衡）→ 目標：**止痛、改善關節運動學**。
2. **次要手術：offload 受影響腔室**（軟骨、半月板修復）。
3. **不穩**（SRO、TTO）。

### 4.3 原則

- **先判斷變形來自遠端股骨、近端脛骨或兩者 → 決定截骨位置**。
- 🔑 **不在變形處截骨 → 次發變形或改變 joint line obliquity（病人耐受差）**。
- **varus → HTO、valgus → DFO**（valgus 多源於股骨、varus 多源於脛骨）；但**冠狀異常常為多處（2024）**。
- 🔑 **股骨與脛骨都有變形，及／或變形大（>10°）→ dual-level osteotomy**，避免 joint line obliquity 增加（**為截骨結果的負面預測因子**）。

### 4.4 病人選擇

| | 條件 |
|---|---|
| **適應症** | **活躍、健康、生理年輕；BMI <30 kg/m²；單腔室病變；能遵守術後限制** |
| **絕對禁忌** | **多腔室退化、關節半脫位、ROM 受限（>10° 屈曲攣縮及／或 <90° 屈曲）、發炎性關節病** |
| **相對禁忌** | **>60 歲、骨量減少或骨鬆、opening wedge 時抽菸** |

### 4.5 Opening vs closing wedge

| | Opening wedge | Closing wedge |
|---|---|---|
| 技術 | **較簡單（常用）** | 較難 |
| 穩定 | **本質上較不穩** | 骨面立即接觸 |
| 風險 | **撐開時 hinge fracture**；**大矯正易 delayed union** | **神經血管傷風險較高**；**外側 closing HTO 需腓骨截骨** |
| 癒合與負重 | 較慢 | **促進癒合、可能較早負重** |

- 規劃正確時兩者矯正量相似。

### 4.6 矯正角計算（冠狀）

1. **股骨頭中心 → 脛骨平台上欲矯正到的點** 畫線。
2. **脛骨 plafond（踝）中心 → 同一點** 畫線。
3. **180° − 兩線夾角 = 欲矯正角度**。

- **理想目標點無共識**：
  - 🔑 **傳統 varus 膝：略過矯到外側關節面 62%（Fujisawa point）**。
  - 部分報告主張**矯正到純中立**，避免對側腔室過載、較正常運動學。
  - 合併軟骨、半月板修復或韌帶重建時 → 個案決定。

### 4.7 SRO（slope-reducing osteotomy）

- 矯正矢狀不良，多用於**慢性 ACL 不足**與 **PTS 過大的 ACLR 失敗**。
- 🔑 **適應症：ACLR 失敗、基線前脛骨移位（尤其 >5 mm）、PTS >12–13°，計畫矯正到 <4–8°**。
- 🔑 **可在 tibial tubercle 之上（supratubercular）、經過（transtubercular）或之下（infratubercular）** 截骨，皆安全，依醫師偏好。
- 見 [Ch.47]({{< relref "/oku15/chapter_47.md" >}})：anterior closing wedge SRO 降低 graft 受力。

### 4.8 TTO

- 主要用於 **PF 不穩**，次為 **PF 軟骨修復的 offloading**。
- PF 不穩多因脛骨結節相對滑車過度外偏 → **TT-TG**：
  - CT 或 MRI 軸位找滑車溝最深點，畫垂直於**後髁軸**的線，量到脛骨結節。
  - 🔑 **傳統正常 <20 mm**。
- 規劃比冠狀矯正簡單；**最常用 Fulkerson 式 AMZ**，切角 **45–60°**：
  - 🔑 **PF 不穩 → 45°（矢狀與冠狀 1:1）**。
  - 🔑 **軟骨修復 offloading → 較陡 60°（主要前移）**。
  - 🔑 **只需前移 → Maquet；只需內移 → Elmslie-Trillat**。
- 見 [Ch.51]({{< relref "/oku15/chapter_51.md" >}})。

## 5. 固定與植骨

- **plate、screw、bone staple**；DFO 與 HTO 多用 **plate-and-screw**（多種專利）。
- 🔑 **無一種專利鋼板設計明確較優**（依偏好）。
- 原則：**剛性固定、早期 ROM、骨癒合後早期負重**。
- **植骨**：證據不一；部分顯示 X 光癒合改善（主要 autograft）；🔑 **近期 RCT 與 meta：不減少併發症、不改善結果分數** → 個案、依醫師決定。

---

## 6. 結果與風險

### 6.1 結果

- **早期：併發症率 >40–50%**（殘痛、僵硬、感染、malunion／nonunion、骨折）；技術與固定進步後 → **可靠選項**。

| 手術 | 結果 |
|---|---|
| **DFO、HTO** | 🔑 **5 年存活 75–90%**；🔑 **2024 SR：HTO 10 年 75%**，PRO 持續改善 |
| 年輕活躍（常合併軟骨或軟組織手術） | 🔑 **RTS 60–80%**，疼痛改善 |
| **SRO**（高 PTS＋翻修韌帶重建） | 🔑 **再斷裂 4–8%**，功能持續改善 |
| **TTO**（PF 不穩與軟骨病變） | 🔑 **RTS 80–90%；臨床失敗 5–8%** |

### 6.2 併發症

- 🔑 **全因併發症 10–30%**：最常 **僵硬、表淺感染、需取內固定**。
- **Delayed union 不常見；多與 opening wedge 與抽菸相關**。
- 🔑 **TTO 後罕見腔室症候群**。
- **骨折**：術中（**hinge fracture**）與術後；🔑 **術後骨折 <5%**。

## 7. 合併手術

- 適應症已超越單純變形矯正 → 常與**韌帶重建、軟骨或半月板修復**並用。
- **ACLR（尤其翻修）＋SRO**：改善關節力學與 **graft 存活**；證據多為回溯與病例系列，失敗率低、PRO 改善。
- **軟骨修復＋截骨**：offload 腔室、提高 graft 存活；🔑 **>1,000 例大型回溯：合併截骨者再手術顯著減少**。

### 7.1 病例（書中）

- **39 歲女性，外側半月板切除 1 年後持續外側痛**；明顯 valgus。
- long-leg：**mLDFA 85.9°、mMPTA 91.7°**（股骨與脛骨都貢獻）→ 目標中立。
- 考慮單獨 lateral opening DFO vs **dual-level（lateral opening DFO＋medial closing HTO）** → 🔑 **選 dual-level 以減少 joint line obliquity 增加、分攤各截骨工作量**；以 PSI 執行。
- 術後 **toe-touch WB 6 週** → 漸進負重；3 個月固定穩定、癒合中；6 個月完全恢復，後續對側也接受截骨。

## 8. 新技術：PSI

- **CT 為基礎的客製導板** → 精準解剖矯正、**限制其他平面的醫源性次發變形**。
- **不需術中校正 → 手術時間與輻射暴露減少**；多篇證實安全有效。
- 🔑 **但近期 meta 與 RCT：PSI 安全準確，但結果與矯正準確度與傳統（徒手或非客製導板）無差**。
- **複雜多平面截骨、合併軟組織與軟骨手術時可能更有益**：可操控 **hinge axis**（例：**opening HTO 把 hinge 放在較前外側 → 同時調整冠狀與矢狀**）。
- 需更多研究（含成本效益）。

---

## 9. Key Study Points（OKU 15）

- 膝周截骨適應症、禁忌與技術考量廣泛。
- **解剖、病理與截骨原則**是成功關鍵。
- 截骨是**韌帶重建與半月板、軟骨修復的有用輔助**。
- **PSI 與術前規劃軟體越來越流行**，效用與成本效益需進一步研究。

## 10. Anki 候選題

1. Mechanical axis 的畫法？→ 股骨頭中心到距骨中心。
2. mLDFA 與 mMPTA 正常值？→ 皆 85–90°。
3. mLDFA 89°、mMPTA 81° 的變形來源？→ 脛骨（varus）。
4. 兒童截骨前必須確認？→ 骨骼成熟度（必要時骨齡）。
5. 截骨前 X 光最少需要？→ WB AP、lateral、patellar、30° 屈曲 PA、WB long-leg AP。
6. 懷疑矢狀變形時加照？→ WB lateral long-leg 或 full-length tibia。
7. Unloader brace 的兩個額外用途或特點？→ 兩個 RCT 支持柔軟變形；可模擬截骨效果。
8. Unloader brace 的缺點？→ 耐受差、矯正量不明、需正確合身。
9. 膝周四種截骨？→ DFO、HTO、TTO、SRO。
10. TTO 屬於 opening 或 closing？→ 皆非，屬 redirectional。
11. 截骨的三類適應症？→ OA 或變形、offloading、不穩。
12. 不在變形部位截骨的後果？→ 次發變形、joint line obliquity 改變（耐受差）。
13. Varus 與 valgus 典型的截骨選擇？→ HTO；DFO。
14. 何時考慮 dual-level osteotomy？→ 股骨與脛骨都變形及／或 >10°。
15. Joint line obliquity 與截骨結果的關係？→ 負面預測因子。
16. 截骨的 BMI 條件？→ <30 kg/m²。
17. 截骨的絕對禁忌？→ 多腔室退化、關節半脫位、>10° 屈曲攣縮或 <90° 屈曲、發炎性關節病。
18. 截骨的相對禁忌？→ >60 歲、骨鬆、opening wedge 時抽菸。
19. Opening wedge 的缺點？→ 較不穩、hinge fracture、大矯正 delayed union。
20. Closing wedge 的優缺點？→ 骨面接觸易癒合、可早負重；神經血管風險較高、外側 HTO 需腓骨截骨。
21. 冠狀矯正角計算？→ 180° 減去（股骨頭中心→目標點）與（踝中心→目標點）兩線夾角。
22. Fujisawa point？→ 外側關節面 62%。
23. SRO 的適應症？→ ACLR 失敗、前移 >5 mm、PTS >12–13°。
24. SRO 的矯正目標？→ PTS <4–8°。
25. SRO 相對脛骨結節的三種位置？→ supratubercular、transtubercular、infratubercular。
26. TT-TG 傳統正常值？→ <20 mm。
27. AMZ 用於 PF 不穩的切角與效果？→ 45°；1:1。
28. AMZ 用於 PF 軟骨 offloading 的切角？→ 60°（主要前移）。
29. 只前移與只內移的 TTO 名稱？→ Maquet；Elmslie-Trillat。
30. 截骨固定原則？→ 剛性、早期 ROM、癒合後早負重。
31. 截骨植骨的證據？→ RCT 與 meta 不減少併發症、不改善分數。
32. 早期膝周截骨併發症率？→ >40–50%。
33. 現代 DFO 與 HTO 5 年存活？HTO 10 年？→ 75–90%；75%。
34. 年輕活躍者截骨後 RTS？→ 60–80%。
35. SRO＋翻修 ACLR 的再斷裂率？→ 4–8%。
36. TTO 的 RTS 與臨床失敗？→ 80–90%；5–8%。
37. 膝周截骨全因併發症率與最常見者？→ 10–30%；僵硬、表淺感染、取內固定。
38. Delayed union 的危險因子？→ opening wedge、抽菸。
39. TTO 罕見但嚴重的併發症？→ 腔室症候群。
40. 術後骨折率？→ <5%。
41. 截骨合併軟骨修復的效果？→ 再手術顯著減少（>1,000 例）。
42. PSI 的優點？→ 精準、減少次發變形、減少時間與輻射。
43. PSI vs 傳統的結果？→ 結果與準確度無差；複雜多平面可能有益。
44. Opening HTO hinge 放前外側的作用？→ 同時調整冠狀與矢狀。
