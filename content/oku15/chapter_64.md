## 1. 流行病學與急診處置 🆕

### 1.1 流行病學

- 🆕 **2023 年美國創傷性 SCI 每年約 18,000 例**（Key Study Point）。
- 🆕 **無神經缺損的主要脊柱損傷約為有神經缺損者的 2 倍**。

### 1.2 初始處置（ATLS）🆕

- 疑脊柱或脊髓傷 → **backboard 固定運送**；急診由急診或創傷團隊決定上或拿掉頸圈。
- 🆕 **ABCDE**：

| 步驟 | 重點 |
|---|---|
| **A** | 確保氣道；現場可能已插管；呼吸衰竭或無法保護氣道 → 創傷室立即插管 |
| **B** | 評估呼吸；需要時呼吸器支持 |
| **C** | **出血性 vs 神經性休克**；🆕 **神經性休克 MAP 維持 85–90 mmHg** |
| **D、E（secondary survey）** | 粗動作、運動感覺；🆕 **log-roll 嚴格脊椎保護（脊柱中立、整體移動）**；觸診頸胸腰棘突（局部壓痛、間隙增寬）；擦傷、撕裂、**degloving（Morel-Lavallée）**；🆕 **直腸檢查：靜止與自主張力、輕觸與針刺** |

- 🆕 **Bulbocavernosus reflex**：若有 Foley → **輕拉應誘發**；🆕 **消失 = spinal shock → 無法評估 SCI 程度**；🆕 **通常傷後 48–72 小時恢復**。

### 1.3 影像 🆕

- 🆕 **CT = 2025 年美國創傷中心篩檢頸、胸、腰脊柱損傷的首選與建議**；許多中心另加**頸部 CTA**（blunt cerebrovascular injury）。
- 🆕 **MRI：應「刻意而非反射性」使用**：
  - 適用：**神經傷或狹窄**；**CT 未見骨折時的韌帶傷或骨髓水腫**。
  - 可見：**顱頸或後方韌帶穩定結構、隱匿骨折、骨髓水腫、椎間盤突出、脊髓挫傷或斷裂、根傷、硬膜外血腫**。
  - 細微異常可能使決策複雜化。
  - **重要序列：T2、STIR（對急性水腫特別敏感）**。
  - 🆕 **高能量胸腰傷前瞻研究：MRI 多找出 40% 隱匿傷、改變分型 24%、改變處置 16%**。
- 🆕 **負重 X 光**（便宜、易取得、有臨床價值）：
  - **神經完整、非明顯不穩、可負重** → 受傷區 AP＋lateral → 生理負荷下對位。
  - **上頸椎傷 → open-mouth odontoid view**。
  - 不能負重 → **upright** X 光。
  - 顯示不穩指標：**過度局部 kyphosis、脫位、滑脫、軸向塌陷**。
  - 模稜兩可的手術傷（如胸腰 burst）→ X 光或 MRI 依醫師與機構。
  - 即使明顯保守者，受傷時的負重片也是追蹤基線。
- 🆕 **急性創傷不建議常規 flexion-extension 片（保護性收縮會低估真正不穩）**。

### 1.4 頸椎 clearance 🆕

- 清醒者：通常由急診或創傷團隊處理。
- 🆕 **昏迷者：MRI 可協助決策，但角色仍有爭議**。
- 已驗證規則：**NEXUS、Canadian C-Spine Rules**。

## 2. 脊髓損傷（SCI）🆕

### 2.1 病理

- 🆕 **原發傷**：骨折碎片移位造成機械性傷害。
- 🆕 **二次傷（生物性）**：**出血、發炎、vasogenic 與 cytotoxic 水腫（持續數天）、缺血、凋亡、gliosis**。

### 2.2 分類 🆕

- 🆕 **bulbocavernosus 恢復後才能分 complete vs incomplete**：
  - **Complete**：損傷以下無運動與感覺。
  - **Incomplete**：保留部分功能。
- 頸椎 → quadriplegia；胸椎 → paraplegia（下半身運動、感覺、腸功能）。
- 🆕 **偏好用 complete／incomplete，而非過去的 tetraparesis／paraparesis**。
- 🆕 **Spinal shock**：bulbocavernosus 消失、全脊髓功能障礙 → 此期無法判斷嚴重度。
- 🆕 **ASIA 分級（恢復後）**：

| Grade | 定義 |
|---|---|
| **A** | **損傷以下無運動與感覺；無薦部神經保留** |
| **B** | **無運動；損傷以下有部分感覺** |
| **C** | **損傷以下過半主要肌群 <3 級（未達抗重力）** |
| **D** | **損傷以下過半主要肌群 ≥3 級（抗重力以上）** |
| **E** | **運動與感覺正常** |

### 2.3 神經性休克 🆕

- 🆕 **T5 以上 SCI → 心臟交感支配下降 → 迷走（CN X）張力無對抗 → 低血壓＋矛盾性心搏過緩**。
- 對比：**出血性休克 → 低血壓＋心搏過速**（代償）。
- 🆕 **Priapism**：男性完全 SCI，**薦部自律神經叢副交感無對抗**（交感喪失）→ **提示 complete SCI**。

### 2.4 不完全 SCI 症候群 🆕

| 症候群 | 機轉／位置 | 表現 |
|---|---|---|
| 🆕 **Central cord** | **最常見**；**頸椎狹窄＋過伸**（± 結構傷） | 皮質脊髓束**上肢 > 下肢**；手部燒灼性 dysesthesia；恢復時間與程度不一；**手術時機與標準仍爭議** |
| 🆕 **Anterior cord** | 前脊髓傷 | **損傷以下運動與痛覺喪失；dorsal column（深觸、本體、震動）保留** |
| 🆕 **Posterior cord** | **罕見，多為血管傷** | **本體感覺、深觸、震動喪失；運動與痛覺保留** |
| 🆕 **Brown-Séquard** | 半側脊髓傷 | **同側運動與本體感覺喪失；對側痛溫喪失** |
| 🆕 **Conus medullaris** | **T12–L1** | **大小便功能障礙＋不同程度下肢運動感覺** |
| 🆕 **Cauda equina** | 腰薦椎內**根層級（周邊神經）** | **大小便、saddle anesthesia、不同程度下肢** |

## 3. 上頸椎損傷 🆕

### 3.1 枕髁骨折（Anderson-Montesano）

| Type | 定義 | 處置 |
|---|---|---|
| **I** | **粉碎、無移位** | 多穩定 → **硬式護具** |
| **II** | **顱底骨折延伸至枕髁** | 多穩定 → **硬式護具** |
| **III** | 撕脫（OCR 截斷） | 🆕 **可能伴 CCD** |

- 🆕 **雙側枕髁骨折也提示 CCD**；🆕 **確診 CCD＋枕髁骨折 → 手術穩定**。

### 3.2 Craniocervical dissociation（CCD）🆕

- 高能量（車禍）；**顱頸交界韌帶斷裂、死亡率高**；辨識增加改善存活，但**常漏診**。
- 🆕 **Harris rule of 12（CT）：basion–dens interval，以及 basion 到「後齒突切線」的垂直距離，都不應 >12 mm**。
- 影像：上頸椎**前軟組織腫脹**；**枕髁自 C1 半脫位**；MRI：**alar、apical ligament、tectorial membrane 斷裂**、枕髁–C1 關節水腫、後韌帶傷。
- 🆕 **處置**：
  - 先以**沙袋、膠帶、reverse Trendelenburg** 固定。
  - 🆕 **避免硬頸圈（對交界造成分離力）**。
  - CT 與 MRI 不確定 → **術中牽引測試**。
  - 🆕 **不穩 → 至少 occiput–C2 手術固定**。

### 3.3 C1（atlas）骨折 🆕

- 軸向負荷；**lateral mass 外擴或環斷裂**。
- 🆕 **真正 Jefferson fracture = 前弓＋後弓都骨折 → 多為「擴大椎管」、保留神經**。
- 🆕 **coronal CT 或 open-mouth 片 lateral mass spread >6.9 mm → 懷疑合併 TAL 傷與不穩** → **C1 ring osteosynthesis 或 C1–2 融合**。
- 🆕 **C1 lateral mass 矢狀裂 → cock-robin deformity（枕髁經骨折縫向下沉）→ 多手術（C1 ring ORIF 或融合）**。
- 🆕 **前環水平裂 → 與 CCD 相關**。

### 3.4 Atlantoaxial instability 🆕

- 外傷、發炎疾病、先天異常。
- 🆕 **單純外傷性 TAL 斷裂罕見；upright 影像 ADI >4 mm → 懷疑**。
- 🆕 **外傷性 → C1–2 融合**。

### 3.5 Odontoid 骨折 🆕

- **Anderson-D'Alonzo**：**I = alar ligament 撕脫；II = 齒突腰部；III = 延伸入 C2 椎體**。
- 🆕 **次分類（斜度影響手術決策）**：

| | Eysel-Roosen | Grauer |
|---|---|---|
| **IIA** | **橫向**（經腰部） | **無移位** |
| **IIB** | **前上 → 後下斜** | **前上 → 後下，或移位的橫向** |
| **IIC** | **前下 → 後上斜** | **前下 → 後上，或粉碎** |

- 🆕 **治療**：

| 類型 | 處置 |
|---|---|
| **年輕活躍、移位 type II** | **偏好手術** |
| 🆕 **IIA** | **頸圈** |
| 🆕 **IIB** | **anterior odontoid screw（lag 壓縮骨折）** |
| 🆕 **IIC** | **posterior C1–2 融合** |
| 🆕 年輕、不能前螺釘、又想避免融合 | **暫時後方內固定，之後取出** |
| 🆕 **Type III** | **兩寬大鬆質面、低應變 → 癒合潛力佳 → 穩定無移位可外固定** |

- 🆕 **anterior odontoid screw 理想病人：非桶狀胸、骨質佳、非老年**；🆕 **上頸前方解剖與器械增加術後吞嚥困難，老年耐受差**。
- type II 治療仍有爭議（缺乏 RCT、回溯選擇偏誤）。

### 3.6 C2 traumatic spondylolisthesis（Hangman）🔄

- **Effendi-Levine 分類**：依移位與成角（I、II、🆕 **IIa：明顯成角無平移**、III）。
- **Type I → 可保守**；🆕 **較嚴重（IIa、III）→ 多需手術**；**神經受損或不穩 → 復位＋融合**。
- 🆕 **Atypical hangman fracture**：骨折經 **C2 後方椎體**，後方元素經**完整 pars 或 pedicle 仍相連** → 🆕 **神經傷風險較高 → 需手術**。

## 4. 下頸椎損傷（C3–C7）🔄

### 4.1 分類 🔄

- 🆕 **Allen-Ferguson（機轉分類，六類）**：flexion-compression、vertical compression、flexion-distraction、extension-compression、extension-distraction、lateral flexion。
  - 強調機轉 → 可提示固定策略；🆕 **但觀察者一致性低**。
- ✅ **AO Subaxial Cervical Spine Injury Classification**：以**形態**為主，一致性較好。
  - **A 壓縮、B 牽張（前或後張力帶失效）、C 平移、F facet 修飾**，另有神經修飾。

### 4.2 AO 各型處置 🆕

| 型 | 定義 | 處置 |
|---|---|---|
| **A0** | **非結構性**（棘突、橫突、單純椎板骨折） | **硬式護具**；🆕 **橫突骨折延伸入椎動脈入口層級的 foramen transversarium → 查腦血管傷** |
| **A1** | 單終板壓縮 | **硬式護具** |
| 🆕 **A2** | **coronal split（pincer）** | **監測 kyphotic 塌陷；進展則手術** |
| **A3** | 單終板 burst（後壁受累） | **神經完整且無明顯 kyphosis → 護具；神經傷或 kyphosis 過大 → corpectomy** |
| **A4** | 雙終板 burst | 同 A3 |
| 🆕 **B1** | **純骨性屈曲失效**（後張力帶） | 可保守密切追蹤；**多建議手術** |
| 🆕 **B2** | **後方囊韌帶斷裂（如 flexion teardrop）** | **手術** |
| 🆕 **B3** | **extension-distraction**（常為 spondylotic 或 ankylotic） | **非強直脊椎椎間盤層級伸展傷 → 硬式護具監測；強直脊椎不穩 → 手術**；🆕 **高度伴 SCI** |
| **C** | **平移（任何方向）** | **手術** |

### 4.3 Facet 修飾 🆕

| F | 定義 | 處置 |
|---|---|---|
| 🆕 **F1** | **小的單側 facet 骨折（<40% lateral mass、<1 cm 高）** | **通常硬式護具**；🆕 **大小與穩定性不確定 → 看 upright 側面片是否滑脫；有滑脫 → 手術**；神經缺損多為根層級，**外傷性根病變可觀察恢復，明顯根病變 → 手術** |
| 🆕 **F2** | **較大（>40% lateral mass 或 >1 cm）** | 同 F1，但**較可能不穩 → 不穩者手術** |
| 🆕 **F3** | **floating lateral mass（同一節的 pedicle＋lamina 骨折）** | 🆕 **骨折 pedicle 上下兩個椎間盤層級融合（兩節）** |
| **F4** | **半脫位或脫位（單或雙側）** | 見下 |

### 4.4 Facet 脫位：閉鎖復位 🆕

- **嚴重不穩、常伴神經缺損 → 緊急復位**。
- 🆕 **清醒、可配合 → 急診或手術室緊急閉鎖復位**：
  1. **Gardner-Wells tongs**。
  2. 🆕 **小劑量 benzodiazepine**：放鬆肌肉利復位，但病人須**清醒到能回答問題並配合檢查**。
  3. 重現變形（**頸屈曲**）＋牽引及／或旋轉 → 最後**伸直**；或繩上**每次加 5 或 10 lb**。
  4. **每次操作或加重後都重新檢查神經**。
  5. 🆕 **reverse Trendelenburg → 身體當反牽引**；或助手以腕帶或床單反牽引。
  6. 復位後頸保持**伸直**。
- 🆕 **昏迷或無法配合 → 任何復位前先做頸椎 MRI（排除大椎間盤突出）**；若計畫前方 ACDF，可省略術前 MRI。
- 🆕 **絕對不可：不做 MRI 就直接進手術室做純後方開放復位（可能把椎間盤拖入椎管）**。
- 🆕 **手術**：**單側 → 依個案；雙側 → 前方及／或後方固定（不穩）**。
- 🆕 **facet 脫位＋同節終板骨折 → 單節 ACDF 失敗率高 → 考慮前後合併或純後方**。

## 5. 胸腰椎損傷 🔄

### 5.1 分類 🔄

- 由**僵硬胸椎 → 活動腰椎**的轉換主導受傷型態。

#### Denis 三柱 ✅

| 柱 | 組成 |
|---|---|
| **前** | 椎體前 2/3、前 anulus、**ALL** |
| **中** | 椎體後 1/3、後 anulus、**PLL** |
| **後** | pedicle、facet、lamina、棘突、**PLC** |

- **壓縮骨折 = 單柱傷**；**burst = 前＋中柱（軸向負荷）**；三柱傷 → 屈曲或伸展力矩或另加平移。

#### TLICS（2005）✅

- ✅ **首個納入神經狀態的系統**。

| 項目 | 給分 |
|---|---|
| **形態** | **壓縮 1、burst 2、平移或旋轉 3、牽張 4** |
| **神經** | **完整 0、根傷 2、完全脊髓傷 2、不完全脊髓傷 3、cauda equina 3** |
| **PLC** | **完整 0、不確定 2、斷裂 3** |
| **總分** | ✅ **≤3 保守；≥5 手術；4 不確定**（看局部 kyphosis、能否活動、疼痛） |

- 🆕 **TLICS 的挑戰：PLC 斷裂定義的觀察者間不一致；不確定傷的頻率高**。

#### AO Spine Thoracolumbar（2013）✅

- **A0–A4**（非結構、壓縮、pincer、不完全 burst、完全 burst）、**B1**（**經骨張力帶斷裂 = Chance**）、**B2**（後張力帶骨性或韌帶失效＋A 型骨折）、**B3**（**伸展牽張，前張力帶失效，常強直脊椎**）、**C**（平移）。
- **神經修飾**：**N0 無；N1 已恢復的短暫缺損；N2 根病變；N3 不完全 SCI 或 CES；N4 完全 SCI；NX 無法評估**。
- 🆕 **M1：影像上不確定的張力帶傷**（無 MRI 時用，可能需 MRI 決定是否手術）；**M2：病人特定共病（如 AS、受傷區嚴重燒傷）**。

### 5.2 各型處置 🆕

| 型 | 處置 |
|---|---|
| **A 型** | **神經完整 → 保守為主**；有神經缺損 → 手術 |
| 🆕 **A2 pincer** | **密切監測進行性 kyphosis** |
| 🆕 **A3／A4 於 TL junction（約 T10–L2）與低腰（L4、L5）且明顯創傷後 kyphosis** | **耐受差 → 可能受益於手術** |
| 🆕 **B1（真正 Chance）** | 🆕 **旋轉軸在 ALL 前方 → 整個骨折為張力失效**；**年輕、骨癒合佳者可石膏**，但多偏好手術 |
| 🆕 **B2** | **通常建議手術（尤其 TL junction）**；🆕 **上胸椎若肋骨與胸骨完整、kyphosis 不進展 → 可密切追蹤保守** |
| 🆕 **B3** | **多不穩、常伴強直脊椎 → 手術**；🆕 **長力臂 → 延長固定（如骨折上下各三節 pedicle screws）** |
| 🆕 **C** | **高度不穩：幾乎都需手術，即使神經完全損傷** |

### 5.3 特殊考量 🆕

- 🆕 **TL junction（T10–L2）**：移行區 → **較易 kyphosis**。
- 🆕 **低腰（L3–L5）**：
  - **融合犧牲關鍵活動**，但有時為防 kyphosis、維持矢狀平衡所需。
  - 因融合罹病率 → **可考慮保守**；但 **kyphotic 塌陷 → 正矢狀失衡、功能障礙**。
  - 🆕 **需穩定時可考慮「固定但不融合」**（癒合期提供穩定）。
- 🆕 **強直脊椎（AS、DISH）**：
  - **上下皆僵硬 → 高度不穩**。
  - 🆕 **術前固定採「舒適姿勢」——通常是 kyphosis（其強直時的姿勢）**；背或頸後可能需墊高維持 kyphosis，**尤其做進階影像時**。

## 6. 未來方向 🆕

- 🆕 **經皮固定（胸腰椎）**：
  - 優點：**失血較少（但輸血率差異的臨床意義有爭議）**、**手術時間可能較短**。
  - 🆕 **適應**：
    - **低腰**：活動保留比 TL junction 更重要。
    - **AO B1**：特別適合**經皮固定不融合** → 器械當 **internal brace**，骨對骨癒合後**取出或任其疲乏**。
    - **AO B3（強直脊椎伸展骨折）**：骨形成旺盛 → 以骨折癒合為目標。
- 🆕 **構造長度**：
  - **短節段 = 骨折上下各一節；傳統長節段 = 上下各二節**。
  - 🆕 **生物力學：短節段納入骨折節（index level screws）可增加構造剛性**。
  - 🆕 **43 例回溯：短節段可行，但 BMI >30 → kyphosis 矯正流失風險 OR 3.2**。
- 🆕 **SCI 神經復健研究**：**brain-spine interface、分子治療、細胞治療、epidural electrical stimulation**。

## 8. Key Study Points（OKU 15）

- **2023 年美國創傷性 SCI 每年約 18,000 例**。
- 疑脊柱或脊髓傷的初始處置**遵循 ATLS**。
- 不完全脊髓與根傷症候群：**central cord、anterior cord、posterior cord、Brown-Séquard、conus medullaris、cauda equina**。
- **ASIA** 分級由 **A（運動感覺完全喪失）到 E（正常）**。
- 脊柱損傷依解剖位置分：**上頸椎、下頸椎、胸腰椎**。
