## 1. 總論 🆕

### 1.1 歷史

- 早期擔心肘空間太小、神經血管太近；**1971 年小型器械**改善活動與視野 → 80 年代中期技術與適應症逐漸成熟。
- 🆕 **18 年回顧：輕微併發症 11%**（表淺傷口感染、暫時神經麻痺、持續滲液）；隨解剖理解與經驗增加，併發症持續下降。

### 1.2 病史與鑑別診斷

- 問：發病、病程、急慢性、位置、疼痛時機、神經症狀、**機械症狀（卡住、彈響）**。

| 位置 | 鑑別 |
|---|---|
| **內側** | 尺神經、flexor-pronator 肌腱炎或撕裂、**lacertus syndrome**、UCL；未成熟者 → **內上髁 apophysitis 或撕脫** |
| **前方** | 二頭肌腱炎或斷裂、brachialis 傷、前關節囊傷 |
| **外側** | radiocapitellar 疾病（OCD、游離體、plica），**最常見 = 外上髁炎** |
| **後方** | 三頭肌腱傷或 apophysitis、olecranon stress fracture、VEO 骨刺、olecranon bursitis、後方撞擊、游離體 |

### 1.3 檢查與影像

- **雙側比較**（排除個人解剖變異）；視診（舊切口）、ROM（屈伸、旋前旋後）、觸診、肌力、神經血管；**要檢查肩與頸椎**（轉移痛）。
- 🆕 **尺神經位置與穩定度是關鍵：神經不穩或曾轉位 → 關節鏡時神經傷風險增加**。
- 🆕 **X 光五張：AP、lateral、internal rotation、external rotation、axial**（stress reaction、骨病灶、關節炎、游離體）。
- X 光找不到原因 → **MRA** 提高診斷準確度；MRI 看骨壞死、radius 或 capitellum 骨軟骨病灶、軟骨、UCL、上髁炎、二頭肌與三頭肌附著。

### 1.4 適應症

- **游離體移除、radius 或 capitellum 骨軟骨病灶清創、OA 清創、滑膜切除、感染 I&D、攣縮軟組織鬆解**。
- 🆕 **北美最常見適應症 = 游離體；亞洲 = OCD**。

### 1.5 擺位

| 擺位 | 優點 | 缺點 |
|---|---|---|
| **仰臥**（手臂橫過胸、懸吊或自持 positioner） | 麻醉與團隊最好處理；**需要轉開放時直接放到手桌，不必重新消毒** | **後區較難進入** |
| **側躺**（前後 bolster 或 bean bag、手臂放墊高 arm board） | 方便操作肢體；**麻醉仍可碰到呼吸道** | 擺位較費工 |
| **俯臥**（翻到胸兩側 bolster；**肩外展 90°＋最大內旋**，手臂垂在 arm holder） | 關節鏡視角與側躺相同 | **最麻煩：必須插管、術中幾乎碰不到呼吸道** |

## 2. Portal 與神經血管（Table 1）🆕

### 2.1 建立順序

1. 🆕 **先從 lateral soft spot 用 spinal needle 打約 30 mL 生理食鹽水**：方便 trocar 進入，**把神經血管推離關節**。
2. **第一個 portal：近端或遠端 anterolateral**（看 radial head、內側、coronoid、trochlea、brachialis 附著、coronoid fossa）；**nick-and-spread** 保護**橈神經或 PIN**。
3. 由 anterolateral 看，**直視下建立 medial portal**（前區游離體、攣縮、瀰漫滑膜炎、需進內側溝）。
4. **Direct lateral（soft spot）**：常用 **2.7 mm 鏡**；直接看 capitellum、radial head、olecranon → capitellar OCD 與 radial head 病變。**遠端約 1.5 cm 的 accessory lateral portal** 可作工作通道，也能進後區。
5. 由此直視建立 **posterolateral**，肘稍伸直再建 **direct posterior**（工作通道）→ 常用於**切 olecranon 骨刺、取游離體**；有傷 **PABCN、medial brachial cutaneous nerve、尺神經**的風險。

### 2.2 Portal 表

| Portal | 定位 | 危險神經與距離（屈曲／伸直） |
|---|---|---|
| **Proximal anterolateral（PAL）** | 外上髁**近端 1–2 cm、前方 1 cm** | **橈神經 34／36 mm** |
| **Distal anterolateral（DAL）** | 外上髁**遠端 1–3 cm、前方 1 cm** | **PIN 28 mm**（兩姿勢）；**LABCN 39／38 mm** |
| **Direct lateral（soft spot）** | **olecranon、radial head、外上髁三角**中央 | **LABCN 21 mm**；**整體相對安全** |
| **Anteromedial** | 內上髁**前方 2 cm、遠端 2 cm** | **MABCN 約 5 mm**；**尺神經（若曾轉位）** |
| **Proximal anteromedial（PAM）** | 內上髁**近端 2 cm、肌間隔前方** | **尺神經約 13 mm**；**MABCN 約 5 mm** |
| **Posterior（direct posterior）** | olecranon **近端 3 cm、中線穿 triceps** | **尺神經約 20 mm**；**PABCN 33／30 mm**；需肘稍伸直 |
| **Posterolateral** | olecranon **近端 2–3 cm、triceps 外側** | **PABCN 14／13 mm**；medial brachial cutaneous nerve；**橈神經 34／36 mm** |

- 💡 記法：**外側近端 → 橈神經；外側遠端 → PIN；內側 → MABCN（最近，約 5 mm）與尺神經；後方 → PABCN 與尺神經**。PAL 比 DAL 安全（34 vs 28 mm）。

### 2.3 併發症

- 🆕 **最常見 = 術後僵硬**，偶爾需再手術改善 ROM。
- **Neurapraxia 也常見，最常傷尺神經**；通常暫時性，術前要告知。
- Key Study Points：**建立 portal 時的神經血管傷是最常見併發症**（與內文「最常見 = 僵硬」並存，題目以出處為準）。

## 3. Capitellar OCD 與軟骨病灶 🆕

### 3.1 病因與流行病學

- **OCD = 一部分軟骨下骨與其上軟骨因缺血而部分或完全與骨床分離**；🆕 **定義上一定有軟骨下骨壞死**，要和單純局部軟骨缺損區分。
- 病因理論：基因、急性或反覆微創傷、血管阻塞、骨化缺陷無法癒合。
- 好發**凸面負重關節**（股骨頭、股骨髁、距骨頂、遠端脛骨）；**凸面非負重的肱骨頭與 capitellum 在過頭投擲者也會發生**。**肘最常見位置 = capitellum**（radiocapitellar 力傳導大）。
- 過頭投擲或體操的**慣用手**、**10–20 歲**。
- 🆕 **男性顯著居多，男女比 42:4**。
- 生物力學：valgus torque 增加 radiocapitellar 接觸壓力。
- 🆕 **55% 的肘 OCD 病人最終進展到需要手術**。

### 3.2 表現

- 疼痛、ROM 下降、積液、機械症狀（卡、彈、鎖、crepitus）；**外側最常見**。
- 🆕 **典型病人：男性過頭運動員（慣用手）或女性體操選手（常為非慣用手）**。

### 3.3 影像

- X 光：AP、lateral、IR、ER、axial；🔄 加 **屈肘 45° AP**。
- 🆕 **X 光敏感度低：約 50% capitellar OCD 的 X 光正常**。
- **MRI**：早期病灶、大小、碎片穩定度。🆕 **加 gadolinium 做 MRA 不會提高 OCD 診斷準確度**。

| | MRI | CT |
|---|---|---|
| **OCD 敏感度** | **96%** | **100%** |
| **游離體敏感度** | **65%** | **90%** |

- 🆕 **2022（28 例）：CT 找到 89 個次發變化，術前 MRI 只找到其中 51 個（57%）** → CT 對碎裂與晚期次發變化較敏感 → **許多醫師以 CT 作為術前首選高階影像**。
- 🔄 對照：Ch.31 寫「MRI 對早期較敏感」、Ch.33 寫「MRI 或 CT」；本章強調**術前規劃 CT 較好**。

### 3.4 分類 🆕

| 系統 | 依據 | 分級 |
|---|---|---|
| **1979** | X 光 | **1：capitellum 透亮囊狀影（穩定）**；**2：病灶與軟骨下骨之間有清楚分界帶**；**3：脫離、關節內游離體** |
| **Timmerman-Andrews Elbow Score（1994）** | 主觀（痛、卡鎖、腫、活動量）＋客觀（屈曲攣縮、旋轉弧、總屈伸弧） | **20–200 分**；**優 180–200、好 160–179、可 120–159、差 <120**（最常用；原為創傷後痛與僵硬設計） |
| **1998 關節鏡** | 術中 | **1：平滑但軟、可 ballot**；**2：纖維化或裂隙**；**3：露骨、碎片固定**；**4：鬆動但未移位**；**5：移位＋游離體** |
| **ICRS（2003）** | 術中 | **1：穩定、連續但變軟**；**2：部分不連續、探針下穩定**；**3：完全不連續但未脫位**；**4：空洞或碎片脫位或在床內鬆動** |
| **2014 MRI** | MRI | **1：形狀正常、多處訊號高但低於軟骨**；**2：加上高於軟骨的訊號**；**3：軟骨面不連續、不圓，但病灶與底部之間無高訊號界面**；**4：病灶被高訊號線分開**；**5：病灶自底部移位或缺損** |

### 3.5 保守治療

- **骨骼未成熟＋穩定病灶的主要治療**：停止活動、加強周圍肌力、有時短暫固定。
- 🆕 **未成熟者 stage 1–2 保守癒合率 50–90%**；**不穩定或骨骼成熟 → 癒合潛力明顯下降**。
- 🔄 **同時符合三條件的病人，休息即可完全恢復並回到原等級**：**capitellar physis 未閉、軟骨下骨局部變平或透亮、ROM 良好**。

### 3.6 手術

- 保守失敗或一開始就不穩 → **關節鏡**；多數先做**關節鏡清創**，部分加 **microfracture**（以纖維軟骨填補）。
- 大或 uncontained、不適合清創＋骨髓刺激 → **開放骨軟骨移植（autograft 或 allograft）**。
- 急性或亞急性不穩病灶 → 可嘗試**復位固定**（生物可吸收、加壓螺絲等）。

**① 清創＋骨髓刺激**（小病灶的**金標準**）
- **Direct lateral soft spot portal 看**、**遠端約 1 cm accessory lateral portal 做**（2022）。
- 術後軟敷料＋sling。復健：

| 期別 | 週數 | 內容 |
|---|---|---|
| 1 | **0–6 週** | 恢復正常 ROM、止痛、讓軟骨癒合 |
| 2 中度保護 | **7–12 週** | 二頭肌與三頭肌輕阻力；投手加入 **Thrower's Ten Program** |
| 3 最小保護 | **13–20 週** | 可加入跑步 |
| 4 | **21–26 週** | plyometrics |
| 5 | **≥26 週** | return-to-play 投球計畫（**投手可能再 4 個月**）；可恢復伏地挺身、臥推 |

- 🆕 **4–6 個月前不可過度負荷**（保護癒合中的纖維軟骨）。
- 🆕 **投手術前要告知：手術到回場通常約 8–9 個月**。
- **結果**：
  - 🆕 **小病灶單純清創 RTS 85%**；**大病灶 RTS 明顯較低，且 75% 出現 OA 變化**。
  - 🆕 **系統性回顧：ROM 平均 +15.9°，Timmerman-Andrews 明顯改善，RTP 71%**。
  - 🆕 **2024 SR：81% 回到運動**。
  - 🆕 **6 年 X 光：capitellum 變平 67%、radiocapitellar 退化 33%、游離體 27%**。
  - 🆕 **長期（平均 7.2 年）：46% 日常活動會痛；大或 uncontained 病灶全部歸為差**；另一研究大病灶 **43% 日常輕度痛、61% X 光有 radiocapitellar 關節炎**。

**② 骨軟骨 autograft／allograft 移植**
- **大、uncontained** 病灶。
- Autograft：從供區（常為膝）取單一或多個骨軟骨柱；**allograft：無供區損傷，但缺乏自身的生物癒合能力**。
- 都經**開放 arthrotomy**；🆕 **capitellar OCD 常偏後 → 多數用 anconeus-splitting**：**lateral portal 上下各延長 1 cm**，**最大屈肘**看清病灶。
- Autograft：膝 **medial parapatellar arthrotomy，從 trochlea 取**。
- 🆕 **uncontained 且 <1 cm² → 單一 plug 通常足夠；較大 → mosaicplasty** 重建 capitellum 曲率。
- 🆕 **MRI 實驗：單一大 plug 最佳供區 = inferior medial trochlear ridge**（曲率與 capitellum 最吻合）。
- 🔄 Ch.33 的說法是「≤1 cm 單一 plug、取自股骨髁非負重區」，本章是「<1 cm²、trochlea」。
- **結果**：
  - 🆕 **少年棒球員 allograft（4 年）：MEPS 與 VAS 臨床意義改善，RTP 100%**。
  - 🆕 **Autograft 系列：回原等級 69%、回一般運動 100%；MRI 關節面一致性恢復 86%、graft 融合 93%**。
  - 🆕 **Meta：autograft 回原等級 94%、RTS 95%、平均 5.9 個月**。
  - （Ch.33 引用 2024 SR 454 位：RTS 97%）

## 4. Valgus extension overload 與後內側 olecranon 骨刺 🔄

### 4.1 機轉 🆕

- 🆕 **投球時內側張力最高 64 N·m、外側 radiocapitellar 壓迫最高 500 N**；🆕 **acceleration 期伸肘角速度約 5,000°/s**；**球放手時肘約 25° 屈曲**。
- Acceleration 期：軀幹旋轉、肩內旋、伸肘 → **valgus＋extension moment** → **內側張力、外側壓迫、後區剪力**。
- 後內側 olecranon 反覆撞 olecranon fossa → **骨刺** → **球放手時（投球週期末段）痛**。
- 🔄 Ch.33 寫「肘承受達 45 N·m」，本章為 64 N·m（不同研究）。

### 4.2 流行病學與表現

- 盛行率不明；**過頭投擲者慣用手最常見**；🆕 也見於**游泳、體操、球拍運動**。
- 🆕 **VEO 痛在 ball release 或 deceleration 期；UCL 傷痛在 late cocking 或 early acceleration**。
- 可能慣用手**失去終末伸直**。
- 檢查：後內側 olecranon 壓痛、伸直受限（2025）。
- 🆕 **Bounce test**：反覆強迫完全伸直（模擬放球或 deceleration）。🆕 **Arm bar test**：持續施伸肘力。**後內側痛再現 = 陽性**。

### 4.3 影像

- 五張 X 光常可清楚看到後內側骨刺，也可能看到游離體或 **UCL 鈣化**；**MRI 或 MRA 排除 stress reaction、軟骨缺損、韌帶傷**。

### 4.4 治療

- **保守為主**：停止所有投球、NSAIDs、類固醇注射、**肩與肘伸展**、**評估並改善投球動作**、**強化 flexor-pronator**。
- **手術**：保守失敗的活躍投手。
  - 術前確認骨刺大小與位置，**評估是否 UCL 不足**。
  - 🆕 **UCL 不足 = 切骨刺的相對禁忌**（會增加鬆弛、加重 UCL 負擔）。合併 UCL 不足時：可先關節鏡檢查再開放處理 UCL，或在 UCL repair／reconstruction 時一起開放切骨刺。
  - **單純後內側骨刺 → 關節鏡切除最常見**（俯臥、仰臥、側躺皆可）；**posterolateral portal 看、direct transtriceps portal 做**。
  - 🆕 **尺神經就在後內側 olecranon 淺層軟組織 → 用 burr 或 shaver 時最好關掉吸引**。
  - 🆕 **切多少有爭議**：有研究認為**可切到 3 mm 原生 olecranon**；也有研究認為**切任何原生 olecranon 都會讓 UCL 應變增加到不可接受**。共識：**激進切除增加 valgus 力與 UCL 應變 → 只切骨刺**。
  - 切完後可看肱骨軟骨的 **contrecoup 傷**；有軟骨病灶 → 清創＋取游離體。
- **結果**：
  - 🆕 **2022：>80% 回原等級**。
  - 🆕 **回溯：Timmerman-Andrews 明顯改善、97% 回原等級**。
  - **2023：77% 回到運動、分數好或優；但 18% 之後出現 UCL 不足需手術** → **最小切除**以兼顧回場與避免再手術。

## 5. Arthrofibrosis 🔄

- 病因：外傷、全身性發炎、**TBI**、長期固定、先天疾病。
- 🆕 **正常肘：屈伸總弧約 150°、旋前旋後 ≥160°**；**多數日常活動至少需要 100° 弧（30–130°）**（吃飯、洗澡、梳洗）。
- **影像**：X 光判斷是 malunion、HO、內固定或骨刺造成的機械阻擋，或單純軟組織攣縮；骨性異常 → **CT**；🆕 **MRI 在 arthrofibrosis 評估中角色很小**。
- **保守**（依病因）：
  - 創傷後：**static progressive splint**、治療、NSAIDs，或**放射治療預防 HO**。
  - 發炎性：**DMARDs**。
  - 🆕 **遺傳疾病（如 arthrogryposis）：肉毒桿菌注射處理軟組織攣縮**。
- **手術**：開放或關節鏡鬆解；關節鏡下以 ablation 或電燒鬆解攣縮關節囊。
- 🆕 **關節鏡攣縮鬆解：ROM 平均 +60°，92% 自評好或優**。
- **最常見併發症 = 神經傷與感染**；🆕 **輕度感覺變化 → 觀察；運動受累 → 減壓 ± 轉位**。
- 🔄 Ch.32 補充：關節鏡鬆解併發症約 5% vs 開放約 23%。

## 6. 其他適應症 🆕

- **OA**：🆕 **X 光上最佳關節鏡對象 = 有游離體但沒有明顯關節退化**。
- **游離體**：卡、鎖、ROM 下降；**關節鏡取出 = 金標準**。
- **滑膜炎**：**最常見於 RA**（全身性發炎疾病）；運動員可見 **radial head 與 capitellum 之間的 plica band** 反覆動作發炎。全身性疾病先用口服類固醇、NSAIDs、DMARDs；無效 → 關節鏡滑膜切除。

## 7. Key Study Points（OKU 15）

- 肘關節鏡技術近幾十年明顯進步 → **功能分數與滿意度提高**。
- **最常見適應症**：游離體移除、radius 或 capitellum 骨軟骨病灶清創、OA 清創、滑膜切除、感染 I&D、攣縮軟組織鬆解。
