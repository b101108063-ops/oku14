## 1. 髕骨骨折 🆕

- 🆕 **約 1% 兒童與青少年骨折**；較成人少（髕骨活動度大、軟骨對骨比例高）。
- 🆕 **3–5 歲開始骨化，約 12 歲成熟**。
- 型態：**transverse、comminuted、patellar sleeve avulsion（最多）**。
- 🆕 **撕脫部位與機轉**：

| 撕脫部位 | 機轉 |
|---|---|
| **內側** | **髕骨脫位** |
| **外側** | **vastus lateralis 反覆傷** |
| **上、下極** | **類似成人 quadriceps、patellar tendon 傷** |

- PE：大量積液、ROM 減少、常無法負重、🆕 **無法做或維持 straight leg raise**。
- 影像：膝 AP＋側位；🆕 **sleeve fracture vs Sinding-Larsen-Johansson**：sleeve 有急性外傷史、**髕前腫脹增加、關節積液、片移位較大、髕骨位置較高（2022）**；🆕 **慢性或不確定 → MRI 或超音波**。
- 🆕 **保守：伸肌機制完整且 X 光移位 <3 mm → 4–6 週不負重長腿固定**。
- 手術同成人：**ORIF（transosseous suture、cannulated screws、suture anchors、transosseous wiring）**；結果多極佳；最常見併發症：**內固定症狀、膝僵硬、殘餘痛**。

## 2. Tibial eminence 骨折 🆕

- 🆕 **年長兒童與青少年特有；ACL 撕脫內側 tibial spine**；🆕 **8–14 歲**。
- 機轉：高能量碰撞或**低能量非接觸外翻**。
- 外傷性膝積液（類 ACL 傷）；AP＋側位 X 光通常可診斷。
- 🆕 **Meyers and McKeever（Zaricznyj 修訂）**：

| Type | 定義 |
|---|---|
| **1** | **無移位** |
| **2a** | **前方抬起，後方鉸鏈完整** |
| **2b** | **鉸鏈完整但粉碎** |
| **3a** | **完全移位** |
| **3b** | **完全移位＋粉碎** |
| **4** | **完全移位且旋轉**（OCR 截斷） |

- CT：可看粉碎與型態，但需權衡輻射。
- 🆕 **MRI：約 45% 合併傷，其中 87% 需治療；最常見合併傷為外側半月板**。
- 🆕 **保守**：**無移位或 type II 可復位至 <5 mm → 石膏或 brace ≤20° 屈曲 4–6 週**。
  - 併發症：arthrofibrosis、不穩、malunion、impingement。
  - 🆕 **保守 vs 手術：症狀性不穩與不癒合較多，但 arthrofibrosis 較少**。
- 🆕 **手術：不可復位的 type II＋所有 type III → 開放或關節鏡復位固定**。
  - 🆕 **開放與關節鏡結果相當 → 選最熟練者**。
  - **螺釘或縫線**（依片大小與粉碎）。
  - 🆕 **術後膝 0–20° 屈曲固定 4–6 週 → ROM 計畫**。
- 🆕 **手術併發症**：不癒合、malunion（痛＋前方 impingement → 翻修）、殘餘鬆弛、arthrofibrosis。
  - 🆕 **殘餘鬆弛即使解剖復位也會出現 → 歸因於 ACL 本身的間質傷；但長期臨床結果不受影響**。
  - 🆕 **arthrofibrosis 最高 23%；危險因子：年幼、非運動傷、合併 ACL 傷、石膏固定**。

## 3. Tibial tubercle 骨折 🔄

- ✅ **最高佔近端脛骨骨折 2.7%**。
- 🆕 **危險因子：男性、肥胖、既往 Osgood-Schlatter（2024）**。
- 機轉：**跳躍時 patellar tendon 離心負荷**。
- PE：類似成人 patellar tendon 斷：大量積液、伸肌機制失能。
- 🔄 **腔室症候群**：傳統認為 anterior tibial recurrent artery 傷 → 風險高；🆕 **2024：只有約 1.35%**。
- 影像：AP＋側位，**patella alta**；🆕 **不確定 → 對側片、膝輕度內旋側位**；CT（關節內範圍、規劃）；MRI（patellar tendon、骨膜撕脫、無移位或年幼軟骨骨折）；🆕 **Ogden IV、V 尤其適合進階影像**（正式適應未定）。
- ✅ **Ogden 分類（Watson-Jones 修訂；Ryu-Debenham 增 type IV）**：

| Type | 定義 |
|---|---|
| **IA** | 遠端 tuberosity 骨折 |
| **IB** | 鉸鏈於前方近端 |
| **IIA** | 二次骨化中心與脛骨分離 |
| **IIB** | 粉碎 |
| **IIIA** | 延伸進關節面 |
| **IIIB** | 粉碎 |
| **IV** | 延伸至後方近端 physis |

- 🆕 **保守：無或輕移位、可閉鎖復位**；部分研究建議**鎮靜下或血腫抽吸＋局麻後復位** → **全伸直、加墊 LLC 4–6 週**，密追。
- 🆕 **手術適應**：**移位、閉鎖復位後仍 >2 mm、開放、神經受損、關節內**。
  - 可閉鎖復位 → **經皮光滑或無螺紋 wire、或 cannulated screws**。
  - 🆕 **生長潛力大 → 光滑 wire（減少生長障礙）**；🆕 **片夠大 → cannulated screws（較強）**。
  - 不能閉鎖 → ORIF。
  - 🆕 **技巧：膝全伸直下復位；避免雙皮質螺釘（神經血管傷）；準備以粗線修補撕裂的支持帶與骨膜**。
- 🆕 **術後固定 4–6 週；brace 結果優於石膏**；**6 週開始 ROM 與負重；約 12 週回到原活動**。
- 🆕 **結果**：

| 指標 | 數值 |
|---|---|
| **癒合** | **98%** |
| **恢復全 ROM** | **97%** |
| **回到運動** | **88%** |
| **大腿周徑持續減少** | **25%**（不影響股四頭肌力或 PRO） |
| **併發症** | **約 28%**：最常**內固定症狀、bursitis**；少見**再骨折、腿長差、genu recurvatum** |

## 4. 近端脛骨骨折 🆕

### 4.1 近端脛骨 physis 🆕

- 🆕 **約 1% physeal 傷**；與 tubercle 不同，多為**高能量（車禍、割草機）→ 固定膝的過伸或外展力**。
- 🆕 **popliteal artery 在 soleus 下方被拴在後脛 → 過伸使脛骨幹骺後移 → 血管傷**；🆕 **需重複血管檢查（可延遲出現）**。
- SH 分類；🆕 **不確定 → 對側片，或 7–10 天後重照看癒合**；CT 看關節、MRI 看隱匿或應力骨折。
- 🆕 **無移位 SH I、II → LLC 4–6 週；7–10 天重評延遲移位**。
- 手術：CRPP 或 ORIF（依可否閉鎖、關節受累、physis 生長潛力）。
- 🆕 **近端脛骨 physis 貢獻脛骨長度 55%、整肢長度 25%**。
- 🆕 **2 年生長停止 6.4%；危險因子：SH III、高能量、移位與複雜型態、外院治療（2023）**。

### 4.2 近端脛骨幹骺與 Cozen 🆕

- 🆕 **高能量 → 移位，可合併近端腓骨；注意 popliteal artery 與 common peroneal nerve**；處置同 physeal 傷。
- 🆕 **低能量：3–6 歲遊樂場或溜滑梯跌倒** → 痛、難負重；X 光**輕移位或 valgus 橫向近端幹骺骨折** → **LLC 4–6 週**。
- 🆕 **Cozen phenomenon：癒合後 valgus 增加**：
  - **最高 14%**；**1 年內出現、可持續到 2 年**。
  - 🆕 **多篇自然史：多數自行改善，不需 brace 或手術** → 事先告知家長。

## 5. 脛骨幹骨折 🔄

### 5.1 Toddler fracture 🔄

- 🔄 🆕 **9 個月–3 歲、會走路；單純、無移位的螺旋脛骨幹骨折（2022）**（OKU 14：9 個月–6 歲、斜行遠端 1/3）。
- 旋轉力（跌倒或扭轉）。
- 初次 X 光常看不到；**3–4 週後可見 callus** → 隱匿者多為臨床診斷：**壓痛、踝蹠屈痛、負重痛**。
- 🆕 **移位最多 2 mm 仍本質穩定（軟組織厚、骨膜完整）→ 快速癒合、極少併發症**。
- 🆕 **過度治療與固定併發症受到關注**；傳統：**LLC、SLC 或骨折 boot＋早期負重 3–4 週**。
- 🆕 **2022 RCT（1–3 歲 44 人）：不固定組（30 人）在 4、8 週結果極佳，功能與石膏組幾乎相同 → 建議只觀察，避免回診與皮膚等石膏併發症**。

### 5.2 兒童與青少年脛骨幹骨折 ✅

- ✅ **約 15% 小兒長骨骨折**；🆕 **30% 合併同側腓骨骨折**。
- 機轉：**年幼：足固定的扭轉；青少年：高能量**。
- 🆕 **遠端同時有踝骨折約 4.3%**；🆕 **回溯：37% 有先前漏診的同側遠端 physeal 骨折**。
- 初始多試保守：**LLC（膝上控旋轉）＋冠狀面塑形**。
- ✅ **變形方向**：

| 腓骨 | 預期變形 |
|---|---|
| **完整** | **varus**（外側韌帶與肌肉附著） |
| **也骨折** | **valgus** |

- ✅ **閉鎖復位容許度（以 8 歲為界）**：

| | <8 歲 | >8 歲 |
|---|---|---|
| **Varus** | **≤10°** | **≤5°** |
| **Valgus** | **≤5°** | **≤5°** |
| **Procurvatum** | **≤10°** | **≤5°** |
| **Recurvatum** | **≤5°** | **0°** |
| **旋轉** | 最少 | 最少 |
| **短縮** | **≤1 cm** | **5 mm** |
| **平移** | **50%（不論年齡）** | **50%** |

- 🆕 **患側脛骨過度生長 >1 cm 可能，尤其男性與彈性釘治療者**。
- 脛骨可延遲癒合；🆕 **依 callus 與軸向穩定可將 LLC 改為 SLC**。
- 🆕 **早期頻繁追蹤；流失 → wedging 有效，但避免矯正大角度（皮膚壓力 → 潰瘍）**。

### 5.3 腔室症候群 🔄

- 🆕 **小兒（初診、閉鎖復位後、手術後）用 3A：anxiety、agitation、analgesic requirement 增加**。
- 預防：**抬高、石膏 bivalve、避免強力環狀壓迫**。
- 🆕 **臨床或壓力監測確診 → 緊急四腔筋膜切開；及時診斷結果好**。

### 5.4 手術 🆕

- 🆕 **適應：開放、腔室症候群、floating knee、血管傷、保守失敗**。
- 🆕 **過去 <5% 脛骨幹骨折需手術；30 年來手術率穩定上升**。
- 🆕 **彈性釘**：
  - 不破壞 physis 的 IM 固定；🆕 **入點約距近端 physis 遠側 2 cm 的內、外側幹骺**；**對側預彎**使骨折處最大撐開。
  - 穩定或不穩型態皆可；**主控冠狀與矢狀面；旋轉控制較差 → 需要時加石膏**。
  - 🆕 **57% 影像癒合時殘餘角度 >5°**；🆕 **高風險（高能量、開放、腔室症候群）較易 malunion、需再介入**；🆕 **延遲癒合（>6 個月）最高 10%**。
  - 🆕 **2023：延遲癒合 6.2%、不癒合 2.7%**。
  - 🆕 **2024：閉鎖復位石膏 vs 彈性釘 → 活動與疼痛 PRO 無差**。
- 🆕 **Rigid IM nail**：
  - 傳統避免：**前方 physis 停止 → 近端脛骨 recurvatum**。
  - 已有保留 physis 技術與 physis 閉合分期研究；確切適應待研究。
  - 🆕 **目前建議：近端脛骨已骨骼成熟，且病人與骨折型態需要剛性 IM 固定**。

## 6. 踝骨折 🔄

### 6.1 轉換期踝骨折總論 🔄

- ✅ **小兒骨折頻率僅次於遠端橈骨**；運動、跌倒、扭轉。
- 🆕 **2022 流行病學（2 年 1,929 例 physeal 骨折）：下肢骨折 35% 為脛骨 physeal 骨折，其中 73.9% 在遠端脛骨**。
- 多數保守；🆕 **LLC vs SLC 依旋轉控制與能否維持復位；傳統轉換期骨折用 LLC，但 120 例回顧：SLC 流失率不高於歷史**。
- 🆕 **低能量內收或旋後、X 光無骨折線 → 懷疑遠端腓骨 physis SH I → SLC 或骨折 boot 約 3–4 週**。
- 🆕 **疑關節移位或 PE 與 X 光不一致 → 進階影像；X 光可能低估關節移位（2024）**。
- ✅ **同成人：關節 step-off >2 mm → 閉鎖或開放復位＋內固定**。
- 骨折沿較弱的 physis 傳遞、受軟組織附著影響 → 型態不同於成人旋轉傷；**Salter-Harris 或 Dias-Tachdjian（足位置＋受力方向）**。
- ✅ **遠端脛骨 physis 閉合順序：中央 → 前內 → 後內 → 外側（女約 14 歲、男約 16 歲）**。
- 🆕 **2023 mapping（83 例轉換期骨折）：triplane 多呈 Y 型，骨片對應遠端脛腓韌帶附著 → 挑戰「型態由 physis 閉合狀態決定」的傳統教學**。
- ✅ **遠端脛骨 physis 每年約 3–4 mm**。
- 🆕 **SH 分布**：

| SH | 比例 | 備註 |
|---|---|---|
| **II** | **40–55%（最常）** | — |
| **I** | **3–15%** | 少 |
| **III** | **17–25%** | **最常早閉之一** |
| **IV** | **25%** | **最常早閉之一** |
| **V** | **<1%** | 最少 |

### 6.2 遠端脛骨 SH II 🆕

- 🆕 **約 40% 小兒踝骨折，為多數遠端脛骨 physeal 骨折**。
- 🆕 **旋後蹠屈或旋後外旋 → 大幹骺片（前或後 Thurston Holland）**。
- 🆕 **充分鎮靜與放鬆下閉鎖復位，避免反覆嘗試傷 physis**。
- 🆕 **骨膜翻入 physis 間隙可阻礙復位；可接受移位與是否需處理骨膜有爭議（2023）**；初始或殘餘移位是否預測 physeal arrest → 證據衝突。
- 🆕 **2023 CORTICES 調查：多數成員認為 physis 殘餘間隙 >3 mm → 復位 ± 內固定**。
- 🆕 **功能多良好到極佳；只有 5% 因 malunion 或早閉二次手術** → 長期追蹤。

### 6.3 Tillaux 🔄

- ✅ **前外側脛骨骨骺孤立骨折；強力旋後外旋 → 在最後閉合處失敗**；**AITFL 外側張力 → SH III、片向前外移位**。
- ✅ **關節不吻合 >2 mm → 復位**。
- 🆕 **2022（42 例）：全骨骺 vs 斜向跨 physis 螺釘 → 無 physeal bar、功能無顯著差**。
- 🆕 **多在 physis 閉合後期 → 生長併發症極罕見；關節吻合復位 → 預後好**。

### 6.4 McFarland（內踝 physis）🆕

- 🆕 **內側遠端脛骨 SH III 或 IV**。
- 機轉：**外旋外展 → 內踝撕脫**；或**內收 → 內側壓迫失敗**。
- 🆕 **可復位至 ≤2 mm 且片無平移 → 可保守**。
- 🆕 **早閉最常在 SH III、IV**：

| 來源 | bar 形成率 |
|---|---|
| 過去 | **6–50%** |
| 🆕 **2024 大型 cohort（888 例 SH III、IV 內踝）** | **57%，與復位品質無關** |

- 🆕 **約 50% 在術後 3–6 個月診斷，25% 在 6 個月後**。

### 6.5 Triplane 🔄

- 冠狀、軸、矢狀三面延伸 → 合併前述關節型態特徵。
- ✅ **AP 似 SH III、側位似 SH II**；依 CT 分**兩片、三片、四片**。
- CT：不確定型態、評估 physeal 與關節移位、規劃螺釘方向。
- 🆕 **10 年回溯：側位 X 光幹骺移位 >1 mm → CT 有手術意義關節移位的 PPV 94%**。
- 🆕 **X 光低估幹骺與關節移位最多 229% 與 184%**。
- 🆕 **57 例 Tillaux 與 triplane（平均 4.5 年）：plafond 殘餘間隙 2–5 mm 時，較大關節 step-off、併發症、保守治療 → 功能較差的預測因子**。

## 7. 足部骨折 🔄

### 7.1 距骨 🔄

- 機轉：**軸向負荷（高處墜落或車禍），足背屈**。
- 🆕 **處理同成人：解剖復位、矯正最常見的 varus 變形、可暫時 ex-fix 維持脛距撐開**。
- 🆕 **年幼、Hawkins 等級低 → 結果好**。
- 🆕 **2022 SR：不論固定方式（K-wire、plate＋screws、ex-fix），青少年 Hawkins III 更易 ON 或不癒合**。
  - 🆕 **Hawkins III ON 53.3%**；🆕 **Hawkins I、II 的 ON 率與成人相近 → 距骨血管傷比預期更難重建、更易 ON**。
  - 🆕 **不癒合雖少，>12 歲較多**。
- 🆕 **併發症處理：ON → subtalar 或 pantalar 融合；不癒合 → 植骨＋翻修 ORIF**。
- 長期追蹤 ON 與關節炎。

### 7.2 跟骨 🔄

- 極罕見、常延遲診斷。
- 🆕 **年幼多為關節外；關節內多見於骨骼成熟者高能量軸向力（墜落、車禍）**。
- 同側合併傷常見。
- 🆕 **多保守；少數明顯關節移位、對位喪失、型態威脅軟組織 → 手術**；🆕 **經皮或小切口（如 sinus tarsi）**。

### 7.3 Lisfranc 🆕

- 罕見；🆕 **20% 初診漏診或誤診**。
- 機轉：**蹠屈足扭轉**；中足痛、不能負重、🆕 **足弓底水腫與瘀斑**。
- X 光（可負重則負重）：**第二蹠骨基部與內楔骨間變寬**；不確定且懷疑高 → **MRI 或 CT**。
- 🆕 **2022 SR 演算法**：

| 情況 | 處置 |
|---|---|
| **穩定、移位 <2 mm** | **保守** |
| **不穩、Lisfranc 間隙移位較大、保守失敗** | **手術** |

- 固定：**K-wire、螺釘、plate、suture-button**。
- 🆕 **併發症與失去解剖復位相關（術後移位 → 負重痛，因內固定失敗或復位不良）**。

### 7.4 第五蹠骨與 Jones 🆕

- 🆕 **兒童最常骨折的蹠骨，多保守**。
- Jones（近端 watershed）：成人常延遲癒合、可能需手術；🆕 **兒童先保守 6–8 週（石膏或 boot），症狀性不癒合或再骨折才手術**。
- 🆕 **238 例回顧**：

| 位置（距近端尖） | 需手術 |
|---|---|
| **整體** | **6.3%** |
| **watershed 2–4 cm** | **18.8%** |
| **較近端** | **約 4.9%** |
| **>4 cm** | **0%** |

## 9. Key Study Points（OKU 15）
