## 1. 胸椎椎間盤突出（TDH）🆕

### 1.1 病理

- 發生率**遠低於頸椎與腰椎**；**多數無症狀**，常是其他檢查時的偶然發現。
- 🆕 **原因：胸椎活動受限**（**肋骨與 costovertebral 關節、冠狀 facet**）→ 前方椎間盤受力小。
- 🆕 **下胸椎較活動 → TDH 較多**（上胸較僵硬）。
- 🆕 **但症狀可很嚴重**：
  - **自然 kyphosis** → 即使很小的突出也易**腹側壓迫脊髓與出口根**。
  - **cord-to-canal ratio 較高**。
  - **分水嶺區（常在較活動的下胸）→ 壓迫時神經惡化加劇**。

### 1.2 表現與檢查

- 從**輕度局部背痛到急性進行性 myelopathy**。
- 🆕 **即使嚴重脊髓壓迫，多數 TDH 無症狀** → 可能被誤判需緊急處理；反之，有症狀者常**延遲診斷**（非特異表現、鑑別多：**帶狀疱疹**、內臟等）。
- 依位置：
  - 🆕 **孔或孔外型 → 單側根病變，沿胸壁或前腹的皮節分布**。
  - 🆕 **中央或旁中央型 → 以 myelopathy 表現**。
- 影像：
  - 先照**站立胸椎及／或全長 scoliosis 片**（骨折、局部變形、不穩）。
  - **MRI（不打顯影）= 主力**。
  - 🆕 **若考慮手術 → 定案前必做 CT：許多 TDH 是鈣化的 → 影響入路**。
  - 🆕 **CT（尤其 CT myelogram）→ 評估 TDH 是否侵蝕進入硬膜內**。

### 1.3 保守 🆕

- 🆕 **與頸腰相同，許多有症狀 TDH 會慢慢緩解**。
- **孔型、無脊髓壓迫**：口服 NSAID 或類固醇、PT、**transforaminal ESI**。
- **中央或旁中央、僅輕度 myelopathy**：衛教其他脊髓病症狀 → **密切追蹤**；口服類固醇、NSAID。
- 🆕 **有脊髓壓迫時，專門胸椎 PT 有爭議（多認為風險大於效益）；多數 ESI 亦同**。

### 1.4 手術 🆕

- 原則：**突出相對脊髓的位置＋是否鈣化**。
- 🆕 **孔型 TDH（根痛）**：
  - 主要**後方入路切除覆蓋的 pars** → **需同時對該節儀器融合**。
  - 🆕 **新式 extraforaminal 內視鏡 → 不需大量切骨，也就不需融合（2023）**。
- 🆕 **有脊髓壓迫時規劃更重要**：
  - **後方只用於旁中央型**；🆕 **關鍵：脊髓邊緣不可在突出頂點的外側**（才能不碰脊髓安全切除）。
  - 後方光譜：**單純 laminectomy＋少量 facetectomy → 積極 facet 切除 → transpedicular → costotransversectomy → lateral extracavitary**。
  - 🆕 **除單純 laminectomy 外，其他都需儀器重建**（骨切除量大）。
  - 後方要夠到內側常很困難。
- 🆕 **中央型，或旁中央型致脊髓背移 → 前方入路最常用**：**transsternal、medial claviculectomy、thoracotomy**（各有併發症、可能需另一外科醫師開路）。
  - 🆕 **應強烈考慮：後方入路處理中央 TDH 結果差**。
- 內視鏡技術與經驗增加 → **較中央的 TDH 也可用單純 MIS 減壓**。
- 🆕 **最難的是正確定位節段（在破壞節段穩定之前）**：用**一個以上標記**並對照術前影像 → **AP 看第 1 與第 12 肋；側面看壓迫變形或明顯骨刺**。

## 2. 腰椎椎間盤突出（LDH）🔄

### 2.1 定義與型態 🆕

- 🆕 **Herniation**：**nucleus、anulus 或終板物質**移位超出 anulus 與椎體邊界 → 推移硬膜外脂肪、神經根、硬膜囊。
- 🆕 **Bulge**：**瀰漫、非局部**超出椎間盤空間，**無神經壓迫證據**。

| 型態 | 定義 |
|---|---|
| 🆕 **Protrusion** | 偏心隆起，**anulus 完整** |
| 🆕 **Extrusion** | **穿出 anulus，但仍與椎間盤連續** |
| 🆕 **Sequestration** | **與椎間盤不再連續** |

- 另描述是否被 **PLL** 包住（contained）。
- 🆕 **根痛機轉 = 機械＋化學**：壓迫 → 輕痛與局部缺血；**nucleus 釋放 TNF-α 等發炎因子 → 神經水腫、纖維化、去髓鞘、Schwann 細胞變化**。

### 2.2 表現 🔄

- 🆕 **多數不願久坐**（坐姿增加盤內壓 → 暫時加重根壓迫）。
- 腿部：痛、感覺異常、麻、無力（多為皮節分布）。
- 🆕 **位置與受壓根**：
  - **posterolateral → traversing root**。
  - **foraminal 或 extraforaminal（far lateral）→ exiting root**；🆕 **far lateral 還會刺激 DRG → 更頑固的根痛**。
  - **central** → 可能不壓根，但**明顯下背痛（前彎、搬重、坐）**；🆕 **推測為 anulus 傷害活化 sinuvertebral nerve 痛覺受器**。
- PE：感覺減退、無力、肌萎縮、反射低下。

| 測試 | 定義 | 敏感 | 特異 |
|---|---|---|---|
| ✅ **SLR** | **抬腿 35–70° 重現同側腿痛** | **90%** | **低（可低至 10%）** |
| ✅ **Contralateral SLR** | 抬健側腿重現患側痛 | **約 30%** | **90%** |

- 🆕 **SLR 只牽拉下位根（L5、S1）→ 只適用尾側突出（L4–5、L5–S1，遠較常見）**。
- 🆕 **頭側 LDH（L1–L4）→ femoral stretch test：側臥或俯臥，髖伸＋膝屈 → 前大腿痛**。

### 2.3 Cauda equina syndrome 🆕

- 常由**大 LDH**造成；🆕 **基礎椎管較小者（併 spondylotic 或先天狹窄）→ 小 LDH 也可成為「最後一根稻草」**。
- 症狀光譜：單或雙側腿痛、無力、**肛周或會陰麻**、**膀胱與腸功能障礙**。
- 🆕 **膀胱：常先表現為滯留導致的尿急與頻尿 → 進展為溢流性尿失禁**。
- 🆕 **膀胱超音波可提供尿急頻尿主訴的客觀資訊**。

### 2.4 影像 🆕

- 頑固症狀 → **站立腰椎片**：滑脫、峽部、側彎、壓迫骨折；**辨識腰薦移行椎**以利手術規劃。
- ✅ **MRI（不打顯影）= 首選**。
- 🆕 **曾做 diskectomy → 加 gadolinium**：區分 **T1 高訊號、富血管的疤痕**與**無血管的復發突出**。

### 2.5 保守 🔄

- 🆕 **約 80–90% 不手術即改善**（注意：許多研究以下背痛而非根病變為主訴）。
- 🆕 **多數保守治療的效果在於讓病人舒服、「爭取時間」等待自然病程，而非改變 LDH 本身**。
- 🆕 **2024 meta-analysis：椎間盤整體吸收率 70%**：

| 型態 | 吸收率 |
|---|---|
| **Sequestration** | **88%** |
| **Extrusion** | **67%** |
| **Protrusion** | **38%** |
| **Bulge** | **13%** |

- 🆕 **2024 前瞻：單節與多節 LDH 的吸收率與緩解時間無差**。
- 常用：藥物、PT、活動調整、ESI。
  - 🆕 **雙盲 RCT：口服類固醇（prednisone 15 天遞減）→ 3 週與 52 週功能改善，但疼痛分數無改善；手術率與安慰劑無差**。
  - NSAID：尤其急性下背痛。
  - **暫時活動調整；避免長期臥床**；之後 PT。
  - **選擇性腰椎 ESI**：口服藥與 PT 不滿意時討論；手術避免率不一（高 crossover、病人偏好）。
  - 🆕 **NERVES RCT：microdiscectomy vs transforaminal ESI 臨床結果無差；但 ESI 組 41% 最後手術**。
  - 🆕 **ESI 效果不足後再 diskectomy 的結果 = 直接手術**（可安心先打）。

### 2.6 手術 🔄

- 🆕 **保守 6 週後仍頑固 → 減壓手術結果良好**。
- 🆕 **SPORT：手術相較保守顯著改善，4 年後仍成立**。
- 🆕 **Maine Lumbar Spine Study（隨機）：手術症狀減少、功能與滿意度較好**。
- 🆕 **加拿大 RCT：慢性根病變（>4 個月）→ 早期 microdiscectomy 比 6 個月保守結果更好、更具成本效益**。
- 🆕 **手術效益較小的族群：肥胖及／或 DM、勞保傷害**。
- 技術：
  - ✅ **unilateral laminotomy＋partial diskectomy = 最常用**。
  - ✅ **避免積極 subtotal 或 total diskectomy**（長期功能與 X 光較差）。
  - 開放 vs tubular：早期比較無差；**內視鏡對孔型與孔外型前景佳**。
- 🆕 **CES**：
  - 嚴重壓迫 → 可能需**加做雙側 laminectomy**＋diskectomy。
  - **急性 CES → 緊急減壓**。
  - 🆕 **<24 小時內確切時機證據少，多數主張越快越好；>48 小時減壓 → 力量與膀胱功能明顯較差**。
- 🆕 **復發 LDH**：
  - **發生率 5–15%**。
  - 🆕 **定義：術後改善 6 週後症狀再出現**（不同於減壓不足）。
  - 🆕 **多數復發仍可保守改善**（但病人常偏向手術）。

## 3. 腰椎狹窄與退化性滑脫 🔄

### 3.1 病理 🆕

- 🆕 **隱性起病，50–60 歲出現症狀；先天狹窄者 40–50 歲**。
- 🆕 **DM 與血糖控制差 → LSS 風險較高（2024）**。
- 🆕 **Kirkaldy-Willis 退化瀑布**：
  - **功能單位 = 三腳架（椎間盤＋兩側 facet）**。
  - 椎間盤退化 → 高度下降、**anulus 向後隆起** → facet 應力增加 → **facet 肥大與骨刺**＋**ligamentum flavum 肥大與皺摺** → **三向侵占硬膜囊**。
  - 進展：**microinstability → macroinstability → spondylolisthesis**。
- 🆕 **神經根血供少於周邊神經；至少 50% 營養依賴 CSF 擴散** → 機械壓迫不只局部刺激，還造成**神經缺血 → 典型 neurogenic claudication**。

### 3.2 表現 ✅

- **站立或行走 → 臀部與腿的跛行症狀**；漸漸不想走遠或久站（腿痛、抽筋、疲倦）。
- 🆕 **鑑別神經性 vs 血管性跛行**：

| | Neurogenic | Vascular |
|---|---|---|
| 緩解 | 🆕 **需前傾或坐下** | 🆕 **只需停止行走** |
| 提問 | 🆕 **「能否在廚房水槽洗碗？」**（站立不走也會痛 → 神經性） | — |
| PE | — | **脈搏減弱、毛髮脫落、水腫** |

- 🆕 **Tandem spinal stenosis**：排除血管性後，**一定要評估頸椎脊髓病**。
  - 🆕 **盛行率 0.25–25%**（不同族群）。
  - 🆕 **先天 LSS 者約 20% 合併先天頸椎狹窄** → 問上肢症狀、**查 Hoffmann**。

### 3.3 影像 🔄

- **站立 X 光**：滑脫、側彎、冠狀節段塌陷、spina bifida、spondylolysis。
- 🆕 **仰臥 MRI 會漏掉節段不穩；只用仰臥 MRI 約三分之一退化性滑脫會被漏診** → **一定要站立片**。
- 🆕 **屈伸片相對標準側面站立片無額外價值**（多篇研究類似）。
- CT：懷疑 spondylosis 或醫源不穩而 X 光、MRI 不明時。
- ❌ OKU 14 的「動態不穩：位移 >4 mm 或旋轉 >10°」本章未列。

### 3.4 保守 🆕

- 🆕 **強調：LSS 很少造成嚴重神經缺損或癱瘓 → 觀察等待並嘗試保守的神經風險很低**（SPORT LSS 組支持）。
- NSAID、**抗痙攣神經痛藥**、PT、ESI；簡單活動調整（自我限制走與站的時間）。
- 🆕 **ESI 對 LSS 的效果不如 LDH；雙盲 RCT：類固醇＋lidocaine 相較單用 lidocaine 短期幾乎無額外效益**。

### 3.5 減壓手術 🆕

- 🆕 **laminectomy ± lateral recess 與孔減壓 = LSS 標準手術**。
- 🆕 **技術要點**：
  - **向外減壓到 pedicle 內緣，直接看到 traversing root**。
  - **lateral recess 多可 undercut facet 完成 → 保留至少 50% facet 關節，防醫源性不穩**。
  - **pars 勿切除過多（OCR：less than 10 mm）**，用 Kerrison 時勿延伸骨折線穿過 pars。
- 🆕 **2022 RCT：unilateral laminotomy with crossover vs bilateral laminotomy vs spinous process osteotomy（傳統 laminectomy）→ 2 年臨床無差**。
- 🆕 **減壓節數與程度由病史與 PE 決定；目標 = 以耐久手術解除目前症狀，而非追 MRI 或預防未來症狀**。
- 🆕 **若必須破壞 facet 才能充分減壓 → 同時儀器融合**（許多人視同以 lateral 或 anterior interbody cage 間接減壓）。

### 3.6 退化性滑脫：融合與否 🆕

- 傳統：LSS＋退化性滑脫 → 融合。
- 🆕 **儀器 vs 非儀器融合**：
  - 20–30 年前：功能相同，**非儀器 nonunion 明顯較高**。
  - 🆕 **2023 RCT（54 例）：1、2 年 PRO 無差；CT 實心融合 94% vs 31%；2 年內再手術 2% vs 13%（P = 0.031）**。
- 🆕 **是否需要任何融合**：

| 研究 | 結果 |
|---|---|
| 🆕 **北美 RCT** | **laminectomy＋fusion → 整體生理健康 QOL 略高但有臨床意義的改善；再手術 14% vs 單純減壓 34%（P = 0.05）** |
| 🆕 **瑞典 RCT** | **臨床結果無差；額外腰椎手術 22% vs 21%** |
| 🆕 **2022 MRI 2 年** | **融合後近端鄰節狹窄 44% vs 17%；同節再狹窄 4% vs 14%** |
| 🆕 **非劣性研究（2 與 5 年）** | **再手術：2 年 12.5%（單純減壓）vs 9.1%（融合）；5 年 5% vs 10%** |

- 🆕 **融合的前期成本＋再手術率 → 質疑其成本效用**；單純 laminectomy 在許多病人仍可行。
- 🆕 **Key Study Point：退化性滑脫合併狹窄，選擇性病人可只做 laminectomy、不需融合**。

### 3.7 Lumbar facet arthroplasty 🆕

- 🆕 **目的：同時避免（1）單純減壓後持續不穩 → 復發狹窄；（2）融合後病理性活動重分配 → 鄰節退化（2023）**。
- 🆕 **2024 FDA 前瞻 RCT：2 年時 arthroplasty 在多數 PRO 優於儀器融合，症狀性鄰節退化較少**。

## 6. Anki 候選題

1. 為何 TDH 少見？→ 肋骨、costovertebral、冠狀 facet 限制活動。
2. TDH 好發胸椎哪段？→ 下胸椎（較活動）。
3. 為何小 TDH 也可造成嚴重症狀？→ 胸椎 kyphosis、cord-to-canal ratio 高、下胸分水嶺。
4. TDH 常見的鑑別診斷？→ 帶狀疱疹、內臟疾病。
5. 孔型與中央型 TDH 的表現差異？→ 單側胸壁或前腹根痛 vs myelopathy。
6. 考慮 TDH 手術前必做？為什麼？→ CT；許多 TDH 鈣化。
7. CT myelogram 在 TDH 的用途？→ 評估是否侵入硬膜內。
