## 1. 骨性解剖 🆕

### 1.1 髖臼

- 胚胎期 **acetabular cartilage complex**：內側 **triradiate cartilage**＋外側杯狀部分，介於 ilium、ischium、pubis 之間；主要為 **hyaline cartilage**；間質生長使髖臼擴大加深，股骨頭球形決定其凹度。
- 🆕 **青春期三個次級骨化中心**：**前（pubis）、上（ilium）、後（ischium）** → 融合成骨性髖臼壁。
- 🆕 **2024：後壁骨化中心較大，且落後於前壁與上壁** → 用於區分青少年正常變異與病理覆蓋。
- 覆蓋與髖臼緣形成、triradiate 深度與發育相關。
- 🆕 **最常用的覆蓋量測 = Wiberg CEA（仰臥 AP 骨盆）；正常上外側覆蓋 25–35°**。
- 🆕 **髖臼前傾（屍體）：19.9° ± 6.6°；女 21.3° ± 7.1° > 男 18.5° ± 5.8°**；但**功能性前傾受骨盆位置動態影響**（腰椎融合或退化會限制）。

### 1.2 近端股骨

- 嬰兒期三個生長區：**physeal plate、大轉子生長板、femoral neck isthmus**。
- 🆕 **physeal plate 約貢獻成熟股骨長度的 30%**；isthmus 貢獻外側寬度。
- 受血供、肌肉拉力、負重影響 → 生長異常 → 各種兒童與成人病變；近年研究**青少年運動與 FAI** 的關聯。
- 🆕 **骨小樑**：依 Wolff law 排列 —— **主壓力、主張力、次壓力**骨小樑交會成 **Ward triangle**（弱點，近端股骨骨折起點）；**骨鬆 = Ward triangle 骨小樑減少**（2023）。
- 🆕 **Calcar**：股骨頸與幹交界**後內側**的垂直緻密骨板，承壓並把應力由股骨頭分散到股骨幹 → 近端股骨骨折固定的關鍵。
- 🆕 **200 具成人骨骼：平均頸前傾 9.73°、頸幹角 129.23°**（性別與年齡有差）。

## 2. 關節囊與韌帶 🔄

### 2.1 關節囊

- 內層環形纖維＋外層縱向纖維。
- 🆕 **Zona orbicularis**（內層環形，附著於股骨頭底的螺旋環）：
  - **伸直＋外旋時 screw-home**、作為 **checkrein 限制股骨頭牽引**。
  - 🆕 **關節鏡地標：分隔中央腔與周邊腔**。
  - 可能協助滑液循環。

| 韌帶 | 起止 | 功能 |
|---|---|---|
| 🆕 **Pubofemoral** | 上恥骨枝 **iliopectineal eminence** → 繞 iliofemoral → 與 ischiofemoral 一起止於下股骨頸（形成下方 sling） | **控制伸直時過度外展與外旋**；🆕 **前方入路鬆解 → 伸直時易抬起股骨並外旋** |
| 🆕 **Ischiofemoral** | ischial ramus 與後髖臼緣 → **兩束**往上外：**上束 → 大轉子前上底；下束 → 後 intertrochanteric crest** | **強化內旋、限制屈曲內收** |
| 🆕 **Iliofemoral（最大）** | **AIIS 與前髖臼緣** → 分內外兩束 = **Y ligament of Bigelow**；**內側束垂直走、止於 intertrochanteric ridge 的 Marion tubercle**；外側束止於 intertrochanteric line 上方大轉子嵴 | **鬆解外側束 → 屈曲時外旋增加；內側束 → 伸直時外旋增加** |

### 2.2 關節囊是動態穩定結構 🆕

- 🆕 **iliofemoral 韌帶與 gluteus minimus、iliopsoas 腱膜相連** → 關節囊傳遞肌腱與腱膜力量 → **動態穩定**。
- 🆕 **2024 SR：capsulotomy 修補或重建改善抗牽引穩定** → 支持修補。
- 🆕 **Iliocapsularis**：位於 rectus femoris 深層、沿前關節囊；過去認為是 iliacus 延伸，🆕 **2022 認為是獨立肌肉、也參與穩定**；**direct anterior approach 地標，capsulotomy 或 capsulectomy 前先掀起**。

### 2.3 Labrum 🔄

- 纖維結締組織附著髖臼緣；🔄 **關節囊側 I、III 型膠原；關節側纖維軟骨**；🆕 **與髖臼軟骨連續，有 1–2 mm 移行區**。
- 環形膠原為主，與 **transverse acetabular ligament**（連接下方前後緣）形成連續環。
- 功能：**加深髖臼、增加負重面**、抵抗股骨頭側向與垂直移動；維持滑液與壓力（潤滑）；**suction seal**（抗牽引）；與滑液一起分散壓力 → **降低軟骨峰值應力**（保護軟骨）。
- 🆕 **2024 meta（生物力學）：修補撕裂的 labrum 不一定改善抗牽引，但多數研究優於清創**；✅ **labral 高度與 seal 抗牽引強度相關**。
- 🆕 **血供：periacetabular periosteal vascular ring 的放射支，在關節囊側穿過 osseolabral junction，由外往游離緣流**（矽膠灌注）。
- 🆕 **神經豐富：游離神經末梢＋三種感覺末梢器官，前上與後上區最多** → 可介導疼痛與本體感覺。

### 2.4 Ligamentum teres 🔄

- 關節內、**滑膜外**；fovea capitis → cotyloid fossa；✅ **雙束約 30–35 mm、類比 ACL**。
- 🔄 **I、III、IV、V 型膠原**；含**閉孔動脈後支的前分支**。
- 游離神經末梢與 Pacini 小體 → 痛覺與本體感覺、可能是疼痛來源。
- 過去認為退化殘留；關節鏡普及後重新重視其**次要穩定角色**。
- 🆕 **2024 屍體：缺 ligamentum teres → 峰值牽引力顯著下降 → 參與 suction seal**。
- 🆕 **2024 生物力學（術中取下）：破壞強度相對其他穩定韌帶弱 → 整體穩定角色受質疑**。

## 4. 神經解剖 🆕

- 主要神經：**股神經、LFCN、坐骨神經、superior gluteal、pudendal**；都含本體與痛覺纖維 → 關節囊受傷是重要痛源；痛可放射到鼠蹊、大腿、臀、膝。

| 神經 | 重點 |
|---|---|
| **股神經** | psoas 與 iliacus 之間 → 腹股溝韌帶下出骨盆；前內大腿感覺、psoas、pectineus、sartorius、quadriceps 運動；運動支在 rectus 與 vastus intermedius 間往外到 vastus lateralis；🆕 **第一支在 medial calcar 遠端 1–2 cm 跨過股骨**（遠端暴露小心）；🆕 **越往遠端越靠近髖臼緣 → THA 時 90° 位置前方拉鉤風險最高** |
| **LFCN** | 近端外側大腿感覺；位於**皮下脂肪深層**；🆕 **三型**：**sartorius 型 36%**（主前支沿 sartorius 外緣）、**posterior 型 32%**（ASIS 遠端立即分出往後 → **近端暴露危險**）、**fan 型 32%**（多分支散在 TFL 上 → **幾乎無法避免傷到**）；多在 ASIS 內側，也可上外；傷到 → 前外大腿麻、痛性神經炎 |
| **坐骨神經** | 最大神經（common peroneal＋tibial）；經 greater sciatic notch，多在 **piriformis 與短外旋肌之間**（變異多）；🆕 **後方入路與 posterolateral portal 最危險**；拉鉤間接傷 |
| **Superior gluteal** | 支配 **gluteus medius、minimus、TFL**；🆕 **唯一在 piriformis 上方出骨盆的神經**；分上下支；🆕 **上支在大轉子尖端近端約 5 cm 跨 gluteus medius 深面**；下支跨 minimus、止於 TFL；**大轉子近端的暴露或 portal 都有風險 → 外展肌不全麻痺、Trendelenburg** |
| **Pudendal** | 經 greater sciatic foramen → lesser sciatic foramen → 回骨盆前方（骨盆底與會陰感覺）；🆕 **關節鏡或骨折處理時牽引 neurapraxia** |

## 5. 血管解剖 🆕

- **股動脈**：外髂動脈延續，在股三角（ASIS 與恥骨結節間、腹股溝韌帶下）、**股神經內側**；分出 circumflex iliac 與 profunda femoris；🆕 **姿勢或前方拉鉤可造成內膜傷**。
- 🆕 **股骨頭主要血供 = MFCA 的 superior retinacular vessels**（矽膠灌注）；🆕 **部分人以 inferior gluteal artery 為主**。
- 🆕 **MFCA**：由 profunda 分出 → 沿 calcar 往後 → **穿過 quadratus femoris 與 obturator externus 之間** → **股骨頸後上方入囊**；主供大轉子與股骨頭；末端與 **inferior gluteal**（後上髖臼）及 **LFCA**（上外關節囊）吻合；retinacular arteries 穿囊沿頸上行。
- **LFCA**：由 SFA 或 profunda 分出、在 rectus femoris 與 TFL 之間往外；供前關節囊與前大轉子；🆕 **上升支在 direct anterior approach 常規結紮，無臨床影響**。
- **Superior gluteal artery**：greater sciatic foramen；淺支供 gluteus maximus、**深支供髖臼**。

## 6. 生物力學 🔄

### 6.1 ROM 🔄

| 動作 | OKU 15 |
|---|---|
| **屈曲** | **伸膝約 100°；屈膝（hamstrings 放鬆）140°** |
| **伸直** | **15–20°** |
| 外展／內收 | 10–45°／10–30° |
| **最大內旋／外旋** | **60°／90°** |

- 🆕 股骨頭為 **conchoid** 形、髖臼馬蹄形 → **以旋轉為主、平移極少**。

### 6.2 功能 ROM 🔄

- 步態：**旋轉 40–50°、屈曲 10–59°、伸直 10°**。
- 🆕 **爬樓梯：屈曲弧 19.6–67.8°**。
- 🆕 **蹲：平均屈曲 120°；坐上與起身馬桶：112°（2022）**。

### 6.3 關節受力 ✅

- 日常活動時股骨髖臼關節**永遠不會完全卸載**；由**體重力臂與大轉子外展肌拉力**平衡骨盆。
- ✅ **單腳站與擺盪期：2–4 倍體重**。
- 🆕 **慢走時單腳站期較長 → gluteus minimus 與 medius 產生較大力量**。
- ✅ **絆倒：>8 倍體重**（關節炎與 THA 早期病人有害）。
- 🆕 labral 撕裂、cam 或 pincer → **降低 suction effect、增加接觸壓**、改變負荷 → 疼痛與功能異常（2023）。

### 6.4 Spinopelvic 🆕

- **正常 spinopelvic mobility：站到坐時骨盆後傾 20–35°、股骨屈曲約 55–70°** → 股骨可前屈而不骨性撞擊（2024）。
- **坐（骨盆後傾、rollback）→ 功能性髖臼前傾增加；站（前傾）→ 減少**。
- 🆕 **每 0.8° pelvic tilt 改變 ≈ 1° 髖臼前傾改變**。
- 腰椎退化 → 脊椎活動度下降、代償性骨盆 rollback。
- 🆕 **Stiff spine = 站到坐 sacral slope 變化 <10°** → 骨盆活動受限 → **stuck standing 或 stuck sitting**。
- → **THA 植入物擺位**避免併發症的關鍵（Key Study Point：檢查髖痛要包含脊椎與膝）。

## 7. 臨床評估 🔄

### 7.1 病史 🆕

- 位置、發作、病程、性質、嚴重度、機轉、加重與緩解因素、相關症狀、已試治療。
- 🆕 **骨壞死、創傷後關節炎或感染風險**：**癌症、HIV、鐮刀型貧血、類固醇、酒精使用障礙、Paget disease、免疫抑制的風濕病、DDH、SCFE、IV drug use**。
- **全身症狀**（發燒、寒顫、倦怠、體重變化）→ 惡性或感染。
- 了解生活品質影響與期待 → 最大化 PRO。

### 7.2 理學檢查 🔄

- 🆕 **四大疼痛來源：osteochondral、capsulolabral、musculotendinous、neurovascular**；**膝與腰椎也要檢查**（轉移痛）。
- 🆕 **依位置鑑別**：

| 位置 | 關節內 | 關節外 |
|---|---|---|
| **前方（鼠蹊）** | OA、**股骨頸 stress fracture**、labral 撕裂、FAI、骨壞死、游離體 | 屈髖肌腱炎或拉傷、**sports hernia**、**iliopsoas snapping**、閉孔或 ilioinguinal 神經卡壓、**osteitis pubis** |
| **外側** | — | **GTPS**（bursitis、gluteus medius 肌腱病、外展肌撕裂或功能異常）、**external snapping hip**、ITB、**meralgia paresthetica** |
| **後方** | — | **deep gluteal syndrome、ischiofemoral impingement**、坐骨或 pudendal 神經卡壓、**SI 關節痛**、neurogenic claudication |

- 站、仰臥、側躺、俯臥檢查；先觀察坐姿與走進診間。
- 🆕 **屈曲＋外旋坐姿 → 增加關節囊容積 → 緩解 septic hip 疼痛**。
- 先檢查健側建立基準；皮膚瘀青、舊切口；觸診 ASIS、AIIS、髂嵴、恥骨結節、大轉子、坐骨結節。
- **腿長**：仰臥比較內踝，或站立比較肩與髂嵴高度。

**Provocative tests**

| 檢查 | 做法 | 意義 |
|---|---|---|
| **Log roll** | 固定同側膝、輕滾患髖 | 痛 = **關節內病變** |
| **FADDIR** | 屈曲、內收、內旋 | **FAI 或前 labral 撕裂** |
| 🆕 **Scour** | 由屈曲內旋 → 外展伸直＋軸向壓 | 區分**前 labral 撕裂** |
| **FABER** | 屈曲、外展、外旋 | 痛 = **SI 或後方撞擊**；**前鼠蹊痛 = iliopsoas 或關節內**（撞擊、labral、OA） |
| 🆕 **Stinchfield** | 抗阻直腿抬高 | **屈髖肌或 psoas 抑制**（肌腱病或 capsulitis） |
| 🆕 **Ling test** | 抗阻直腿伸直 | **區分髖關節內痛與腰椎痛** |
| **Ober**（側躺）、**Thomas** | — | **屈髖緊**（原文：hip flexion tightness） |
| **Anterior apprehension、Beighton** | — | **microinstability**（關節鏡術後或全身韌帶鬆弛） |

### 7.3 步態 🆕

- foot progression angle、stance phase、步幅、擺臂。
- 🆕 **Intoeing = 股骨前傾增加的代償；out-toeing = 股骨後傾**。
- **Antalgic**：縮短患側 stance。
- **Trendelenburg**：外展肌弱 → **對側半骨盆下垂**。

## 8. 影像 🔄

### 8.1 X 光 🔄

| 片 | 用途 |
|---|---|
| **AP 髖或骨盆** | 骨折、病灶、關節間隙、骨質、髖臼版本；**LCEA、Tönnis（acetabular inclination）、FEAR index** |
| **Cross-table lateral** | **髖臼組件版本** |
| **False-profile** | **前方覆蓋** |
| **Modified Dunn** | **head-neck offset ratio、alpha angle（cam）** |
| Inlet、outlet、Judet | 柱完整性、變形、discontinuity |
| 同側膝、腰椎 | 排除轉移痛 |

- 🆕 **spinopelvic deformity 增加 THA 不穩、脫位與翻修風險** → 專家建議**術前站立 AP 骨盆＋站立與坐姿兩張 spinopelvic 側位**。

### 8.2 超音波 🆕

- 便宜的檢查輔助；軟組織、積液；**兒童不受輻射**。
- 🆕 **動態超音波：髖不穩、FAI、ischiofemoral impingement、snapping hip 病因（2023）**。
- **評估 labral 撕裂有限**。
- **超音波導引注射**：即時、無輻射、更安全精準 → 診斷與治療都重要。
- 🆕 **2023 回顧：OA 病人 THA 前接受同側關節內類固醇注射 → PJI 風險增加** → 要審慎。

### 8.3 CT ✅

- 骨盆：髖臼版本、股骨頭覆蓋、壁與柱的大小與完整；🆕 **AIIS 與 subspine 形態**（關節外痛來源）。
- 股骨：head-neck junction、offset、**version、torsion**。
- **多平面與 3D 重組**＋病人專屬技術 → 精準術前規劃（2022）。

### 8.4 MRI／MRA 🔄

- **MRI 最全面**（關節內外結構）。
- ✅ **MRA（關節內 gadolinium）= labral 評估標準、敏感度與特異度高**；也看軟骨、ligamentum teres；**軟骨 mapping**、積液、滑膜炎、滑膜增生疾病。
- 🆕 **多項研究：無症狀者 labral 與軟骨病變比例很高 → 解讀要小心**。
- 🆕 **外傷後劇烈髖痛：MRI 找無移位近端股骨骨折（T1 序列）敏感與特異近 99%**。
- stress fracture、骨壞死、骨水腫。
- 🆕 **MARS（metal artifact reduction sequence）MRI = MoM THA 或 ALTR 疑慮時的建議影像**。

### 8.5 未來 🆕

- **Convolutional neural networks**：可能辨識影像模式、預防 THA 後脫位等併發症，仍需資料驗證。

## 10. Key Study Points（OKU 15）

- 了解**髖臼發育**與各種髖臼形態相關病變，是正確診斷髖痛的關鍵。
- **關節囊與韌帶是髖關節的主要穩定結構**。
- 熟悉髖周**神經血管的位置**，手術才能安全有效、減少併發症。
- **Spinopelvic mobility** 對髖生物力學影響很大；髖痛檢查應包含**完整的脊椎與膝評估**。
- 多種影像可評估髖痛；**影像導引的髖部處置**兼具治療與診斷角色。
