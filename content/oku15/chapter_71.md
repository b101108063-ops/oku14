## 1. Developmental dysplasia of the hip（DDH）🔄

### 1.1 定義與流行病學 🆕

- 🆕 **嬰幼兒最常見肌骨疾患；hip dysplasia 約 1／100，脫位約 1／1,000**。
- 正常發育：髖臼與 innominate bones（triradiate cartilage）均衡生長，同時股骨頭位置居中 → 同心圓形關節。
- 🆕 **DDH 不同於神經肌肉、畸胎性、症候群性的發育不良**（後者為異常發育或肌張力作用）。
- 🆕 **術語**：

| 名詞 | 定義 |
|---|---|
| **DDH** | 發育性（排除神經肌肉、症候群、畸胎性）的光譜：髖臼發育不良、近端股骨半脫位、脫位 |
| **Simple（classic）dysplasia** | **髖臼淺，無半脫位或脫位** |
| **Subluxation** | **股骨頭相對髖臼向上或外移，部分仍接觸** |
| **Dislocation** | **股骨頭完全不接觸髖臼** |
| **Neonatal hip instability** | **出生 4 週內的生理性鬆弛（2024）** |

- 早期辨識 → **dynamic（Pavlik）或 static（rigid orthosis）splinting** 有效；未治療 → 年輕即髖 OA。

### 1.2 病因 🆕

- 🆕 **危險因子：第一胎、女性、多產、臀位、家族史**。
- 🆕 **tight packaging（子宮緊、肌肉性壓迫）：第一胎、臀位、oligohydramnios、多產（2024）**。
- 🆕 **女性：母親與女嬰本身雌激素 → 軟組織鬆弛**。
- 🆕 **左髖較常：left occiput anterior 胎位 → 左髖貼母親脊椎、較受限**。
- 🆕 **遺傳**：

| 家族 | DDH 風險 |
|---|---|
| **一位家長受累** | **12%** |
| **家長＋手足受累** | **36%** |

- 🆕 **族群：高 → Native American、Laplander、中歐（奧地利、斯洛維尼亞）；低 → 南方華人、黑人**。
- 🆕 **出生後：不良擺位（某些傳統襁褓）**。

### 1.3 病理生理與阻礙復位 🆕

- 🆕 **缺乏股骨頭接觸力 → 淺（upsloping）髖臼**；可持續到成人。
- 🆕 **無凹面引導 → 股骨頭不圓＋coxa valga；髖臼與股骨前傾都比同儕大**。
- 🆕 **軟組織攣縮與肥厚 = 同心復位的主要阻礙（開放復位時必須處理）**：
  - **adductor tendon 攣縮**、**iliopsoas 攣縮**、**transverse acetabular ligament 攣縮**
  - **pulvinar 肥厚**、**ligamentum teres 延長肥厚**、**冗長關節囊**
  - **labrum 肥厚**、🆕 **limbus：上髖臼緣的病理纖維組織（labrum 與囊被壓在透明軟骨上）**

### 1.4 篩檢與超音波 🆕

- 🆕 **AAP CPG：普遍臨床篩檢＋選擇性超音波**（OCR 部分缺失）。
- 🆕 **超音波為嬰兒首選（軟骨、無輻射）**；🆕 **約 6 週可篩檢，之後追蹤治療反應**；🆕 **4–6 個月為上限（骨化中心與下 ilium 造成偽影）**。
- 冠狀切面：ilium、ischium、外展肌、股骨頭、labrum。

| 參數 | 定義 | 正常 |
|---|---|---|
| 🆕 **Alpha angle** | **ischium baseline 與 bony line（髖臼斜面）** | **>60°；<60° → 淺髖臼** |
| 🆕 **Beta angle** | **baseline 與 cartilaginous roof line**（較少用） | **<55°；>55° → 擔心半脫位或脫位** |
| 🆕 **股骨頭覆蓋** | 股骨頭在髖臼內百分比 | **理想 50%** |

- 🆕 **inverted labrum = Pavlik harness 失敗的危險因子**。
- 🆕 **Graf 分類（與治療反應相關）**：

| Type | 成熟度 | α | β | 年齡 |
|---|---|---|---|---|
| **I** | 成熟 | **≥60°** | Ia ≤55°、Ib >55° | 全部 |
| **IIa+** | 不成熟但合適 | **50–59°** | — | **<3 個月** |
| **IIa−** | 不成熟且不合適 | 50–59° | — | <3 個月 |
| **IIb** | 發育延遲 | 50–59° | — | **>3 個月** |
| **IIc** | 穩定或不穩、嚴重不足 | 50–59° | **>77°** | 全部 |
| **D** | 偏心（decentering） | **43–49°** | >77° | 全部 |
| **III／IV** | 偏心髖 | **<43°** | labrum 移位 | 全部 |

### 1.5 X 光與進階影像 🔄

- 🆕 **≥4 個月可照 AP 骨盆**；🆕 **先評估片子品質（骨盆旋轉或傾斜影響測量）**。
- 🆕 **股骨頭骨化核通常 6 個月才出現；延遲（尤其 >12 個月）或不對稱（較小、偏心）→ 提示發育不良**。
- ✅ **Hilgenreiner line、Perkin line、Shenton line（連續弧為正常，中斷 → 半脫位或脫位）**；Shenton 不連續可能是最早徵象。
- 🆕 **IHDI classification**：描述近端股骨半脫位或脫位。
- 髖臼發育不良描述：淺或 upsloping、**teardrop 變寬**、**subchondral sclerosis 位置**、**acetabular index**。
- ✅ **AI**：Hilgenreiner line 與骨化髖臼上外緣；正常值隨年齡變；可作閉鎖復位後反應指標。
- 🆕 **CT、MRI 不屬診斷流程；復位後用於評估同心度與非骨性構造（軟骨 anlage）；MRI 優先（避輻射），依機構、儀器、麻醉而定（2023）**。

### 1.6 治療 🔄

- 🆕 **健康兒確診即可開始**；🆕 **延後情境：NICU（管線、引流、監測器）、congenital knee hyperextension 需先處理**。
- ✅ **Pavlik method（dynamic splint）：<6 個月首選；屈曲＋外展 → 逐漸復位＋同心接觸促髖臼重塑**。
  - 🆕 **定期回診：依生長調整、監測 femoral nerve palsy（股四頭肌活動減少）、超音波評估**。
  - 🆕 **3–4 週無改善 → 可考慮改 static splint（rigid hip orthosis）；持續脫位時是否轉換有爭議**。
  - ✅ **成功約 90%**。
  - 🆕 **併發症：近端股骨生長障礙、股骨頭 ON、Pavlik harness disease（長期股骨頭壓迫 → 後外側髖臼發育不良）**。
- 🆕 **Pavlik 失敗或延遲診斷 → 手術**：
  - **麻醉下檢查：safe zone（髖 90° 屈曲下維持復位的外展範圍）＋考慮 adductor tenotomy**。
  - **hip arthrogram：復位可能性與解剖（上外側髖臼軟骨 anlage）**。
  - **閉鎖 vs 開放**依年齡、預期穩定、醫師演算法；🆕 **無法以閉鎖達成並維持同心 → 開放復位，必須移除所有阻礙（殘留 → 再半脫位或脫位）**。
  - **spica → 透視或進階影像確認同心**；🆕 **石膏 6–12 週，之後可接 rigid orthosis**。
- 🆕 **截骨**：
  - **股骨截骨 → 減少股骨頭接觸力、降低 ON**。
  - **骨盆截骨 → 明顯發育不良且重塑潛力低**。

## 2. Legg-Calvé-Perthes disease（LCP）🔄

### 2.1 流行病學 🔄

- 定義：**近端股骨骨骺的無菌、非發炎、自限性特發性 ON**；經長期可預測分期 → 骨骺變形 → 髖臼變化、關節不吻合。
- 🆕 **0.4–24.4／100,000／年；英國較低**；🆕 **2023 美國資料庫：LCP 相關住院下降（推測發生率下降）**。
- 🆕 **相關因子：男性、白人、吸菸暴露、地理緯度越高、過動行為、社經地位**。
- ✅ **男:女約 5:1**；🆕 **女性較嚴重、骨骼成熟時結果較差**（推測荷爾蒙）。
- 🆕 **學齡兒童，平均 6 歲（2–13 歲）**；診斷技術進步 → 較年幼者較早發現。
- 🆕 **過去描述為身材小；近年肥胖率增加，最高 40% 過重或肥胖（2024 有上升趨勢）→ 肥胖可能為獨立危險因子**。
- 🆕 **5–15% 有家族史**。
- 🆕 **約 10% 雙側（2022）**；🆕 **雙側且同期 → 評估骨骼發育不良及／或血液病：實驗室、脊柱側位片、站立髖到踝片**。

### 2.2 病因 🆕

- 🆕 **家族性 LCP：COL2A1 突變 → 異常 type II collagen → 骨骺血供受損**。
- 🆕 **leptin 阻抗增加**。
- 🆕 **前上股骨頭最常受累：由 lateral retinacular vessels 供血，最易缺氧**。
- 🆕 **血管不足為慢性而非急性（多無外傷史）**；吸菸等微血管傷環境因子。
- 血管侵入與壞死骨吸收 → 結構變弱 → 骨小樑骨折與囊腫。

### 2.3 表現 🆕

- 🆕 **跛行（可無痛）**；疼痛最常在**髖**，或大腿、膝（轉移痛）。
- 🆕 **ROM 受限：外展平均比對側少 15°**。

### 2.4 影像與分期 🔄

- ✅ **AP＋frog-lateral 骨盆**；依 **Waldenström 分期**。
- 🆕 **標準 MRI 若在前 6 個月內 → 可能低估軟骨傷與壞死（缺血表現延遲）**。
- 🆕 **perfusion MRI → 較能顯示血供、壞死範圍與再血管化、關節變形 → 預後與治療決策**；常規使用有爭議（幼兒需全麻）。
- ✅ **修訂 Waldenström**：

| 分期 | 表現 |
|---|---|
| **I** | 骨骺部分或全部硬化（IA 無高度喪失；IB 高度喪失、未碎裂） |
| **II** | 碎裂（IIA 剛開始 1–2 條垂直裂；IIB 進階、外側無新骨） |
| **III** | 重骨化（IIIA 外側早期新骨、<1/3 寬；IIIB 正常質地新骨 >1/3 寬） |
| **IV** | 癒合完成、無缺血骨 |

- 🆕 **Stage II（碎裂）= 股骨頭變形風險最大**；🆕 **Stage III：可恢復正常血供，或跨 physis 血管 → physeal bar**。

### 2.5 分類 ✅

- ✅ **Catterall**：碎裂期依受累位置與範圍；**head-at-risk 徵象**：
  - **股骨頭外側半脫位、外側鈣化、廣泛幹骺反應、水平 physis、Gage sign**（🆕 **骨骺或幹骺外緣 V 型透亮**）。
- ✅ **Herring lateral pillar（早期碎裂期）**：

| Group | 外側柱高度 | 預後 |
|---|---|---|
| **A** | **完整** | **通常好** |
| **B** | **>50%** | **>6 歲者差** |
| **C** | **<50%** | **全部差** |

- ✅ **Stulberg I–IV**：最廣用的結果分類；**骨骼成熟時**評估股骨頭與髖臼形狀；級數越高 → 越不圓越不吻合 → OA 越重。

### 2.6 治療 🔄

- 目標：**預防續發退化 → containment（讓股骨頭留在髖臼內度過病程）**；🆕 **無 RCT，只有少數前瞻 cohort**。
- 🆕 **手術適應證據**：

| 情況 | 手術效益 |
|---|---|
| **>8 歲＋lateral pillar B 或 B/C** | **改善 Stulberg** |
| **>8 歲＋A 或 C；或 <8 歲** | **無顯著益處** |
| **>6 歲＋>50% 股骨頭壞死** | **手術優於保守** |
| **<6 歲＋>50% 壞死** | **無差** |

- 🆕 **保守**：
  - **長期免負重**：🆕 **2023 建議減負至股骨頭癒合（Waldenström IIIb）**；多研究支持保護股骨頭形狀，但擔心心理社會與功能影響。
  - 🆕 **經皮 adductor 延長＋Petrie cast → A-frame**：結果滿意。
  - 🆕 **保持髖外展至少 30° → 減少股骨頭外擠**。
  - 優點：避免股骨截骨的短縮與外展肌功能不良；缺點：療程長、繁瑣。
- 🆕 **手術 containment**：proximal femoral varus osteotomy 及／或髖臼截骨；新研究主張依解剖選股骨側或骨盆側。
  - 🆕 **Proximal femoral osteotomy**：可靠；🆕 **早期截骨可縮短碎裂期（改變力學與修復生物學）**。
    - 🆕 **術後頸幹角避免 <105° → 延遲重塑、大轉子過度生長、明顯短縮**。
    - 🆕 **前瞻多中心：varus 矯正 10–15° 即可，更大角度不必要**。
    - 🆕 **2022：術後頸幹角 105–125° → 成熟時較可能為圓頭（Stulberg）**。
  - 🆕 **骨盆截骨**：股骨截骨不足或有髖臼發育不良 → **shelf procedure**（擴大覆蓋、支撐 labrum）、**triple innominate osteotomy**。
- 🆕 **Arthrodiastasis（articulated hip distraction）**：外展、伸直、中立旋轉；減少關節壓力、利軟骨修復、creeping substitution。
  - 🆕 **12 篇 meta：適用晚發活動期或嚴重變形的救援；可能增加 ROM、改善 Stulberg，但資料不足以證明優於其他**。

### 2.7 結果 🔄

- 自限但變形與修復 → 長期痛、僵硬、OA 風險增加。
- 🆕 **Stulberg 預後差：發病年齡大、女性、外側柱塌陷 >50%**；🆕 **髖僵硬與最終 Stulberg 無關**（有爭議）。
- **發病年齡為關鍵**：

| 年齡 | 結果 |
|---|---|
| ✅ **<6 歲** | **約 80% 好（不論手術或保守，尤其 A 或 B）** |
| ✅ **6–8 歲** | **手術 68–69% vs brace 62%，無顯著差**；🆕 **brace 不如骨盆截骨（外移較少、AI、Sharp angle、深寬比較好；但痛與 ROM 無差）** |
| 🆕 **>8 歲** | **髖臼重塑潛力低；C 型手術 vs 保守無差；B 或 B/C 有中度益處** |

- 🆕 **青少年或成人殘餘變形 → 多處 FAI（關節內或外）及／或髖不穩、代償性髖臼發育不良 → 軟骨與 labrum 傷**。
- 🆕 **2022 網路調查（約 1,200 成人 LCP）：近 1/3 成年後接受手術；22% 已 THA**；🆕 **過去長期系列 THA 26–41%**。

## 3. Slipped capital femoral epiphysis（SCFE）🔄

### 3.1 定義與流行病學 🔄

- ✅ **近端股骨 physis 旋轉變形：幹骺相對骨骺外旋、伸直、前移**。
- ✅ **青少年最常見髖疾患；平均 12–13 歲**（快速生長期 physis 易受機械過載）。
- 🆕 **10／100,000；男性、非裔美國人較多**（OCR 截斷）。

### 3.2 病因：解剖與危險因子 🆕

- 🆕 **近端股骨 physis 隨年齡變垂直，9–12 歲變化最快**。
- 🆕 **增加 physis 剪力：股骨相對後傾、head-neck offset 減少、後方 epiphyseal inclination、髖臼相對後傾**。
- 🆕 **epiphyseal tubercle（後上骨骺骨突，與幹骺互鎖提供穩定）在青春期變小 → 對旋轉與剪力抵抗降低**。
- 🆕 **內分泌代謝**：

| 類別 | 疾病 |
|---|---|
| **內分泌（最常）** | 🆕 **甲狀腺低下：2024 篩檢 32%** |
| **內分泌** | 🆕 **GH 缺乏、rhGH 治療（2022）** |
| **代謝** | **腎性骨病（renal osteodystrophy）、肥胖**（機械過載＋代謝失調＋較垂直 physis） |

- 🆕 **非肥胖的少見型 SCFE → 篩檢：TSH、free T4、GH、BUN、serum creatinine**。

### 3.3 症狀與徵象 🆕

- 🆕 **衛教與認知提升後，診斷時間仍未改善：輕度平均 10 週、重度 20 週**；🆕 **公共保險、單一監護人家庭 → 延遲診斷獨立危險因子（2023）**。
- 症狀模糊、間歇；疼痛可轉移到大腿或膝。
- 🆕 **小兒膝痛檢查無發現（尤其過重、內分泌或代謝病）→ 照髖 X 光篩檢**。
- 跛行、**足外旋**；✅ **Drehmann sign：屈曲時髖被迫外旋外展**；屈曲與內旋減少（synovitis 或 FAI）。

### 3.4 分類 🔄

- ✅ **時間**：**acute <3 週、chronic >3 週、acute on chronic（前驅症狀後突然惡化）**。
- ✅ **穩定性（Loder，具預後價值）**：
  - **stable：可行走（含拐杖）**；**unstable：即使輔具也不能走**。
  - 🆕 **亦可依術中相對易復位或 hemarthrosis 定義不穩**。
  - 🔄 **不穩 ON：早期研究最高 47%，近期文獻約 23.9%**。
- ✅ **嚴重度（Southwick 角或滑脫百分比）**：

| 嚴重度 | Southwick | 滑脫 |
|---|---|---|
| **Mild** | **<30°** | **<33%** |
| **Moderate** | **30–60°** | **33–66%** |
| **Severe** | **>60°** | **>66%** |

### 3.5 影像 🔄

- ✅ **AP＋frog-lateral 骨盆**；✅ **Klein line（沿股骨頸上緣）應與骨骺相交**。
- 🆕 **症狀典型但 X 光正常 → 非顯影 MRI 診斷 preslip：physis 周圍水腫、physis 變寬、epiphyseal tubercle 透亮**。
- 🆕 **acute on chronic 或 chronic → 3D CT：變形程度、後方 callus、規劃手術**。

### 3.6 治療 🔄

- 🆕 **主要目標：穩定骨骺、保護後方 retinacular vessels（骨骺血供）**；**次要：矯正變形（多為初次癒合後的二次手術）**。
- ✅ **穩定、輕度 → 經皮 in situ 固定（首選）**：
  - **一支 6.5 或 7.3 mm 全牙 cannulated screw，垂直 physis，至少 5 牙跨過 physis**。
  - 🆕 **入點：intertrochanteric line 外側（避免釘頭撞前髖臼緣）＋小轉子近端（避免植入物周圍骨折）**。
  - 🆕 **一支 vs ≥2 支：穩定性好、併發症最少**；**in situ → ON 低**。
- 🆕 **不穩 → in situ 兩支螺釘可能較佳**（強度、剛性、破壞負荷較高）；🆕 **多支 → 關節穿透與 chondrolysis 風險增加**。
- 🆕 **閉鎖復位有爭議**：擔心醫源性拉扯扭轉 retinacular vessels；**歷史 ON 25–100%**；不穩者擺位時可能意外復位。
- 🆕 **capsular decompression**（解除 hemarthrosis 對血管的填塞）：**前入路正式 capsulotomy**，或**經皮 Cobb elevator 沿前頸撐起關節囊**。
- 🆕 **中重度 → 開放復位**：

| 方式 | 特點 |
|---|---|
| 🆕 **前或前外入路部分手指復位** | **避免強力復位與短縮血管張力、可減壓血腫、ON 低** |
| 🆕 **Modified Dunn（surgical dislocation）** | **retinacular flap 保護血供、移除幹骺 callus 減張 → 較完整復位與矯正**；🆕 **不穩滑脫 ON 26–29%**；🆕 **用於中重度穩定 SCFE 有爭議（in situ ON 極低 vs 移動血管風險）** |

### 3.7 預防性固定 🆕

- 🆕 **雙側 20–24%；較常見於：年幼（女 <10 歲、男 <12 歲）、腎或內分泌異常、Down syndrome**。
- 🆕 **約 1/3 單側病人在平均 6.5 個月後對側滑脫，通常在 18–24 個月內**。
- 🆕 **對側預測**：
  - **modified Oxford score = 最佳預測**。
  - **≤11 歲、modified Oxford ≤20、兩髖 epiphyseal-diaphyseal angle 差 ≤21°**。
  - 🆕 **posterior sloping angle（frog-lateral 量 physis 垂直剪力）>14° → 未來對側 65% → 建議預防性 pinning**。
- 🆕 **預防性固定罕見併發症：植入物周圍骨折、ON → 低風險者與家屬共享決策（固定 vs 密切觀察症狀）**。

### 3.8 殘餘變形 🆕

- 🆕 **in situ 與部分復位的缺點：變形未矯正 → 異常力學 → 早期退化**。
- 🆕 **2023 約 50 年追蹤：in situ 固定 41% 已 THA，比一般人高 15 倍**。
- 🆕 **幹骺前突 → cam → FAI → labrum 與鄰近軟骨傷；大 cam → 髖臼緣撞擊、壓碎 labrum（2022）**。
- 後傾＋伸直變形 → **屈曲、內旋受限 → 坐、走等日常活動受限**。
- 🆕 **年幼者：殘餘變形與 FAI 可影響髖臼外側骨骺生長中心 → sourcil 上翹、相對髖臼發育不良、subchondral sclerosis 增加**。
- 🆕 **處理**：

| 情況 | 處置 |
|---|---|
| **輕度 FAI** | **髖關節鏡：改善 head-neck offset、修補 labrum**；🆕 **但術後 ROM 與術前相似（physis 層的伸直與旋轉變形未矯正）** |
| **嚴重 FAI、ROM 減少** | 🆕 **近端股骨矯正截骨：屈曲＋前傾（比單純前傾增加更多無撞擊屈曲，2023）** |
| | 🆕 **截骨離原變形處越遠 → ON 風險越低，但矯正越少（2024）** |
| | 🆕 **surgical dislocation → 頭頸 osteoplasty＋intertrochanteric 截骨 → 減少所需屈曲矯正與截骨處續發變形** |

## 5. Key Study Points（OKU 15）

- **DDH 為 1／100 出生的病理光譜**：從輕微形態改變（髖臼發育不良）到完全髖脫位。
- 診斷：**臨床檢查；<3 個月 → 超音波；>4 個月 → 髖 X 光**；治療依發育不良嚴重度與年齡。
- **LCP = 近端股骨骨骺的無菌、非發炎、自限性特發性 ON**。
- LCP 治療目標：**股骨頭 containment 於髖臼內** → 預防續發退化。
- **SCFE 病人常跛行、足外旋，髖屈曲與內旋減少**。
