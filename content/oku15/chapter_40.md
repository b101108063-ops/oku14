## 1. 屈肌腱傷 🔄

### 1.1 解剖 🆕

- **9 條外在屈肌腱**：FDS 4 條、FDP 4 條、FPL 1 條。
- **FDS**：兩頭（ulnohumeral 與 radial），起於內上髁前方、sublime tubercle、近端橈骨前；🆕 **前臂分淺層（中、無名指）與深層（食、小指）**；在中節底前分成兩股（**Camper chiasm**）。
- **FDP**：起於近端尺骨掌內側與骨間膜，最深層，穿過 FDS 兩股，止於遠節底。
- **FPL**：起於橈骨幹掌側與骨間膜，止於拇指遠節底。
- 🆕 **腕隧道內層次：中、無名 FDS 最掌側 → 食、小 FDS → FDP 與 FPL 最深**。
- **滑車**：5 個 annular（A1–A5）＋3 個 cruciate；**A2、A4 分別在近節與中節**；A1、A3、A5 在 MCP、PIP、DIP；C1–C3 在 A2–A3、A3–A4、A4–A5 之間。
  - 🆕 **A0 pulley（掌腱膜）**位於 A1 近端，與**難治性 trigger finger** 有關。
  - **A2 與 A4 最重要**（防弓弦）。
  - 🆕 **拇指：A1、A2、oblique pulley**，另有**位置不定的 Av pulley**（A1 與 oblique 之間）。
- **雙層滑液鞘**（內 epitenon、外 parietal）；深部感染可經 **Parona space** 擴散到前臂。
- 手指肌腱營養：**vincula**（指動脈分支）、止點骨內血管、滑液擴散。

### 1.2 分區 ✅

| Zone | 範圍 |
|---|---|
| **I** | FDS 止點以遠 |
| **II** | FDS 止點到 A1 近端（**no man's land**） |
| **III** | A1 到腕隧道遠端 |
| **IV** | 腕隧道 |
| **V** | 橫腕韌帶近端到肌肉肌腱交界 |

- 拇指 3 區。

### 1.3 修補科學 🔄

- 🆕 **癒合三期**：
  1. **止血＋發炎期：受傷後 48–72 小時**（fibrin clot）。
  2. **增生期：2–28 天**（新膠原、血管長入，強度增加）。
  3. **重塑期：1–4 個月**（膠原與肌腱平行排列）。
  - **前兩期修補強度完全靠縫合 → 最易失敗**。
- 原則：保留血供、**修補處縫隙最小**、輕柔操作、平順對合以利滑動、**強度足以早期活動**。
- ✅ **強度與跨過修補處的 core suture 股數成正比 → 至少 4 股**；更多股更強，但更多穿刺增加組織傷與粘連。
- 🆕 **3-0 線比 4-0 強 → 一般建議 3-0**。
- 🔄 **加 epitendinous 縫合增強 10–50%**，並改善滑動（OKU 14：20–50%）。
- ✅ **修補處兩側各需 7–10 mm 肌腱**供縫合抓取與鎖扣。
- 🆕 **結打在修補處外，time-zero 強度較好**。

### 1.4 Zone I：Jersey finger（Leddy-Packer）🔄

- FDP 收縮時 DIP 被強迫伸直 → 撕脫；🆕 **最常見無名指**。
- **Type I、II 最常見**。

| Type | 回縮位置 | Vincula | 修補時限 |
|---|---|---|---|
| **I** | **手掌（lumbrical 起點）** | **VLP 與 VBP 都斷 → 肌腱幾乎無血供** | 🔄 **7–10 天內**（防壞死與攣縮）；結果最差 |
| **II** | **PIP**＋小掌側骨片 | **VBP 斷、VLP 保留** | 🔄 **可延到 6 週**（OKU 14：3 個月） |
| **III** | 大骨片卡在 **A4** | 兩條都保留 | 較不急；**先固定骨片再修腱** |
| 🆕 **IV** | 骨性撕脫＋**肌腱另外撕脫並回縮**（segmental） | 不定 | — |
| 🆕 **V** | 骨性撕脫＋**P3 粉碎骨折** | 不定 | — |

- 🆕 **兩側都有 ≥1 cm 肌腱 → 可直接縫**。
- Type I、II 無法直接縫：**pull-out button、suture anchor、經骨橋縫合** —— 🆕 **無一證明較好，但錨釘可能較快回工作**。
- 🆕 **未治療 >6 週**：回縮與壞死 → 難處理；**PIP 功能好可保守**；**慢性 DIP 痛＋PIP 正常 → DIP 融合或 tenodesis**。

### 1.5 Zone II 🔄

- 過去結果差；通常 FDP（較掌側）先受傷，FDS 一或兩股也可能斷。
- Bruner 或 midaxial 切口；回縮到 PIP 或更遠（依 vincula），**lumbrical 防 FDP 回縮到腕**。
- 🆕 **撕裂 <50% 可修邊不縫**（改善滑動）。
- **縫合為主**；≥4 股 core 改善強度與結果。
- 挑戰：**滑車處理**與**合併 FDS 傷**；臃腫修補會卡在 A4 或 A2。
- ✅ 🆕 **2022：A4 全部與 A2 最多 2/3 可切開而無臨床意義的弓弦** → 必要時 **vent A4 或 A2 遠端**。
- 🆕 **估計 A2 要 vent 多少：量修補處到 A4 近端緣的距離**。
- 仍滑動不佳 → 🆕 **切除一條 FDS，或兩條都斷時只修一條**，增加滑車內空間。

### 1.6 Zone III–V 🆕

- **Zone III**（A1 到橫腕韌帶，**無腱鞘**）：近**淺掌弓、正中神經運動支**；回縮肌腱可能需**腕隧道鬆解**取回；primary 縫合即可；🆕 **修完考慮放 A0 與 A1** 以完全伸指；結果與 zone II 相近。
- **Zone IV**（腕隧道）：較少見（有橫腕韌帶保護）；常合併**正中、尺神經與橈、尺動脈**傷；🆕 **一般要做腕隧道鬆解**（幫助修補、防擁擠）。
- **Zone V**（腕隧道近端）：常合併神經血管與多條肌腱傷；**≥4 股 core＋epitendinous**、🆕 **由深到淺修**；修完**檢查手指休息 cascade**；🆕 **最終 ROM 比 zone II 好**（前臂較耐受臃腫修補）。

### 1.7 部分撕裂與重建 🔄

- 🆕 **部分撕裂**：

| 撕裂比例 | 處理 |
|---|---|
| **<1/3** | 清修邊緣，使滑動平順 |
| **33–60%** | **只做 epitendinous 修補** |
| **>60%** | **標準 core 縫合** |

- 延遲就醫但未回縮 → primary repair 仍可行。
- 大量組織缺損、忽略回縮、修補失敗 → 無法端對端；勉強縫合 → **攣縮與 quadriga**。
- **重建適應症（有爭議）**：**慢性或 zone II 失敗、手指柔軟、無神經血管缺損**。
- 🆕 **PIP 功能好 → 考慮 DIP 融合**（經完整 FDS 重建 FDP 易疤）。
- **單期 vs 兩期**：
  - 單期：大量肌腱缺損但**滑車與腱鞘保留**。
  - **兩期（較常用）**：合併滑車、骨、皮膚、神經血管傷；**第一期放矽膠 spacer（常同時重建 A2、A4）** → 🔄 **等 6–8 週**（形成 pseudosheath、恢復 ROM）→ 第二期穿 graft。
- 供體（extrasynovial）：**palmaris longus、EDM、EIP**。
- 🆕 **side-to-side 縫合取代 Pulvertaft weave**：較不臃腫、生物力學較強、較簡單。

### 1.8 復健 🔄

- 醫師與手部治療師要密切溝通；修補變強 → 早期活動協定 → 功能與 ROM 改善。
- 🆕 **功能改善可持續到至少術後 1 年（2023）**。
- 🔄 🆕 **Cochrane**（固定、EAM、place-and-hold、早期被動 Kleinert 與 Duran、雷射、超音波）：**證據品質低，無法推薦特定協定**。
- 🆕 **2022 RCT（zone I、II）：EAM vs 早期被動＋place-and-hold → ROM、力量、功能無差**。
- 🆕 **2023 RCT（zone II）：EAM vs Kleinert → EAM 力量與 PRO 改善略快，1 年無差**。
- 🆕 **2023 meta（zone II）：EAM 的 TAM 優於早期被動；但 2 股修補無法承受任何早期活動協定（再斷）**。
- ❌ OKU 14 的「2019 SR：place-and-hold 優於被動協定」被上述證據取代。

### 1.9 併發症 🔄

- 🔄 **再斷裂最高 8.7%** → **相對盡快手術**（OKU 14：3–10%、3 週內可再縫）。
- **粘連**：僵硬或恢復停滯的常見原因 → **先加強手部治療**，無改善 → **tenolysis**。
- 🆕 **Lumbrical plus**：**graft 太鬆** → 屈曲力全傳到 lumbrical（起於 FDP、止於伸肌擴張）→ **PIP 與 DIP 反常伸直**。
- 🆕 **Quadriga**：**修補太緊** → 共同肌腹的 FDP 中一條過短 → 該指先完全屈曲，**鄰指無法完全屈曲**；🆕 **肌腱前移 >1 cm 有風險**。

## 2. 伸肌腱傷 🔄

### 2.1 解剖 🔄

- 位於皮下 → 常受傷；🆕 **多為年輕男性、慣用手、拇指最常見**；銳器切傷最常見，鋸與壓砸傷常合併骨或神經血管傷。
- 外在伸肌：
  - **淺層**：ECRL、ECRB、EDC、EDM、ECU。
  - **深層**：APL、EPB、EPL、EIP。
  - 經 extensor retinaculum 下 **6 個纖維骨管**。
- MCP 處外在伸肌分成**兩側 slip＋central slip**；側 slip 與 interossei、lumbricals 匯成 **lateral band**；**central slip 止於中節底（伸 PIP）**；**lateral band 在 DIP 合成 terminal tendon（伸 DIP）**。
- 拇指：**EPL 在 EPB 尺側**，止於遠節；兩者由 retinaculum 連接、sagittal band 穩定。
- 支持結構：
  - **Juncturae tendinum**（掌骨上）：**可掩蓋近端肌腱傷**。
  - **Sagittal band**（MCP）：起於 volar plate，吊帶穩定 central tendon。
  - **Triangular ligament**（中節）：連接兩側 lateral band，**防屈曲時掌側滑脫**。
  - **Transverse retinacular ligament**（PIP）：**防 lateral band 背側半脫位 → 防 swan neck**。
  - **ORL（Landsmeer）**：起於 A2 掌側、到 terminal tendon 背側，**連動 PIP 與 DIP 屈伸**。

### 2.2 分區 ✅

| Zone | 位置 |
|---|---|
| **I** | 甲根到中節中段（DIP、terminal tendon） |
| **II** | 中節 |
| **III** | PIP |
| **IV** | 近節 |
| **V** | MCP |
| **VI** | 掌骨 |
| **VII** | 腕骨到 extensor retinaculum |
| **VIII** | 前臂遠 1/3 到肌肉肌腱交界 |

- 🆕 **拇指：T I（IP）、T II（近節）、T III（MCP）、T IV（掌骨）、T V（腕骨）**。

### 2.3 各區處理 🔄

**Zone I：Mallet finger**
- DIP 伸直時被強迫屈曲；可有 DIP 屈曲姿勢或 **swan neck**。
- **Doyle 分型**：

| Type | 內容 | 處理 |
|---|---|---|
| **I** | 閉鎖 ± 小骨片 | 🔄 **DIP 伸直副木 6–8 週 → 溫和 ROM＋夜間副木 4 週**；🆕 **24 小時配戴是成功關鍵** |
| **II** | **開放切傷** | 徹底沖洗＋**figure-of-8 縫合**，遠端肌腱不足 → 🆕 **dermatotenodesis**（縫線穿過遠端皮膚與骨膜）；術後同 type I 副木 |
| **III** | 皮膚與遠端肌腱缺損 | 覆蓋或肌腱移植 |
| **IV** | 遠節大撕脫骨折 | 依骨片大小與 DIP 穩定 → 副木 vs K-wire |

- 🆕 **手術適應症（有爭議，2023）：開放骨性傷、副木下仍持續 DIP 半脫位**。
- 🆕 **骨折 >50% 關節面 → 很可能 DIP 半脫位 → 考慮固定**；**跨 DIP K-wire 或 extension block pinning**，無一證明較好。
- ❌ OKU 14 的 IVB（20–50%）、IVC（>50%＋掌側半脫位）細分本版未列。

**Zone II**：常合併明顯軟組織傷；**<50% → 副木 1–2 週 → 主動活動**；**>50% → figure-of-8 等縫合**；大量軟組織缺損 → 肌腱移植。

**Zone III：central slip**
- 可出現 **boutonnière**；🆕 **Elson test** 診斷完全 central slip 傷。
- 閉鎖：**單獨 PIP 副木 3–6 週 → 主動活動＋夜間副木 6 週**。
- 開放：懷疑**外傷性 PIP arthrotomy** → 考慮探查；大骨片 → 螺絲或 pin；小骨片或肌腱撕脫 → 中節錨釘；無法直接縫 → 🆕 **central tendon turndown flap**。

**Zone IV**：近節上肌腱寬而薄 → **多為部分撕裂**；DIP 與 PIP 伸直保留 → PIP 伸直副木 3–6 週；有伸直缺損 → 縫合或局部肌腱 flap＋副木保護。

**Zone V**：包括 **fight bite** → 懷疑**外傷性 MCP arthrotomy**；🆕 **受傷時 MCP 屈曲 → 肌腱傷位於皮膚傷近端**；多為部分撕裂，無伸直缺損 → 清創即可；**>50% → 縫合**；考慮 central tendon 穩定與 **sagittal band 修補**。

**Zone VI**：肌腱較厚、可用一般 core 縫合；**juncturae 常掩蓋缺損**；🆕 **juncturae 近端的傷回縮較多**；running interlocking horizontal mattress 可早期主動活動，但無一技術較好。

**Zone VII**：在 retinaculum 下 → **粘連與臃腫修補卡住風險高**；🆕 **至少保留部分 retinaculum 防弓弦**；滑動不佳 → **Z 延長 retinaculum**；強 core 縫合以早動。
- 🆕 **遠端橈骨骨折後 EPL 磨損斷裂**：無法直接縫 → **EIP 轉位**。
- 🆕 **第 6 管外傷性斷裂造成症狀性 ECU 半脫位 → 用鄰近 retinaculum 重建第 6 管**。

**Zone VIII**：肌肉肌腱交界 → 近端肌腹抓線困難；**盡量保留筋膜**，利用**肌內腱縫（tendinous raphe）**增加抓力。

### 2.4 伸肌復健 🆕

- 🆕 **腕伸肌傷不需固定手指**。
- 🆕 **Zone V–VIII：動態副木優於靜態**。
- 🆕 **RCT：zone V、VI 用 relative motion extension orthosis（RMO）→ 早期手功能、TAM、滿意度優於 controlled active motion**。

## 3. 肌腱病 🔄

### 3.1 Trigger finger（手指狹窄性屈肌腱鞘炎）🔄

- 🆕 **盛行率 2–3%**；與**糖尿病、RA** 相關；機轉：**A1 pulley 變硬＋屈肌腱增厚**。
- 🆕 **臨床或電生理 CTS 合併率最高 60%**。
- 症狀：A1 處掌側痛、彈響卡住、屈曲鎖死；未處理 → 僵硬、需另一手扳開。檢查：A1 處壓痛或結節、屈曲時 click、鎖死、握力弱；**不需影像**。
- **保守**：
  - 🆕 **副木（固定 MCP、PIP 與 DIP 可屈）：40–87%**（依時間與配合度）。
  - 🆕 **手部治療（FDS 與 FDP 分別滑動）：約 69%（小系列）**。
  - ✅ **注射（屈肌腱鞘、A1 附近）：60–90%**，第一線。
  - 🆕 **效果較差：多指、糖尿病或其他內分泌病、肥胖、病程較長**。
  - 🆕 **2023 全國資料庫：第 2 次注射 79.4%、第 3 次 79.6%** → 復發可再注射。
  - 🆕 **併發症：血糖暫時升高、注射處脂肪萎縮、罕見肌腱斷裂**。
  - 🆕 **注射後 90 天內手術 → 感染風險小幅增加**；🆕 **鄰近手部注射後 90 天內手術也一樣（2025）**。
- **手術**：
  - 開放鬆解最常見（縱、橫或斜切口）；鈍性分到肌腱、保護指神經血管束；**放 A1，必要時放 A0 與近端 25% A2**。
  - 🆕 **2023：A0 pulley 是最多 47% 病人卡住的主因 → 多數病人兩者都應放**。
  - **拇指：橈側神經血管束跨過 A1 → 常用 Bruner 切口**。
  - 🆕 **經皮法：拇指、食指、小指風險明顯較高**（神經血管靠近 A1）。
  - **WALANT**：可請病人動手指確認不再卡；🆕 **資料庫：procedure room 清醒鬆解的併發症可能比 OR 低**。
  - 復發或難治（少見）→ **切除一條 FDS**（減少滑車內體積）。
- ❌ OKU 14 的 Grade I–IV 分級表與「低 vs 高劑量 triamcinolone 6 週無差」本版未列。

### 3.2 FCR 肌腱炎 🆕

- FCR 經 **trapezial ridge 旁獨立纖維骨隧道** → 易因受限或鄰近病變（**CMC 或 STT OA、舊腕骨折**）受傷。
- **掌橈側腕痛，抗阻屈腕＋橈偏加重**；與 CMC、STT 病變重疊且可並存；🆕 **可出現 FCR 鞘內反覆 ganglion（2024）**。
- X 光與 MRI 排除關節炎與韌帶傷，或顯示 FCR 磨損與鞘內積液。
- 保守：NSAIDs、副木、休息、PT；持續 → 注射（診斷＋治療，避開神經血管）；🆕 **主要風險 = 肌腱斷裂**（FCR 斷或 tenotomy 長期缺損很少，但注射長期效果仍有爭議）。
- 手術：**FCR 減壓＋腱鞘切除＋清除磨損**；掌側入路由腕紋到遠端止點；🆕 **保護 palmar cutaneous nerve 分支與 radial artery 淺掌支**；結果一般良好。
- 🆕 **已斷 >50% → FCR tenotomy ± FCR 轉到 palmaris longus（2024）**。

### 3.3 de Quervain 腱鞘炎 🔄

- **第 1 背側管（APL、EPB）**；解剖誘因：**EPB 被隔膜分成 subsheath、APL 多條**。
- 與**懷孕與產後（抱小孩）**、重複橈尺偏（**鎚、越野滑雪、釣魚**）有關；🆕 **女性、糖尿病、RA、lupus、甲狀腺低下風險較高（2022）**。
- 臨床診斷；X 光排除遠端橈骨或腕骨病變（如拇指 CMC OA）。
- 第 1 管背橈側痛腫，**抗阻拇指動作、橈偏與伸直**加重；**Eichhoff 與 Finkelstein test**（拇指屈入掌心、主動或被動尺偏）。
- **保守**：
  - 🆕 **單純副木只有 14–18% 成功**；forearm-based thumb spica 可休息肌腱。
  - PT：活動調整、消腫、肌腱滑動。
  - 🔄 **注射 = 保守主力：62–100%**。
  - 🆕 **2022 全國資料庫：第 1 次注射持久緩解 71.9%、第 2 次 66.3%、第 3 次 60.5%** → 重複注射合理。
- **手術**：
  - 🆕 **2022：只有 11.6% 最終需要手術**。
  - 橫、斜或縱切口；✅ **保護橈淺神經分支**（就在管淺層）；✅ **在管的背側切開 → 減少掌側肌腱脫位**；**處理 EPB 的獨立隔間**。
  - 術後早期活動；併發症少：**掌側半脫位、橈淺神經炎或神經瘤**、殘餘症狀、疤痕。
  - 🆕 **病人對症狀持續時間的負面認知 → 結果較差** → 可考慮 biopsychosocial 介入。

### 3.4 其他伸肌腱鞘炎 🆕

- **第 4 管最常**；見於 **RA 或其他發炎**，也可在局部腕外傷或**遠端橈骨骨折**後（腕僵硬增加伸肌力臂）。
- 受累管痛、壓痛、腫，**強迫伸腕加重**。
- 🆕 **Tuck sign**：伸指時腫塊或滑膜增厚隨肌腱移動、在 retinaculum 處堆積。
- 休息、冰敷、副木、治療、NSAIDs → 注射；持續 → 🆕 **懷疑副肌腱或異常肌肉造成管內擁擠**；難治 → MRI、開放腱鞘切除（增生性腱鞘炎＋伸腕受限者可改善伸腕與握力）。

### 3.5 Intersection syndrome 🔄

- **第 2 管（ECRL、ECRB）腱鞘炎**；🔄 **位於腕關節近端約 5–7 cm**（第 1 管肌腱在淺層跨過第 2 管）。
- 較少見；**划船、網球、舉重**等反覆伸腕運動員；APL、EPB 與 ECRL、ECRB 摩擦。
- 痛、腫、有時 crepitus，**約在腕近端 6 cm** → 與較遠端的 de Quervain 區分；**伸腕＋橈偏**加重。
- 臨床診斷；必要時用**局麻區分注射**或 MRI、超音波與 de Quervain 區分。
- 保守：消炎、休息、活動調整、**副木中立或微伸**；難治 → 第 2 管注射；罕見手術 → **第 2 管鬆解＋腱鞘切除**。

### 3.6 ECU 🔄

- 尺側腕痛常見原因，常與 **TFCC** 混淆。
- **ECU：前臂旋前時為尺偏肌、旋後時為伸腕肌**；提供靜態與動態穩定。
- 兩大病變：**腱鞘炎**與**不穩定**（可並存，但治療不同）。
- **腱鞘炎**：反覆過度使用或特發，握物、伸腕、重活加重；ECU 壓痛，**抗阻尺偏與伸腕痛**；🆕 **尺神經背側支感覺過敏或麻常見**。
- **不穩定**：🆕 **ECU 半脫位可為正常變異**；**症狀性半脫位常在外傷後（球拍運動），旋後時痛性彈響**；評估：**由旋後＋伸直移到屈曲＋尺偏**，看到半脫位或彈響。
- 🆕 **ECU synergy test**：前臂旋後、肘靠桌、手指伸直；檢查者握住拇指與中指，請病人**抗阻將拇指往橈側外展** → **ECU 處痛 = 陽性**（區分 ECU 病變與 TFCC 等關節內病變）。
- 影像：X 光看 ulnar variance；**動態超音波與 MRI** 區分腱鞘炎與 TFCC。
- **治療**：休息、活動調整、PT、消炎；副木或 **wrist widget**（休息或增加穩定）；注射小心**不要打進肌腱（斷裂）或皮下（色素脫失）**。
- 手術：腱鞘炎 → **第 6 管縱切口鬆解＋腱鞘切除**，可做 retinacular flap 修補；不穩定 → 縫合、錨釘修補或重建（2024 結果良好）；🆕 **ECU subsheath 重建通常用鄰近 extensor retinaculum 做 pulley 防復發**。

## 5. Key Study Points（OKU 15）

- 屈肌與伸肌腱傷的處理**依解剖分區**而定；了解解剖才能在手術中重建肌腱間的原生關係。
- **直接修補至少 4 股 core suture**，降低再斷並允許較快活動以防粘連；**加股數或 epitendinous 可增加強度與滑動**。
- **較強的修補方式使早期主動活動協定成為可能**，可能加快力量與 ROM 恢復。
- 若能改善修補後滑動，應**審慎 vent 滑車**。
- 手腕肌腱病常見，**多可靠病史與檢查診斷**；多數經**休息、支具、類固醇注射**改善；難治者需手術，**最常是鬆解病因處**。

## 6. Anki 候選題

1. FDS 在前臂的淺層與深層各供應哪些手指？→ 淺層：中、無名；深層：食、小。
2. 腕隧道內屈肌腱由掌側到背側的順序？→ 中、無名 FDS → 食、小 FDS → FDP 與 FPL。
3. 哪個 pulley 與難治 trigger finger 有關？→ A0（掌腱膜）。
4. 拇指的 pulley？→ A1、A2、oblique＋不定的 Av。
5. 屈肌腱鞘感染擴散到前臂的空間？→ Parona space。
6. 屈肌腱癒合三期與時間？→ 發炎 48–72 小時；增生 2–28 天；重塑 1–4 個月。
7. 屈肌腱修補至少幾股 core？建議線徑？→ 4 股；3-0（比 4-0 強）。
8. Epitendinous 縫合可增加多少強度？→ 10–50%。
9. 修補處兩側需要多少肌腱？結打在哪？→ 各 7–10 mm；修補處外。
10. Jersey finger 最常見手指？→ 無名指。
11. Leddy-Packer type I 回縮位置、vincula 與修補時限？→ 手掌；VLP 與 VBP 都斷；7–10 天。
12. Leddy-Packer type II 回縮位置與修補時限？→ PIP（VLP 保留）；可延到 6 週。
13. Leddy-Packer type III 處理？→ 大骨片卡在 A4；先固定骨片再修腱。
14. Leddy-Packer type IV 與 V？→ IV：骨片＋肌腱另外撕脫回縮；V：合併 P3 粉碎骨折。
15. FDP 撕脫固定方式哪種較快回工作？→ suture anchor（但無一證明較好）。
16. Jersey finger 未治療 >6 週、PIP 功能好時？→ 可保守；DIP 痛 → DIP 融合或 tenodesis。
17. Zone II 多少比例撕裂可修邊不縫？→ <50%。
18. 多少 A2 與 A4 可切而無臨床弓弦？→ A4 全部、A2 最多 2/3。
19. 如何估計 A2 需 vent 的長度？→ 修補處到 A4 近端緣的距離。
20. Zone II 滑動不佳時對 FDS 的處理？→ 切除一條 FDS 或只修一條。
21. Zone III 修完應考慮放哪些滑車？→ A0 與 A1。
22. Zone IV 屈肌腱傷應同時做什麼？→ 腕隧道鬆解。
23. Zone V 多條肌腱修補順序？→ 由深到淺。
24. 部分屈肌腱撕裂的三個處理切點？→ <1/3 修邊；33–60% 只 epitendinous；>60% core 縫合。
25. 屈肌腱重建的適應症？→ 慢性或 zone II 失敗、手指柔軟、無神經血管缺損。
26. PIP 功能好的慢性 FDP 傷，替代重建的選擇？→ DIP 融合。
27. 兩期重建第一期常同時重建哪些滑車？間隔多久？→ A2、A4；6–8 週。
28. 取代 Pulvertaft weave 的新縫合法？→ side-to-side。
29. 屈肌腱修補後功能改善可持續多久？→ 至少 1 年。
30. Cochrane 對屈肌腱復健協定的結論？→ 證據品質低，無法推薦特定協定。

32. 屈肌腱再斷裂率最高？→ 8.7%。
33. Lumbrical plus 的原因與表現？→ graft 太鬆；屈曲時 PIP、DIP 反常伸直。
34. Quadriga 的原因與風險切點？→ 修補太緊；前移 >1 cm。
35. 伸肌腱傷最常見的手指？→ 拇指。

37. 連動 PIP 與 DIP 屈伸的韌帶？→ ORL（Landsmeer）。
