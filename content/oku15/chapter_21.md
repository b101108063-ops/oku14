## 1. OA 是全關節疾病

- 過去視為 wear-and-tear；現為 **whole-joint disease**：軟骨破壞、骨重塑、骨刺、關節發炎
- **哪個組織最先受影響仍不清楚**
- Chondrocyte 平衡：**anabolism（ECM 合成）vs catabolism（MMP、aggrecanase 分解）**
- MMP 受發炎因子刺激，參與受傷後的 **autodébridement** 期

### 1.1 Nav1.7（新）
- **電壓門控鈉通道 Nav1.7**：原屬感覺神經疼痛訊號，**也表現在非興奮性的 chondrocyte**
- **人類 OA 軟骨中上調**；**TNF、IL-1β 增加其表現**
- **刪除 chondrocyte Nav1.7 → 軟骨流失、疾病嚴重度、疼痛行為↓**；**DRG 神經元 Nav1.7 → 負責疼痛感知**
- **選擇性抑制劑 PF-04856264 與 carbamazepine（FDA 核准非選擇性鈉通道阻斷劑）→ 小鼠 OA 進展減緩、疼痛減輕**
- → **同時 disease-modifying 與止痛的雙重標的**

## 2. Synovitis

- 滑膜變化：**纖維化、肥厚、發炎**
- 小鼠：DMM 後**軟骨退化程度與 synovitis 正相關**
- **MRL/MpJ「superhealer」小鼠**（不易得創傷後 OA）：**gut microbiome 與 synovitis 減少相關，保護作用可經菌相移植轉移**（2024）
- **Fibroblast = 正常與 OA 滑膜中最多的細胞**；產生 ECM 與滑液成分
- Synovial fibroblast 分泌 **IL-1β、TNF-α → chondrocyte MMP↑**；並維持 synovitis

### 2.1 單細胞定序發現（新）
- **ACL 斷裂後**：**Thy1⁻ PRG4⁺ lining fibroblast**（可能源自 **DPP4⁺ 間葉前驅細胞**）分泌 **R-spondin 2（Wnt agonist）**
  - → 促使 **Sox9⁺ osteochondral progenitor** 走向**成骨表型**
  - → 經鄰近 fibroblast 的 **LGR4–6** → 分泌因子使 monocyte/macrophage 走向 **M1**；軟骨生成基因↓、肥大基因↑
- 關節面損傷模型：**PRG4⁺ fibroblast → 成熟 FLS → lining hypertrophy** → 促免疫細胞浸潤、血管新生與神經生長
- **Mast cell → tryptase β 切斷 PRG4（lubricin）** → **失去潤滑**，且切割產物經 **TLR 活化 NF-κB**（chondrocyte、fibroblast、macrophage）

## 3. 發炎介質

### 3.1 Cytokines
- 相關：**TNF-α、IL-1β、IL-6、IL-15、IL-17、IL-18、IL-21、LIF**
- **IL-1β 與 TNF-α 為核心**
  - 促 **MMP-1、-9、-13** → 分解 collagen 與 aggrecan
  - **抑制 type II collagen 與 aggrecan 合成**
  - 招募活化 macrophage、T cell；**fibroblast 增生與 pannus**
  - 誘導 **NO、PGE₂、IL-6**、chemokine
- **Anti-IL-1β、anti-TNF-α 在 OA 臨床試驗皆無效**，可能原因：
  1. **兩者平行、冗餘** → 單一標的不足
  2. **全身給藥關節滲透差**
  3. 在**晚期 OA** 才評估
- **MMP 抑制劑**：無效或毒性不可接受
- 方向：**局部、控制釋放**、**同時針對多種 cytokine**

### 3.2 TNFR1 vs TNFR2 與 PGRN（新，作者團隊研究）

| | **TNFR1** | **TNFR2** |
|---|---|---|
| 作用 | **促發炎、異化** | **保護、再生** |

- **Progranulin（PGRN）**：天然 **TNF/TNFR1 拮抗劑**＋**TNFR2 配體**；**對 TNFR2 親和力約為 TNF-α 的 600 倍**
  - → **Treg 分泌 IL-10**、調控 macrophage 極化抑制 synovitis、促合成抑異化
- **Atsttrin**：由 **3 個 PGRN 的 TNFR 結合片段**組成的工程蛋白；小鼠與兔 OA 模型有效（2024）
  - **選擇性結合 TNFR → 避免 anti-TNF 的全身副作用**

### 3.3 Chemokines

| Chemokine | 作用 |
|---|---|
| **IL-8** | 滑液濃度與**臨床嚴重度相關**；促 MMP-1、-9、-13 |
| **CCL2（MCP-1）** | 滑液中升高 → **MMP-3↑** → PG 流失 |
| CCL3、CCL4、CCL5 | 上調、促發炎 |
| **CCR5** | **CCR5 缺陷小鼠對創傷後 OA 軟骨侵蝕有部分保護** |
| **CXCL12（SDF-1）** | **招募間葉前驅 → 促修復**（chemokine 的雙面角色） |

- 受體：CCR1、CCR2、CCR3、CCR5

### 3.4 Growth Factors

| 因子 | 角色 |
|---|---|
| **TGF-β** | 維持軟骨恆定，但也促**骨刺與滑膜纖維化** |
| **FGF2、FGF8、FGF18** | 軟骨維持、與 OA 進展相關；**關節內 rhFGF18 臨床試驗中** |
| **VEGF** | 發炎滑膜產生 → 血管新生、免疫細胞浸潤；**動物模型抑制 VEGF 有益** |
| **NGF** | 影響 monocyte 發炎反應；**NGF 抑制劑 tanezumab、fulranumab 顯著減輕 OA 疼痛** |

- 風險：**不想要的骨形成**、生長因子全身擴散

### 3.5 ROS
- 過量 → oxidative stress → 經 **PI3K/AKT、MAPK、NF-κB** 加重滑膜發炎與軟骨退化
- 證據：OA 體液與軟骨中 **oxidized LDL、nitrite、nitrotyrosine、nitrate**；**SOD、catalase、glutathione peroxidase↓**
- **關節內 ROS 清除生物材料**可減緩 OA

## 4. Innate Immunity

### 4.1 Pattern Recognition Receptors
- **TLR、NOD receptor** 結合 PAMP 與 **ECM 釋出的 DAMP** → **NF-κB、MAPK** → 異化因子（cytokine、chemokine、MMP、complement）↑，合成因子↓
- **ECM 分解片段經 TLR2 與 NOD2** 觸發人類 chondrocyte 發炎與異化
- **抑制 TLR4** → 大鼠 chondrocyte type II collagen↑、MMP-13↓；體內 macrophage、neutrophil 浸潤↓、軟骨退化↓
- **NOD/RIPK2 路徑**：人類 coding variant 與**家族性早發 OA** 相關；**Ripk2 單一胺基酸變異小鼠受傷後極易 OA** → 重要危險因子

### 4.2 Complement
- C1–C9；OA 滑液與滑膜中升高
- **C5 與 C6 缺陷 → DMM 模型 synovitis 與軟骨損傷受保護**
- 藥物阻斷 complement → 手術誘發 OA 受保護；**延緩 Dunkin-Hartley 天竺鼠自發 OA**（2024，C3 抑制阻斷 STAT1）
- FDA 核准藥：**avacopan（C5aR antagonist）**、**APL-2（C3 抑制 peptide）** → 但**尚未用於 OA，因感染風險**

### 4.3 Macrophage
- **OA 滑膜中最多的免疫細胞**；產生 IL-1β、TNF-α、MMP；參與**骨刺形成**
- **M1（促發炎、組織損傷）vs M2（修復、消炎）**
- **OA 膝 M1 為主、M1/M2 比值升高且與嚴重度相關**（單細胞 RNA 定序證實）
- 加強 M1 → DMM 惡化；抑制 M1 → ACLT 與 DMM 軟骨受保護；**M1 → M2 再極化 → collagenase 與 ACLT 模型減輕**
- **重要反直覺發現**：**macrophage 全面清除（MaFIA 小鼠＋AP20187）反而使 OA 惡化** → 全身發炎、CD3⁺ T cell 與 neutrophil 浸潤↑ → 由 macrophage 依賴轉為 **neutrophil 依賴**
  - → **關鍵在 M1→M2 極化轉換失敗，而非 macrophage 數量**

### 4.4 Neutrophil
- **最早浸潤**的免疫細胞之一；分泌 **neutrophil elastase**、cytokine、chemokine
- **Neutrophil elastase 只出現在有 synovitis 的滑膜與滑液**
- 滑膜組織中少，但**滑液中較多**；**neutrophil-to-lymphocyte ratio 高 → 膝 OA 較嚴重**
- Macrophage：慢性發炎、滑膜增生；neutrophil：急性反應、釋放分解酵素

### 4.5 Mast Cell
- 正常滑膜中 macrophage 或 mast cell **約 3%**（哨兵）
- 慢性發炎 → 滑膜增厚、**mast cell 密度顯著上升**；mast cell 數與血管數與 synovitis、嚴重度相關
- 增加血管通透、招募免疫細胞、誘導 MMP
- **Mast cell 分泌高量 NGF → 感覺痛覺纖維新生、周邊與中樞敏感化** → 慢性痛；**anti-NGF 減少大鼠發炎與神經纖維新生**
- 釋放酵素**加速 hyaluronic acid 降解**
- **Palmitoylethanolamide（PEA）** 生理性抑制 mast cell；OA 中內源 PEA↓ → mast cell 過度活化
- **Adelmidrol（PEA 增強劑）＋HA** → 軟骨退化、mast cell 浸潤、cytokine 下降；止痛與功能改善（臨床前＋臨床）

## 5. Adaptive Immunity

### 5.1 T cell
- **OA 滑膜浸潤免疫細胞：macrophage 約 65%、T cell 約 22%、B cell 約 5%**
- T cell 集中於發炎滑膜區；**fat pad** 浸潤也較多
- **Th1、Th17↑，Treg↓**（**早期 OA 即可見**）
- **滑液 Treg/Th17 比例失衡與嚴重度相關**（2023）
- OA 病人 T cell **in vitro 可攻擊自體 chondrocyte**
- **CD4 T cell 缺陷 → 小鼠 ACLT OA 減少**
- **抗軟骨分子自體抗體**（type II collagen、proteoglycan、aggrecan）存在於血清與滑液 → **OA 是 multiantigenic 發炎疾病** → 可用關節內**抗原特異性免疫調節**
- **滑膜 Treg 少 → 疼痛與失能較重**（2022）
- **含 type II collagen＋rapamycin 的奈米顆粒 → 誘導 collagen II 特異性 Treg** → 免疫耐受、浸潤↓、軟骨退化↓（DMM 小鼠）
- **淋巴結**：ACLT → 關節與引流淋巴結 **Th17 signature** → fibroblast 老化、軟骨退化；機械負荷 → 局部淋巴結 T cell 與 cytokine↑；**阻止 T cell 離開淋巴結 → 減少負荷誘發的軟骨退化**（2024）

### 5.2 B cell
- 僅約 **5%**，研究少
- **Clonal expansion**、抗體產生、與滑膜 cytokine／chemokine 相關（2023）
- **嚴重 OA 滑液中 IL-10⁺ regulatory B cell 較少**
- OA 滑液 B cell **較成熟、類似 plasma cell** → 可能與自體抗體有關

## 6. Neuroinflammation（新）

- 周邊與中樞神經的局部發炎；**與 OA 疼痛相關**（仍在起步）
- 特徵：**glial cell（含 microglia）活化**、**DRG 與 dorsal horn 的 macrophage 浸潤**
- 大鼠 **MIA（monoiodoacetate）** 模型：IL-1β、TNF-α、IL-6 時間依賴性上升並持續數週；小鼠 **IL-6 第 14 天、IL-1 第 21 天**升高
- **NF-κB** 驅動 cytokine 表現與痛覺過敏
- **DRG 浸潤 macrophage（M1 標記）→ 疼痛**；**轉為 M2 → 止痛**
- **MIA 前清除 macrophage → 第 7 天疼痛緩解，但不影響初期疼痛發生** → **DRG macrophage「維持」而非「啟動」OA 疼痛**（myostatin、CXCL11 參與）
- 脊髓神經發炎 → **晚期膝 OA 疼痛慢性化**（類似 neuropathic pain）
- **Supraspinal astrocyte 活化** → 焦慮加重的疼痛行為

## 7. 陷阱與易混淆

1. **Nav1.7 在 chondrocyte 也有表現**；carbamazepine 在小鼠可減緩 OA
2. **Anti-TNF、anti-IL-1 在 OA 臨床試驗無效**（RA 有效）→ 冗餘、滲透差、太晚期
3. **TNFR1 = 發炎；TNFR2 = 保護**；**PGRN 對 TNFR2 親和力約 600 倍**
4. **CXCL12 促修復**；IL-8、CCL2、CCR5 促惡化
5. **Mast cell tryptase β 切 PRG4（lubricin）** → 潤滑喪失＋TLR 活化
6. **Macrophage 最多（65%）**；全面清除 macrophage **反而惡化**；關鍵是 **M1→M2 轉換**
7. **Neutrophil elastase 只見於有 synovitis 的滑膜**；滑液 NLR 高 → 嚴重
8. **Th17↑、Treg↓**；B cell 約 5%、嚴重者 IL-10⁺ Breg↓
9. **NOD/RIPK2 → 家族性早發 OA**
10. **C5、C6 缺陷保護**；complement 抑制劑因**感染風險**未用於 OA
11. **DRG macrophage 維持（不是啟動）疼痛**
12. **NGF 抑制劑（tanezumab、fulranumab）可減 OA 疼痛**
13. OKU 14 Ch.20 的 RA biologic、術前停藥、疫苗、checkpoint 內容不在本章

## 8. Key Study Points（OKU 15）

- OA 主要特徵為**慢性低度發炎**，在疾病起始與進展扮演關鍵角色
- 先天與後天免疫及滑膜發炎的交互作用，顯著造成 OA 關節組織退化
- **Neuroinflammation** 是新興關鍵因子，影響疼痛感知與疾病嚴重度
- Chondrocyte、synovial fibroblast 與免疫細胞動態交互，持續維持發炎與組織破壞
- 了解 OA 免疫發炎機轉，有助發展標靶治療
