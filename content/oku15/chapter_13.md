## 1. 骨的類型與結構

- 形狀分類：long、short、flat、sesamoid（patella）、irregular（vertebra、sacrum）
- **皮質骨約 80%**、**海綿骨約 20%** 的成熟骨骼
  - 皮質骨：osteon（haversian system）＋ Volkmann canal 相連；外覆 periosteum、內襯 endosteum
  - 海綿骨：代謝較活躍 → **礦物含量較低、較多孔**；主要在 epiphysis 與椎體
- Periosteum 富含血管、神經、osteoblast、osteoclast 與間葉前驅細胞 → 骨形成與生長的關鍵
- Flat bone = 兩層緻密骨夾一層海綿骨

## 2. 骨基質（ECM）— 數字題

| 成分（重量比） | 比例 |
|---|---|
| 有機（osteoid） | 25%–30% |
| 無機（hydroxyapatite 為主） | 50%–70% |
| 水 | 5%–10% |
| 有機中 type I collagen | **85%–90%**（少量 III、V 型） |
| 有機中 NCPs | 10%–15% |

> **Pitfall**：OKU 14 Ch.14（力學章）用的是「HA 40%／collagen 35%／水 25%」的力學框架；本章是「有機／無機／水」重量比。看清楚題目問的是哪一組。

**NCP 四大類**
1. **Proteoglycans**（SLRPs：biglycan、decorin、fibromodulin）— GAG 帶負電吸水，影響力學；調控生長因子可用性
2. **Gla proteins**（vitamin K 依賴羧化）
   - **Osteocalcin（OCN）**：骨中最多的 NCP、**只由 osteoblast 表現**；排列 HA 晶體
   - 吸收陷窩低 pH → OCN 去羧化入血 → **undercarboxylated OCN 結合 GPRC6A** → 調控醣類與脂肪代謝（骨的內分泌功能）
   - Matrix Gla protein：**防止軟組織異位鈣化**
   - Periostin：collagen fibrillogenesis、osteoblast 黏附存活
3. **Glycoproteins**
   - **ALP**：水解 pyrophosphate → 提供 inorganic phosphate；多以 GPI anchor 掛在 osteoblast 膜上
   - RGD 蛋白（osteonectin/SPARC、fibronectin、thrombospondin）：經 integrin 調控細胞；**植入物表面加 RGD peptide** 促進整合
4. **SIBLINGs**：BSP-II、OPN（osteopontin）— 直接參與 HA 沉積

- 外源 NCP（cytokine、GF）結合在基質時為非活性，**骨吸收時釋放活化**
- **Warfarin（vitamin K antagonist）抑制骨基質蛋白羧化 → 抑制礦化**

## 3. 骨細胞

| 細胞 | 比例／來源 | 考點 |
|---|---|---|
| Osteoblast | 4%–6%；MSC 來源 | **RUNX2 = master regulator**；BMP＋RUNX2 → **osterix（SP7）**；RUNX2＋SP7＋ATF4 → COL1、OPN、BSP-II、ALP、OCN |
| Osteocyte | **90%–95%（最多）** | lacuna–canaliculi、gap junction；**unloading → RANKL↑、sclerostin（SOST）↑**；loading → sclerostin↓ → WNT/β-catenin↑；osteocyte apoptosis 是 osteoclast 趨化訊號 |
| Bone-lining cell | 靜止的 osteoblast | 可能阻擋 osteoclast 接觸基質；可分泌 OPG、RANKL |
| Osteoclast | 造血 myeloid（monocyte/macrophage）來源 | **PU.1 = myeloid master regulator**（＋MITF、RUNX1）；M-CSF → c-Fms → RANK 表現；RANKL → **NFATc1**、NF-κB、AP-1 |

- **RUNX1 雙向角色（新）**：早期 myeloid 分化必需，但**晚期抑制 osteoclast 分化與功能**
- **OPG = RANKL decoy receptor**（stromal cell、osteoblast、osteocyte 分泌）
- **Clastokines**（osteoclast 分泌，促骨形成）：SLIT3、CT-1、CTHRC1、WNT5A
- MSC 可分化為 myocyte（MRF/MEF2）、chondrocyte（SOX5/6/9）、adipocyte（PPARγ）、osteoblast

## 4. 骨發育

- **Endochondral**：大多數骨；軟骨 anlage → 中央 chondrocyte 肥大 → 血管／osteoprogenitor／osteoclast 入侵 → primary ossification center；epiphysis 有 secondary center；growth plate 負責縱向生長
- **Intramembranous**：flat bone；**無軟骨模板**，由中央 ossification center 放射狀鈣化
- Woven bone（膠原排列紊亂）→ 逐漸由 **lamellar bone（排列整齊、強度高很多）** 取代

## 5. 骨恆定與重塑（新版核心）

- Peak bone mass：**約 20 歲出頭**（第二個十年末）
- 成人骨骼**約每 10 年完全更新一次**
- 重塑單位：**BMU（bone multicellular unit）** 於 **basic remodeling compartment** 進行

**Remodeling 五期**

| 期 | 事件 |
|---|---|
| 1. Activation | 激素、GF、IL 或結構損傷招募 osteoclast 前驅；osteocyte apoptosis 釋放 **CXCL12（SDF-1）→ CXCR4** |
| 2. Resorption | lining cell 掀起形成 **canopy**；integrin 結合 → **sealing zone**；lysosome 融合成 **ruffled border**（V-ATPase proton pump、**CLCN7**）；酸溶 HA → MMP、**TRAP、cathepsin K** 消化有機質；產物經 **transcytosis** 排出 |
| 3. Reversal | osteoblast 系 **reversal cell** 清除殘渣並沉積 **cement line（富含 OPN）** |
| 4. Formation | osteoblast 分泌 collagen＋NCP，啟動礦化 |
| 5. Termination | osteoblast 凋亡／變成 lining cell／埋入成 osteocyte |

**Coupling 分子**
- **Ephrin B2（osteoclast）–EphB4（osteoblast）**：雙向訊號 → osteoclastogenesis↓、osteoblast 分化↑
- **RANKL reverse signaling（新）**：膜上 RANKL 當受體，促 osteoblast 分化
- 吸收釋放基質中的 **TGF-β1、IGF-1** → 招募 MSC 分化為 osteoblast

## 6. 全身調控（cross-talk）

| 因子 | 來源／刺激 | 對骨與礦物的作用 |
|---|---|---|
| **PTH** | 低血鈣（次要：高磷） | 腎鈣再吸收↑、腎磷再吸收↓、活化 vit D↑；osteoblast/osteocyte 上 **PTH1R → RANKL↑、OPG↓**；**間歇低劑量 → 合成作用**（降低 sclerostin、DKK1；誘發 ephrin B2）→ **teriparatide** |
| PTHrP | 間葉細胞（autocrine/paracrine） | 軟骨成熟、osteoblast 分化 |
| **Vitamin D** | 皮膚 UVB → 肝 calcidiol → **CYP27B1** → calcitriol | 腸道鈣磷吸收↑、腎鈣再吸收↑；**轉運與羥化需要 magnesium**；CYP27B1 受 PTH、FGF23、Ca、P 調控；osteocyte 上 VDR → 抑制 PTH 與 FGF23（負回饋） |
| **FGF23** | osteoblast／osteocyte，**高磷刺激** | 腎 **FGFR1 ＋ coreceptor α-Klotho** → 磷再吸收↓、vit D 合成↓；骨內經 **FGFR3** 降低 ALP |
| **Calcitonin** | 甲狀腺，高血鈣 | osteoclast 上受體 → **ruffled border 消失** → 停止吸收 |
| Estrogen | — | osteoclastogenesis↓、osteoclast 凋亡↑、osteoblast 凋亡↓ |
| Testosterone | — | 骨形成作用比 estrogen 強 → **男性皮質骨較多、骨小梁較厚、BMD 較高** |
| Gut hormones | 腸道內分泌細胞 | collagen cross-linking↑、osteoclast 分化↓（GLP-1 等糖尿病／肥胖藥物研究中） |
| Microbiota | — | 部分菌分泌 **β-glucuronidase → 活化 estrogen**；dysbiosis → 腸壁通透↑、發炎、活性 estrogen↓ → 骨吸收↑ |
| Immune／nervous | — | IL-17、IL-6、IL-1、TNF-α 調控 osteoclast/osteoblast；骨分泌 N-cadherin、angiopoietin、RANKL 維持 HSC niche |

## 7. 影響骨健康的疾病

- **>500 個基因**的突變可造成骨骼疾病
- Metabolic bone disease 為**第三常見的內分泌疾病**；DXA 的 BMD **無法區分**病因

### 7.1 Table 1 速記

| 疾病 | 表現 | 機轉／基因 |
|---|---|---|
| Osteoporosis | 骨量與礦物↓ | 吸收 > 形成；多因子 |
| Rickets／Osteomalacia | 礦化不足 | vit D 生成／代謝／吸收不足、CKD／肝病、**FGF23、PHEX**；生長板未閉合 = rickets，閉合後 = osteomalacia |
| Hyperparathyroidism | 礦化與骨量↓ | PTH↑，**最常見為良性 parathyroid adenoma** |
| **Hypophosphatasia** | 礦化缺陷 | **ALP 突變** → pyrophosphate 無法轉成 inorganic phosphate |
| OI | 骨脆 | COL1A1/COL1A2 或膠原加工基因（SERPINF1、IFITM5、CRTAP、PPIB、SERPINH1、BMP1、SP7、WNT1、SPARC、MESD 等） |
| **Osteopetrosis** | 骨量與密度↑ | osteoclast 分化（**TNFSF11/RANKL、TNFRSF11A/RANK**）或基質降解（**CA-II、CLCN7、TCIRG1**、OSTM1、SNX10、PLEKHM1） |

### 7.2 Osteoporosis

- 定義：**T score < −2.5**；osteopenia：−1.0 至 −2.5
- 50 歲以上：**女性 1/3、男性 1/5**；女性較易得，**男性進展較嚴重**；hip fracture 1 年死亡率高
- 主要危險因子：**年齡、性別、種族**（2023 研究：**白人女性風險最高**）；其他：vit D 不足、活動少、吸菸、酗酒
- 續發性：diabetes、CKD、hyperthyroidism、celiac、自體免疫、遺傳病
- 藥物：**glucocorticoid、SSRI**、甲狀腺藥物、癌症治療、抗癲癇藥 → osteoclast 功能↑；**warfarin → 礦化↓**
- Bisphosphonate：一線；**長期儲存在骨基質中，停藥後仍持續作用**；ONJ、AFF

### 7.3 骨質疏鬆藥物總表（Table 2）

| 類別 | 藥物 | 機轉 | 主要副作用 |
|---|---|---|---|
| 抗吸收 | Bisphosphonates | pyrophosphate 類似物 → 進入 osteoclast → 凋亡 | ONJ（高劑量癌症病人） |
| | **Denosumab** | anti-RANKL mAb | **AFF、ONJ** |
| | Raloxifene | SERM | **VTE** |
| | Calcitonin（Miacalcin） | 抑制 ruffled border | 副作用少但效果差 |
| | **Odanacatib** | cathepsin K 抑制劑 | 腦血管事件與骨折↑ → **已退出試驗** |
| 合成 | **Teriparatide** | 重組 PTH 片段 | 高血鈣、高尿鈣 |
| | **Abaloparatide** | 合成 PTHrP 類似物 | 高血鈣 |
| | **Romosozumab** | anti-sclerostin mAb | **MI、stroke、心血管死亡↑** |
| 其他 | Estrogen（HRT） | osteoclast 凋亡、osteoblast 存活 | MI、stroke、PE、乳癌 |
| | **Burosumab** | anti-FGF23 mAb | 注射反應、頭痛；無長期資料 |

- Romosozumab：歐美核准用於**高骨折風險的停經後重度 osteoporosis**；sclerostin 抑制也會增加骨吸收
- 抗吸收與合成藥物**依序合併**治療具潛力（2023）

### 7.4 Osteogenesis Imperfecta

- Type I collagen = **2 條 α1 ＋ 1 條 α2** 三股螺旋；**每第三個位置為 glycine**（Gly-X-Y，**338 個重複**）
- **>80%** 病人為 COL1 基因**點突變，最常見是 glycine 被置換** → 蛋白滯留 ER → ER stress／細胞死亡，或三股螺旋結構異常
- Procollagen 胞外切除 **P1NP（N 端）與 P1CP（C 端）** → **P1NP = 骨形成血清標記**
- **22 型**（AD、AR、**X-linked**）；同一突變表現型差異大 → 有其他修飾因子
- **沒有標靶治療**，常用 bisphosphonate

## 8. 陷阱與易混淆

1. **Osteocyte 才是最多的骨細胞（90%–95%）**，osteoblast 只有 4%–6%
2. **OCN 只由 osteoblast 表現**；去羧化型才具內分泌活性
3. **PU.1 = osteoclast 系 master regulator；RUNX2 = osteoblast master regulator**；RUNX1 早期促進、晚期抑制 osteoclast
4. **Cement line 富含 OPN**，由 reversal cell 沉積，不是 osteoblast 直接形成
5. **FGF23 作用於腎臟需要 α-Klotho**；FGF23 是由**骨**分泌，不是腎
6. PTH 的 **連續 vs 間歇**：連續 → 吸收；間歇低劑量 → 合成
7. Osteopetrosis 是**高 BMD 但骨脆**；DXA 高 ≠ 骨好
8. **Hypophosphatasia（ALP 突變）** vs **hyperphosphatemia** 不要混
9. **Romosozumab 有心血管警示**；**denosumab 也有 AFF 風險**，不只 bisphosphonate

## 9. Key Study Points（OKU 15）

- 骨骼組織來自幹細胞：osteoblast 來自 MSC（亦可分化為 myocyte、chondrocyte、adipocyte）；osteoclast 來自 HSC 的 myeloid 系（monocyte/macrophage）
- 骨恆定靠 osteoblast／osteoclast 平衡，受局部與多器官全身因子調控
- 骨具內分泌功能：醣類與能量代謝、腎臟磷再吸收
- 吸收與形成失衡 → 代謝性骨病（骨質差、骨折風險↑）
- 治療分抗吸收（bisphosphonate）與合成（重組 PTH、anti-sclerostin）
