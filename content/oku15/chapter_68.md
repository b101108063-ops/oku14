| 🆕 **流行病學與胚胎** | 胚胎軸向與發育不全的機轉 | 🔄 🆕 **美國大型族群：約 3／1,000 活產**；🆕 **肢芽 day 26（第 4 週）開始 → 約 day 52（第 8 週）**；lateral plate mesoderm（骨、軟骨、肌腱前驅）、somatic mesoderm（肌、神經、血管）、外胚層；Hox、FGF、BMP、Wnt、retinoic acid、Shh；✅ **AER（FGF）→ 近遠軸；破壞 → 橫向缺損**；✅ **ZPA（Shh，尺側後緣）→ 橈尺軸；破壞 → 尺側缺損**；✅ **非 AER 外胚層（Wnt）→ 背腹軸** | 🔄 |
| 🆕 **OMT 分類** | — | 🆕 **IFSSH 採用 Oberg-Manske-Tonkin**（發育生物、遺傳、分子）；🆕 **malformation（發育或分化失敗；再分全肢或手板與受累軸）—最常見；deformation（正常發育後受損，如 amniotic band）；dysplasia（組織型異常：生長如 macrodactyly、腫瘤性如 hemangioma、NF、osteochondromatosis、攣縮如 camptodactyly、arthrogryposis）；syndrome（Apert、Poland、Fanconi）** | 🆕 |
| 🆕 **病人中心照護** | 臨床檢查與團隊合作原則 | 🔄 🆕 **偏好用語：「limb difference」而非 deformity 或 abnormality**；🆕 **2023：照顧者關注未來期待與下一步治療；醫師著重病因與心理社會影響** | 🔄 |
| **Preaxial polydactyly** | Flatt-Wassel 分型 | 🔄 ✅ **Wassel-Flatt；🆕 type IV 最常見**；多為偶發，🆕 **可伴 Holt-Oram、Fanconi、Rubinstein-Taybi**；評估各指大小、活動、穩定與病人偏好；🆕 **手術延到 12–24 個月**（OKU 14：約 9–12 個月）；🆕 **多切除最橈側指＋spare parts 重建保留指**；🆕 **type II、IV：切除近節或掌骨頭多餘面，保留副韌帶近端附著；以切除指的副韌帶重建優勢指 IP 或 MCP 副韌帶**；暫時 pin；或 **Bilhaut-Cloquet** 合併兩半；🆕 **結果多良好，但殘餘變形或不穩再手術率相對高** | 🔄 |
| **Postaxial polydactyly** | — | 🆕 **最常見多指**；🆕 **type A：形成良好、骨性連接 → 伴 ectodermal dysplasia（Ellis-van Creveld）等；type B：發育不全、軟組織連接 → 非裔較常、不伴他病、AD 變異外顯**；🆕 **A：spare parts＋UCL 重建 ± abductor digiti minimi 轉移**；🆕 **B：早期切除；傳統縫線結紮已不流行 → 門診局麻（lidocaine＋epinephrine）切除**，依蒂寬可吸收線縫合或雙極電燒 → 殘留 nubbin 與症狀性神經瘤較少 | 🆕 |
| **Syndactyly** | 最常見先天手差異約 1／2,000；男 2 倍；6 個月後至 2 歲前；邊緣指 9 個月前 | 🔄 AER 控制分指；🆕 **雙側尺側邊緣指併指 → Timothy syndrome（長 QT、無心臟防護時術中心臟事件高，2024）**；✅ **complete vs incomplete；simple（軟組織）vs complex（骨性融合、synonychia）vs complicated（非典型骨）**；🆕 **long-ring 最常 > index-long > ring-little > thumb-index**；🆕 **約 50% 雙側、男性較多**；🔄 **18–24 個月釋放（減少 web creep 與翻修）**；🆕 **背側皮瓣約近節長 2/3 重建 commissure；交錯皮瓣；可無植皮，但多需全層植皮（兩指周長和小於分開兩指）；可用 dermal substitute**；synonychia 重建甲襞；🔄 **長度不同的邊緣指 → 3–6 個月早釋放（防較長指關節攣縮）**；thumb-index → 背側旋轉皮瓣；🆕 **多指蹼 → 分期，任一指兩側不同時釋放（血供），間隔 3–6 個月：如先 1、3 蹼，再 2、4 蹼**；🆕 **Apert：可用直線釋放（symphalangism、IP 少活動）達五指手** | 🔄 |
| 🆕 **Amniotic band** | 羊膜帶症候群（與裂手、巨指同節） | 🔄 🆕 **與其他併指區別：近端 fenestration＋殘餘 constriction band**；病因不明；🆕 **造成神經血管危害的 band → 出生數天內釋放**；🆕 **連續 Z-plasty 或切除＋間斷 Z-plasty；通常一次釋放半圈、6–12 週後另半圈（部分可一次）**；🆕 **acrosyndactyly：3–6 個月釋放遠端 ± 全層植皮**；之後可再分離、指蹼重建 | 🔄 |
| 🆕 **Symbrachydactyly** | — | 🆕 從短指到 U 型非典型裂手、單指、無指；多為孤立，🆕 **可伴 Poland（胸大肌胸骨頭缺如）**；🆕 **中胚層喪失、外胚層保留 → 形成 nubbins**；🆕 **Foucher 分類（I–IV）**；🆕 多不需手術；nubbin 反覆甲溝炎 → 切除；🆕 **功能最大化：拇指＋post（可對捏的指或手的一部分）**；distraction 延長；🆕 **缺 post → 血管化趾移植** | 🆕 |
| **Cleft hand** | V 型；25–40% 合併症候群；雙側常伴足 | 🔄 ✅ **V 型（vs symbrachydactyly 的 U 型）**；🆕 **常為遺傳、多 AD**；功能多佳但有社會烙印；可不手術；🆕 **手術：cleft 閉合＋併指釋放，通常 18–24 個月；有拴住的併指或裂中有橫向掌骨 → 早切（橫向掌骨生長會撐寬裂）**；🆕 **Snow-Littler 皮瓣把裂皮移到 thumb-index web**；index 轉位、掌骨截骨、橫向掌骨間韌帶重建；皮瓣壞死；翻修：web 變緊、MCP 不穩、進行性 camptodactyly、index 過長或偏斜；✅ **Manske-Halikis（thumb-index web）vs Ogino（中央列缺損數）** | 🔄 |
| 🆕 **Macrodactyly** | （與裂手同節） | 🆕 **指的 fibrofatty 過度生長**；可伴 **lipofibromatous hamartoma**、神經鞘瘤或 🆕 **PIK3CA 突變**；🆕 **PIK3CA 相關過度生長 → Wilms tumor；考慮每 3 個月腹部超音波至 8 歲（有爭議）**；static vs progressive；🆕 **PIK3CA 抑制劑可減緩過度生長，長期效果與毒性未明，由腫瘤科處理、限嚴重者**；🆕 **手術：debulking＋生長調控 → 讓指長到同性家長大小再做 epiphysiodesis**；部分截肢；🆕 **易 hypertrophic 或 keloid 疤痕**；常需多次 | 🆕 |
| **Camptodactyly** | 約 30% 近節指骨頭背側扁平 | 🔄 **矢狀面先天屈曲，多在 PIP**；對稱、小指最常；🆕 **2022 三型：infantile（I）、adolescent（II）、syndromic（III）**；屈伸力失衡；X 光：近節頭扁平、中節基部適應性向掌側半脫位；🆕 **Bouvier maneuver：被動屈 MCP 再被動伸 PIP → 判斷屈肌緊度與可矯正性**；🆕 **幼兒副木效果佳，生長期需密追，副木至骨成熟**；🆕 **手術：嚴重（>60°）、固定、保守失敗、影響功能**；🆕 **禁忌：明顯指骨頭扁平、治療配合差**；Z-plasty、旋轉皮瓣；FDS、lateral band、volar plate 釋放、副韌帶延長；背側 closing wedge 或 PIP 融合；併發症常見 | 🔄 |
| **Clinodactyly** | — | ✅ **冠狀面成角，多雙側小指**；🆕 **>10° 定義**；中節最常（短、梯形或三角）；小指向橈側偏（apex ulnar）；拇指受累 → 近節，Apert、Rubinstein-Taybi；🆕 **bracketed（C 型）epiphysis = delta phalanx**，<3 歲難看；🆕 **副木無效 → 觀察**；🆕 **20° 可提供手術，通常保留給 >30–40°**；🆕 **切除 bracket 及／或截骨；切 bracket 後隨生長矯正 → 應 <6 歲手術** | 🔄 |
| **Trigger thumb** | （扳指症與彈響指） | 🔄 IP 屈曲變形；FPL 與腱鞘生長不匹配；固定屈曲、伸直鎖住或卡；MCP 代償過伸；可雙側；🆕 **Notta node（MCP 掌側硬結）**；🆕 **自然病程：約 30% 自癒（多為 IP 屈曲 <30°）；初診 >30° → 自癒僅 2.5%，手術合理**；🆕 **A1 pulley 開放釋放，成功率高；小心橈側神經血管束（極近）** | 🔄 |
| **Trigger finger** | 兒童發生率約拇指 1/10 | 🔄 🆕 **少見 → 想到 JIA、代謝（mucopolysaccharidoses）、Down syndrome、解剖異常**；可多指或雙側；A1 或 A3 壓痛；較少固定鎖住；🆕 **解剖：FDS 交叉較近端、FDS 與 FDP 關係異常、異常肌肉**；🆕 **保守第一線（痛少、可矯正）**；🆕 **手術：A1 釋放＋常切除 FDS 尺側束 ± A3 釋放；用 extensile Brunner 而非成人切口**；多不需 PT | 🔄 |
| **RLD** | **Bayne-Klug（含 James 與 Goldfarb）**；type IV 最多 27% | 🔄 ✅ **Bayne & Klug with James modification（N、0、I–V）**；🆕 **OMT：malformation，前後軸**；男較多；✅ **相關症候群：Fanconi、TAR、Diamond-Blackfan、Holt-Oram、Pierre-Robin、VACTERL**；🆕 **Table 3：Holt-Oram（AD，心臟 → 心超）、Fanconi（AR，aplastic anemia → CBC、DEB 染色體脆性、BMT）、VACTERL（偶發 → 脊柱片、心超、腹部超音波）、TAR（AR → CBC）**；🆕 **肘無主動屈伸時，腕橈偏對手到嘴與中線很重要**；🆕 **出生即伸展副木**；🆕 **輕或無橈骨缺損＋嚴重拇指發育不全（CMC 不穩、Blauth IIIB–V）→ index pollicization**；🆕 **肘功能佳＋腕明顯橈偏 → centralization（背側旋轉或 bilobed 皮瓣、尺骨截骨、ex-fix、橈骨延長）**；外觀手術需慎（會改變功能） | 🔄 |
| **拇指發育不全** | Blauth＋Manske | ✅ **Blauth＋Manske IIIA／IIIB**：I 較小、不需治療；II 加窄 web、thenar 發育不全、UCL 不穩 → **opponensplasty（FDS III 或 IV）、MCP UCL 重建、web 加深**；IIIA（CMC 穩）→ 同 II；**IIIB（CMC 不穩）、IV（pouce flottant）、V（缺如）→ pollicization（若尚未形成尺側抓握偏好）** | ✅ |
| **ULD** | 尺側手指多達 90%；拇指異常達 70%；併指多達 30% | 🔄 ✅ **ZPA–Shh 破壞**；🆕 **1–7.4／100,000 活產；80% 單側**；🆕 **手受累 93%**；橈骨頭脫位、radiohumeral synostosis（重型）；🆕 **伴 PFFD、腓骨缺損、側彎**；🆕 **過去認為不伴內科病，但 2024 registry：20% 有共病、8% 心臟異常 → 需小兒科心臟評估**；✅ **modified Bayne：0 限手、I 輕度發育不全（遠近骨骺完整）、II 部分缺如（近端尺骨存在）、III 尺骨完全缺如但橈骨直、IV 完全缺如＋anlage 致橈骨彎、V 完全缺如＋radiohumeral synostosis**；🆕 **處置：web 加深、併指釋放、拇指掌骨去旋轉截骨；進行性尺偏 → anlage 切除；旋前旋後與肩內旋固定 → 旋轉截骨** | 🔄 |
| **Congenital RUS** | CRUS 手術策略 | 🔄 ✅ 胎兒橈尺為同一旋前軟骨 anlage，由遠往近分節失敗；🆕 **20% 家族史、60–80% 雙側**；🆕 **高度伴症候群、性染色體異常、內臟異常 → 完整檢查**；肩、radiocarpal、midcarpal 代償 → 常學齡才發現；X 光近端骨性融合；🆕 **纖維性融合罕見需 MRI**；✅ **只有極度旋前（>60°）且功能受損才手術**；🆕 **切除融合恢復旋轉結果不佳 → 前臂旋轉截骨至輕度旋前**；🆕 **急性矯正 → 血管危害、神經缺損、腔室症候群** | 🔄 |
| 🆕 **先天橈骨頭脫位** | — | 🆕 軟骨病、骨骺骨化異常、橈尺生長不成比例；偶發或家族；單或雙側；🆕 **伴 ulnar dysplasia、RUS、先天尺骨假關節、OI、nail-patella**；常較晚出現痛或 ROM 限制、青少年外側突起；🆕 **X 光：凸的脫位橈骨頭、capitellum 發育不全、橈骨頸彎曲、近端尺骨彎增加**；🆕 **後方 65%、前方 18%、外側 17%**；🆕 **需與外傷後（如 Monteggia malunion）區分：外傷後需重新對位，先天通常不需**；嬰兒期發現可考慮復位；🆕 **有症狀 → 橈骨頭切除：改善痛，但不改善屈伸、旋前旋後僅輕度改善**；近端橈骨再生、進行性尺側變化致腕痛 | 🆕 |
| 🆕 **Madelung** | — | 🆕 **遠端橈骨幹骺：尺側傾斜增加、lunate fossa angle 增加、月骨下沉、腕骨掌側移位、ulnar positive**；🆕 **病因：增厚的短 radiolunate ligament（Vickers ligament）起於遠端橈骨掌尺側幹骺 → 掌尺側 physis 生長障礙**；偶發或 AD；🆕 **多雙側、女性 4 倍**；🆕 **評估兄弟姊妹（影像可先於症狀）**；🆕 **Leri-Weill dyschondrosteosis、MHE、Ollier → 遺傳轉介**；青少年腕背屈受限、ulnocarpal impaction 痛；晚期遠端尺骨背側半脫位突出；早期 MRI 看 Vickers；🆕 **輕度無症狀 → 觀察；生長仍多 → Vickers 釋放＋遠端橈骨 physiolysis ± guided growth；晚期骨性變形 → 遠端橈骨截骨及／或尺骨縮短＋epiphysiodesis** | 🆕 |
| **BPBI** | 3 個月探查；可等到 6 個月；6 個月未恢復 = neurotmesis；標靶神經轉移至 18 個月 | 🔄 🆕 **美國 16 年發生率下降；0.9／1,000 活產**；🆕 **危險因子：過期妊娠、妊娠糖尿病、產鉗或真空、LGA（>4.5 kg）、缺氧、肩難產；但至少一半無危險因子；剖腹產風險較低**；✅ **Narakas**：🆕 **1：C5–6（上幹、最常見、多 postganglionic）、肩功能與屈肘缺損、近 80% 極佳恢復**；🆕 **2：C5–7，加 wrist drop、肘與 MCP 伸直缺損，約 60% 良好恢復**；**3–5：global（C5–T1），差在 Horner（preganglionic、交感鏈）有無、暫時或持續**；🆕 **Narakas 1、2 最重要：抗重力屈肘的時間；約每月由有經驗者評估（Active Movement Scale）**；🆕 **肌骨後遺症：肩內旋攣縮與 GH dysplasia（半脫位或脫位）→ 首診即教外旋與外展伸展；subscapularis 或囊釋放、肌腱轉移、botulinum toxin、肩 spica 石膏；超音波或 MRI 評估**；🔄 **上幹：6 個月未恢復抗重力屈肘 → 可神經轉移（median 及／或 ulnar 多餘 fascicles → biceps、brachialis；spinal accessory → suprascapular（外旋）；radial → axillary（外展））**；🆕 **嚴重 global → 3–6 個月行 brachial plexus 重建或 extraplexal 神經轉移** | 🔄 |
| 🆕 **Arthrogryposis** | — | 🆕 **多發先天關節攣縮；AMC（amyoplasia）vs distal arthrogryposis（只手足）**；🆕 **AMC 典型：肩內旋、肘伸直、前臂旋前、腕屈尺偏、thumb-in-palm、camptodactyly、髖脫位、膝伸直、嚴重 clubfoot**；🆕 **出生即治療（伸展、副木、石膏），第一年可大幅改善**；🆕 **手術：先處理肘 → triceps 延長＋後囊釋放，達 90° 被動屈曲（手到嘴）**；腕：掌側釋放、背側肌腱轉移、腕骨截骨 → 被動伸到中立；thumb-in-palm：皮膚釋放、局部皮瓣、屈肌延長 ± MCP 穩定；camptodactyly：掌側皮膚延長 ± 肌腱延長；少數肱骨或前臂去旋轉截骨（掌對掌） | 🆕 |

## 1. 流行病學、胚胎與分類 🔄

### 1.1 流行病學 🆕

- 真實盛行率可能未知；許多孩子功能影響小、無合併病。
- 🆕 **美國大型族群研究：約 3／1,000 活產**。

### 1.2 肢體發育 🔄

- 🆕 **第 4 週（day 26）開始**：lateral plate mesoderm（骨、軟骨、肌腱前驅）＋somatic mesoderm（肌、神經、血管前驅）＋外胚層聚集。
- 調控：轉錄因子（**Hox**）、生長因子（**FGF、BMP**）、訊號（**Wnt、retinoic acid、Sonic Hedgehog**）。
- 🆕 **肢芽生長持續到第 8 週（約 day 52）**，沿三軸：

| 軸 | 控制中心 | 訊號 | 破壞 → |
|---|---|---|---|
| **近遠（proximodistal）** | **AER（肢芽遠緣外胚層增厚）** | **FGF** | **橫向肢體缺損** |
| **前後（橈尺）** | **ZPA（尺側後緣中胚層）** | **Shh** | **尺側缺損** |
| **背腹** | **非 AER 外胚層** | **Wnt** | 背腹異常 |

### 1.3 OMT 分類 🆕

- 🆕 **IFSSH 採用 Oberg-Manske-Tonkin（OMT）**，依發育生物、遺傳與分子生物分類：

| 類別 | 定義 | 例 |
|---|---|---|
| **Malformation** | **正常發育或分化失敗**；再分全上肢或手板，並指定受累軸 | **最常見**（RLD、ULD、拇指發育不全、多指、併指…） |
| **Deformation** | **正常發育後才受傷** | **amniotic band sequence** |
| **Dysplasia** | **某組織型的異常發育** | 生長異常（**macrodactyly**）、腫瘤性（**hemangioma、NF、osteochondromatosis**）、攣縮（**camptodactyly、arthrogryposis**） |
| **Syndrome** | 伴上肢異常的診斷 | **Apert、Poland、Fanconi anemia** |

### 1.4 病人中心照護 🆕

- 提供準確診斷與功能期待；🆕 **建議用描述性詞彙如「limb difference」，避免 deformity、abnormality**。
- 🆕 **2023：初診時照顧者關注「未來期待與下一步治療」，醫師則著重「病因與心理社會影響」**。

## 2. 多指與併指 🔄

### 2.1 Preaxial polydactyly 🔄

- 橈側；✅ **Wassel-Flatt 分類**；🆕 **type IV 最常見**。
- 多偶發；🆕 **可伴 Holt-Oram、Fanconi anemia、Rubinstein-Taybi**。
- 評估各指大小、活動、穩定；觀察孩子玩玩具時偏好用哪一指。
- 🔄 **手術通常延到 12–24 個月**（OKU 14：約 9–12 個月）。
- 🆕 **多數切除最橈側指，並以 spare parts 重建保留指**：
  - **type II、IV：切除近節（II）或掌骨頭（IV）的多餘關節面，保留副韌帶近端附著**。
  - **以被切除指的副韌帶重建優勢指的 IP 或 MCP 副韌帶**；需要時暫時 pin。
  - 或以 **Bilhaut-Cloquet** 合併兩半成一指。
- 🆕 **結果多良好，但殘餘變形或不穩的再手術率相對高**。

### 2.2 Postaxial polydactyly 🆕

- 🆕 **尺側，最常見的多指**。

| Type | 特徵 | 相關 | 處置 |
|---|---|---|---|
| 🆕 **A** | **形成良好，與手有骨性連接** | **ectodermal dysplasia（如 Ellis-van Creveld）等遺傳病** | 同 preaxial：**spare parts＋UCL 重建 ± abductor digiti minimi 轉移** |
| 🆕 **B** | **發育不全，軟組織連接** | **非裔較常；不伴其他疾病；AD、外顯不一** | **早期切除** |

- 🆕 **type B：傳統縫線結紮已不流行 → 門診局麻（lidocaine＋epinephrine）切除**；依蒂寬以可吸收線縫合或雙極電燒 → **殘留 nubbin、症狀性神經瘤較少**。

### 2.3 Syndactyly 🔄

- 兩指以上未分開（AER 控制）；可孤立、遺傳或伴他病。
- 🆕 **雙側尺側邊緣指併指 → Timothy syndrome：長 QT、若無心臟防護術中心臟事件率高（2024）**。
- ✅ **分類**：

| 面向 | 類型 |
|---|---|
| 範圍 | **complete（全長）vs incomplete** |
| 程度 | **simple（只有軟組織）、complex（骨性融合、synonychia）、complicated（非典型骨構造）** |

- 🆕 **最常受累：long-ring web > index-long > ring-little > thumb-index**。
- 🆕 **約 50% 雙側；男性較多**。
- 🔄 **通常 18–24 個月釋放 → 減少 web creep 與翻修**（OKU 14：6 個月後至 2 歲前）。
- 🆕 **技術**：
  - **背側皮瓣，長約近節 2/3 → 重建 commissure**。
  - **交錯皮瓣 → 減少疤痕攣縮**。
  - 部分可無植皮；🆕 **但多需全層植皮（併在一起的兩指周長小於分開兩指周長之和）**；可用 dermal substitute。
  - synonychia → 分開並重建甲襞。
- 🔄 **長度不同的邊緣指 → 早期（3–6 個月）釋放**，避免較長指被拴住而關節攣縮（OKU 14：9 個月前）。
- thumb-index → **背側旋轉皮瓣**。
- 🆕 **多個指蹼 → 分期：不可同時釋放任一指兩側（血管危害）；間隔 3–6 個月**；例：全指併指 → **先 1、3 指蹼，再 2、4 指蹼**。
- 🆕 **Apert syndrome：可用直線釋放取代 zigzag 交錯皮瓣達成五指手**（常 symphalangism、IP 少活動，2024）。

## 3. Deformation 與其他手板異常 🔄

### 3.1 Amniotic band syndrome 🔄

- 肢體纏入羊膜 → **constriction band、指或肢體完全缺失、acrosyndactyly**。
- 🆕 **與其他併指的區別：近端 fenestration（窗孔）；殘餘 constriction band 為 hallmark**。
- 病因不明。
- 🆕 **造成血管或神經危害的 band → 出生後數天內釋放**。
- 🆕 **連續 Z-plasty，或切除 band＋間斷 Z-plasty**；🆕 **通常一次處理一半圓周，6–12 週後再處理另一半**（部分可一次）。
- 🆕 **acrosyndactyly → 3–6 個月釋放遠端指，視需要全層植皮**；之後可再近端分離、指蹼重建、釋放。

### 3.2 Symbrachydactyly 🆕

- 表現廣：**短指 → 非典型 U 型裂手 → 單指 → 無指**。
- 多孤立；🆕 **可伴 Poland syndrome（胸大肌胸骨頭缺如＋上肢異常）**。
- 🆕 **機轉：中胚層喪失、外胚層保留 → 形成外胚層成分（nubbins）**。
- 🆕 **Foucher 分類**：

| Type | 定義 |
|---|---|
| **I** | 所有骨與指存在（brachydactyly） |
| **IIA** | ≥2 指、拇指正常、手指發育不全 |
| **IIB** | 功能性邊緣指、中央不等 nubbins |
| **IIC** | spoon hand：拇指與發育不全尺側指相連 |
| **IIIA** | 單指、拇指正常 |
| **IIIB** | 單指、拇指發育不全、穩定不一 |
| **IVA** | peromelic、有腕活動、無拇指 |
| **IVB** | peromelic、無腕活動、無拇指 |

- 🆕 **多數不需手術**；nubbin 反覆甲溝炎 → 可切除；有併指 → 釋放。
- 🆕 **整體手功能最大化需「拇指＋post」**（拇指可對捏的另一指或手的一部分）。
- 可用 **distraction osteogenesis 延長指**；🆕 **缺 post → 血管化趾到手移植**。

### 3.3 Cleft hand 🔄

- ✅ **V 型裂（symbrachydactyly 為 U 型）**；區分很重要：🆕 **cleft hand 常為遺傳，多為 AD**。
- 功能多佳，但可能有社會烙印；可不手術。
- 🆕 **手術：cleft 閉合＋併指釋放，通常延到 18–24 個月**。
  - 🆕 **例外：有拴住的併指，或 cleft 內有橫向掌骨 → 橫向掌骨生長會使裂變寬 → 早期切除**。
- 🆕 **Snow-Littler 皮瓣：把 cleft 的皮膚轉到 thumb-index web space**。
- 另可 **index 轉位、掌骨截骨、橫向掌骨間韌帶重建**以縮小裂。
- 併發症：**皮瓣壞死**；翻修：**web 變緊、MCP 不穩、進行性 camptodactyly、index 列過長或偏斜** → 長期追蹤。
- ✅ **Manske-Halikis（thumb-index web）**：I 正常、IIA 輕度變窄、IIB 中度變窄、III thumb-index 併指、IV 拇指併入裂；✅ **Ogino（中央列缺損數）**：無缺列 → 1 列 → 2 列 → 3 列 → 4 列。

### 3.4 Macrodactyly 🆕

- 🆕 **指的 fibrofatty 過度生長**；孤立或廣泛過度生長的一部分。
- 🆕 **可伴：神經的 lipofibromatous hamartoma（受累神經分布區過度生長）、神經鞘瘤、PIK3CA 突變**。
- 🆕 **PIK3CA 相關過度生長症候群可發生 Wilms tumor → 考慮每 3 個月腹部超音波直到 8 歲（仍有爭議）**。
- **static vs progressive**。
- 🆕 **PIK3CA 藥物抑制**可減緩過度生長，長期結果與毒性未明；**由腫瘤科處理，目前限於嚴重病例**。
- 🆕 **手術**：debulking＋生長調控：
  - 🆕 **讓指長到同性家長的大小，再做 epiphysiodesis** ± debulking。
  - 部分情況截肢可帶來整體功能好處。
  - 🆕 **易形成 hypertrophic 或 keloid 疤痕 → 規劃切口時考慮**。
  - 結果不一、常需多次（尤其 progressive）→ **術前期待管理關鍵**。

## 4. 指的攣縮與偏斜 🔄

### 4.1 Camptodactyly 🔄

- 🆕 **矢狀面先天屈曲，最常在 PIP**；多對稱、**小指最常**、多孤立；可多指或伴症候群。
- 🆕 **2022 三型：infantile（I）、adolescent（II）、syndromic（III）**。
- 機轉爭議：屈伸力失衡（肌腱結構或附著異常、異常或殘餘肌腱、循環）。
- 臨床：輕者功能限制小；重者影響大抓握、戴手套、打字。
- X 光：**近節指骨頭扁平、中節基部適應性、向掌側半脫位**。
- PE：雙側對稱、掌側皮膚軟組織不足、PIP 屈曲 ± MCP 過伸。
- 🆕 **Bouvier maneuver（幼兒）：被動屈 MCP → 被動伸 PIP → 判斷屈肌緊度與可矯正性**；青少年可能已僵硬。
- 治療：
  - 🆕 **infantile：副木效果好；生長期易惡化需密追；副木通常持續到骨骼成熟**。
  - 🆕 **手術：嚴重（>60°）、固定、伸展與副木失敗、造成功能限制**。
  - 🆕 **禁忌：明顯指骨頭扁平、治療配合差**。
  - 關節形態保留＋掌側皮膚不足 → **Z-plasty 或局部旋轉皮瓣**；深部：**FDS、lateral bands、volar plate 釋放、副韌帶延長**；骨性：**指骨頭背側 closing wedge 截骨或 PIP 融合**。
  - 併發症常見：無改善、僵硬、復發、神經血管傷。

### 4.2 Clinodactyly 🔄

- **冠狀面成角，最常雙側小指**；可為症候群、AD 或孤立。
- 🆕 **>10° 成角定義 clinodactyly**；縱向生長改變所致。
- **中節最常受累**，短、梯形或三角形；**小指向橈側（ring 指方向）偏，apex ulnar**。
- 拇指受累 → 多在近節，見於 **Apert、Rubinstein-Taybi**。
- 🆕 **X 光：bracketed（C 型）epiphysis = delta phalanx，或拴住的骨骺板；<3 歲難看到**。
- 🆕 **副木改善有限 → 觀察**。
- 🆕 **手術**：bracketed epiphysis 或嚴重偏斜影響功能；**20° 即可提供，但通常保留給 >30–40°**。
  - **切除 epiphyseal bracket 及／或指骨截骨**。
  - 🆕 **切除 bracket 後隨生長逐漸矯正 → 應在 <6 歲進行**。
  - 告知：神經血管傷、僵硬、疤痕、沾黏、復發。

### 4.3 小兒 trigger thumb 🔄

- **拇指 IP 屈曲變形**；遺傳與後天皆有；普遍接受 **FPL 與腱鞘生長發育不匹配**。
- 表現：**固定屈曲、IP 鎖在伸直、或卡住**；MCP 代償過伸；可雙側。
- 🆕 **Notta node：MCP 掌側可觸及的硬腫**。
- 🆕 **自然病程**：

| 初診 IP 屈曲 | 自癒 |
|---|---|
| **<30°** | **約 30%（多在此組）** |
| 🆕 **>30°** | **只有 2.5% → 手術合理** |

- 🆕 **手術：開放釋放拇指 A1 pulley，成功率高**；風險罕見：復發、僵硬、🆕 **神經血管束傷 → 橈側束極近，須仔細分離保護**。

### 4.4 小兒 trigger finger 🔄

- 第 2–5 指，**少見**；🆕 **應想到潛在診斷：JIA 等發炎、代謝（mucopolysaccharidoses）、Down syndrome、其他解剖異常**。
- 可多指或雙側；**A1 或 A3 壓痛**；典型卡住或不均勻活動；🆕 **不像 trigger thumb 常見固定鎖住**。
- 🆕 **解剖因素：FDS 交叉較近端、FDS 與 FDP 關係異常、異常肌肉**。
- 長期 IP 攣縮或懷疑骨性病因 → X 光。
- 🆕 **保守第一線（痛少、可矯正的卡住）：伸展、副木、觀察**。
- 🆕 **手術：A1 釋放，常同時切除 FDS 尺側束 ± A3 釋放**；🆕 **需較延伸的 Brunner 切口（非成人切口），以確保完全解決並評估病因**。
- 傷口癒合後即可活動，多不需正式治療。

## 5. 縱向缺損 🔄

### 5.1 Radial longitudinal deficiency（RLD）🔄

- 又稱 radial dysplasia、radial clubhand；**橈側光譜性缺損**：肱骨、橈骨、腕骨、拇指（拇指發育不全），以及前臂、手、肘的神經血管與肌肉。
- 🆕 **OMT：malformation，前後軸模式異常（2022）**。
- 男性較多；病因（遺傳、環境）未定。
- ✅ **相關症候群：Fanconi anemia、TAR、Diamond-Blackfan anemia、Holt-Oram、Pierre-Robin、VACTERL** → **必須完整 PE、遺傳諮詢、全面檢查**。

| 症候群 | 遺傳 | 臨床 | 檢查 |
|---|---|---|---|
| **Holt-Oram** | **AD** | **心臟異常（VSD 等）**、三指節拇指、肱骨缺損 | **心臟超音波** |
| **Fanconi anemia** | **AR** | **aplastic anemia、急性骨髓衰竭** | **CBC；DEB 染色體脆性測試**（保留給身材矮小或典型面容者）；**骨髓移植** |
| **VACTERL** | **偶發** | 脊椎、肛門閉鎖、心臟、氣管食道瘻、腎、肢體 | **脊柱 X 光（較大時）、心超、腹部超音波** |
| **TAR** | **AR** | **血小板低下** | **CBC** |

- ✅ **Bayne & Klug（James modification）**：

| Type | 肱骨 | 近端橈骨 | 遠端橈骨 |
|---|---|---|---|
| **N** | 正常 | 正常 | 正常（只有拇指發育不全或缺如） |
| **0** | 正常 | 正常、RUS 或先天橈骨頭脫位 | 正常（腕骨缺如、發育不全或融合） |
| **I** | 正常 | 正常、RUS 或橈骨頭脫位 | **比尺骨短 >2 mm** |
| **II** | 正常 | 發育不全 | 發育不全 |
| **III** | 正常 | 不等發育不全 | **physis 缺如** |
| **IV** | 正常 | **缺如** | **缺如** |
| **V** | **近端異常** | 缺如 | 缺如 |

- 嚴重型：**腕明顯橈偏**（腕骨橈側缺支撐）；肘可能無功能。
  - 🆕 **肘無主動屈伸時，腕橈偏對「手到嘴」與「手到中線」很重要**。
- 治療依嚴重度；**外觀手術需慎重（會改變功能）**。
  - 🆕 **出生即開始伸展與副木**。
  - 手術目標：前臂、腕、拇指的穩定與對位 → 抓握、捏取。
  - 🆕 **輕或無橈骨缺損＋嚴重拇指發育不全（CMC 不穩，Blauth IIIB–V）→ index pollicization**。
  - 🆕 **肘功能良好＋腕明顯橈偏 → wrist centralization**：骨與軟組織技術（**背側旋轉或 bilobed 皮瓣、尺骨截骨、ex-fix、橈骨 distraction 延長**）。

### 5.2 拇指發育不全 ✅

- 可孤立、伴 RLD 或症候群；OMT：malformation（前後軸）。
- 表現：抓握、捏取、對捏無力；thenar 小或缺、**UCL 不足致 MCP 不穩**、外在肌腱缺陷、web 變窄、殘餘或完全缺如；拇指較小較僵、缺屈伸紋。
- ✅ **Blauth＋Manske**：

| Grade | 表現 | 手術 |
|---|---|---|
| **I** | 較小，構造完整且有功能 | **通常不需** |
| **II** | 較小、**web 變窄、thenar 發育不全、UCL 不穩** | **拇指重建：opponensplasty（FDS III 或 IV）、MCP UCL 重建、web 加深** |
| **III** | 較小、web 窄、內外在肌發育不全、MCP 全面不穩 | **IIIA（CMC 穩）→ 同 II 重建；IIIB（CMC 不穩）→ pollicization** |
| **IV** | **floating thumb（pouce flottant）** | **pollicization** |
| **V** | **完全缺如（aplasia）** | **pollicization**（若尚未形成尺側抓握偏好） |

- 關鍵分界：**CMC 是否穩定（IIIA vs IIIB）**。

### 5.3 Ulnar longitudinal deficiency（ULD）🔄

- ✅ **ZPA 的 Shh 訊號破壞**。
- 🆕 **罕見：1–7.4／100,000 活產；80% 單側**。
- 🆕 **手受累 93%；拇指異常常見**。
- 重型：**橈骨頭脫位、radiohumeral synostosis**。
- 🆕 **伴其他肌骨異常：PFFD、腓骨缺損、側彎**。
- 🆕 **過去認為不伴內科病；2024 registry：20% 有共病，其中 8% 心臟異常 → 需小兒科心臟評估**。
- ✅ **modified Bayne**：

| Type | 定義 |
|---|---|
| **0** | **限於手** |
| **I** | **輕度發育不全，遠近骨骺完整** |
| **II** | **部分缺如，近端尺骨存在** |
| **III** | **尺骨完全缺如，橈骨直** |
| **IV** | **尺骨完全缺如，有 anlage → 橈骨彎曲** |
| **V** | **完全缺如＋肱骨（radiohumeral）融合** |

- 🆕 **治療**：
  - 拇指：**web 加深、併指釋放、拇指掌骨去旋轉截骨**（優化捏握）。
  - **進行性前臂尺偏 → 尺側 anlage 切除**。
  - **前臂旋轉位置、固定肩內旋 → 旋轉截骨**。

## 6. 前臂與肘 🔄

### 6.1 Congenital radioulnar synostosis（RUS）🔄

- ✅ 胎兒期橈尺骨為**同一軟骨 anlage、位於旋前**，由遠往近分節；**分節失敗 → 不同程度固定旋前**。
- 🆕 **20% 有家族史；60–80% 雙側**。
- 🆕 **高度伴症候群、性染色體異常、內臟異常 → 完整檢查**。
- 以**肩動作、radiocarpal 與 midcarpal 旋轉**代償；腕與肘屈保留 → 🆕 **常到學齡才被老師或家長發現功能受限**。
- X 光：近端橈尺不同程度骨性融合；橈骨頭可異常、缺如及／或脫位；🆕 **罕見纖維性融合需 MRI**。
- ✅ **只有極度旋前（>60°）且有功能缺損才手術**。
  - 🆕 **切除融合以恢復旋轉 → 結果不佳**。
  - ✅ **前臂旋轉截骨 → 重新定位於輕度旋前**。
  - 🆕 **併發症（急性矯正軟組織張力）：血管危害、神經缺損、腔室症候群**。

### 6.2 先天橈骨頭脫位 🆕

- 🆕 **原因**：底層軟骨疾患、骨骺骨化異常、骨骺板外異常骨化、橈尺生長不成比例。
- 偶發或家族；單或雙側；🆕 **常伴：ulnar dysplasia、RUS、先天尺骨假關節、OI、nail-patella syndrome**。
- 🆕 **常較晚出現（肘痛或 ROM 受限）；青少年注意到肘外側骨性突起**。
- 🆕 **X 光：凸的脫位橈骨頭、capitellum 發育不全、橈骨頸彎曲、近端尺骨彎曲增加**。
- 🆕 **方向：後方 65%、前方 18%、外側 17%**。
- 🆕 **與外傷後（如 Monteggia malunion）區分**：**外傷後需重新對位恢復 radiocapitellar；先天通常不需**。
- 嬰兒期發現 → 可考慮復位讓關節重塑。
- 🆕 **多數較晚就醫（已有骨性變形）→ 有症狀者橈骨頭切除**：
  - **改善疼痛；不改善屈伸；旋前旋後僅輕度改善**。
  - 併發症：**近端橈骨再生**、**進行性尺側變化致腕痛**。

### 6.3 Madelung deformity 🆕

- 🆕 **遠端橈骨幹骺一組變化：尺側傾斜增加、lunate fossa angle 增加、月骨下沉、腕骨掌側移位、ulnar positive**。
- 🆕 **病因理論：增厚的短 radiolunate ligament（Vickers ligament），起於遠端橈骨掌尺側幹骺 → 掌尺側 physis 生長障礙**。
- 偶發或 **AD（表現與外顯不一）**。
- 🆕 **多雙側；女性 4 倍**。
- 🆕 **應評估兄弟姊妹**（影像變形可先於症狀）。
- 🆕 **可見於軟骨或骨形成疾患（Leri-Weill dyschondrosteosis、MHE、Ollier）→ 遺傳轉介**。
- 表現：**青少年腕背屈受限、ulnocarpal impaction 痛**；晚期：遠端尺骨過長且背側半脫位 → 背尺側突起。
- X 光符合診斷標準；🆕 **早期變形少 → MRI 證實 Vickers ligament**。
- 🆕 **治療依嚴重度**：

| 情況 | 處置 |
|---|---|
| **輕度、無症狀** | **觀察** |
| **早期、生長仍多** | **Vickers ligament 釋放＋遠端橈骨 physiolysis ± guided growth** |
| **晚期骨性變形** | **遠端橈骨截骨及／或尺骨縮短截骨＋epiphysiodesis** |

- 併發症：矯正不完全或持續變形、不癒合、持續尺側問題。

## 7. 臂神經叢生產傷害（BPBI）🔄

### 7.1 流行病學 🔄

- 圍產期臂神經叢牽拉 → 上肢麻痺。
- 🆕 **美國 16 年間發生率下降；大型系列 0.9／1,000 活產**。
- 🆕 **危險因子：過期妊娠、妊娠糖尿病、產鉗或真空、LGA（>4.5 kg）、出生缺氧、肩難產**；🆕 **但至少一半新生兒 BPBI 無可辨識危險因子**；🆕 **剖腹產風險較低**。

### 7.2 Narakas 分類 ✅

| Group | 根 | 表現 | 預後 |
|---|---|---|---|
| **1** | **C5–6（上幹）** | **最常見、多為 postganglionic**；**肩功能缺損、缺屈肘** | 🆕 **近 80% 極佳恢復** |
| **2** | **C5–7** | 同 1，**加 wrist drop、肘與指 MCP 伸直缺損** | 🆕 **約 60% 良好恢復**（早恢復者類似 Narakas 1） |
| **3–5** | **C5–T1（global）** | **整個上肢完全麻痺**；差別在 **Horner sign 有無、暫時或持續** | 差 |

- 🆕 **Horner（ptosis、miosis、anhidrosis）→ 可能 preganglionic，破壞交感鏈**。

### 7.3 評估 🆕

- 🆕 **Narakas 1、2 最重要的臨床發現 = 恢復抗重力屈肘的時間**。
- 🆕 **出生起約每月由有 BPBI 經驗者評估**；常用 **Active Movement Scale**；重點是**序列檢查**看隨時間變化。

### 7.4 肌骨後遺症 🆕

- 🆕 **肩內旋攣縮＋glenohumeral dysplasia → 半脫位或脫位**。
- 🆕 **首診即教家長外旋與外展伸展**以防攣縮。
- 進階 dysplasia 與外旋喪失：**subscapularis 或囊釋放、肌腱轉移、botulinum toxin、肩 spica 石膏**。
- **肩超音波與 MRI** 都可評估 GH dysplasia（各有優缺點）；🆕 **進行性外旋喪失 → 需進一步檢查**。
- 也需評估肘、前臂、腕、指攣縮。

### 7.5 神經手術 🔄

- 時機仍有爭議。
- 🔄 **上幹受累、6 個月時仍未恢復抗重力屈肘 → 可提供神經轉移**：

| 目標功能 | 神經轉移 |
|---|---|
| **屈肘** | **median 及／或 ulnar 多餘 fascicles → biceps、brachialis** |
| **肩外旋** | **spinal accessory → suprascapular** |
| **肩外展** | **radial → axillary** |

- 🆕 **嚴重 global 傷 → 臂神經叢重建或 extraplexal 神經轉移；因良好自然恢復機率低，通常 3–6 個月手術**。
- ❌ OKU 14 的「**3 個月探查**」「**6 個月仍無恢復＝neurotmesis**」「**標靶神經轉移可至 18 個月**」本版未以相同方式陳述。

## 8. Arthrogryposis 🆕

- 🆕 **多發先天關節攣縮**；兩類：**arthrogryposis multiplex congenita（AMC，amyoplasia）** 與 **distal arthrogryposis（只限手足）**。
- 🆕 **AMC 典型攣縮**：**肩內旋、肘伸直、前臂旋前、腕屈與尺偏、thumb-in-palm、手指 camptodactyly、髖脫位、膝伸直、嚴重 clubfoot**。
- 🆕 **出生即早期診斷與治療：伸展、副木及／或石膏；第一年可大幅改善，減少手術需求**。
- 🆕 **手術：攣縮治療無改善或停滯於不可接受範圍**：

| 部位 | 處置 |
|---|---|
| 🆕 **肘（通常最先）** | **triceps 延長＋後囊釋放 → 達 90° 被動屈曲（手到嘴）** |
| **腕屈** | **掌側組織釋放、背側肌腱轉移、及／或腕骨截骨 → 被動伸到中立** |
| **thumb-in-palm** | **拇指皮膚釋放＋局部皮瓣、屈肌腱延長、± MCP 穩定** |
| **camptodactyly** | **掌側皮膚延長 ± 肌腱延長** |
| 少數 | **肱骨及／或前臂去旋轉截骨 → 掌對掌功能** |

- 先天手差異常伴**心臟、腎臟、血液及／或症候群**異常 → **常需遺傳轉介或檢測**。
