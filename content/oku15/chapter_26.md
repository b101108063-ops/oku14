## 1. 固定時機 🆕

- 與髖部骨折一樣，**早期確定性固定 → 併發症少、ICU 與住院短**；**老人與共病者尤其重要**
- **2024 NTDB（>6,000 位 >60 歲需手術的髖臼骨折）：入院到手術每多 1 天，併發症 odds +7%**（有選擇偏差：傷勢重者較常延遲）
- **穩定病人建議 48 小時內確定性固定**
- 結果高度依賴復位品質 → **為了等骨盆專家而短暫延遲是合理的**
- 過去建議**前方入路延後**以減少出血；**4 篇研究**：失血結果不一、**輸血無差異** → **前方入路不應只因擔心出血而延後**（2023）

## 2. 圍術期出血與 VTE 🆕

- **TXA**：在關節置換與髖部骨折可減少出血且不增加 VTE；但**骨盆骨折手術證據弱：2023 MA（5 篇）估計失血與輸血皆無差異**
- **Autologous cell salvage**：**ASA 建議失血可能 >500 mL（或 >10% 血容量）的手術使用**
  - 開放髖臼固定常超過此量；cell salvage 平均回輸**約 1 單位**
  - **前方入路失血可達 2,000 mL → 應考慮 cell salvage**（2024）
- **VTE 化學預防**
  - **AAST：術前不要停（腦或脊椎手術除外）**
  - 「等待手術」是外傷病人漏打最常見的原因；**漏打多劑 → VTE odds 8 倍**
  - 多篇研究：**術前給予不影響失血或輸血**

## 3. 術中與術後影像 🆕

- **2024（髖臼）：術後 CT 發現的翻修適應症 15.5%** → 值得做
- **3D fluoroscopy**：比術中 CT 方便
  - **2023 連續病例：12% 因 3D fluoroscopy 而受益**（確認關節復位、找出關節內游離體、發現植入物位置不良）

## 4. 骨盆環損傷

### 4.1 初始評估 🆕
- 急診 AP 骨盆片
- **檢查開放傷口，排除會陰隱匿開放傷**；出血多 → **無菌紗布填塞**
- **直腸或陰道出血 → 可能隱匿開放骨折**
- **血尿或尿道口出血 → CT cystography**（尿道、膀胱）
- **記錄骶神經根功能**
- **AP、inlet、outlet** 片
- 🆕 **所有病人都做 CT，包括看似單純的恥骨支骨折**（通常合併後環損傷）
- 🆕 **雙側骶骨骨折 → 懷疑橫向骶骨骨折 → spinopelvic dissociation**；**軸切 CT 可能看不出 → 必須看矢狀面**

### 4.2 血流動力學不穩定 🆕
- **骨科急症**；**死亡率約 30%，30 年來一直沒降**（2023）
- 移位＋失血性休克 → **床單或 binder**
- 進手術室做其他緊急手術時 → **改為外固定**（方便照護、避免壓傷）
  - **Supra-acetabular pin 優於 iliac wing pin**（穩定與復位較好）
- **binder 後仍休克 → 緊急血管攝影與栓塞**
- **PPP**：作為第一線與栓塞效果相近，但**前側骨盆感染與 VTE 較多** → **留給無法立即做血管攝影、正在大出血者**
- **Zone 3（腎下）REBOA**：可能比 resuscitative thoracotomy＋主動脈夾閉傷害小
  - **2022 病例系列：主要併發症 54%（筋膜切開、截肢、深部感染）、院內死亡 48%** → **留給有失血致死風險的嚴重休克**
- 🆕 **2023（>1,000 創傷中心、1,396 位不穩定骨盆骨折接受止血介入）**

| 項目 | 數值 |
|---|---|
| 院內死亡 | **36%** |
| Angioembolization | **55%**（最常用） |
| PPP | 47% |
| Zone 3 REBOA | 9% |
| **唯一降低死亡的介入** | **Angioembolization** |
| PPP | **併發症增加** |

- **多數死亡不是骨盆出血造成**，而是頭、胸、腹部損傷（2024）

### 4.3 分型 🆕

**Tile**

| Type | 穩定性 |
|---|---|
| A | 穩定 |
| B | 旋轉不穩 |
| C | 旋轉＋垂直不穩 |

**Young-Burgess（受力方向）**

| 型 | 定義 |
|---|---|
| **APC1** | 恥骨聯合分離 **<2.5 cm**、**前 SI 韌帶完整** |
| **APC2** | **>2.5 cm**、**前 SI 韌帶斷裂** |
| **APC3** | **前＋後 SI 韌帶斷裂** |
| **LC1** | **骶骨骨折＋恥骨支骨折** |
| **LC2** | **髂骨翼骨折（crescent fracture）**取代骶骨骨折 |
| **LC3** | LC 型＋**對側 APC**（常為隱匿，CT 上 SI 可無移位 → 需高度懷疑） |
| VS | 垂直不穩 |
| Combined | 混合 |

- APC 1 → 3 嚴重度遞增；🆕 **LC1–3 不代表嚴重度遞增**，每型都涵蓋從輕微穩定到嚴重不穩

**AO/OTA 61（2018）**：結合 Tile 與 Young-Burgess，表達不穩程度與側別 → 適合研究
- **A：後環完整**（單純 innominate 骨折、**S3 以下**橫向骶骨骨折）
- **B：後環不完全斷裂** → B1 無旋轉不穩、B2 單側旋轉不穩、B3 雙側旋轉不穩
- **C：後環完全斷裂** → C1 單側、C2 雙側（B＋C）、C3 雙側 C

**骶骨骨折**

| 分型 | 內容 |
|---|---|
| **Roy-Camille**（橫向骶骨骨折，矢狀面移位） | 1 無移位、2 成角、3 完全移位、4 嵌插 |
| **Denis**（縱向骨折線與孔的關係） | **1 孔外側、2 經孔、3 孔內側** |
| **AOSpine** | A：低位 sacrococcygeal，不破壞後環；**B：縱向骶骨骨折** → **B1 孔內側、B2 孔外側、B3 經孔**；**C：雙側** → C0 無移位 U 型、C1 單側 B 型合併同側 L5-S1、C2 雙側 B 型、C3 移位 U 型 |

- 🆕 **AOSpine B1／B2／B3 的神經損傷率約 0–1%／5%／25%**（順序與 Denis 不同，因為依神經損傷機率排列）

> **Pitfall**：**Denis 3 = 孔內側（神經損傷最高）**；**AOSpine B1 = 孔內側（神經損傷最低 0–1%）**。兩者編號方向不同，AOSpine 的 B3 是**經孔**（25%）。

### 4.4 Stress Imaging 🆕
- 輕微移位骨盆環傳統保守、結果好，但部分會移位形成難治的 malunion 或 nonunion；部分病人長期臥床
- **EUA 動態不穩**：輕微移位看似穩定的 **APC1 50%、LC1 37%、LC2 63%**
- EUA 限制：需麻醉、手術室、醫師、施力不標準、透視難客觀測量；多只對高風險（完整骶骨骨折、高能量）做
- 🆕 **LC 骨折動態不穩的唯一獨立相關因子：恥骨支骨折粉碎**
- 🆕 **EUA 替代方式**

| 方法 | 特點 |
|---|---|
| **Lateral stress radiograph** | 側臥 AP 片；**不需鎮靜或醫師在場**；以重力與體重施力；可客觀測量 |
| **Supine ED stress radiograph** | 不需鎮靜或側臥；但施力主觀（同 EUA） |
| **Pelvic binder radiograph** | 仰臥、不需鎮靜；**以秤標準化 binder 壓力** |

- 仍有爭議；**2023：stress 片上動態不穩者因疼痛行動困難；固定 → 活動與出院去向改善**
- 課本兩例對照：兩位輕微移位 LC1、stress 片明顯動態移位 → 經皮固定者 2 週幾乎不痛、可獨立行走；保守者 3 週疼痛 8/10、需 oxycodone、無法上下樓、2 個月後移位如 stress 片所示

### 4.5 術前規劃 🆕
- **經皮固定前 CT 規劃必要**；以矢狀重建測量**骶骨 inlet、outlet 角**
- **60% 病人 S1 與 S2 inlet 角相差 >10°** → 影響術中影像與螺絲安全
- 肥胖或骶骨斜率陡 → 理想 outlet 影像可能做不到（C-arm 撞到病人或床）→ **sacral bump 使骨盆後傾**改善 outlet
- **Sacral dysmorphism：11–44%** 人口 → **S1 transsacral corridor 狹窄或消失**（骶骨翼陡且成角）
  - 特徵：**mammillary bodies**（橫突發育不全）、outlet 片上**骶骨上緣與 iliac crest 共線**、**殘留上位骶椎間盤**
  - **S1 corridor 不夠時，S2 transsacral corridor 通常足夠**

### 4.6 恥骨聯合固定 🆕
- 多採 **ORIF＋鋼板**
- **鋼板鬆動或斷裂常見（43%），但多無症狀 → 翻修僅 3%**
- **建議同時做後側 SI 固定**（否則前方固定較易失敗）
- ORIF 高風險（**重度肥胖、合併腹膜內外膀胱損傷、之前做過 pelvic packing**）→ **外固定或 INFIX**：聯合復位較差，但**功能相似**
- **腹膜外膀胱損傷：膀胱修補＋同時前方 ORIF → 深部感染 0–4%（低風險）**；**膀胱未修補或用恥骨上導尿管 → 即使沒有前方固定，感染風險也較高**（2024）
- 🆕 **泌尿與性功能障礙常見**：2022 手術骨盆環病人**泌尿損傷 21%、神經損傷 22%**；男女的泌尿與性功能障礙**長期不變甚至惡化** → **篩檢並轉介**

### 4.7 恥骨支固定 🆕

| 方法 | 優點 | 缺點 |
|---|---|---|
| **External fixation** | 易放；避免開放入路併發症（膀胱、深部感染、神經血管） | 針道感染、穩定較差、行動與坐不便、**肥胖者壓瘡** |
| **INFIX** | 無骨盆內植入物；皮下，較穩定；**肥胖者適用** | **需二次手術移除**、**LFCN 刺激**、**HO**、皮膚破損、**可能壓迫股神經血管（災難性）** |
| **ORIF** | 立即穩定 | 開放入路；**脆性骨折螺絲抓力差** |
| **髓內恥骨支螺絲** | **經皮、load sharing**；常用 **≥6.5 mm 空心**或 **4.5 mm 非空心鈍頭** | corridor 小時技術困難；誤放傷及神經血管或膀胱；症狀性血腫 |

- 可順行或逆行；**逆行螺絲（遠端恥骨支骨折）易鬆動 → 建議雙皮質固定**

### 4.8 後環固定 🆕
- 多為經皮 **≥6.5 mm 空心螺絲**
  - **Iliosacral**：跨單側 SI，垂直於關節或骨折
  - **Transsacral**：跨雙側髂骨與 SI
- **全螺紋 transsacral（跨六層皮質）抓力優於半螺紋** → 骨質差時特別重要
- **全螺紋＋lag by technique** 比**半螺紋 lag by design** → **加壓力較大、拔出強度較高**

**Spinopelvic dissociation**
- **移位但無神經缺損 → 不復位、後方螺絲固定 → 癒合 98%**（2023）
- **神經損傷最多 33%**（多為**腸道與膀胱**），**骶骨 kyphosis 越大越多**
- **移位＋神經損傷 → 嘗試復位＋減壓 laminectomy → 58% 神經恢復**
- 開放復位困難：**2024：即使嘗試開放復位，術後 kyphosis 改善有限**
- 開放復位減壓後常做 **lumbopelvic fixation**，但有 SSI 與傷口問題

### 4.9 脆性骨盆骨折 🔄
- 與髖部骨折類似：死亡、功能退化、失去獨立的風險增加
- 🆕 **住院或復健平均 ≥1 個月**；**1 年死亡率 15–20%**
- 與髖部骨折不同：**輕微移位者常規保守**
- 🆕 **80% 為 LC 型**
- 許多保守成功的研究是**年輕高能量族群**，不能直接套用
- 🆕 **疼痛導致無法活動者（最多 22%）→ 一般建議固定**；但常延遲治療、長期臥床 → 部分作者建議 **stress imaging**（活動能力與動態不穩強烈相關）
- 🆕 **2023：前＋後固定 vs 只後固定 → 鴉片用量↓、較能通過物理治療、較多出院回家**

## 5. 髖臼骨折

### 5.1 初始評估 🆕
- 下肢旋轉與短縮、骨盆瘀青、壓痛
- **神經血管檢查並記錄骶神經根功能**（坐骨神經損傷常見）
- **經後壁的股骨頭脫位 → 緊急復位＋牽引維持**
- 關節內卡住骨片或股骨頭往骨盆內移位 → 牽引可減少軟骨進一步損傷與股骨頭血供受損

### 5.2 分型與影像 🆕

**Letournel（5 基本＋5 複合）**

| 基本型（一條主骨折線） | 複合型（多條骨折線） |
|---|---|
| Posterior wall | **Transverse＋posterior wall** |
| Posterior column | **T-type** |
| Anterior wall | **Anterior column＋posterior hemitransverse** |
| Anterior column | **Posterior column＋posterior wall** |
| Transverse | **Both-column** |

**影像對應**

| 影像 | 評估 |
|---|---|
| **Obturator oblique** | **前柱＋後壁** |
| **Iliac oblique** | **後柱＋前壁** |
| AP：**iliopectineal line** | **前柱** |
| AP：**ilioischial line** | **後柱** |

### 5.3 後壁骨折穩定性 🆕
- 傳統：**後壁 <20% → 穩定**；但 **23% 在動態 EUA 下不穩**
- **EUA 做法**：髖屈曲＋內旋，經膝施以向後的力，**obturator outlet** 透視比較施力前後；**任何半脫位或脫位 → 建議手術**
- **骨折頭側線距 dome 5.0 mm 內 → 不穩危險因子**
- 🆕 **2024：關節中心與骨折頭尾側出口形成的矢狀角 >70° → 不穩 100% 敏感與特異**
  - 相對地，「頭側距 dome 5 mm 內」與「≥50% 後壁受累」特異度有限（<80%）
  - 需驗證；EUA 陽性是否一定要手術仍待研究
- 課本例：15 歲，矢狀角 48°，EUA 時股骨頭移位，但仍保守，順利恢復

### 5.4 術前規劃 🆕
- 仔細看軸、矢、冠狀 CT；**3D CT 重建**有助理解
- **Articular impaction（多為 marginal impaction）必須辨識**：容易在術中遺漏 → 關節不同心 → 創傷性關節炎（課本例：內側大範圍嵌插未復位 → 3 個月關節快速破壞 → THA）
- **後柱骨折出口接近 sciatic notch → 注意 superior gluteal artery（SGA）**；CT 可見 **SGA 卡在骨折中** → 未先取出就復位 → 傷及 SGA、大出血

### 5.5 前方入路 🆕
- 前柱、前壁或 **quadrilateral plate** 移位 → 前方入路
- **Ilioinguinal 三窗**

| 窗 | 位置 | 可達 |
|---|---|---|
| Medial | 股血管內側 | 上恥骨支、恥骨聯合 |
| Middle | iliopsoas／femoral nerve 與股血管之間 | pelvic brim、quadrilateral plate |
| Lateral | iliopsoas 外側 | iliac fossa、前 SI 關節 |

  - 可直接看 iliac fossa 骨折線，**間接處理 quadrilateral plate**
  - 風險：**LFCN 損傷 18%**、膀胱、股神經、股血管、**corona mortis**（obturator 與 external iliac 吻合）
- **Modified Stoppa（anterior intrapelvic）**：Pfannenstiel＋rectus 垂直劈開；**不直接剝離 external iliac 血管與神經**；**quadrilateral plate 看得較清楚**；限制在 middle window 範圍的骨折線 → 可加 lateral window（± ASIS osteotomy 或 peel）
- **OTA 會員調查：多數偏好 Stoppa**
- 🆕 **2024：Stoppa vs ilioinguinal → 手術較短、失血較少、併發症較少，但解剖復位較少**

### 5.6 後方入路 🆕
- **Kocher-Langenbeck、modified Gibson、digastric trochanteric osteotomy**
- KL 與 Gibson 可側臥或俯臥；**digastric 需側臥**（才能脫位）
- **側臥**：重力協助軟組織牽開（肥胖、肌肉發達、助手少時有用），但**重力可能加重骨盆內移位**
- **俯臥**：去除重力變形力，但需持續牽開後方軟組織 → **可能較易傷坐骨神經**
  - 🆕 **2023 多中心（1,045 人）：坐骨神經麻痺俯臥 9.5% vs 側臥 1.5%**
  - 🆕 **2024（644 人，排除 <5 例的術者）：3.1% vs 3.3%，無差異 → 神經損傷主要取決於術者**
  - 俯臥利於經皮前後柱或骨盆環螺絲；側臥較難取得透視
- **KL**：劈開 fascia lata 與 gluteus maximus；**short external rotators 在離大轉子附著點 1.5 cm 處切斷 → 保護股骨頭血供**；風險結構：**MFCA、坐骨神經、SGA**
- **Modified Gibson**：沿股骨幹直切口，在 **gluteus maximus 與 TFL 之間**；用於需要較多前上方暴露時，但一研究顯示暴露與 KL 無顯著差異
- **Digastric trochanteric osteotomy**：前上方暴露**優於 KL 與 Gibson**；gluteus medius＋vastus lateralis 留在大轉子塊，short external rotators 留在股骨；**可向前脫位股骨頭** → 處理**股骨頭骨折**、取出游離體

### 5.7 經皮螺絲 🆕
- 適用：輕微移位，或可閉合／經皮復位的移位骨折（尤其宿主差）

| 螺絲 | 入點 | 影像 | 風險結構 |
|---|---|---|---|
| **逆行前柱** | 恥骨支前方 | **obturator outlet＋inlet** | **女性 clitoral body、男性 spermatic cord** |
| 順行前柱 | 髂骨外板 | obturator outlet＋inlet | — |
| **LC2（supra-acetabular corridor）** | 順行：**AIIS 上緣** | **iliac oblique＋obturator inlet** | 髖關節、LFCN、股神經與股動脈 |
| 順行後柱 | 內板（需小 lateral window 牽開 iliopsoas） | obturator oblique、iliac oblique、AP | — |
| **逆行後柱** | **ischial tuberosity** | obturator oblique、iliac oblique、AP | **坐骨神經、股後皮神經、cluneal nerve 分支** |

### 5.8 合併骨盆環＋髖臼 🆕
- **先恢復後環穩定**，作為髖臼固定的穩定基礎
- **髖臼的解剖復位比骨盆環更重要 → 應優先**
- **2022（150 例手術）：深部感染 11%、轉 THA 29%**；**後壁骨折為需 THA 的獨立因子**；固定順序與 THA 無關

### 5.9 老人脆性髖臼骨折 🔄
- 骨質差、宿主差；選項：**保守、經皮螺絲、ORIF、急性 THA ± ORIF**
- **Secondary congruence（股骨頭與髖臼關係維持）→ 保守＋立即活動**
- 即使有明確手術適應症（**關節不同心、股骨頭內移、關節移位 >2 mm、關節內骨片**），也有證據支持保守：**26 人保守＋立即活動 → 功能尚可**；1 人因無法活動做 ORIF、**3 人 2 年內 THA**
- **創傷性關節炎率高**：**ORIF 後 16% 轉 THA，其中 52% 在 1 年內**
- **轉 THA 的獨立因子**：**transverse posterior wall、股骨頭突出、髖脫位、BMI↑、年齡↑**
- 🆕 **急性 THA**

| 研究 | THA | ORIF |
|---|---|---|
| 2024：併發症 | 41% | 36% |
| 2024：**翻修** | **6%** | **27%** |
| 高風險型（嚴重 marginal impaction、股骨頭骨折）：**無翻修存活** | **100%** | **29%** |

## 6. 異位骨化（HO）🆕

- 髖臼固定後的 HO 可嚴重限制功能
- 過去認為**放療是唯一有效預防**；🆕 **2023 質疑**：10 年間**嚴重 HO（Brooker III 或 IV）12%（44/361）**，與未處理族群相當
- 🆕 **2023（22 中心、277 人）**

| 預防 | 比例 | 嚴重 HO |
|---|---|---|
| Indomethacin | 12% | **8%** |
| Radiation | 36% | **8%** |
| 無 | 52% | **9%** |

- 🆕 **RCT：indomethacin 6 週 vs placebo → 不降低嚴重 HO（31% vs 19%），nonunion 增加（62% vs 19%）**
- 🆕 **indomethacin（167）、radiation（104）、無（202）→ 傷口併發症：放療 20% vs indomethacin 6.6% vs 無 5.0%**
- 🆕 **Gluteus minimus 清創**：嚴重 HO **19% vs 10%（P = 0.62），無差異**
- 🆕 **嚴重 HO 的唯一相關因子：ASA 分級較高、頭部損傷、腹部損傷**

> **Pitfall**：傳統答案「放療或 indomethacin 預防 HO」在 OKU 15 被推翻：**兩者都不降低嚴重 HO，且分別增加傷口併發症與 nonunion**。

## 8. Key Study Points（OKU 15）

- 骨盆骨折**早期確定性固定**可降低併發症、縮短住院，且**不明顯增加失血**
- **術前停止化學性 VTE 預防會增加 VTE，不建議**，因為未證實會增加失血或輸血
- 骨盆環損傷後**性與泌尿功能障礙常見，且長期持續** → 需諮詢與轉介
- 有創傷性關節炎高風險的老人髖臼骨折：**急性 THA** 或**保守＋立即活動**都可以是成功策略
- **以放療或 indomethacin 預防 HO 不會降低嚴重 HO，且增加併發症風險**

## 9. Anki 候選題

1. >60 歲髖臼骨折每延遲 1 天手術，併發症 odds 增加多少？建議固定時機？→ 7%；穩定者 48 小時內。
2. 前方入路髖臼固定應不應該為了減少出血而延後？→ 不應該；失血結果不一、輸血無差異。
3. TXA 在骨盆骨折手術的 2023 MA 結論？→ 失血與輸血無差異。
4. ASA 建議使用 cell salvage 的失血門檻？→ 預期失血 >500 mL 或 >10% 血容量。
5. 骨盆手術前應不應停化學性 VTE 預防？漏打多劑的風險？→ 不應停（腦、脊椎手術除外）；VTE odds 8 倍。
6. 髖臼術後 CT 發現需翻修的比例？3D fluoroscopy 改變處置的比例？→ 15.5%；12%。
7. 血尿或尿道口出血的骨盆骨折要做什麼檢查？→ CT cystography。
8. 雙側骶骨骨折要懷疑什麼？看哪個 CT 切面？→ 橫向骶骨骨折（spinopelvic dissociation）；矢狀面。
9. 血流動力學不穩定骨盆骨折的死亡率？→ 約 30%，30 年未改變。
10. 外固定的 pin 位置哪種較好？→ Supra-acetabular pin 優於 iliac wing pin。
11. PPP 的缺點與適用時機？→ 前側感染與 VTE 較多；留給無法立即做血管攝影的大出血病人。
12. Zone 3 REBOA 的主要併發症與死亡率？→ 54%；48%。
13. 全國 1,396 人研究中唯一降低死亡的止血介入？→ Angioembolization。
14. APC1、APC2、APC3 的定義？→ <2.5 cm 前 SI 完整；>2.5 cm 前 SI 斷裂；前後 SI 皆斷裂。
15. LC1、LC2、LC3 的定義？是否代表嚴重度遞增？→ 骶骨＋恥骨支骨折；crescent（髂骨翼）骨折；LC＋對側 APC；不代表嚴重度遞增。
16. AOSpine 骶骨 B1、B2、B3 的位置與神經損傷率？→ 孔內側 0–1%、孔外側 5%、經孔 25%。
17. Denis 1、2、3 的位置？→ 孔外側、經孔、孔內側。
18. EUA 下輕微移位 APC1、LC1、LC2 的動態不穩率？→ 50%、37%、63%。
19. LC 骨折動態不穩唯一的獨立相關因子？→ 恥骨支骨折粉碎。
20. 不需鎮靜、以重力施力的骨盆 stress 攝影？→ Lateral stress radiograph（側臥 AP 片）。
21. 多少比例病人 S1 與 S2 inlet 角相差 >10°？→ 60%。
22. Sacral dysmorphism 的盛行率與特徵？S1 corridor 不夠時怎麼辦？→ 11–44%；mammillary bodies、骶骨上緣與 iliac crest 共線、殘留上位骶椎間盤；通常可用 S2 transsacral corridor。
23. 恥骨聯合鋼板鬆動或斷裂率與翻修率？→ 43%；3%。
24. 腹膜外膀胱損傷同時修補＋前方 ORIF 的深部感染率？→ 0–4%。
25. 手術骨盆環病人的泌尿與神經損傷率？→ 21%、22%。
26. 逆行恥骨支螺絲的注意事項？→ 易鬆動，建議雙皮質固定。
27. 全螺紋 lag by technique 相較半螺紋 lag by design 的優點？→ 加壓力較大、拔出強度較高。
28. 移位但無神經缺損的 spinopelvic dissociation 怎麼處理？癒合率？→ 不復位、後方螺絲固定；98%。
29. Spinopelvic dissociation 的神經損傷率與減壓後恢復率？→ 最多 33%；58%。
30. 脆性骨盆骨折的 1 年死亡率與 LC 型比例？→ 15–20%；80%。
31. 前＋後固定 vs 只後固定（脆性 LC）的差異？→ 鴉片用量較少、較能通過物理治療、較多出院回家。
32. Obturator oblique 與 iliac oblique 分別看什麼？→ Obturator oblique：前柱＋後壁；iliac oblique：後柱＋前壁。
33. 後壁 <20% 仍在 EUA 下不穩的比例？哪個 CT 角度預測不穩？→ 23%；矢狀角 >70°（100% 敏感與特異）。
34. 後柱骨折接近 sciatic notch 要注意什麼？→ SGA 可能卡在骨折中，未取出就復位會大出血。
35. Ilioinguinal 入路 LFCN 損傷率？→ 18%。
36. Stoppa 相較 ilioinguinal 的優缺點？→ 手術較短、失血較少、併發症較少，但解剖復位較少。
37. 俯臥 vs 側臥的坐骨神經麻痺率？最終結論？→ 9.5% vs 1.5%（1,045 人）；排除低量術者後 3.1% vs 3.3%，取決於術者。
38. KL 入路切斷 short external rotators 的位置？為什麼？→ 離大轉子附著點 1.5 cm；保護 MFCA 對股骨頭的血供。
39. 逆行前柱螺絲與逆行後柱螺絲的風險結構？→ 前柱：clitoral body／spermatic cord；後柱：坐骨神經、股後皮神經、cluneal nerve。
40. 合併骨盆環＋髖臼骨折的固定順序與優先？→ 先後環作為基礎；髖臼解剖復位優先於骨盆環。
