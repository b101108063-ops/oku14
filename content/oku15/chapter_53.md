## 1. 骨與關節 🆕

### 1.1 基本結構

- **28 塊骨**、多平面運動（常在同一關節內）；一處受傷或變形 → **漣漪效應**，甚至影響膝、髖、背。
- **踝 = distal tibia＋distal fibula＋talus → mortise**（榫卯結構）：**本身極穩定，需多處受傷才不穩**。
- **後足**：talus、calcaneus；**中足**：navicular、cuboid、內／中／外楔骨。
- 距下關節提供部分後足內外翻；🆕 **後足變形可能與距下關節本身解剖變異有關**。

### 1.2 足踝關節炎 🆕

- 🆕 **與膝髖不同：創傷後最常見 → 踝 OA 的 78%、距下 OA 的 70.35%**。
- 🆕 **踝軟骨是下肢最薄：距骨側約 1–1.6 mm、脛骨側 1.1–1.6 mm**。
- 🆕 **關節吻合度與 ROM 越大 → 軟骨越薄**。

### 1.3 Chopart joint 與 PTT 🆕

- **Chopart = talonavicular＋calcaneocuboid**，步態關鍵。

| 時期 | PTT | Chopart | 中足 |
|---|---|---|---|
| **Toe-off** | **收縮 → 足內翻** | 被拉離對齊 | **鎖定（剛性）→ 小腿三頭肌把體重抬到前足** |
| **Heel strike** | **放鬆** | 對齊 | **解鎖 → 屈曲、適應地面** |

- 🆕 **過去認為 PTT dysfunction 是扁平足主因，但研究顯示：PCFD 有無 PTTD 無差；單一結構失能不足以造成變形**（Key Study Point：需多於一個結構失能才會不穩或變形）。

### 1.4 融合與相鄰關節退化 🆕

- 🆕 **TN 關節 ROM 為足部最大**（中足背蹠屈、後足內外翻、前足內外展）。

| 融合 | 結果 |
|---|---|
| 🆕 **單獨 TN 融合** | **後足 ROM 減少 80–90%** |
| 🆕 **單獨距下融合** | **後足 ROM 減少 50%** |
| 🆕 **踝融合** | **距下 OA 24–100%；TN 與 CC OA 18–77%** |
| 🆕 **三關節融合**（距下、TN、CC） | **踝 OA 38–61%；中足 OA 33–73%** |

## 2. 血管 🔄

### 2.1 主要動脈

| 動脈 | 走行 | 手術相關 |
|---|---|---|
| **Anterior tibial → dorsalis pedis** | popliteal 分出 → 穿骨間膜 → 前腔脛骨外側；踝部於 **EHL 與 TA 之間** | **直接前方入路**；中足背側入路（TMT 融合、Lisfranc）遇分支 |
| **Posterior tibial** | tibioperoneal trunk 分出；隨脛神經於深後腔 → **tarsal tunnel** | 內側入路（屈肌腱、tarsal tunnel release）需保護；供應大部分蹠側 |
| **Peroneal** | 沿骨間膜後方 → 外側足踝 | **後外側入路**（後踝骨折） |

- 先天或代償性變異常見。
- 🆕 **Angiosome**：切口應在主要灌流來源之間 → **後方入路直接正中沿 Achilles；前方入路建議較弧形**。
- 🆕 **Doppler 可見 lateral calcaneal artery → 跟骨骨折 extensile lateral 入路傷口併發症較少**。

### 2.2 距骨血供 ✅

- **無肌肉或肌腱附著 → 主要骨外血供**。

| 來源 | 分支 |
|---|---|
| **ATA** | medial talar、medial recurrent tarsal、lateral talar、lateral tarsal（→ posterior recurrent） |
| **PTA** | **deltoid artery**、**artery of the tarsal canal** |
| **Perforating peroneal** | **artery of the tarsal sinus** |

- **tarsal canal 與 tarsal sinus 動脈在 sinus tarsi 匯合**。
- 🆕 **距骨大部分由 PTA 供應；前內側由 ATA**。
- 骨壞死：**距骨頸骨折**高風險；全身因素（**sickle cell、類固醇、酒精**）、特發性 → 痛、關節炎、塌陷；治療依分期：**core decompression、血管化骨移植、融合、置換**。

### 2.3 Navicular 與 Mueller-Weiss 🆕

- 🆕 **舟骨血供：dorsalis pedis 的 medial tarsal 分支（背側）＋PTA（內側與蹠側）**。
- 🆕 **Mueller-Weiss disease = 舟骨特發性骨壞死**：
  - **外側先塌陷 → 距骨頭過度覆蓋 → cavovarus**。
  - **碎裂加重 → 距骨頭蹠屈落入缺口 → 雖有後足 varus 卻呈「矛盾性扁平足」（paradoxical pes planus）**。

## 3. 神經 🆕

| 神經 | 重點 |
|---|---|
| **Superficial peroneal** | 支配外側腔；穿肌間隔跨腓骨 → 前踝分支 → 足背與趾感覺；**前踝與足背切口常遇** |
| **Deep peroneal** | 支配前腔；**與 ATA 走在 EHL 與 TA 之間**；**第一指蹼**感覺與中足深部；🆕 **deep peroneal neurectomy 對中足關節炎與創傷後疼痛效果佳** |
| 🆕 **Sural** | **純感覺**；**脛神經與腓總神經共同形成**；小腿後方淺層 → **Achilles 外側** → 外側跟與足；🆕 **Achilles 手術即使正中或內側入路，器械仍可能傷**；跟骨 extensile lateral、後外側踝入路亦會遇 |
| **Saphenous** | 股神經分支，伴大隱靜脈；內踝與內側足；**內踝骨折或 deltoid 手術** |
| **Tibial** | tarsal tunnel 內（PTT、FDL、PT 動靜脈、FHL 同行）→ 分 **medial 與 lateral plantar**；🆕 **經 abductor hallucis 肌腹深層 → 肌肉肥大可壓迫** |
| 🆕 **Baxter nerve** | **lateral plantar nerve 第一分支**，橫過足跟；🆕 **刺激可類似 plantar fasciitis** |

### 3.1 Tarsal tunnel syndrome 🆕

- **纖維骨隧道：屋頂 = flexor retinaculum；底 = tibia、talus、calcaneus**。
- 原因：**佔位病灶、tendinitis、retinaculum 肥大**；外在因素：**踝變形、下肢水腫、疤痕**。
- 檢查：WB X 光（變形）；CT／MRI（佔位）；🆕 **EMG／NCS：確定神經傷與位置，區分 tarsal tunnel 與 S1 radiculopathy**。
- 保守：NSAID、PT、orthotics 卸載變形。
- 手術：針對原因（清除佔位、釋放肥大組織）。
  - 🆕 **必須完整釋放：整條 flexor retinaculum、abductor hallucis 肌腹筋膜、medial 與 lateral plantar 神經遠端各自的 tunnel、周圍小纖維帶**。
  - 🆕 **軸突再生 → 恢復可 >1 年**。

### 3.2 坐骨神經傷為何以腓總為主 🆕

- 🆕 **脛神經在坐骨神經內 fascicle 較多 → 耐受較多傷害；較大 → epineurium 較多、保護機械力**。
- 🆕 **腓總神經固定與夾擠點多（如腓骨頭）→ 牽拉時易傷**。

## 4. 肌腱 🔄

### 4.1 Achilles 🔄

- gastrocnemius（起於遠端股骨，**也屈膝**）＋ soleus（起於後腓骨與脛骨）→ Achilles → 跟骨後方；plantaris 在內側。
- 🆕 **插入點近端 3–5 cm 相對低血供 → 易傷**。
- 🆕 **插入性與非插入性 tendinopathy：正常磨耗修復不足（膠原紊亂、新生血管、鈣化）→ 痛，但不是發炎**。
- 🆕 **meta：eccentric contraction = 最有效保守**。
- 🆕 **X 光可見的鈣化外生骨是 tendinopathy 的「症狀」，不是疼痛原因**。
- 手術：剝離肌腱、清創、切除外生骨與 **Haglund deformity**、修補。
- 🆕 **近年流行：minimally invasive Haglund 清創、Zadek osteotomy**。
  - 🆕 **Zadek = 背側跟骨 closing wedge osteotomy → 縮短 Achilles 經過距離、改變 Haglund 角度避免夾擠**。
- ❌ OKU 14 的「double-row 比 single-row 失效負荷多 50 N」未列。

### 4.2 Posterior tibial tendon 🆕

- 起於脛骨、腓骨、骨間膜；**廣泛附著於足內側與蹠側**。
- 功能：**內翻、踝動態穩定、push-off 時鎖 Chopart**。
- 退化 → 痛、腫；**單腳踮腳（single-leg heel rise）逐漸變差**；**完全斷裂 → 痛可能減少但功能差** → 相鄰結構負擔增加 → **縱弓塌陷、扁平足**。
- 保守：NSAID、固定、卸載、PT；🆕 **避免肌腱類固醇注射（斷裂風險）**。
- 手術：**小撕裂 → 清創修補；嚴重退化或失能 → FDL tendon transfer**。

### 4.3 Peroneal tendons 🆕

| | Peroneus brevis | Peroneus longus |
|---|---|---|
| 起點 | 下段腓骨、骨間韌帶 | 近端腓骨 |
| 走行 | 外側腔 → 腓骨後溝 | 外側腔 → 腓骨後溝 → **繞 cuboid 進入蹠側** |
| 附著 | **第五蹠骨背外側** | **內楔骨蹠外側＋第一蹠骨基底** |
| 主要功能 | **外翻** | **第一列蹠屈** |

- 兩者皆為踝動態穩定；**SPR（腓骨後溝）**、**IPR（跟骨外側壁）** 固定。
- 🆕 **撕裂位置**：
  - **最常見：SPR 處** → 肌腱半脫位或腓骨後溝擁擠；SPR 受傷 → 半脫位 → 反覆撕裂；擁擠原因：**low-lying PB 肌腹、peroneus quartus**。
  - **IPR 處 → peroneal tubercle 肥大**。
  - **PL 撕裂多在 cuboid notch**（急轉進入足底）。
- 保守：休息、NSAID、活動調整、PT、踝固定、🆕 **lateral posting orthotic**；🆕 **避免類固醇注射**。
- 🆕 **手術**：
  - tendinitis：開放或內視鏡 synovectomy＋處理擁擠原因。
  - 🆕 **撕裂 <50% → 清創＋tubularize 剩餘肌腱**。
  - 🆕 **>50% 受損 → 近端與遠端 tenodesis 到健康肌腱後切除該段；張力需適當**。
  - 🆕 **兩條皆不可修補 → 評估肌腹**：
    - **有 excursion（肌肉有活性）→ allograft 或 autograft 橋接**（近端接健康肌腱、遠端接殘端或第五蹠骨鑽孔）。
    - **無 excursion → FHL 或 FDL transfer**：在 **knot of Henry** 取、經脛骨後方、接殘端或第五蹠骨；🆕 **勿走在神經血管束淺層**。
  - 🆕 **PL → PB transfer：增強外翻、減弱第一列蹠屈 → 輔助 cavovarus 重建**。
  - 🆕 **PB → PL transfer：減弱外翻、增強第一列蹠屈 → 輔助 planovalgus 重建**。
- 🆕 **其他原因**：**後足 varus**（增加 peroneal 應力；反之 peroneal 傷 → 外翻弱 → 後足 varus）；**跟骨骨折外側壁 blowout**；**subfibular impingement**（blowout 或嚴重後足 valgus）；**外踝骨折腓骨鋼板突出（尤其後方鋼板）**。

## 5. 韌帶 🔄

### 5.1 功能分工

| 結構 | 穩定方向 |
|---|---|
| **Deltoid** | **valgus、外旋** |
| **Lateral ligaments** | **varus、前方半脫位** |
| **Syndesmosis** | 脛腓關節；斷裂 → **距骨楔入 → diastasis** |

### 5.2 外側韌帶與慢性不穩 🔄

- ATFL、CFL、PTFL；**ATFL 與 CFL 最常傷（內翻）**。
- 🆕 **Functional treatment → 恢復最快、無晚期症狀疑慮** → 急性手術大幅減少，**慢性不穩手術並未增加**。
- 🆕 **轉為慢性不穩約 20–30%**。
- 🆕 **復發危險因子：cavovarus、韌帶鬆弛、BMI 較高、籃球與足球**。
- 🆕 **2023：慢性不穩者大腦功能與結構改變 → 訊號反應、運動輸出協調、本體感覺改變；copers（受傷但無慢性症狀者）大腦與未受傷者無差**。

### 5.3 多韌帶傷 🆕

- 🆕 **協同效應：多韌帶傷修補後結果明顯差於單純外側修補**。
- 🆕 **屍體研究**：
  - **外側韌帶或 syndesmosis 的「單一」韌帶受傷不造成不穩**。
  - **AITFL＋deltoid → syndesmosis 不穩**。
  - **ATFL＋syndesmosis 韌帶 → 外側踝不穩**。
- ❌ OKU 14 的「關節鏡矢狀位移 ≥2 mm」「WBCT 3D 體積（穹窿上 5 cm）最敏感」本章未列。

### 5.4 Deltoid-spring ligament complex 🆕

| 結構 | 跨越 | 組成 | 功能 |
|---|---|---|---|
| 🆕 **Superficial deltoid** | **距脛＋距下** | **tibiocalcaneal、tibionavicular、tibial spring** | **限制踝外翻** |
| 🆕 **Deep deltoid** | **只跨距脛** | **anterior、posterior tibiotalar** | **限制外旋** |
| 🆕 **Spring ligament** | — | **superomedial＋inferior calcaneonavicular** | **限制舟骨在距骨上外展**；🆕 **superomedial band 內有關節軟骨面與距骨頭相關節** |

- 🆕 **spring 重建早在 1927 已描述**，但數十年焦點在 PTT。
- 🆕 **spring 越來越被認為與 PCFD 相關 → 扁平足重建時需修補或重建**。
- 🆕 **內側韌帶視為複合體 → 考慮整體重建**。

### 5.5 Lisfranc 🔄

- TMT 關節＋多條韌帶；🆕 **最強 = plantar band of Lisfranc ligament（內楔骨 → 第二蹠骨）**。
- 🆕 **第一與第二蹠骨之間沒有 intermetatarsal ligament**（不同於其他蹠骨）。
- 維持**橫弓與縱弓**。
- 🆕 **第二蹠骨 = keystone**：
  - **第二 TMT 關節內凹、比第一與第三更近端 → mortise 結構 → 防止蹠骨內外移**。
  - **冠狀切面呈三角形，位於橫弓頂點**（如羅馬拱頂石）。
- 🆕 **內側柱（第 1 列）與中柱（第 2、3 列）剛性 → 穩定；外側柱（第 4、5 列）活動 → 適應不平地面**；🆕 **融合外側柱治療損傷 → 結果不可接受**。
- 治療：固定、ORIF、primary fusion、flexible ligament fixation；**無共識**。
  - 🆕 **純韌帶傷急性融合結果最佳**；但**年輕人與運動員有爭議**（需活動度、相鄰退化較晚出現）。
  - 🆕 **2023 建議：WB X 光與 CT 位移 <2 mm → 固定保守，結果佳**。
  - 🆕 **ORIF vs primary arthrodesis 無共識；2024 SR：支持 primary arthrodesis 的研究 fragility index 較不脆弱**。
  - 🆕 **運動員與年輕人：flexible fixation 可作為 rigid ORIF 的替代 → 結果佳、減少取內固定**（需較長追蹤）。

## 6. 步態與生物力學 🆕

### 6.1 步態週期

- 以同一腳同一姿勢始末；分 **stance（著地）** 與 **swing（在空中）**；之間有**雙支撐期**。
- 🆕 **因為有雙支撐期 → stance phase 比 swing phase 長**（Key Study Point）。

| Stance | Swing |
|---|---|
| **Initial contact（heel strike）** | **Initial swing** |
| **Loading response（foot flat；中足解鎖）** | **Midswing（feet adjacent）** |
| **Midstance（全體重，對側 swing）** | **Terminal swing** |
| **Terminal stance（heel rise；中足鎖定）** | — |
| **Preswing（→ toe-off）** | — |

- 影響因素：**步長、cadence、速度**；任何下肢或核心的無力、變形、ROM 改變；中樞神經的神經肌肉控制、本體感覺、平衡。

### 6.2 Windlass mechanism 🆕

- **縱弓＋plantar fascia＋MTP 關節** 協同。
- 🆕 **MTP 背屈 → plantar fascia 繞蹠骨頭拉緊（等於縮短）→ 中足升高（較 cavus）、穩定** → 配合 Chopart 鎖定 → **toe-off 軸向負重**。
- **MTP 回中立 → fascia 延長、中足回中立** → 配合 Chopart 解鎖 → heel strike 到 foot flat 足較柔軟。
- 🆕 **病理惡化**：
  - **Cavovarus**：病理 cavus 拉緊 fascia → **MTP 背屈、爪趾**。
  - **進行性神經肌肉病**：徵用伸趾肌協助踝背屈 → **爪趾** → MTP 背屈 → fascia 更緊 → **cavus 惡化**。
  - **Pes planovalgus**：**fascia 退化 → 失去 windlass → toe-off 中足無法升高** → 穩定性下降 → **spring ligament 與 PTT 負擔增加** → 加速退化、planovalgus 惡化。

### 6.3 Tripod concept 🆕

- 🆕 **負重足三腳：heel、第一蹠骨頭、第五蹠骨頭**；三點都要著地才平衡（Key Study Point）。
- 🆕 **代償**：
  - **後足 varus → 跟骨負重點內移、三腳旋轉 → 第一列必須蹠屈著地**。
  - **第一列蹠屈 → 三腳抬高 → 跟骨必須內移 → 後足 varus**。
- 🆕 **只矯正一腳、不矯正或代償其他腳 → 足不平衡、結果差**（orthotics 或手術都要確保三點著地）。
- 🆕 **骨牌效應**：

| 起點 | 下游結果 |
|---|---|
| **Cavus** | 外側足壓力 → **第五蹠骨骨折**；後足 varus → 踝 varus 應力 → **外側韌帶不穩、peroneal 傷** |
| **Planus** | 前足扭轉 → **hallux valgus 惡化**；後足 valgus 代償 → **subfibular 與 sinus tarsi impingement（外側痛）**；踝 valgus 應力 → **deltoid-spring 與 PTT 受損** |
| 🆕 **Hallux rigidus**（Key Study Point） | 大拇趾無法背屈 → 足向外傾 → **動態後足 varus → peroneal 撕裂、外側不穩** |
| 踝變形 | 膝、髖、骨盆、脊椎代償 → 遠處疼痛 |
| **近端變形（膝 varus、側彎）** | 向下傳遞 → 代償性足踝變形 |

- 代償本身複雜，**無法對特定變形預測代償型態**。

## 8. Key Study Points（OKU 15）

- 步態 = **stance**（heel strike → midstance → toe-off）＋ **swing**；因有雙支撐期，**stance 長於 swing**。
- **需多於一個結構受傷或退化才會不穩或變形**；但單一結構失能會改變其他結構受力 → 久了退化。
- **足需三點著地（第一蹠骨頭、第五蹠骨頭、跟）**；任一點移位 → 其他點調整 → cavovarus 或 planovalgus；**治療時必須確保三點著地**。
- **一處失能 → 骨牌效應**：如**痛性 hallux rigidus → 足外傾 → 動態後足 varus → peroneal 撕裂與外側不穩**。
