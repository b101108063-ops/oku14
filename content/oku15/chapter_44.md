## 1. 術前影像 ✅

### 1.1 標準 X 光

- **AP 骨盆、患側側位、false-profile**；側位技術：cross-table lateral、**45° 或 90° Dunn**、frog-lateral；**需標準化**以提高準確度。

### 1.2 AP 骨盆

| 項目 | 定義 |
|---|---|
| 🆕 **Hip center 外移** | 股骨頭最內側到 **ilioischial line > 10 mm** |
| 🆕 **Coxa profunda** | **髖臼底碰到** ilioischial line |
| 🆕 **Protrusio acetabuli** | **股骨頭碰到** ilioischial line |
| **Retroversion** | 前緣線與後緣線交叉 = **crossover sign**（anteverted 則不交叉） |
| **Tönnis angle** | **正常 0–10°**；**>10° = 傾斜增加、不穩風險**；**降低（<0°）= 可能 pincer**。畫法：兩側 teardrop 連線 → 平行線通過 sourcil 下緣 → sourcil 下緣到外緣的線，第 2、3 線夾角 |
| **LCEA** | **正常 25–40°**；**<25° 可能覆蓋不足** |

### 1.3 False-profile 與側位

- **ACEA（false-profile）**：股骨頭中心垂直線與中心到前髖臼的線夾角；**<20° → 前方覆蓋不足、不穩**。
- **Cam**：位於前外側 head-neck，作者偏好 **45° Dunn**。
- **Alpha angle**：🆕 **最初用 MRI axial 描述**，可外推到側位 X 光；**>42° 提示 head-neck offset 異常**。畫法：股骨頸中心線 + 股骨頭中心到失去球形處的線。

### 1.4 MRI 與 CT

- 保守無效後 → **MRI（髖周軟組織與關節內結構的金標準）**：labral 撕裂、早期軟骨磨損、**量化 OA → 判斷能否做保留手術**；osteonecrosis 範圍與有無軟骨下塌陷。
- **CT（＋3D 重建）**：骨性解剖、cam 形態、dysplasia 程度 → 決策與術前規劃。

## 2. FAI 🔄

### 2.1 型態

- 核心：**球形髖臼與不對稱股骨頭不匹配**；分 **cam、pincer、mixed**。
- **Cam**：head-neck junction 異常，**最常在前上方**；Dunn 側位、alpha 角（🔄 **>55° 可代表 cam**）；**FADIR** 時異常骨撞到髖臼與 labrum → 反覆傷害 labrum 與 chondrolabral junction。
  - labrum 功能：加深髖臼、**維持 suction seal**、降低接觸壓。
  - 🆕 **沒有骨性異常時，labral 撕裂很少發生**。
- **Pincer**：髖臼過度覆蓋。
  - **局部**（最常前上）：**LCEA >40° 或 Tönnis <0°**。
  - **全面**：**retroversion**（crossover sign）、**profunda、protrusio**。
  - 深屈時髖臼撞到股骨頸 → 關節囊緣 labrum 傷 → **後下方 contrecoup 軟骨傷** → 退化。
- 🆕 **大型前瞻多中心手術資料：cam 47.6%、mixed 44.5%、pincer 只有 7.9%**。
- 🆕 **FAI（尤其 cam）是 OA 危險因子，但多數 FAI 髖永遠不會發展成 OA**；哪些會進展仍需研究。

### 2.2 手術適應症 🆕

- **labral 撕裂造成的疼痛＋骨性解剖異常＋至少 2 mm 剩餘關節間隙**。

### 2.3 臨床表現與檢查

- **活動相關鼠蹊痛、坐著痛**；機械症狀（click、locking、catching）。
- 檢查：步態；**腰椎檢查**排除合併病變；觸診骨與軟組織（找關節外傷）。
- **Log roll 陽性 = 關節內病變**。
- **抗阻內收** → 排除 adductor 病變；**抗阻仰臥起坐痛 → core muscle 功能異常**。
- ROM：關節內外病因都會痛；**FADIR 痛且再現症狀 = FAI**。
- **FABER**：**前方痛 = 關節內病變；後方痛 = SI 關節**。

### 2.4 治療 🔄

- 先**活動調整、NSAIDs、監督下 PT**（柔軟度、核心與下肢肌力）。
- 診斷不明 → **關節內 lidocaine**：即使短暫緩解也支持關節內來源。
- 🆕 **保守 3 個月症狀控制不佳 → 考慮手術**：開放或關節鏡，**labral repair＋切除異常骨**。
- **恢復無撞擊 ROM** 是成功關鍵；labral repair 無法恢復 suction seal → **augmentation 或 reconstruction**。
- 🆕 **關節鏡 10 年追蹤：疼痛與功能 PRO 改善，但約 1/3 轉 THA**；轉換相關：**手術時年齡較大、關節間隙 ≤2 mm、需要 acetabular microfracture**。
- ✅ **labral repair 比單純 labral 清創臨床與 X 光結果都較好**。

## 3. Dysplasia 🔄

### 3.1 定義 🔄

- 範圍從出生脫位到成人淺髖臼；本章討論**青少年與成人的較輕型**。

| 參數 | Dysplasia |
|---|---|
| **Tönnis** | **>10°** |
| **LCEA** | **<20°** |
| **ACEA** | **<20°** |
| **Borderline** | **LCEA 20–25°** |

- 🔄 OKU 14：borderline 18–25°、<18° 嚴重。

### 3.2 機轉 🆕

- 外側覆蓋不足 → **外展肌必須更費力穩定髖**。
- 前方覆蓋不足 → **iliopsoas 壓力增加**。
- 股骨與髖臼接觸面積小 → **負重時外側軟骨與 labrum 受力增加** → 無法代償 → 退化（2022）；dysplasia 與 OA 的關聯已確立。

### 3.3 表現 🆕

- **全髖痛**：鼠蹊、外側（外展肌）、後方。
- 常在**第 2 或第 4 個十年**就醫；年輕者常在**開始新活動後**。
- 常有 **hypermobility** 病史、**髖會 pop**。
- 檢查：**ROM 增加**、撞擊動作痛。
- 🆕 **Dial test**：腿伸直、施外旋力後放開；**患側沒有回彈內旋 = 陽性（髖不穩）**。

### 3.4 治療 🔄

- 活動調整、消炎、PT；疼痛來源不明 → **診斷性關節內注射**。
- 保守失敗 → **單獨關節鏡、reorienting osteotomy、或開放＋關節鏡合併**；矯正異常解剖並處理關節內病變 → 結果優良且持久。
- ❌ OKU 14 的 PAO 技術、存活率（10 年 >90%、18 年約 75%、30 年約 30%）、Tönnis 1 vs 2 轉換率、預後不良因子（>25 歲、間隙 <2 mm 或 >5 mm）與「LCEA <18° 禁單獨關節鏡」本版未列。

## 4. 股骨頭骨壞死 🆕

### 4.1 病因與診斷

- 血流不足 → 細胞死亡 → **軟骨下骨折 → 股骨頭塌陷** → 劇痛與失能。
- 🆕 **美國每年約 2–3 萬例**。
- 最常見：**外傷、類固醇、過量飲酒**；其他：**自體免疫疾病、鐮刀型貧血、惡性腫瘤（ALL）、HIV、減壓病**。
- 早期常無症狀；進展後**鼠蹊痛、活動痛**；檢查可正常或 ROM 減少且痛。
- **早期 X 光常正常 → 需要 MRI 確診**；晚期 X 光：軟骨下塌陷、股骨頭塌陷、髖臼退化。
- **MRI 高敏感且特異**：**T1 帶狀低訊號病灶**、**T2 反應性骨髓水腫**。

### 4.2 分期（Table 1）

| 期 | **Ficat** | **ARCO** | **UPenn** |
|---|---|---|---|
| **0** | — | 無 X 光證據，懷疑或有症狀 | X 光正常但痛 |
| **I** | 正常 X 光＋MRI 陽性 | 正常 X 光，MRI 或骨掃描陽性 | 正常 X 光，MRI 或骨掃描陽性 |
| **II** | 硬化增加、混合透亮與硬化 | X 光異常，無骨折或變平 | 股骨頭透亮或硬化變化 |
| **III** | **軟骨下塌陷（crescent sign）**、股骨頭變平 | **軟骨下骨折；IIIA <2 mm 變平、IIIB >2 mm 變平** | crescent sign，無股骨頭變平 |
| **IV** | **股骨頭塌陷、關節間隙減少** | X 光上關節炎 | 股骨頭變平，關節間隙未減少 |
| **V** | — | — | 關節間隙狹窄 |
| **VI** | — | — | 關節變形、關節間隙消失 |

- **Ficat（1964）最常用**，最初依 X 光，後納入 MRI；ARCO 與 UPenn 較晚發展。

### 4.3 治療

- 依分期與症狀。
- **觀察：失敗率高**。
- **NSAIDs、acetaminophen** 止痛。
- 🆕 **雙磷酸鹽：早期有希望，但 5 個 RCT 的 meta 證據極少**。
- 🆕 **Statin 合併 core decompression 有希望**。
- **Core decompression**：**塌陷前**的早期；**小而中央的病灶最有效**；機轉 = 降低骨內壓、促進骨癒合；短長期都改善症狀、延後 arthroplasty。
- **骨移植**：非血管化與血管化；🆕 **血管化骨移植：塌陷前病灶 5 年髖存活率 80%**。
- **THA = 最終治療，長期結果極佳**；🆕 **因 osteonecrosis 做 THA 的病人，最多一半之後需要對側 THA**。

## 5. OKU 14 CH40 中 OKU 15 不再列出的內容 ❌

- ❌ False-profile 拍法（站立、骨盆後旋 65°）；仰臥屈髖 95–120°、屈 90° 測內外旋。
- ❌ **PART（prone apprehension relocation test）**與 3 點鐘髖臼前傾相關。
- ❌ **Beck 軟骨（malacia、debonding、cleavage、defect）與 labrum（degeneration、full-thickness tear、detached、ossified）分型**。
- ❌ **無症狀志願者 69% MRI 有 labral 撕裂**。
- ❌ Cam 與青少年高衝擊運動的骺板應力；pincer 1824 年 protrusio、女性較多。
- ❌ **UK FASHIoN trial**（348 例，PT vs 關節鏡）。
- ❌ **關節鏡預後因子**：正向（年輕、男性、BMI <24.5、Tönnis 0、注射有效）；負向（>45 歲、BMI >25、症狀 >8 個月、軟骨缺損、只做 labral 清創）。
- ❌ **Ganz surgical dislocation**（360° 暴露）。
- ❌ **Bernese PAO（1988 Ganz）技術**與 3.5 或 4.5 mm 全螺紋螺絲。
- ❌ **PAO 存活：10 年 >90%、18 年約 75%、30 年約 30%**；**Tönnis 1：5 年 2%、10 年 11% 轉 THA；Tönnis 2：23%、53%**；預後不良：>25 歲、間隙 <2 mm 或 >5 mm。
- ❌ PAO 併發症：傷口、HO、**LFCN 最常見**、**VTE 90 天 0.6%**。
- ❌ **LCEA <18° 禁止單獨關節鏡**的 danger zone。

## 6. Key Study Points（OKU 15）

- **了解正常髖部影像**是辨識病變的關鍵。
- **FAI 是運動員髖痛的常見原因**。
- **Hip dysplasia 範圍很廣**；早期辨識與介入可改善結果。
- **較晚才發現的 osteonecrosis 常需要 THA**。
