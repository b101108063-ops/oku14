## 1. 總論 🔄

- 光譜：**vertebral osteomyelitis、discitis、granulomatous disease、paraspinal abscess、epidural abscess**，可單獨或合併；🆕 **最多 14% 有跳躍病灶**（2025）。
- 病原：**S aureus、MRSA**；肉芽腫性：**Mycobacterium、Actinomyces、Brucella**；罕見黴菌。
- 🆕 **治療三目標：感染控制、早期安全活動、維持脊柱對位**（不論手術與否）。
- 🆕 **手術原則與四肢相同**：清除所有失活骨與軟組織、充分減壓神經、穩定骨性結構以維持對位、適當局部抗生素、重建骨與軟組織缺損、**辨識病原以長期針對性抗生素**。
- 🆕 **致病三途徑**：
  1. **遠處感染血行散播**。
  2. **術後直接外部接種**。
  3. **鄰近組織擴散**（主動脈、食道、腹盆腔）。
  - 病原**卡在終板的動靜脈弓**後擴散。
- 🆕 **發生率上升**：免疫抑制增加、IVDU 增加、高齡與共病。
- 🆕 **脊椎感染佔所有骨髓炎最多 7%**；部位：**腰椎約 58%（歸因於靜脈叢逆流）、胸椎 33%、頸椎最多 11%**。

## 2. 化膿性椎體骨髓炎（PVO）🔄

### 2.1 病理

- 細菌感染椎體並延伸到椎間盤；可由 osteodiscitis 起始，或依範圍波及鄰節。
- 🆕 **最常見機轉：靜脈逆流血行散播；相鄰 intermetaphyseal arteries 受累 → 椎間盤炎波及兩側終板**。
- 相關軟組織感染：**paraspinal（psoas）abscess**、頸椎 **retropharyngeal abscess**；可擴散到硬膜外或後方元素。

### 2.2 流行病學 🆕

- 🆕 **發生率約 4.8／100,000；死亡率 2.1%**。
- 🆕 **30–45% 合併菌血症**。
- 🆕 **年齡雙峰：<20 歲，以及 50–70 歲高峰**。
- 🆕 **約 14% 有遠處或跳躍的脊椎病灶**。
- ✅ **最常見菌 = S aureus（約 50%）**。
- 🆕 **美國：每 2 例 S aureus 約 1 例為 MRSA**。
  - 🆕 **MRSA → 手術 OR 1.19；再手術 OR 1.29（6 個月）、1.36（1 年）**。
  - 🆕 **MRSA 手術併發症較多：AKI、輸血、肺炎**。
- 🆕 **院內死亡 4–6%；死亡預測：modified Charlson Comorbidity Index 高、DM**。

### 2.3 臨床 🆕

- 🆕 **背或頸痛約 90%（最常見）**；**發燒第二常見，但不特異**；體重減輕、倦怠。
- 🆕 **神經缺損約 20–30%**，**最常見於頸胸受累與合併 SEA**。
- 🆕 **危險因子**：高齡、免疫抑制（**HIV、免疫抑制治療、慢性肝或腎病、DM、腫瘤史**）、**IVDU**、**長期留置裝置**、**近期脊椎手術**。

### 2.4 檢查 🆕

- **實驗室（標準照護）**：**ESR、CRP（鑑別＋追蹤療效）**；**抗生素前抽血液與尿液培養**。
  - 🆕 **入院 CRP >150（OCR 單位為 mg/dL，一般文獻多為 mg/L）→ 嚴重神經惡化與較高死亡的獨立危險因子**。
- **X 光**：常見第一步；🆕 **骨破壞出現延遲（最多 12 週），最終診斷時約 30% 可見**；多用於門診，急診與住院不常規照；可作基線。
- 🆕 **全脊椎 CT**：骨異常與破壞（**終板侵蝕**）、骨質與穩定；🆕 **14–20% 跳躍病灶 → 急性評估應影像全脊椎**；退化嚴重時協助辨識侵蝕；**CT 導引經皮切片**。
- ✅ **MRI = 金標準**：
  - 🆕 **感染後 3–5 天即可見變化**。
  - 🆕 **敏感約 96%、特異 93%**。
  - **應做打與不打 gadolinium**。
  - 特徵：**T2 高訊號、T1 低訊號、顯影增強**。
  - 🆕 **與腫瘤鑑別：骨髓炎與椎間盤炎起於椎間盤附近；腫瘤多侷限於椎體、椎間盤保留**。
- 🆕 **核醫**：**MRI 與 PET-CT 都不成功時的第三選擇**；追蹤劑取得與影像時間受限；🆕 **敏感約 86%、特異 39%（不如 MRI）**。
- 🆕 **新建議：懷疑 Staphylococcus、Streptococcus、Enterococcus → 心臟超音波（尤其初始治療無反應）；最多 30% 骨髓炎合併細菌性心內膜炎，可能需換瓣**。

### 2.5 治療 🔄

- ✅ **不論是否手術都從內科治療開始**；**建議感染科會診**（選藥、劑量、療程）。
- 保守目標：針對性抗生素、止痛、維持穩定、防止神經功能惡化。
- 🆕 **經驗性抗生素（病原未明前）：三代 cephalosporin＋fluoroquinolone ± vancomycin**。
- 🆕 **IV 抗生素約 6 週，之後口服抑制性抗生素 6 週**；治療失敗或神經變化 → 可能需手術。
- 🆕 **培養陰性 → 全程廣效抗生素（2024）**。
- 追蹤 **ESR、CRP** 監測療效。
- 🆕 **保守失敗危險因子**：

| 類別 | 因子 |
|---|---|
| 局部 | **paravertebral abscess、gibbus deformity、慢性流膿竇道、連續 ≥3 節受累、需重建的明顯前柱受累** |
| 全身 | **反覆菌血症、DM、免疫抑制** |
| 遠處感染 | **UTI、肺炎、心內膜炎、敗血症** |

- 🆕 **CRP 每週未下降約 50% → 單用抗生素可能失敗**。

### 2.6 手術 🔄

- 目標：**source control、辨識病原、保存或恢復神經、維持與恢復脊柱穩定與形態**。
- 入路：**後方、前後合併、經皮與 MIS**；依感染位置與需前柱支撐的骨破壞程度。
- 🆕 **固定時機**：**急性 vs 延遲固定 → 再感染率相似（meta）；但「不固定」的手術治療再感染較高**。
- 🆕 **新技術**：
  - **內視鏡清創（單或雙 portal、後外側入路）→ 只有 17% 需二次手術**。
  - **經皮螺釘固定 → 約 10% 需前方 corpectomy 型翻修；螺釘錯置或鬆動與開放無差**。
- 頸椎 spondylodiscitis 較少見；**前方入路**方便提供結構支撐；合併 SEA 時可 **360° 融合**。

### 2.7 預後 🆕

- 🆕 **無菌或培養陰性 PVO：無復發存活 — 保守與不固定組 87%；固定組 91%**。
- 🆕 **復發危險因子：Charlson 高、感染性心內膜炎、psoas abscess**；另研究：**入院 CRP 高、抗生素療程 <6 週、就診體溫**。

## 3. 肉芽腫性（結核）椎體骨髓炎 🆕

### 3.1 病理與流行病學

- 🆕 **non-pyogenic vertebral osteomyelitis，形成肉芽腫**。
- 🆕 **M tuberculosis 佔 97–99%**，開發中國家較多；**緩慢生長、需氧、挑剔**；**飛沫傳染**；多由**肺 TB 血行散播**。
- 🆕 **三型脊椎受累：anterior、peridiscal、central**。
- 🆕 **椎間盤組織多被保留 → 可與 PVO 鑑別**。
- 其他：**Brucella、Actinomyces、Nocardia、黴菌**。
- 🆕 **肌骨 TB 佔所有 TB 最多 3%、肺外 TB 25%**；🆕 **脊椎是散播性 TB 最常見部位**。
- 🆕 **分布：80% 下胸與上腰、15% 頸、3% 薦**。
- 2019 年全球 1,000 萬新 TB 病例（50% 成年男性）。

### 3.2 臨床與診斷

- **背痛最常見、最早**；局部壓痛；結構破壞 → 變形。
- 🆕 **gibbus deformity = 急性 kyphotic 成角（晚期）**。
- 全身：**倦怠、夜汗、非刻意體重減輕、全身無力**；常**合併肺 TB**；淋巴腺病、GI 症狀、神經缺損（依變形與狹窄）。
- 🆕 **通常症狀出現數週到數月後才就醫**。
- 病史含**疫區旅遊史**；WBC、ESR、CRP、**PPD**。
- 🆕 **肺外 TB 常培養陰性 → 必須切片；壞死性肉芽腫性發炎 = TB 的 hallmark**。
- 危險：**疫區旅遊、HIV 等免疫抑制、社經條件差**。
- 影像：
  - X 光：早期**局部骨鬆、軟骨下骨與終板連續性喪失**；晚期破壞性 gibbus。
  - **CT：早期鬆質破壞與皮質吸收**；晚期變形評估。
  - 🆕 **MRI 首選**：早期骨髓發炎；**椎間盤保留**；🆕 **T1 脂肪抑制顯影見「邊界清楚、薄壁」的椎管內或椎旁膿瘍 → 與化膿性鑑別的典型表現**。

### 3.3 治療 🆕

- **首選內科**（同 PVO）。
- 🆕 **急性散播時，術前若可行先給 2–4 週標準抗結核藥，緩解中毒症狀**。
- 手術適應：**恢復結構完整、減壓神經**。
- 角狀 kyphosis → **posterior vertebral column resection 或 anterior column resection** 矯正。
- 🆕 **Tuberculosis Spine Instability Score（TSIS，2022，多中心驗證）**：

| 項目 | 給分 |
|---|---|
| **年齡** | <5 歲 3；…；>15 歲 0 |
| **位置** | **交界區（occiput–C2、C7–T2、T10–L2、L5–S1）2**；活動區（C3–C6、L2–L5）1；剛性區 0 |
| **疼痛** | 休息也痛或臥床不緩解 3；負重活動痛但臥床緩解 2；偶爾或非機械性 1；無痛 0 |
| **Adjusted kyphosis** | **>60° → 3**（實測＋每個頸或腰受累 5°、L4–5 與 L5–S1 各 15°） |
| **椎體流失** | **>1.5 → 3**（每節分 10 等份累加） |
| **後方元素** | 雙側 facet 破壞或側彎／平移 3；單側 facet 2 |
| **多節連續** | ≥3 節 3；2 節 2；1 節 1；中央型（無椎間盤）0 |
| **膿瘍** | 有 1；無 0 |
| **總分** | 🆕 **<7 穩定；7–10 即將不穩；>10 不穩** |

- 傳統：**posterolateral approach**；目標 = 足夠結構支撐、充分清創、減少神經操作。
- 🆕 **前方 vs 後方（不論骨或鈦 graft）結果相似；前方失血較多、手術時間較長**。
- 🆕 **預後**：**最多 95% 對內科與手術有反應**。
- 🆕 **MDR-TB**：預後較差；成功目標 = **6 個月臨床漸進改善、治療期間影像改善、少用二線藥、療程中不換藥**。

## 4. 硬膜外膿瘍（SEA）🔄

### 4.1 流行病學 🔄

- 🆕 **定義：dura 與椎骨骨膜之間的感染**；罕見。
- **多為血行**；少數由 **PVO 或 facet septic arthritis 延伸**。
- 可危及生命、造成嚴重神經缺損。
- 🔄 **最常見位置 = 胸椎**（OKU 14：腰椎 54.7%、胸椎 39.1%）。
- ✅ **最常見菌 = S aureus**（亦有 aspergillosis 等罕見菌）。
- 🆕 **近年發生率增為三倍，約每 1,000 住院 1 例**（高齡、醫療複雜度、IVDU）。

### 4.2 致病 🆕

- 🆕 **>80% 有 ≥1 危險因子：DM、IVDU、ESRD、酒精濫用、其他免疫抑制（癌症、HIV／AIDS）**。
- 🆕 另：**BMI >30、風濕性疾病、痛風**（2023）。
- 神經缺損機轉：**直接壓迫＋血管受損 ± 血管發炎** → 可致脊髓梗塞。

### 4.3 臨床 🔄

- 從背或頸痛到完全癱瘓。
- ✅ **四期：局部痛 → 神經根痛 → 運動無力 → 癱瘓**。
- 🆕 **全脊椎受累 = holospinal epidural abscess**；少數合併 PVO。
- ❌ OKU 14 的症狀百分比（**背痛 66.8%、無力 52%、感覺 40%、發燒 43.7%、大小便 27.1%**）未列。

### 4.4 診斷 🔄

- ESR、CRP 多升高但不特異；🆕 **追蹤指數判斷手術或保守療效**。
- ✅ **gadolinium MRI = 標準照護**：**T1 低訊號、T2 高訊號、T1 顯影周邊增強**。
- CT：看不到軟組織液體；延遲就醫者可見骨受累與不穩。
- 🆕 **全脊椎影像：最多 10% 為非連續 SEA**。
- 🆕 **TEE 可排除心內膜炎**。

### 4.5 治療 🔄

- 🔄 🆕 **頸椎或胸椎 SEA → 即使無神經損傷也強烈建議手術**（快速進展與神經缺損風險）。
- 🆕 **手術減壓＋清創＋抗生素 = 標準照護**。
- 目標：source control、辨識病原、保存或恢復神經、維持穩定、減壓、**排膿**、必要時固定。
- **融合 vs laminotomy**：依病人與醫師判斷。
- ❌ OKU 14 的「**無神經缺損 SEA 保守日益成為第一線**」「**1,099 例 SR：59.7% 手術、40.3% 非手術、結果無差**」「**IV 抗生素者 41% 最終需手術**」本版未列。

### 4.6 預後 🆕

- 🆕 **90 天併發症約 61%**。
- 🆕 **結果主要由就診時神經狀態與共病決定**。
- 🆕 **術後 QOL 的重要驅動因子 = 行走功能**。
- 🆕 **脊髓層級膿瘍：手術比單純內科結果較好**；共病少者術後再入院較少。
- 🆕 **90 天全因死亡約 14%**。
- 🆕 **長期死亡危險因子：免疫抑制、WBC >12、就診時敗血症或敗血性休克、ASA 4、之後心跳停止；DM 與慢性肺病**。
- 🆕 **經濟負擔：每次住院約 $100,000–140,000**。

## 5. 術後（醫源性）感染 🆕

- 🆕 **來源：術中直接接種或血行散播**。
- 🆕 **危險因子：使用器械、多節、手術時間長、失血多；病人年齡、DM、吸菸**。
- 表現：疼痛、發燒、**膿性分泌物**、神經缺損、敗血症；ESR 與 CRP 升高。
- 🆕 **依時間分類**：

| 類型 | 時間 |
|---|---|
| **Early** | **術後 6 週內** |
| **Delayed** | **6 週到 1 年** |
| **Late** | **>1 年** |

- 🆕 **植入物：鈷鉻（CoCr）比不鏽鋼與鈦更易發生軟組織相關感染；三者都因 intrawound vancomycin powder 而大幅減少**。
- 🆕 **慢性感染最常見菌：Cutibacterium acnes、Staphylococcus epidermidis**。
- 需高度懷疑＋早期積極介入。
- 🆕 **單次清創失敗約 27%（需再清創）；危險因子：breakthrough bacteremia、高齡、吸菸、肥胖、DM 控制差**。
- **S aureus 為最常見術後感染菌**；🆕 **混合感染 → 需更多次清創、更長抗生素療程**。
