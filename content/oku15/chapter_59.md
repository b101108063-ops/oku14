## 1. 解剖 🆕

- 前方：椎體、uncinate、橫突；後方：椎板弓、棘突、SAP、IAP；**ligamentum flavum** 覆蓋椎板間。
- 椎間盤：**anulus fibrosus（同心層、I 型膠原 → 強度）**＋**nucleus pulposus（proteoglycan、II 型膠原 → 彈性、含水、吸震）**；**血供有限**（外層小血管＋終板被動擴散）。
- **Facet**：雙側滑膜關節、透明軟骨、囊含滑液；方向與大小決定活動度，並構成神經孔背側。
- **Uncovertebral（Luschka）joint**：**下位 uncinate process＋上位椎體下外側斜面**；**肥大或退化 → 孔狹窄、根壓迫**。

## 2. 頸椎退化性椎間盤疾病（axial neck pain）🆕

### 2.1 病理

- 與腰椎類似：🆕 **老化 → keratan sulfate／chondroitin sulfate 比例上升、水分下降** → 乾燥 → 高度下降、塌陷、突出、骨化。
- 突出或 bulge → 壓迫脊髓或根。
- 次發退化：**facet 與 uncovertebral 肥大（壓出口根）**、**ligamentum flavum 肥大（壓脊髓）**。
- **多節塌陷 → kyphosis**；嚴重 facet 與椎間盤退化 → **節段不穩、spondylolisthesis**。

### 2.2 臨床

- **無神經壓迫的 spondylosis → 軸性頸痛（無根病變或脊髓病）**；常為發作性，數天到數週改善。
- 🆕 **疼痛源：椎間盤、facet、伸肌、greater occipital nerve**。
- 位置：頸後正中、後外側斜方肌、肩胛間 ± crepitus。
- 🆕 **常漏診：atlantoaxial osteoarthrosis**（2022）→ **較年長、上頸與枕頸交界局部痛**。

### 2.3 治療 🆕

- **首選保守**：NSAID、PT（**伸展＋頸伸肌強化**）、按摩、熱敷或冷療、**短期軟頸圈**（劇痛期）。
- 🆕 **單純軸痛（無明顯神經壓迫、不穩、變形）的融合 → 仍有爭議，一般不建議**：
  - 難以確認 pain generator；退化變化普遍；**無法僅憑影像判斷是否有症狀**；理學檢查很少能確診。
  - 🆕 小型研究：**2022（90 例）integrated interbody vs separate plate ACDF → 兩組 JOA、NDI 都顯著改善**。
  - 🆕 **122 例回溯：頸痛為主者 ACDF 結果比手臂痛為主者差** → **根病變的手術結果比單純軸痛可靠**。
- 🆕 **CDR 對軸痛不優於 ACDF**；大型試驗多**排除純頸痛**；🆕 **嚴重 facet arthropathy 與節段不穩 = CDR 禁忌**；考慮 CDR 前需仔細評估疼痛源。
- 🆕 **C1–2 OA 或不穩引起的頸痛 → 後方融合結果佳（2023）**。
- 🆕 **嚴重頸椎變形致頑固軸痛 → 矯正＋融合可能帶來重大改善**。

## 3. 頸神經根病變 🔄

### 3.1 病理與臨床

- **孔內根壓迫**：disk bulge 或突出、**uncovertebral 或 facet 肥大** → 根血供與功能受損 → 痛、無力、感覺改變。
- ✅ **頸根從同號 pedicle 上方出**（C6 根在 C5 與 C6 pedicle 之間），**腹外側方向**。
- 🆕 **不同於腰椎：paracentral 突出與孔狹窄都影響「同一條」根**。
- 脊髓＋根同時受壓 → **myeloradiculopathy**。
- ✅ **單節根病變只有 54% 呈典型（Netter）分布**；常表現為**單側頸痛、肩胛痛、不符皮節的上肢痛**。

| 根 | 症狀 | 運動 | 反射 |
|---|---|---|---|
| C2 | 後枕頭痛、顳部痛 | — | — |
| C3 | 枕部頭痛、眼眶後或耳後痛 | — | — |
| C4 | 頸基部、斜方肌痛 | — | — |
| **C5** | **外側臂** | **Deltoid** | **Biceps** |
| **C6** | **橈側前臂、拇指與食指** | **Biceps、腕伸** | **Brachioradialis** |
| **C7** | **中指** | **Triceps、腕屈** | **Triceps** |
| **C8** | **無名指與小指** | **指屈肌** | — |
| **T1** | **尺側前臂** | **手內在肌** | — |

### 3.2 保守 🔄

- 🆕 **自然病程相對良好（尤其軟性突出）：約 70–90% 單純根病變隨觀察或保守改善**。
- 無明顯神經缺損 → 先保守：NSAID、**等長頸部強化**、頸與上肢伸展、PT、**selective nerve root 類固醇注射**、口服類固醇。
- 🆕 **間歇頸椎牽引：部分醫師用於孔狹窄，但無強研究證明優於觀察**。

### 3.3 手術 🔄

- **適應症：保守失敗及／或進行性神經缺損（運動或感覺）**。
- **前方（ACDF、CDR）通常較受偏好**：
  - 🆕 **中央或旁中央突出可直接移除，不需牽拉脊髓或根**。
  - 🆕 **磨除 uncus 內側 → 直接移除造成孔狹窄的 uncovertebral 骨刺**。
  - 🆕 **interbody spacer 增加椎間高度 → 間接孔減壓**。
  - 🆕 **合併明顯軸痛（spondylosis、facet arthropathy）→ ACDF 優於 CDR**。
- **後方（keyhole posterior laminoforaminotomy）**：
  - 🆕 **需切除約 50% inferomedial facet 才能完整背側減壓，同時避免醫源性不穩**。
  - **facet 肥大 → 直接減壓**；**uncovertebral 肥大 → 間接減壓（根往後漂離骨刺）**。
  - 孔內軟性突出依位置可從後方直接移除。
  - 🆕 **前方不利時（如短頸病人 T1–2）→ 後方較佳**。
  - MIS foraminotomy（肌肉剝離少）流行，但臨床結果無明確優勢。
- 🆕 **風險差異**：

| 術式 | 主要風險 |
|---|---|
| **ACDF** | nonunion、**adjacent segment degeneration**、dysphagia |
| **CDR** | 植入物失敗或不穩、**incidental fusion（heterotopic ossification）**、dysphagia |
| **Foraminotomy** | 後方傷口併發症、**再狹窄** |

### 3.4 Level I 證據 🆕

- 🆕 **FACET（Foraminotomy ACDF Cost-Effectiveness Trial，2016–2020）**：
  - **265 例單節單側根病變 → posterior foraminotomy（132）vs ACDF（133），1 年**。
  - **後方在成功率與手臂痛不劣於 ACDF**。
  - **再手術 5%（後方）vs 3%（前方）**，無統計差異；後方**症狀復發（未手術）較多** → 1 年後再手術可能較高。
  - 🆕 **次分析：術後前 5 週後方頸痛較高**。
- 🆕 **CDR vs ACDF**：

| 研究 | 結果 |
|---|---|
| **2022 RCT：120 例（CDR 80、ACDF 40）單節，7 年** | 臨床成功與結果**無差**；**2 年 ASD：CDR 40% vs ACDF 43.9%**；CDR 保留較多 ROM |
| **MoM CDR：269 例（136 vs 133），5 年** | 6 週起兩組都改善並維持；**翻修與再手術無差**；CDR ROM 較高 |
| **兩節：397 例（209 vs 188），7 年** | **CDR 臨床成功與分數較好；index 再手術 4.2% vs 14.7%**（混入 myelopathy，未做根病變次分析） |
| **一或兩節：599 例（413 vs 186），5 年** | **ACDF 再手術較高：一節 17.3% vs 4.5%、兩節 21.0% vs 7.3%**（index＋adjacent） |

- 限制：ACDF 技術與植入物異質、CDR 廠牌不同；**ACDF 再手術率遠高於一般實務**、可能偏誤影響結果與再手術決策。
- 🆕 **三術式比較（僅回溯或資料庫）**：
  - **17 CDR vs 18 foraminotomy，平均 83.2 個月 → 臨床與滿意度無差**。
  - 🆕 **2023 資料庫 18,614 例（CDR 1,731、ACDF 15,862、foraminotomy 1,021）；PSM 後每組 535 → foraminotomy 再手術 2.1% vs CDR 0.6% vs ACDF 0.4%；傷口併發症或感染較高**（無臨床結果）。
- 🆕 **結論：無明確最佳術式**；ACDF、CDR、laminoforaminotomy 正確執行於適當病人都可得極佳結果 → 依**腹側／背側病理、病人目標、風險**個別化。

## 4. 頸椎脊髓病 🔄

### 4.1 病理與臨床

- 椎管尺寸受損 → 直接壓迫脊髓：
  - 🆕 **先天狹窄（矢狀椎管徑 <13 mm）**。
  - disk 突出或 bulge、嚴重 facet 或 uncovertebral 肥大、**ligamentum flavum 肥大或骨化、OPLL**。
  - **kyphosis** 也可造成或加重壓迫。
- 表現：**上肢感覺或運動異常、精細動作與靈巧障礙、步態平衡與協調問題**；晚期 **下肢明顯無力、大小便失能**；頸臂痛可有可無。
- myeloradiculopathy：脊髓＋孔內根同時受壓。
- 🆕 **嚴重狹窄＋急性頸椎創傷 → 牽拉傷 → central cord syndrome（上肢為主的運動感覺缺損）或急性 SCI（上下肢）→ 多數主張緊急減壓**。

### 4.2 自然病程與保守 🆕

- 🆕 **與根病變不同：myelopathy 為漸進性，通常不會隨時間改善**。
- 🆕 **典型：隱性起病 → 階梯式惡化**；機轉：**脊髓血流受損＋慢性機械壓迫的反應性發炎**。
- 🆕 **手術可防止惡化、改善結果、疼痛與神經狀態；但慢性或嚴重者神經恢復較少**。
- 🆕 **保守只給：輕度症狀，或圍術期風險過高者**；**輕症或無症狀 → 密切追蹤，共享決定手術門檻**。

### 4.3 手術 🔄

| 入路 | 術式 | 優點 |
|---|---|---|
| **前方** | ACDF、anterior corpectomy and fusion | **直接移除腹側病灶**（disk、uncovertebral 骨刺）；**較能矯正矢狀對位**；kyphosis 時脊髓 drape 在椎體上 → 前方矯正可**間接減壓** |
| **後方** | laminectomy＋fusion、**laminoplasty** | 移除背側病灶（flavum）；**多節減壓** |

- **Laminoplasty**：擴大椎板弓 → 增加椎管截面積；以自體或異體骨、縫線、anchor、spacer、plate＋screw 重建；**不融合 → 保留部分活動**。
- ✅ **多節 laminectomy 一般需同時融合（postlaminectomy kyphosis → 復發脊髓病與變形）**。
- 🆕 **選擇原則**：病灶節數、壓迫結構（腹側 disk／骨刺／OPLL vs 背側 flavum）、先天狹窄、整體對位。

| 情境 | 建議 |
|---|---|
| 🆕 **1–2 節 spondylotic myelopathy** | **ACDF 首選** |
| **retrovertebral 壓迫**（前方入路） | **corpectomy**；🆕 **但圍術期併發症較多、kyphosis 矯正較少** |
| 🆕 **>3 節狹窄** | 前後皆常考慮；🆕 **3–4 節 ACDF 的 X 光假關節可達 40–50%（多數無症狀）** |
| **後方：laminoplasty** | 極有效減壓；可同時 foraminotomy；🆕 **可能失去部分前凸**；🆕 **明顯 kyphosis（cervical >13–15°、segmental >5°）→ kyphosis 惡化、分數較差** |
| **明顯 kyphosis、不穩、軸痛為主**（可後方者） | **laminectomy＋fusion** 較佳 |
| 🆕 **明顯 kyphosis＋腹側 draping、不可被動矯正** | **前後合併**（多節 ACDF 或 corpectomy＋後方融合） |
| 🆕 **嚴重 OPLL 或骨化椎間盤** | **偏好後方**（laminoplasty 或 laminectomy＋fusion，依對位），避免從腹側硬膜剝除緊密骨化組織 |

### 4.4 併發症 🆕

| 入路 | 風險 |
|---|---|
| 前方（ACDF、corpectomy） | **dysphagia、dysphonia** |
| 後方 | **傷口併發症、感染、切口頸痛較多** |
| Laminoplasty | **前凸流失、矢狀對位惡化**；以往與長期軸痛相關；🆕 **但適當選擇（前凸保留、術前輕度軸痛）不增加術後軸痛** |
| Laminectomy＋fusion | **假關節**；多節後方融合（尤其跨頸胸交界）→ ROM 受限、僵硬 |

- 🆕 **C5 palsy**：
  - **前方或後方手術皆可發生**。
  - 機轉未明；推測：**脊髓後漂（drift back）牽拉 C5 根**、**中頸分水嶺血供**。
  - **deltoid 不同程度無力 ± 感覺障礙**。
  - 🆕 **預後佳，即使嚴重無力，多數 6 個月內恢復**。

### 4.5 證據 🆕

- 🆕 **CSM-S trial（唯一比較術式的 RCT）**：
  - **163 例 CSM：前方（多節 ACDF 或 corpectomy＋融合，63）vs 後方（laminoplasty 或 laminectomy＋融合，100）**。
  - **排除 segmental 或 global kyphosis >5°**。
  - **1 年臨床無差**。
  - 🆕 **併發症：前方 48% vs 後方 24%；最常見為術後吞嚥困難（41%）**。
- 其他前瞻比較：
  - 🆕 **136 例、5.6 年：前方 vs laminoplasty 恢復率無差；kyphotic 對位者神經恢復較差，尤其 laminoplasty**。
  - 🆕 **2022（46 例、1–2 節）：前凸時 ACDF = laminoplasty；kyphotic 時 ACDF 神經恢復較好**。
  - 🆕 **80 對 PSM：臨床與圍術期無差；前方吞嚥困難較多、後方 C5 palsy 較多**。
- 🆕 **CDR 於 myelopathy**：理論上融合穩定較有利 → **仍有爭議**。
  - 🆕 **一節 myelopathy 與 radiculopathy：CDR 242 vs ACDF 221，10 年 → 整體臨床成功 81.3% vs 66.3%、保留活動、鄰節翻修 6.9% vs 11.7%**。
  - 🆕 105 例 2 年：CDR 臨床與神經功能較好。
  - **多節狹窄與 CSM 的 CDR Level I 證據仍缺**。
  - 🆕 **hybrid**（CDR 或 laminoplasty＋融合）依各節穩定度與關節病變分別處理 → 適應症與比較結果仍在爭議。
- 🆕 **結論：無單一最佳**；依**病灶節數、壓迫結構、整體對位、個人風險**個別化。

## 6. Key Study Points（OKU 15）

- **無神經壓迫或嚴重變形的單純椎間盤或 facet 疾病，融合與 CDR 都有爭議**。
- 根病變通常自限；**保守失敗或進行性神經缺損 → 前方（ACDF、CDR）或後方（foraminotomy）手術**。
- **頸椎脊髓病最好手術治療**；前方（多節 ACDF、corpectomy＋融合）與後方（laminectomy＋融合、laminoplasty）**皆有效**。
- **Laminoplasty 與 CDR 是有前景的保留活動技術**，適應症與比較結果仍在釐清。
