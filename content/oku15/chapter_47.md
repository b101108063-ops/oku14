## 1. 解剖與檢查 🔄

### 1.1 骨性穩定 🆕

- 內側脛骨平台**凹**、內側股骨髁**凸** → 有骨性穩定。
- 🆕 **完全伸直時 screw-home mechanism → 骨性穩定最大**；屈曲過程中韌帶扮演主要角色。

### 1.2 ACL 🔄

- 肉眼兩束（實為數千條膠原纖維）；**以脛骨附著命名**。

| | AM bundle | PL bundle |
|---|---|---|
| 股骨起點 | 較**近端** | 較**遠端** |
| 脛骨附著 | 前內 | 後外 |
| 方向 | 🆕 **較垂直** | 🆕 **較水平** |
| 功能 | 🆕 **抗前移** | 🆕 **抗旋轉（內旋）** |
| 檢查 | 🆕 **Lachman（ACL 最敏感檢查）** | 🆕 **Pivot shift** |

- 🆕 **bifurcate ridge 分隔兩束；lateral intercondylar ridge（resident's ridge）為兩束前緣**。
- 🆕 **脛骨足印寬：冠狀在 medial tibial eminence 外側；矢狀約與外側半月板前角根部後緣對齊**。

### 1.3 PCL 🔄

- **主要抗後移**；也抗 anteromedial rotation。
- 兩束：**anterolateral、posteromedial**。
- **股骨**：足印寬，佔**髁間窩最遠端與最前方**；**AL 緊鄰遠端股骨軟骨**，PM 距軟骨緣幾 mm。
  - 🆕 MFC 軟骨上三個點：**trochlear point**（髁間窩內側頂點，軟骨突然轉向內）、**medial arch point**（軟骨轉為直向後）、**posterior point**；🆕 **兩束以 medial arch point 分**，皆在 medial intercondylar ridge 前方。
- **脛骨**：關節面下方 **PCL facet**；🆕 **前上緣 = 內側半月板後角亮白纖維；向遠端延伸到 champagne glass drop-off**。
- 較垂直 → 最適檢查為 **posterior drawer（90° 屈曲）**。

### 1.4 PLC 🔄

- 功能：**抗 varus**，並參與**抗後移與脛骨外旋**。

| 靜態（3） | 動態（3） |
|---|---|
| **LCL** | **Biceps femoris** |
| **Popliteus tendon** | **ITB** |
| **Popliteofibular ligament** | **Gastrocnemius 外側頭** |

- arcuate ligament 與後外側囊對穩定重要，**但重建時通常不考慮**。
- 🆕 **層次與附著**：
  - **ITB 最淺 → Gerdy tubercle**。
  - **LCL**：ITB 深層，起於**外上髁略近端與後方** → **腓骨上最前方的結構**。
  - **Popliteus tendon**：起於 **LCL 起點遠端與前方**，向後內走至脛骨後方肌腹。
  - **Biceps femoris**：**腓骨上最後方的結構**。
- 🆕 **Dial test**（最常用）：俯臥，膝 90° 與 30° 雙側脛骨外旋比較。
  - **只有 30° 左右差 >10° → 單純 PLC**。
  - **30° 與 90° 都有差 → PLC＋PCL**。

### 1.5 Posteromedial corner 🔄

- **MCL（deep＋superficial）＋POL**。
- **deep MCL**：內側關節囊增厚，**緊連內側半月板**。
- 🆕 **sMCL**：起於**內上髁後方與近端**；**脛骨寬附著約 joint line 下 6 cm**；另有**近端次附著約 1 cm**。
- 🆕 **POL**：起於 **gastrocnemius tubercle 遠端與前方**，在 **semimembranosus 腱淺層**附著於脛骨後方、約 joint line 下 1 cm。
- 功能：
  - **sMCL = 外翻主要穩定，尤其屈曲時**。
  - 🆕 **POL**：也抗外翻；後方結構 → **完全伸直時貢獻最大**；**抗脛骨外旋**。
  - PMC（尤其前方部分）受傷 → **anteromedial rotatory instability（AMRI）**。
- 🆕 **檢查**：
  - **valgus stress 0° 與 30°：只有 30° 開 → 單純 MCL；0° 與 30° 都開 → 合併韌帶傷**。
  - **AMRI**：30° 屈曲＋外旋＋valgus → **前內脛骨平台向前半脫位**。

## 2. 影像 🔄

### 2.1 總則 🆕

- 從 X 光開始；**能耐受則負重**，並**與對側比較**。
- 🆕 **Stress radiographs（valgus、varus、posterior）**：判斷嚴重度與不穩程度、引導是否手術（Key Study Point）。

### 2.2 ACL 🔄

- ✅ **Segond fracture = pathognomonic**：前外側囊（或 ALL）在**強制內旋**時撕脫；**特異但不敏感**。
- 🆕 **Tibial spine fracture（骨骼未成熟）**：韌帶完整、脛骨棘骨失效。
  - **非移位 → 伸直固定**；**移位 → 手術**。
  - 🆕 **持續成角的卡入軟組織：內側半月板前角（最常）> intermeniscal ligament > 外側半月板前角**。
  - 開放或鏡下、**screw 或 suture**（如 two-suture four-limb）。
  - 🆕 **術後僵硬極常見 → 必須積極 ROM**；🆕 **生長停滯似與技術無關（2023）**。
- 🆕 **對位**（尤其翻修）：
  - **冠狀不良 → ACL 應力增加 → 早期失敗 → HTO 或 DFO 矯正**。
  - **PTS 增加 → ACL 受力增加 → anterior closing wedge slope-reducing osteotomy** 降低 graft 受力、改善結果。
  - Key Study Point：**PTS 增加或減少分別增加 ACL 或 PCL 重建失敗風險**。
- 🆕 **翻修**：X 光＋CT 評估**舊隧道位置與擴大** → 決定**一或二階段**。
- ✅ **MRI = 首選**：
  - 典型 bone bruise：**後外側脛骨平台＋外側股骨髁**（pivot shift），可能比韌帶本身更明顯（尤其 ACL 疤痕黏到 PCL 時）。
  - 🆕 細微徵象：**髕腱鬆弛**（脛骨略前移）、**ACL 斜度改變（正常約與 Blumensaat line 平行）**。
  - 🆕 **一定要找 ramp lesion**（ACL 撕裂發生率高）。

### 2.3 PCL 🔄

- 骨性撕脫：**非移位 → 保守**；**急性移位＋後方不穩 → 手術**。
- 🆕 **不如 ACL 明顯；MRI 可能仍有連續性但功能不全 → 高度懷疑＋完整理學檢查**。
- 🆕 **posterior stress view**：判斷不穩程度與是否手術（左右差）。
- ❌ OKU 14 的「後抽屜 >10 mm = grade 3」「**ABI <0.9 → CTA**」本章未列。

### 2.4 MCL 🔄

- 通常無骨性成分；✅ **慢性：股骨附著處鈣化 = Pellegrini-Stieda**。
- MRI 判斷範圍與**位置**：
  - 🆕 **近端（股骨起點）斷裂較常見，且癒合率高於遠端撕脫**。
  - 遠端若仍貼近脛骨附著處也可癒合。
  - ✅ **遠端翻到 pes tendons 上方淺層 = Stener lesion → 很難癒合、可能需手術**。
- 不確定是否手術 → stress view。

### 2.5 PLC 🔄

- **腓骨頭撕脫**可見於 X 光；**移位＋varus 鬆弛 → 直接修補成功**。
- MRI 評估 LCL、PFL、popliteus 複合體。
  - 🆕 **LCL 斜行**（外上髁 → 腓骨頭前方），**多數情況單一切面看不全；若冠狀或矢狀可見全長，可能代表某端斷裂**。
  - 🆕 **最可靠：axial 從股骨起點追蹤到腓骨頭**（三平面合併）。
  - 🆕 **common peroneal nerve 繞腓骨頸，sagittal 最清楚**；足下垂時判斷神經是否連續或移位 → 術前規劃。
- 不確定 → stress view。

### 2.6 MLKI 🔄

- 高能量脫位（明顯變形），或**較低能量**、已自行復位、X 光只有**小囊撕脫**。
- 🆕 **無法復位或需 ex-fix 時，術中 stress view** 判斷哪些結構失能（急性期難檢查）。
- 終需 MRI：🆕 **判斷近端撕脫 vs 中段撕裂（repair vs reconstruction）**。

## 3. ACL 處置 🔄

### 3.1 保守 ✅

- 較不活動、不做切轉者 → **PT＋護具**可成功。
- 🆕 **風險：軟骨與半月板傷**。
  - **內側半月板後角 = 前移的次要穩定 → 慢性 ACL 不足時受損**。
  - **外側半月板撕裂較常見於急性 ACL 撕裂**。

### 3.2 ACL repair 與 BEAR 🔄

- 🆕 **ACL repair 越來越被接受**；幾年前仍被否定，**2023：加 internal brace 有前景**。
- **傳統理想對象：年紀稍大、ACL 自股骨端撕脫**（非中段或脛骨端）；概念仍在演進。
- 優點：**移除骨較少、可能本體感覺較好**。
- 🔄 **BEAR（bridge-enhanced ACL repair）**：支架保護撕裂韌帶免受關節內滑液環境影響；**滑液不利血塊形成**（關節內結構癒合力差的原因之一）→ 支架促血塊 → 促癒合。
  - 🔄 **FDA 試驗進行中；臨床資料有限**（OKU 14 寫「2 年 RCT 鬆弛不劣於自體移植、肌力較好」，本版語氣保守）。

### 3.3 重建技術 🆕

- ✅ **重建 = 金標準**。
- 🆕 **Transtibial**（經脛骨隧道鑽股骨隧道）：曾為金標準，但**易鑽出垂直股骨隧道 → 可抗前移、不足以抗旋轉**；需特殊技術與器械才能解剖。
- 🆕 **Double-bundle**：生物力學優於單束，**但臨床無改善、技術要求高、翻修複雜 → 失寵**。
- 🆕 **Single-bundle＋獨立鑽孔 = 目前最常用**：
  - **AM portal（膝過屈以達股骨後壁）** 或 **retrodrill（不需過屈）** → **臨床與螺釘發散無差**。
  - 🆕 **股骨隧道越後越好**（抵抗早期屈曲時的力，此時 ACL 最易斷）。
  - 🆕 **未做 notchplasty → bifurcate ridge 可作為股骨足印中心標記**。
  - 🆕 **脛骨標記：PCL 前 10 mm、intermeniscal ligament 後 9 mm、約對齊外側半月板前角後緣**。

### 3.4 Graft 選擇 🆕

| | 重點 |
|---|---|
| **Autograft vs allograft** | 🆕 **<34 歲（可能 <40 歲）autograft 結果較好、失敗率較低**；年長者失敗風險降低，免供區併發症的好處逐漸超過 |
| **Hamstring** | 傳統首選軟組織 graft；🆕 **quadrupled hamstring 破壞負荷最高**；🆕 **但大型長期研究反覆顯示失敗率高於 BTB 與 quad** |
| **BTB** | 🆕 **骨對骨癒合（約 6 週 vs 軟組織 12 週）**；🆕 **aperture fixation，較接近膝旋轉中心**；**缺點：供區前膝痛（尤其跪）** |
| **Quadriceps** | 🆕 **最新、快速普及，在美國大致取代 hamstring**；軟組織 graft 缺點相同，**但不犧牲 hamstring（抗前移的動態限制）**；🆕 **失敗率低於 hamstring、約等於 BTB；前膝痛少於 BTB**（適合跪的運動員或勞工） |

- 🆕 **軟組織 graft 用 suspensory fixation → bungee cord effect → 隧道溶骨**。
- 最終依病人目標、需求與偏好決定。

### 3.5 LET 🆕

- 10 年來穩定普及，可增強 ACL repair 或重建。
- 🆕 **技術：取 ITB 條帶、保留 Gerdy tubercle 附著 → 穿 LCL 深層 → 固定於 LCL 附著的後上方**。
- 生物力學**降低 ACL 應力** → 🆕 **高風險族群再斷裂減少**。
- 🆕 **STABILITY RCT：年輕 hamstring ACLR＋LET → 2 年 graft rupture 與鬆弛顯著減少**。
- 🆕 **可能適應症：多數翻修 ACLR、膝過伸、高等級 pivot shift、年輕切轉運動員**。

## 4. PCL 處置 🔄

- ✅ **多數單純 PCL 保守**：**股四頭肌訓練**（向前拉力、限制後移）＋🆕 **dynamic PCL brace（防 tibial sag）**。
- 🆕 **斷 PCL 需極大力 → 單純傷少見，多為 dashboard 機轉（近端脛骨受向後力）→ 看似單純時要高度懷疑合併傷**。
- 🆕 **未處理 PCL → PF 與內側腔室 OA**。
- 🆕 **手術適應症：移位骨性撕脫、保守後持續症狀、合併傷**。
  - 撕脫 → **開放後內側入路直接修補**，結果佳。
- 🆕 **單束 vs 雙束**：雙束生物力學較好；早期臨床無差，但 🆕 **2023 研究提示雙束分數可能較好（不同於 ACL）**；理由：**PCL 股骨足印大，單束無法充分重建**。
- 🆕 **Achilles tendon allograft**（需大 graft）。
- 🆕 **Killer turn**：脛骨關節內開口到股骨足印的銳角 → 長期可能鬆弛。
  - **Tibial inlay**（開放後方，直接固定於 PCL facet）vs **transtibial**：**inlay graft 受力略低但臨床無意義；結果相似、transtibial 併發症較少**。

---

## 5. MCL 處置 🔄

- ✅ **四大韌帶中內在癒合力最強**（Key Study Point），**尤其股骨內上髁近端撕脫**。
- 🆕 **單純 MCL（甚至 grade 3）→ hinged knee brace（限 varus-valgus）＋PT＋活動調整 6 週**；結束時仍痛或鬆 → 考慮手術。
- 🆕 **ACL＋MCL**：若無其他急性手術理由（如 bucket-handle）→ **MCL 先保守 3–6 週練 ROM，若 valgus 穩定恢復 → 單純 ACLR**。
- 🆕 **急性 MCL 手術最常因其他理由**（bucket-handle、MLKI）。
- **Repair vs reconstruction**：
  - **avulsion（近或遠端）→ 直接修補**，可加 **heavy braided suture** 或 **allograft** 增強。
  - 🆕 **2023：即使急性，重建可能結果較可靠、僵硬較少**。
  - 🆕 **原則：中段撕裂修補效果較差（較適合重建）；撕脫且韌帶本身完整 → 修補**。
- 🆕 **重建技術**（無明確最佳）：
  - **Achilles allograft**（MCL 為寬片狀，不同於管狀的 LCL）。
  - 股骨內上髁 **inlay**（隧道＋螺釘或 cortical button）→ **穿 pes tendons 深層** → **脛骨兩點：joint line 下約 1 cm（重建 deep MCL）與 6 cm**，anchor 固定。
  - 🆕 **有 AMRI → 加做 POL 重建**（另一條 graft 固定於股骨內上髁與脛骨後內）。

---

## 6. PLC 處置 🔄

- 🆕 **單純 PLC 極少見**（純 varus 力少見，對側膝會擋住內側撞擊）；處置類似 MCL。
  - LCL 癒合力低於 MCL，但單純傷可能無明顯 varus 不穩；**鬆弛持續則需處理**。
- ✅ **直接修補**：腓骨撕脫骨折、囊撕脫、**LCL 自外上髁近端撕脫**（可加 heavy suture 或 allograft）。
- ✅ **避免修補中段撕裂**；**PLC 修補失敗率整體高於重建**。
  - ❌ OKU 14 的 **37–40% vs 6–9%** 本章未列數字。
- 🆕 **所有技術關鍵步驟：找出並游離 common peroneal nerve，全程保護**。

### 6.1 重建技術 🆕

| 技術 | 類型 | 做法 | 適用（作者經驗） |
|---|---|---|---|
| 🆕 **Larson** | 腓骨為基礎（最簡單） | 腓骨隧道＋**LCL 起點單一 socket**；allograft 兩尾穿 ITB 深層進 socket；**膝 20–30° 屈曲＋輕 valgus 固定** | **純 varus 不穩、popliteus 完整** |
| 🆕 **Arciero** | 腓骨為基礎 | 腓骨隧道；**一尾到 LCL 起點、一尾到 popliteus 起點**（LCL 遠端前方） | **popliteus 傷 ± 輕度旋轉不穩** |
| 🆕 **LaPrade** | **脛腓**為基礎、**兩條 graft** | 腓骨隧道＋外側脛骨隧道（前 → 後）；graft 1：腓骨 → LCL 起點＋脛骨隧道；graft 2：popliteus 股骨附著 → 後外繞 → 脛骨隧道 | **明顯旋轉不穩** |

- 🆕 **束縛階梯：Larson < Arciero < LaPrade**；🆕 **2022 生物力學：tibiofibular 重建抗旋轉優於只用腓骨**，臨床意義未定。
- LaPrade 可用於所有情況，但**需第二條 graft、更多隧道 → 手術時間與併發症增加**（MLKI 本已複雜）。

## 7. OKU 14 CH43 中 OKU 15 不再列出的內容 ❌

- ❌ **髕股不穩全部內容**（MPFL 解剖、**五大易感因子**、**Dejour 分型**、**Caton-Deschamps >1.2**、**TT-TG >15–20 mm、CT 與 MRI 不可互換**、**Schöttle point（後皮質線前 1 mm、MFC 後緣起點遠端 2.5 mm、Blumensaat 近端）**、MPFL graft 只作 checkrein）→ **移至 🆕 Ch.51**。
- ❌ **ABI <0.9 → CTA**；膕動脈與腓總神經損傷的 danger zone 敘述。
- ❌ **後抽屜 >10 mm = grade 3**。
- ❌ **PLC primary repair 失敗 37–40% vs 重建 6–9%**（本版只寫 repair 失敗較高）。
- ❌ **BEAR 2 年 RCT 鬆弛不劣、肌力較好**（改為 FDA 試驗中、資料有限）。
- ❌ 「Segond 預示創傷後關節炎」等 bone bruise 預後敘述。

## 8. Key Study Points（OKU 15）

- **ACL AM 束較垂直 → 抗前移；PL 束較水平 → 抗內旋**。
- **對位很重要**：冠狀 varus／valgus 增加韌帶應力 → 重建失敗；矢狀 **PTS 增加或減少 → ACL 或 PCL 重建失敗風險增加**。
- **MCL 是四大韌帶中內在癒合力最強者，常可保守成功**。
- **Stress radiographs** 在嚴重度不確定時很有用，可評估不穩程度、引導治療。

## 9. Anki 候選題

1. 膝完全伸直時最大骨性穩定的機轉？→ screw-home mechanism。
2. ACL 兩束以什麼命名？→ 脛骨附著位置。
3. 分隔 ACL 兩束的股骨骨嵴？兩束前緣的骨嵴？→ bifurcate ridge；lateral intercondylar（resident's）ridge。
4. ACL 脛骨足印的冠狀與矢狀定位？→ medial tibial eminence 外側；約對齊外側半月板前角根部後緣。
5. ACL AM 束與 PL 束的方向與功能？→ AM 較垂直抗前移；PL 較水平抗旋轉。
6. Lachman 與 pivot shift 分別主要測哪一束？→ AM；PL。
7. ACL 最敏感的檢查？→ Lachman。
8. PCL 兩束以 MFC 的哪個點分界？→ medial arch point。
9. PCL 脛骨足印的前上緣與遠端界線？→ 內側半月板後角亮白纖維；champagne glass drop-off。
10. PCL 的最佳檢查？→ 90° posterior drawer。
11. PLC 三個靜態穩定結構？→ LCL、popliteus tendon、popliteofibular ligament。
12. PLC 三個動態穩定結構？→ biceps femoris、ITB、gastrocnemius 外側頭。
13. 腓骨上最前方與最後方的結構？→ LCL；biceps femoris。
14. Popliteus 起點相對 LCL 起點的位置？→ 遠端前方。
15. Dial test 只有 30° 差 >10° 的意義？30° 與 90° 都差？→ 單純 PLC；PLC＋PCL。
16. sMCL 的脛骨主附著與次附著距 joint line？→ 約 6 cm；約 1 cm。
17. POL 何時貢獻最大？另外抗什麼？→ 完全伸直；脛骨外旋。
18. Valgus stress 只有 30° 開 vs 0° 與 30° 都開？→ 單純 MCL vs 合併韌帶傷。
19. AMRI 的檢查？→ 30° 屈曲＋外旋＋valgus，前內脛骨平台向前半脫位。
20. Segond fracture 的機轉與診斷特性？→ 強制內旋致前外側囊／ALL 撕脫；ACL 撕裂特異但不敏感。
21. Tibial spine fracture 卡入軟組織的順序？→ 內側半月板前角 > intermeniscal ligament > 外側半月板前角。
22. Tibial spine fracture 術後最常見問題？生長停滯與技術有關嗎？→ 僵硬；無關。
23. PTS 增加對 ACL 的影響與手術？→ ACL 受力增加；anterior closing wedge slope-reducing osteotomy。
24. 翻修 ACLR 用 CT 評估什麼？→ 舊隧道位置與擴大，決定一或二階段。
25. ACL 撕裂典型 bone bruise？→ 後外側脛骨平台＋外側股骨髁。
26. ACL 撕裂 MRI 細微徵象？→ 髕腱鬆弛、ACL 與 Blumensaat line 不平行。
27. 為何 PCL 損傷易漏診？→ MRI 可能看似連續但功能不全。
28. 慢性 MCL 的 X 光徵象？→ Pellegrini-Stieda。
29. MCL 哪一端斷裂較常見且癒合較好？→ 近端（股骨）。
30. Stener lesion of MCL 的定義？→ 遠端 MCL 翻到 pes tendons 上方淺層。
31. MRI 評估 LCL 最可靠的方法？→ axial 由股骨追蹤至腓骨頭。
32. Common peroneal nerve 在哪個 MRI 切面最清楚？→ sagittal。
33. 慢性 ACL 不足時哪個半月板部位受損？急性 ACL 撕裂？→ 內側半月板後角；外側半月板。
34. ACL repair 傳統理想對象？→ 年紀稍大、股骨端撕脫。
35. BEAR 支架的原理？→ 保護韌帶免受滑液、促血塊形成。
36. Transtibial ACLR 的主要問題？→ 垂直股骨隧道、抗旋轉不足。
37. Double-bundle ACLR 為何失寵？→ 臨床無改善、技術難、翻修複雜。
38. AM portal vs retrodrill？→ 臨床與螺釘發散無差。
39. 股骨隧道位置原則？→ 越後越好。
40. ACL 脛骨隧道的三個標記？→ PCL 前 10 mm、intermeniscal 後 9 mm、外側半月板前角後緣。
41. Autograft 明確優於 allograft 的年齡？→ <34 歲（可能 <40 歲）。
42. 三種 autograft 中破壞負荷最高？長期失敗率最高？→ 都是 hamstring（quadrupled）。
43. BTB vs 軟組織 graft 癒合時間？→ 約 6 週 vs 12 週。
44. Suspensory fixation 的問題？→ bungee cord effect → 隧道溶骨。
45. Quad tendon 相較 hamstring 與 BTB？→ 失敗低於 hamstring、約等於 BTB；前膝痛少於 BTB。
46. LET 的技術？→ ITB 條帶保留 Gerdy 附著、穿 LCL 深層、固定於 LCL 附著後上方。
47. STABILITY trial 結果？→ 年輕 hamstring ACLR＋LET：2 年 graft rupture 與鬆弛減少。
48. LET 可能適應症？→ 翻修、膝過伸、高等級 pivot shift、年輕切轉運動員。
49. 單純 PCL 保守治療內容？→ 股四頭訓練＋dynamic PCL brace。
50. 未處理 PCL 的後果？→ PF 與內側腔室 OA。
51. PCL 手術適應症？→ 移位骨性撕脫、保守後持續症狀、合併傷。
52. PCL 為何雙束可能較好？→ 股骨足印大。
53. PCL 重建常用 graft？→ Achilles allograft。
54. Killer turn 的對策與比較？→ tibial inlay；結果與 transtibial 相似、transtibial 併發症較少。
55. 單純 MCL grade 3 的處置？→ hinged brace＋PT＋活動調整 6 週。
56. ACL＋MCL 合併傷常見策略？→ MCL 保守 3–6 週練 ROM，valgus 恢復後單純 ACLR。
57. MCL 重建 graft 與脛骨固定點？→ Achilles allograft；joint line 下 1 cm 與 6 cm。
58. 有 AMRI 時 MCL 重建要加做？→ POL 重建。
59. 單純 PLC 為何少見？→ 純 varus 力少見，對側膝擋住。
60. PLC 重建所有技術的關鍵步驟？→ 找出並保護 common peroneal nerve。
61. Larson 技術的固定姿勢？→ 20–30° 屈曲＋輕 valgus。
62. PLC 重建束縛階梯？→ Larson < Arciero < LaPrade。
63. 純 varus＋popliteus 完整、popliteus 傷、明顯旋轉不穩各選？→ Larson、Arciero、LaPrade。
