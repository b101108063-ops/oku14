## 1. 拇僵直（Hallux rigidus）🔄

### 1.1 病因與表現

- ✅ **第一 MTP 關節炎 = 足部最常見 OA**（Key Study Point）。
- 🆕 **1887 首述**；確切病因仍有爭議。
- 🆕 **相關因素：蹠骨頭形狀異常、hallux valgus、metatarsus adductus**；亦見於發炎性或結晶沉積性關節炎。
- 臨床：**活動時加重的第一 MTP 局部痛、ROM 下降、背側骨刺**。
- X 光：**JSN、軟骨下硬化、蹠骨頭背側骨刺**。

### 1.2 Coughlin and Shurnas 分類 🔄

| Grade | 臨床 | X 光 |
|---|---|---|
| **0** | **完整無痛 ROM（背屈 40–60°）**，或與對側相比失去 10–20% | 正常 |
| **1** | **末端輕痛，背屈 30–40°**（失去 20–50%） | 輕度背側骨刺，其餘正常 |
| **2** | **末端中度痛，背屈 10–30°** | 中度背側骨刺、**<25% 背側 MTP 受累**、輕度 JSN |
| **3** | **幾乎持續痛；末端痛，背屈 <10°（失去 75–100%）；無中段痛** | 嚴重背側骨刺、**>25% 背側受累**、嚴重 JSN、軟骨下囊腫 |
| **4** | **中段 ROM 痛**、弧度 <10° 及／或失去 75–100% 背屈 | **關節周圍囊腫**、>1/4 背側關節間隙受累 |

- 🆕 **grade 3 vs grade 4 的關鍵 = grade 4 有 midrange pain；grade 3 只有極端角度痛**。

### 1.3 保守 🆕

- **carbon fiber foot plate**、口服或外用 NSAID、活動調整。
- 失敗 → **類固醇注射**合理。
- PRP、幹細胞：可嘗試，**無明確證據**。

### 1.4 保留關節手術 🔄

- **Dorsal cheilectomy**：
  - 移除蹠骨頭（與近節趾骨）背側骨刺、清除不穩軟骨、軟組織釋放。
  - 適合：**早期 OA、以背側骨刺痛為主**。
  - 🆕 **保留副韌帶，避免角度變形**。
  - 🆕 **75% 滿意到非常滿意**。
  - 🆕 **常為暫時性處置**；🆕 **最常見併發症 = 持續痛或功能受限需翻修，約 10%**。
- 🆕 **Moberg osteotomy**：**近節趾骨近端背側 closing wedge** → 把 ROM 移到較有功能的背屈位置；可合併 cheilectomy。
- **Interpositional arthroplasty**：局部組織或 **dermal matrix** 包覆蹠骨頭，或 **polyhydrogel implant**。
  - ✅ **初期研究低併發症；後續系列併發症與翻修率高得多**。
- 第一 MTP arthroplasty。

### 1.5 犧牲關節：MTP 融合 🔄

- ✅ **晚期 MTP OA 的 gold standard**：蹠骨頭與近節趾骨融合於功能位 → **可靠止痛**。
- 🆕 **改善步行、運動能力與步態運動學**。
- 🆕 **限制：鞋子（不能高跟）、踮腳尖活動（芭蕾、部分瑜伽）**。
- 🆕 **最棘手併發症 = 不癒合，部分系列最高 20%**；另有內固定刺激、**IP 關節 OA 進展、transfer metatarsalgia**。
- ❌ OKU 14 的「滿意度 90–100%、癒合 >90%」未重述。

## 2. 小 MTP 關節炎 🔄

### 2.1 Freiberg infraction 🔄

- 🆕 **足部第二常見 osteochondrosis**；🆕 **主要影響年輕女性運動員**。
- 🆕 **危險因子：DM、SLE、高凝狀態**。
- 🆕 **生物力學**：
  - **Lisfranc 關節與 keystone 結構 → 第二列剛性**。
  - **第二或第三蹠骨較長** → 關節應力增加。
  - **腓腸肌緊、穿高跟鞋**。
- ❌ OKU 14 的「第三 27%、第四 3%、第五 <2%」與「五期分期」本版未列。

### 2.2 原發小 MTP OA 🆕

- **MTP 不穩 → 背側磨損**。
- 🆕 **醫源性：縮短截骨後，不穩修補過緊**。
- 發炎性：滑膜炎 → 軟骨磨損與不穩。

### 2.3 診斷與治療 🔄

- **三張 WB 足部 X 光**；**MRI 區分 Freiberg 與原發 OA**；疑 RA → 發炎指標（滑膜炎影響手術）。
- **保守（Freiberg）**：
  - 🆕 **metatarsal bar（第二 MTP 處挖空）或 forefoot rocker**。
  - 骨刺激器（證據不足）。
  - **類固醇**：暫時；**反覆注射 → 不穩與退化**；幹細胞、PRP 無明確證據。
- **保守（原發 OA）**：找主要疼痛源；🆕 **hammertoe → Budin splint＋metatarsal pad**；區分趾 vs MTP 痛，處理 hallux valgus 等。
- **手術**：
  - 保留關節：**清創、microfracture、截骨（重新對位卸載）、軟骨修復（autograft 或 allograft）**。
  - 犧牲關節：**interpositional arthroplasty**、植入物（合成軟骨、dermal matrix）、**蹠骨頭切除**、🆕 **3D 列印客製植入物（2025）**。
- 🆕 **結果**：**15 例 grade 3–5、平均 11 年 → AOFAS 與 VAS 改善、81% 非常滿意**；另一研究 133 個月 ROM、分數、關節間隙改善。
- 🆕 **SR：只有兩篇 Level III → 無法區分保留 vs 犧牲關節手術**。

## 3. 中足關節炎 🔄

- **TMT 關節**：後足 → 前足負荷傳遞。
- 🆕 **矢狀活動由第一到第五遞增：第一 TMT 約 1–2°、第五 TMT 約 10°**。
- 🆕 **TMT = 足部第二常見 OA 部位（僅次第一 MTP）**。
- 🆕 **>60 歲 X 光中足 OA 約 20%**（2024）。
- 多為創傷後；🆕 **危險因子：女性、PCFD、小趾變形、BMI**。
- **保守**：縱弓塌陷 → **鞋子加硬及／或足弓支撐**；🆕 **影像導引 IA 類固醇：可止痛但短暫，多數 6 個月內復發**；無 RCT，但多數保守有部分效果。
- **手術**：保守失敗 → **症狀關節融合**（Key Study Point：gold standard）。
  - 🔄 **TMT 融合不癒合 2–12%**（OKU 14：3–7%）；病史複雜或吸菸者較高。
  - 🆕 **不癒合危險因子：單用鋼板固定、吸菸、非解剖對位**。

## 4. 後足關節炎 🔄

### 4.1 病因與流行病學

- 急性創傷、反覆微創傷、不吻合或對位不良、**相鄰關節融合**、韌帶不穩、發炎、骨壞死。
- 🆕 **盛行 10–35%，尤其肥胖老年女性**。
- 🆕 **距下 OA 最常為創傷後（距骨或跟骨骨折）**：
  - 🆕 **關節內跟骨骨折 → 距下 OA 最多 17%（風險與 Sanders 分類相關）；3–32% 最後需距下融合**。
  - 🆕 **距骨頸骨折 → 距下 OA 50–100%（尤其延伸至 lateral process）；過半以距下融合治療**。

### 4.2 評估

- 受累關節局部痛與腫；🆕 **距下 OA → sinus tarsi 痛**；🆕 **不平地面（沙、碎石）行走困難**。
- 問創傷、不穩、手術史。
- **WB AP（TN 退化、前足內外展）、lateral（距下與 TN 間隙、planus 或 cavus）、oblique**；**hindfoot alignment view（varus／valgus）**。
- **CT 最準確**，利於規劃；**WBCT** 研究增加。

### 4.3 保守 🆕

- 活動調整、NSAID、避免高衝擊。
- **鞋子調整、orthotics**：🆕 **輕中度 → 簡單 rocker-bottom**；晚期 → orthotics 減壓、矯正柔軟變形、限制關節活動、容納固定變形。
- 🆕 **類固醇：只有三分之一效果 >6 個月；三分之一 2 年內需手術**。

### 4.4 手術：融合 🔄

- 保守失敗 → 受累後足關節融合。
- 🆕 **屍體：距下融合 → CC 與 TN 活動限制到正常的一半**。
- 🔄 **單獨 TN 融合 → 距下與 CC 活動降到正常的 <8%**（OKU 14：<10%）。
- 🆕 **三關節融合長期：踝 OA 40–100%、中足 OA 約一半** → 🆕 **趨向選擇性單獨距下或雙關節融合（保留活動、避免相鄰 OA）**。

> ⚠️ **OKU 15 內部數字不一致**：Ch.53 寫三關節融合後**踝 OA 38–61%、中足 OA 33–73%**，本章寫**踝 OA 40–100%、中足約一半**；Ch.53 以「TN 融合使**後足 ROM 減少 80–90%**」表述，本章為「**距下與 CC 活動 <8%**」。考試時注意題目採用哪種描述。

- ❌ OKU 14 的「距下融合癒合 ≥90%；吸菸、翻修、跟骨高度喪失較差」「TN 融合極易不癒合」本版未列。

## 5. 踝關節炎 🆕

### 5.1 病因與保守

- 🆕 **2025：踝 OA 造成的活動受限與鬱血性心衰竭等全身疾病相當**。
- ✅ **不同於髖膝：多為創傷後**（Key Study Point）。
  - 🆕 **SR：創傷後最常見原因 = 旋轉型踝骨折；第二 = 反覆扭傷**。
  - 較少：原發 OA、RA、lupus。
- **保守**（永遠先做）：減少踝活動與負荷 → 活動調整、🆕 **Arizona brace、rocker-bottom 鞋**；NSAID、acetaminophen；**療效證據有限**。
- 保守失敗 → **ankle arthrodesis 或 ankle arthroplasty**。

### 5.2 Ankle arthrodesis 🆕

- **傳統 gold standard**：耐久。
- 缺點：**ROM 喪失 → 步態受限**，常需 PT；但許多病人原本 ROM 已受限，止痛效益抵消。
- 🆕 **相鄰關節**：生物力學顯示應力增加，但**臨床證據有限**；🆕 **22 年追蹤（創傷後踝 OA 融合）：同側足 OA 比對側更常見且更限制功能**。
- 🆕 **技術：關節鏡 vs 開放、植骨選擇、構造 → 無共識**；🆕 **前方鋼板生物力學增加剛性，但無臨床證據 → 許多醫師用全螺釘**。

### 5.3 TAA 🆕

- 🆕 **2022：TAA 發生率 2009–2019 增加 121%**（器械與技術進步）。
- 優點：**保留 ROM、相鄰關節應力較小、步態較正常**（生物力學上比融合更接近正常步態）。
- 🆕 **主要顧慮 = 植入物耐久度**；多數現行植入物上市 <10 年。
- 🆕 **近期研究：7–10 年存活約 90–95%**。
- 詳細 TAA 技術見 [Ch.56]({{< relref "/oku15/chapter_56.md" >}})。

## 6. 距骨骨壞死 🔄

### 6.1 解剖與病因

- ✅ **完全骨外血供；無肌腱附著或肌肉起點**。
- 🔄 **5 個關節面約佔距骨表面 70%**（OKU 14：>60%）。
- ATA、PTA、peroneal 的複雜吻合；🆕 **主要動脈 = artery of the tarsal canal，供應距骨體三分之二**。
- ✅ **四分之三與骨折相關，主要為距骨頸骨折**（Key Study Point）。
- 其他：**sickle cell、發炎性疾病、酒精使用障礙、長期類固醇、特發**。

### 6.2 診斷 🆕

- 🆕 **慢性、漸進性前踝負重痛**；問創傷、手術、共病、危險因子。
- **WB 足踝 X 光**：🆕 **早期常正常** → 進展 → **硬化**（重塑時吸收減少）；鄰近骨相對富血管 → 吸收增加 → 🆕 **緻密硬化區周圍透亮 = crescent sign**。
- 🆕 **MRI = 最敏感、可偵測早期**：骨水腫，進展時軟骨受累。
- 🆕 **Ficat classification**（X 光＋MRI）分期。

### 6.3 治療 🔄

- 🆕 **保守**：NSAID、類固醇注射、護具、活動調整；**非負重：結果尚可但需很長時間**；**patellar tendon bearing brace** 保護負重；**ESWT 證據有限**。
- 🆕 **Bone marrow aspirate：比 core decompression 延緩塌陷、降低塌陷頻率**。
- **早期 Ficat（保留關節）**：
  - **Core decompression**：延緩進展、改善功能；🆕 **但只適用非創傷性（少數病例）**。
  - 🆕 **血管化骨移植：遠端腓骨、cuboid、內外楔骨**；受限於**供區併發症、蒂活動度、難到達 dome 或體部**。
- **晚期（犧牲關節）**：
  - **單一關節退化、部分距骨仍存活 → 單獨 tibiotalar 或 subtalar 融合**。
  - **多數兩關節皆受累 → TTC arthrodesis＋bulk allograft**（**股骨頭** bulk、**腓骨 strut** allograft）。
  - 🔄 **bulk allograft 不癒合最高 32%，但保肢率高 → 成功可能與 X 光癒合無關（2022）**（OKU 14：約 1/5 不癒合）。
  - 🆕 **不加 allograft：脛骨直接融合到跟骨**；縮短 → 🆕 **TTC＋同時脛骨截骨（Ilizarov 導引）**。
  - ✅ **客製 3D 列印鈦籠**：越來越常取代 bulk allograft（結構支撐、支架、包容植骨）。
- **嚴重塌陷 → total talus arthroplasty**：整個距骨移除，以**對側距骨鏡像的 3D 列印客製植入物**置換。
  - 🆕 **2023：10 例陶瓷全距骨（特發性 ON）→ 痛、ADL、QOL 改善**。
  - 🆕 **2023 SR（161 例）：痛減、功能與 ROM 改善；併發症 9.3%**；長期結果待定。

## 7. 舟骨骨壞死 🆕

- 🆕 **兒童 2–9 歲 = Kohler disease；中年成人（女性較多）= Mueller-Weiss syndrome**；病因皆不完全清楚（創傷後、原發 ON、先天異常）。
- 🆕 **與短第一列或長第二列相關 → 舟骨外側不對稱壓迫 → 變扁或碎裂 → 變形**。
- 🆕 **變形型態多樣：cavovarus、planovalgus、後足 varus＋矛盾扁平足**（見 [Ch.53]({{< relref "/oku15/chapter_53.md" >}})）。
- 🆕 **晚期：舟骨外側塌陷 → AP 呈 comma-shaped navicular**；距骨頭外移、可撞 cuneiforms。
- X 光變化延遲＋變形多樣 → **常延遲診斷**。
- 🆕 **保守**：NSAID、活動與鞋子調整、orthoses；**柔軟變形 → 內側足弓支撐＋外側後足楔**；**僵硬變形 → midfoot rocker-bottom 鞋**。
- 🆕 **保守失敗相關：前足外展增加、X 光出現 TN OA**。
- 🆕 **手術無共識；依臨床症狀而非 X 光嚴重度**：
  - 早期保留關節：**減壓、清創、跟骨延長截骨**。
  - 犧牲關節：**TN 融合 vs 雙或三關節融合**。
  - 🆕 **目標：plantigrade、對位良好、保留內側柱長度**。
