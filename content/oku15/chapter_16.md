## 1. Primary vs Secondary Bone Healing（必背表）

| 特徵 | **Primary（direct）** | **Secondary（indirect）** |
|---|---|---|
| 穩定度 | **Absolute** | **Relative** |
| 微結構特徵 | **Cutting cone** | **Fracture callus** |
| 軟骨中介（endochondral） | **無** | **有** |
| 理想部位 | **Periarticular**（關節周圍） | **Diaphyseal**（metadiaphysis） |
| 復位 | 直接、解剖復位 | 間接 |
| 手術構造 | **Lag screw、compression plating** | **IM nail、bridge plate、external fixator** |
| 骨化方式 | Intramembranous（直接形成 lamellar bone，經 osteon 橋接） | Endochondral |

- 非手術治療（石膏）、外固定、髓內釘 → 都走 secondary healing；**自然界最常見**

### 1.1 Primary healing 兩型

| | **Contact healing** | **Gap healing** |
|---|---|---|
| 條件 | **Interfragmentary strain < 2%**、**gap < 0.01 mm** | Gap 太大無法 contact，但 **< 約 800 µm** |
| 機轉 | **Cutting cone**：前緣 osteoclast 鑽出縱向隧道 → osteoblast 填骨（類似正常 remodeling） | 再血管化 osteon 攜 osteoblast 前驅 → 斷端表面形成 **垂直於長軸的 lamellar bone**（力學弱） |
| 後續 | — | 約 **8 週**填滿 gap → 之後 cutting cone 沿新骨再隧道化重塑 |

> **Pearl**：gap healing 是 contact healing 的前驅；gap 內新骨方向**垂直骨長軸**，所以早期強度差。

## 2. Secondary Healing 三期

| 期 | 時間／事件 | 關鍵分子 |
|---|---|---|
| **Inflammation** | 血管破壞 → hematoma（callus 模板）；**急性發炎約第 1 天達高峰、7 天內消退** | **TNF-α、IL-1、IL-6**（先由 neutrophil、monocyte、macrophage，後由 osteoblast、chondrocyte 分泌）；招募骨髓與骨膜 MSC；TGF-β、BMP、**FGF-2** 引導分化 |
| **Repair** | MSC（**主要來自 periosteum**，其次骨髓、endosteum）→ chondrocyte → **type II collagen ＋ proteoglycan** 軟 callus；VEGF → 新生血管；chondrocyte 鈣顆粒移入 ECM → 礦化 → woven bone 取代 → hard callus | TGF-β superfamily、BMP-2、**VEGF** |
| **Remodeling** | osteoclast 分解 hard callus、osteoblast 生成 lamellar bone；恢復**皮質與髓腔連續** | RANKL 等 |

- **Granulation tissue 期能承受最大 strain 才失效**（耐 strain 最高的組織）
- 軟 callus：弱，但提供結構支撐、增加穩定

## 3. 機械負荷

- Wolff law：負荷調控骨轉換
- **適度軸向 interfragmentary loading → 促進 callus**；**tensile 或 shear stress → 阻礙癒合**
- 影響因子：負荷**大小、向量幾何、頻率** → 改變局部應力分布 → 影響 MSC 遷移、GF 表現、新生血管
- **Mechanotransduction**：機械訊號 → 細胞分子變化
- 臨床：股骨骨折（含**老年 distal femur fracture**）術後**承重的軸向負荷**可能改善 callus；早期承重、CPM、振動治療仍在研究

## 4. 微環境調控

- 骨折 → 血管破壞 → **暫時性 hypoxia** → periosteal cell、osteoblast、發炎細胞 **HIF-1↑ → VEGF** → 新生血管
- **發炎的 resolution 是主動過程**：IL-1／IL-6／TNF-α↓，**IL-4、IL-10、IL-13（pro-resolving）**↑；清除殘骸
  - **Resolution 失敗**（感染、手術、反覆創傷）→ 癒合不良
- **代謝物（新）**
  - **Lactate**：糖解終產物，早期發炎細胞分泌、累積於 hematoma → **穩定 HIF-1α**、招募 MSC、膠原沉積、促發炎消退
  - **Succinate**：大鼠癒合骨折中升高；促人類 MSC 成骨分化，**與 IL-1β 協同增強礦化**

## 5. Nonunion

- 定義仍有爭議；多數結合**臨床（疼痛、功能）＋放射學（骨連續）＋時間（6–9 個月）**
- 依 callus 有無與品質分類：

| 類型 | 特徵 | 根本問題 |
|---|---|---|
| **Atrophic** | 無骨連續、**無 callus** | **生物學**環境不良 |
| **Hypertrophic** | **大量不成熟 callus** | 生物學 OK（血供在），**穩定度不足** |
| **Pseudarthrosis** | — | — |
| **Septic** | 局部感染 → 慢性發炎 | 感染 |

> **Pearl**：Atrophic → 補生物學（植骨、BMP）；hypertrophic → 加強穩定（換固定）。

## 6. 異常癒合

### 6.1 Osteoporosis
- Callus 面積與強度↓、癒合延遲
- 機轉：**單位骨面積 osteocyte 數↓** → 骨小梁↓、皮質內孔隙↑；常粉碎、缺乏穩定；**骨髓脂肪↑ → osteoblast 前驅池↓**；常合併 **vit D 缺乏（nonunion 風險↑）**
- 低骨量不利解剖復位與 rigid fixation；mechanosensation 改變影響 primary 與 secondary 兩種策略
- **Three-in-one 策略（2022）**
  1. **受傷前**使用抗吸收藥物
  2. 適當**植骨材料**恢復骨量
  3. **生物活性因子**補充加速癒合

### 6.2 Diabetes
- 全球 >4.5 億人；type 1 與 type 2 骨折風險皆↑
- **核心機轉：慢性 hyperglycemia** → oxidative stress、hyperinflammation、**AGEs**、adipogenesis／osteogenesis 失衡、骨微血管異常、**RANK–RANKL 改變**
- 藥物對骨的作用（新）：

| 藥物 | 骨作用 |
|---|---|
| **Metformin** | 一線藥；活化 **BMP-4／Smad／Runx2** → MSC 成骨分化 |
| **GLP-1 receptor agonist** | 囓齒類：經 **Wnt／β-catenin** 增加骨量與強度；**抑制 RANKL 誘導的 osteoclast 分化** |
| **DPP-4 inhibitor** | 延長 insulin 半衰期；cohort 研究：**骨折風險較安慰劑低** |

- 作為**骨折癒合輔助**的大規模證據仍不足

### 6.3 感染與微生物
- **Septic nonunion**：傳統定義 **6–8 個月**停止癒合＋感染的臨床／檢驗／影像證據；開放性骨折風險高
- 引流竇道、傷口裂開、膿 → 明顯；**發炎指數較不特異**
- **推定無菌 nonunion 中 >10% 意外培養陽性** → 這些人**更常需要再次翻修**
- **Two-stage 仍是 gold standard**：第一階段清創根除感染 → 感染消除（發炎指數正常、培養陰性）後第二階段處理骨缺損
- **局部抗生素、抗生素塗層植入物 → 單階段翻修**成為可能（研究中）
- **Gut microbiome（新）**：影響全身發炎反應；2023：微生物代謝物影響特定 **T-cell 亞群**協助 callus；**probiotics 改善小鼠骨折癒合** → 抗生素對腸道菌的影響值得考量

### 6.4 Skeletal Metastases
- 骨是實體腫瘤最常轉移器官之一；**轉移骨病約佔癌症總醫療成本 20%**
- **Vicious cycle**：腫瘤 → osteoclast 溶骨 → 溶骨產物促腫瘤生長
- 免疫細胞（新）：**T cell 亞群與 dendritic cell 產生 RANKL**；**macrophage 可直接轉變為 osteoclast**
- **病理性骨折很少自行癒合** → 需**同時**治療腫瘤（化療／免疫治療、放療、ablation、切除／刮除）與穩定骨折
- 固定常加 **cement、植骨或額外鋼板**

## 7. 陷阱與易混淆

1. **Absolute stability → primary（cutting cone、無 callus）**；relative → secondary（callus）
2. Contact healing 條件：**strain < 2%、gap < 0.01 mm**；gap healing 上限約 **800 µm**
3. **Periarticular 要 primary（解剖復位）；diaphysis 用 secondary（不需解剖復位）**
4. **Hypertrophic nonunion = 不穩**，不是生物學差；**atrophic = 生物學差**
5. 修復期 MSC **主要來自 periosteum**
6. 急性發炎 **1 天高峰、7 天消退**；**resolution 失敗**也會造成不癒合
7. **Lactate 不只是廢物**：穩定 HIF-1α、促癒合
8. 推定無菌的 nonunion 也要送培養（>10% 陽性）
9. 病理性骨折**不會自己好**，需治療腫瘤＋強化固定
10. OKU 14 的吸菸、NSAID／COX-2、AFF、NF1、PTH 劑型本版未提，但仍是考點

## 8. Key Study Points（OKU 15）

- Primary 與 secondary healing 由機械、生化與代謝環境決定；手術處置的主要目標是控制骨折微環境以支持其中一種
- Osteoporosis、diabetes 會阻礙癒合；相關藥物作為輔助治療有前景，但需大型對照研究
- 調控宿主微生物體是新穎且有前景的策略
- 轉移性病理骨折對癒合有獨特挑戰，決定固定策略

## 9. Anki 候選題

1. Contact healing 的 strain 與 gap 條件？其微結構特徵是什麼？ → Strain < 2%、gap < 0.01 mm；cutting cone
2. Gap healing 中新形成的 lamellar bone 方向為何？為何力學弱？ → 垂直於骨長軸；排列不符受力方向，需之後 cutting cone 重塑
3. Hypertrophic 與 atrophic nonunion 的根本原因與處置方向？ → Hypertrophic：穩定不足 → 加強固定；atrophic：生物學差 → 植骨／生物製劑
4. 哪兩種代謝物在骨折微環境中促進癒合？各自機轉？ → Lactate（穩定 HIF-1α、招募 MSC、膠原沉積、促發炎消退）；succinate（促 MSC 成骨、與 IL-1β 協同礦化）
5. Metformin 與 GLP-1 RA 分別經由哪條路徑影響骨？ → Metformin：BMP-4／Smad／Runx2；GLP-1 RA：Wnt／β-catenin＋抑制 RANKL 誘導的 osteoclast 分化
6. 推定無菌 nonunion 的意外培養陽性率？臨床意義？ → >10%；這些病人更常需要再次翻修手術
7. Osteoporotic fracture 的 three-in-one 策略內容？ → 受傷前抗吸收藥物、植骨恢復骨量、生物活性因子加速癒合
